Studios ⚡

Write and run real code right here in your browser. Nothing to install, and nothing you type is sent anywhere.

Which one do I need?

  • Making a web page? 🌐 Web Studio
  • Learning Python? 🐍 Python Console
  • Learning PHP? 🐘 PHP Console
  • Learning SQL? 🗄️ SQL Sandbox
  • Security or networks? 🧪 Labs below

💻 Code studios

Type code, run it, see the result.

🌐

Web Studio

HTML · CSS · JavaScript · Grades 6–10

Write HTML, CSS and JavaScript in three tabs and watch the page change as you type.

  • Live preview and a console that shows console.log and errors
  • Starter templates: Welcome, Profile Card, Counter, Blank
  • On phones, a Code / Preview switch
  • Export your work as one .html file

Use it with: Projects (5 web projects open here) · HTML lessons

⚡ Open Web Studio
🐍

Python Console

Python 3.11 in the browser · Grades 8–10

Run real Python on this device. Good for loops, lists, dictionaries, functions and files.

  • Five ready-made examples: Welcome & Loop, Zakat Calculator, Grade Analyzer, Fibonacci, Word Counter
  • Real Python engine (Pyodide); it downloads once, which takes a moment on first use
  • input() does not work here: put values straight into your code
  • Errors are shown in the output so you can fix them

Use it with: Python lessons · Pantry & Zakat project

🐍 Open Python Console
🐘

PHP Console

PHP 8.3 in the browser · Grades 9–10

Write and run real PHP without a server. Try variables, decisions, loops, functions, arrays and classes.

  • Eight examples: variables, if/else, loops, functions, arrays, strings, classes, dates
  • Real PHP 8.3 engine: about 12 MB the first time, then saved by your browser
  • Ctrl+Enter runs your code; errors are shown clearly
  • Forms and databases need XAMPP: see the PHP and MySQL lessons

Use it with: 15 PHP exercises · PHP lessons

🐘 Open PHP Console
🗄️

SQL Sandbox

SQL · school library database · Grades 9–10

Ask questions of a real database in your browser: a school library with classes, students, books, loans and donations.

  • Runs real SQL (SQLite engine) and shows results as a table
  • Five tables to explore: classes, students, books, loans, donations
  • Change anything you like, then press Reset to start fresh
  • A few commands differ from MySQL; the lessons point them out

Use it with: 14 SQL exercises · MySQL lessons

🗄️ Open SQL Sandbox

Cyber Defense Studio

Cybersecurity · Grades 9–10

Five safe experiments that show how attacks work and how to stop them.

  • Password strength checker and passphrase maker
  • XSS: unsafe output next to safely escaped output
  • SQL injection: joined-up query next to a prepared statement
  • Phishing detective and the SHA-256 "avalanche" lab

Use it with: Cybersecurity lessons

🛡️ Open the lab
📡

Network Protocol Studio

Networks · Grades 9–10

See what really travels between your browser and a server, step by step.

  • HTTP request and response, shown as the raw text on the wire
  • DNS lookup, one step at a time
  • TCP three-way handshake and sending data
  • Subnet (CIDR) calculator

Use it with: Networks lessons

📡 Open the lab

Good to know

  • 💾 Keep your work. The studios do not save for you. Use Export .html in the Web Studio, or copy your code into a file before you close the tab.
  • 📶 First visit. The Python and PHP engines download once (PHP is about 12 MB), so the first start can take a little while on a slow connection.
  • 🧭 Also inside lessons. The HTML, CSS, JavaScript and Python tracks each have their own practice playground, linked from their lessons.
