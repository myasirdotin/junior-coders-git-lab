BEI Classroom Studio

A program we made for the teacher's own computer, for preparing lessons and teaching them on the classroom projector.

What it does

  • Build a lesson from sections and blocks, and keep your lessons in order by class, subject and chapter.
  • Teach it full screen in Classroom Mode, with a whiteboard you can draw on.
  • Works with no internet. Your lessons stay on your own computer.
  • Comes with a starter curriculum for Classes 4–7 and sample lessons to change.

The manners of teaching technology

Students pick up our manners before they pick up our code. These are the habits we try to keep in front of a class.

Start with the purpose

Before showing how, say who the skill will help: the school library, a family, a neighbour.

Their hands on the keyboard

When a student is stuck, ask a question that moves them one step. Do not take the mouse and fix it for them.

Respect the mistake

An error message is information, not a failure. Read it aloud together, and never laugh at a wrong answer.

Type slowly and explain

Write code in front of the class one line at a time, saying why. Let them see you make a mistake and fix it calmly.

Keep the screen clean

The projector shows only the lesson: wholesome examples, no other tabs, and nothing private such as marks or messages.

Say “I do not know”

When you are not sure, look it up with the class and name where the answer came from. That is Ṣidq in practice.

Make them think and create, not repeat

Bloom's levels of thinking are a ladder. Repeating what the teacher said is only the first step, so do not stop there: in every lesson, plan at least one task where students must decide something and make something of their own.

  1. Remember“What does this tag do?” A fair start, never the whole lesson.
  2. Understand“Explain this loop in your own words to your partner.”
  3. Apply“Use a loop to print our class timetable.”
  4. Analyse“Why does this version print one line too many?”
  5. Evaluate“Which of these two answers is clearer, and why?”
  6. Create“Design and build a small page for the class library.”

Marking code when students can use AI

An AI tool can write a working answer in seconds, so the finished code alone no longer shows what a student understands. These four checks do.

  1. Ask them to explain itThe student tells you, line by line, what the code does and why they wrote it that way.
  2. Change it in classGive working code and ask for one small change, such as turning a loop into a function, with no AI tool open.
  3. Find the mistakeGive code with one mistake in it and watch how the student looks for it, not only whether they find it.
  4. Check the AI (Tabayyun)Give an AI-written explanation that contains an error. The student finds the error and corrects it.

Teaching Technology as a Sacred Trust (Amānah)

An Amānah is something placed in your care that you will one day answer for. Our students are one, and so is the skill we teach them: the apps they build will hold other people's names, messages and records. Every lesson, example and project on Junior Coders follows the same four principles the students read on the home page; here is how to bring each one into class.

  • Amānah: trust

    For every form a student builds, ask what each field is for and who will see what is typed into it. Collecting less is part of the right answer.

  • Iḥsān: excellence

    Give credit for the parts no one sees: clear names, tidy indentation, labels and alt text. Work that runs but was done carelessly is not yet finished.

  • 'Ilm Nāfi': knowledge that benefits

    Let students build for someone real: the class library, a charity drive, a timetable for their family. A real user makes the work matter.

  • Ṣidq: truthfulness

    Students say where borrowed or AI-written code came from and can explain every line they hand in. The four checks above build on this.

None of our examples use interest calculators, gambling games or spyware; please keep the same rule in exercises you write yourself.

Seeing your students' progress

Junior Coders has no accounts, so there is no class dashboard. Each student's progress is saved only in the browser they used. What you can do today:

  • Ask a student to open the home page: “Your progress” shows one bar for each subject.
  • In a lesson, the lesson list shows a tick beside every lesson the student has marked complete.
  • The JavaScript lessons make a certificate on the student's device after all nine are done. It cannot be checked online, so sign it only after you have seen the work.
  • For marks, use the project rubric (out of 12) and the four checks above.
