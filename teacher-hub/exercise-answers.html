Exercise Answers

Answers for the practice files students copy from GitHub. The student copy has no answers in it.

Students get the files from junior-coders-exercises on GitHub (Code, then Download ZIP; no account needed). The same tasks check themselves on the site's exercise pages, where the answers are also in the page code, so treat this page as a marking aid, not a secret.

Jump to: HTML · CSS · JavaScript

HTML

01. The very first line Warm-up

Every web page starts with one line that tells the browser "this is a modern HTML page". Type the missing word.

Missing part: DOCTYPE

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Crescent School</title>
</head>

Why: <!DOCTYPE html> is not a tag that shows anything. It tells the browser to use the newest HTML rules. It always comes first, before <html>.

02. Where does the welcome go? Warm-up

Yusuf typed his welcome message inside <head>, and it does not appear on the page. Where should text that visitors read go?

C) Inside <body>

Why: <head> holds information about the page (its title, its character set). Everything people see on the page goes in <body>. The title only shows on the browser tab.

What text does the browser show on the page? Type it exactly as a visitor would see it.

Rule: 5 < 8 & 9 > 2

Why: &lt;, &gt; and &amp; are character entities: the browser shows <, > and &. The comment is not shown on the page. But anyone can still read it with View Source, so never put secrets in a comment.

Student files · Chapter 7

04. An important warning Warm-up

A science lab notice says "Wear safety goggles". Which tag tells the browser, and screen readers, that this text is important?

B) <strong>

Why: <strong> means "this is important", and a screen reader can say it with more force. <b> only makes text look bold, with no extra meaning.

05. Where does the link go? Warm-up

Which attribute holds the address that a link takes you to?

Missing part: href

<a href="https://example.org/library">Visit the city library</a>

Why: href stands for "hypertext reference": the address of the page to open. Without it, the words are not a working link.

Student files · Chapter 8

06. Words for a photo Warm-up

Which attribute gives a description of the image for people who cannot see it (and for when the image fails to load)?

Missing part: alt

<img src="garden.jpg" alt="Students planting tomato seedlings in the school garden">

Why: alt is the "alternative text". A screen reader reads it aloud to a blind visitor, and the browser shows it if the picture does not load. Describing pictures for everyone is part of being trustworthy with our pages (Amānah).

07. Build the page skeleton Apply

Put these lines in order to make a complete, correct web page for the school library.

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Crescent School Library</title>
</head>
<body>
    <h1>Welcome to the library</h1>
</body>
</html>

Why: The DOCTYPE comes first. Then <html> wraps everything. <head> (with the meta tag and title) closes before <body> opens. Each tag closes in the reverse order it opened, so </html> is last.

08. Crossed tags Apply

One line closes its tags in the wrong order, so they cross over each other. Tap that line.

Line 3 should be:

<p>Please return books by <strong>Thursday <em>afternoon</em></strong>.</p>

Why: Tags nest like boxes inside boxes: the last one opened is the first one closed. <em> opened inside <strong>, so </em> must come before </strong>.

09. Science fair notice Apply

This notice uses <h1> three times, and its sentences are not in paragraphs. Fix it so it has:

  • exactly one <h1>: Science Fair
  • two <h2> headings: When and What to bring
  • each sentence inside its own <p>, under the right heading

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">

Why: Headings are like the outline of a book: one title (<h1>), then section headings (<h2>). Screen readers and search engines use this outline to move around the page.

16. Science fair sign-up form Challenge

Build the sign-up form properly. It needs:

  • a text box with id="student-name" that is required
  • an email box with id="email" and type="email"
  • a dropdown <select id="grade"> with at least 3 options (Grade 6, 7, 8)
  • a <textarea id="project"> for the project idea
  • a <label for="..."> for every box, and a submit button
We only build the form here. Saving what students send is done later, with PHP.

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Science Fair Sign-up</title>
</head>
<body>
    <h1>Science Fair Sign-up</h1>
    <form>
        <label for="student-name">Your name</label>
        <input type="text" id="student-name" name="student-name" required>

        <label for="email">Email</label>
        <input type="email" id="email" name="email">

        <label for="grade">Grade</label>
        <select id="grade" name="grade">
            <option>Grade 6</option>
            <option>Grade 7</option>
            <option>Grade 8</option>
        </select>

        <label for="project">Project idea</label>
        <textarea id="project" name="project" rows="4"></textarea>

        <button type="submit">Sign up</button>
    </form>
</body>
</html>

Why: A label joined with for and id is read aloud by screen readers, and clicking it puts the cursor in the box. type="email" and required let the browser check the answers first. Collect only what you need: students' details are an Amānah (a trust).

01. Pick the notice by its class Warm-up

The paragraph has class="notice". Which character must start the selector so that it picks elements by their class?

Missing part: .

<p class="notice">The library closes at 3 pm today.</p>

/* CSS */
.notice {
    color: navy;
}

Why: A dot picks a class (.notice), a hash picks an id (#notice), and a plain name picks a tag (p).

04. The box model, inside out Warm-up

Every element is a box made of four layers. Put them in order, from the inside to the outside.

content (the text or picture)
padding (space inside the border)
border (the line around the box)

Why: Think of a framed picture: the picture (content), the white card around it (padding), the frame (border), and the space on the wall between frames (margin).

07. Which rule wins? Apply

Three rules give the same heading a colour. Which colour does the heading show? Type the colour word.

purple

Why: All three rules match, so the most specific one wins. An id scores 1-0-0, a class 0-1-0 and a tag 0-0-1. The id rule wins even though it is written first; "later wins" only decides between equal scores.

10. Exactly 300 pixels Apply

The science fair form box has width: 300px, but on screen it is 350px wide, because the padding and border are added on top. Add one line so the box is exactly 300px wide with its padding and border. Keep the padding and border.

<!DOCTYPE html>
<html>
<head>
<meta name="viewport" content="width=device-width, initial-scale=1">
<style>
.box {
    box-sizing: border-box;
    width: 300px;
    padding: 20px;
    border: 5px solid #1d4ed8;
}
</style>
</head>
<body>
<div class="box">Science Fair entry form</div>
</body>
</html>

Why: Normally width is only the content: 300 + 20 + 20 + 5 + 5 = 350px. With box-sizing: border-box the width includes the padding and border, so boxes are the size you wrote.

15. The longest name Challenge

Write longest(names) that returns the longest name in an array. If two are equally long, return the first one.

function longest(names) {
    let best = names[0];
    for (let i = 1; i < names.length; i++) {
        if (names[i].length > best.length) {
            best = names[i];
        }
    }
    return best;
}

Why: Keeping "the best so far" is how you find a maximum. Using > instead of >= decides which one wins a tie.
