MySQL Cheat Sheet

Every SQL query you need — from SELECT to JOINs, one page, always ready!

SQL Structure: COMMAND column/table condition — SQL keywords are written in UPPERCASE by convention. Statements end with a ;.
🗄️ Database Commands
CREATE DATABASE school;Create a new database
DROP DATABASE school;Delete a database (careful!)
USE school;Switch to a database
SHOW DATABASES;List all databases
SHOW TABLES;List all tables in current database
DESCRIBE students;Show columns of a table
DROP TABLE students;Delete a table completely
TRUNCATE TABLE students;Delete all rows but keep structure
🏗️ CREATE TABLE
INTWhole number (age, count)
VARCHAR(100)Text up to 100 characters
TEXTLong text (descriptions)
DECIMAL(8,2)Money: 8 digits, 2 decimal places
BOOLEANTrue (1) or False (0)
DATEDate: YYYY-MM-DD
DATETIMEDate + time combined
PRIMARY KEY (id)Unique identifier column
AUTO_INCREMENTID increases automatically
NOT NULLColumn cannot be empty
DEFAULT 'active'Use this value if none given
UNIQUENo duplicate values allowed
🔍 SELECT (Read)
SELECT * FROM students;Get all rows and columns
SELECT name, grade FROM students;Get specific columns only
SELECT DISTINCT grade FROM students;Remove duplicate values
WHERE grade = 'A'Filter rows by condition
WHERE age > 13Greater than filter
WHERE name LIKE 'A%'Names starting with A
WHERE name LIKE '%ali%'Names containing "ali"
WHERE grade IN ('A','B')Match any of these values
WHERE age BETWEEN 12 AND 15Range filter (inclusive)
WHERE email IS NULLNo email set
ORDER BY name ASCSort A→Z
ORDER BY grade DESCSort Z→A (descending)
LIMIT 10Only return 10 rows
LIMIT 10 OFFSET 20Skip 20, then get 10 (pagination)
✏️ INSERT / UPDATE / DELETE
INSERT
INSERT INTO students (name, grade) VALUES ('Ali', 'A');Add one row
INSERT INTO students VALUES (NULL, 'Sara', 'B', 14);All columns in order
UPDATE
UPDATE students SET grade='A' WHERE id=1;Change a value (always use WHERE!)
UPDATE students SET grade='A', age=15 WHERE name='Ali';Update multiple columns
DELETE
DELETE FROM students WHERE id=1;Delete specific row (always use WHERE!)
DELETE FROM students WHERE grade='F';Delete by condition
📊 Aggregate Functions
COUNT(*)Count all rows
COUNT(email)Count non-null values in email
SUM(price)Add up all prices
AVG(age)Average of all ages
MAX(grade)Highest value
MIN(age)Lowest value
GROUP BY gradeGroup rows by a column value
HAVING COUNT(*) > 5Filter groups (like WHERE for groups)
🔗 JOINs
INNER JOINOnly rows that match in BOTH tables
LEFT JOINAll rows from left table + matching right rows
RIGHT JOINAll rows from right table + matching left rows
Example — students with their classroom:
SELECT s.name, c.name AS class
FROM students s
INNER JOIN classrooms c ON s.class_id = c.id;
ON s.class_id = c.idThe matching condition between tables
table_alias.columnPrefix with alias to avoid ambiguity
🔑 Keys & Constraints
PRIMARY KEYUnique row identifier — only one per table
FOREIGN KEY (class_id) REFERENCES classrooms(id)Link to another table's primary key
UNIQUE (email)No two rows can have the same email
NOT NULLField must always have a value
CHECK (age >= 10)Value must satisfy a condition
ON DELETE CASCADEDelete child rows when parent is deleted
CREATE INDEX idx ON t(col);Speed up searches on a column
💡 Useful Extras
SELECT CONCAT(first,' ',last) AS full_nameJoin two columns into one
SELECT UPPER(name) FROM students;Uppercase text in query
SELECT LOWER(email) FROM students;Lowercase text
SELECT LENGTH(name) FROM students;Character count of value
SELECT NOW();Current date and time
SELECT CURDATE();Current date only
WHERE YEAR(dob) = 2010Filter by year of a date column
IFNULL(grade, 'N/A')Return 'N/A' if value is NULL

Safety Rule: Always use WHERE in UPDATE and DELETE statements — without it you'll update or delete every single row in the table!
