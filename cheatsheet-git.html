Class 8 & 9 Version Control

🐙 Git & GitHub Cheat Sheet

Every essential version control command — staging, branching, conflict resolution & remotes on one quick-reference page!

The 3 Git States: Working Tree (files you edit) ➔ Staging Area (git add) ➔ Local Repository (git commit) ➔ Remote (git push origin main).
⚙️ 1. Setup & Configuration
git --versionVerify Git installation
git config --global user.name "Name"Set your global username
git config --global user.email "name@srinagar.edu.in"Set your global email address
git config --global init.defaultBranch mainSet standard default branch name
git config --listList all active configurations
📁 2. Starting & Status
git initInitialize a new local repo in current folder
git clone <url>Download a remote repo onto your computer
git statusCheck modified, staged, and untracked files
git log --onelineView compact one-line commit history
git log --oneline --graph --allVisual ASCII branch tree of history
💾 3. Staging & Commits
git add index.htmlStage a single file for next commit
git add .Stage all modified and created files
git diffShow unstaged changes in working tree
git diff --stagedShow changes staged for next commit
git commit -m "feat: msg"Save staged changes as a snapshot
git commit --amend -m "new"Fix the message of the last commit
🌿 4. Branching & Switching
git branchList all local branches
git switch -c <branch-name>Create and jump into a new branch
git switch mainSwitch back to the main branch
git merge <feature-branch>Merge feature into current active branch
git branch -d <branch-name>Delete a merged local branch safely
git merge --abortAbort an active merge conflict cleanly
🛟 5. Undoing & Safety Nets
git restore <file>Discard unstaged edits in a file
git restore --staged <file>Unstage a file back to working tree
git stashShelve unfinished work temporarily
git stash popRestore shelved work back to files
git revert <commit-hash>Safely undo a published commit with a new commit
☁️ 6. Remotes & GitHub
git remote add origin <url>Link local repo to GitHub remote
git remote -vView configured remote URLs
git push -u origin mainFirst push and set upstream tracking
git pushPush local commits to remote repo
git fetch originDownload remote changes without merging
git pull origin mainFetch and merge remote commits into branch
Ethical & Clean Git Rule: Never commit passwords, API tokens, or .env files! Always add private configuration files to your .gitignore file before running git add ..
