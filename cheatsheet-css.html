🎨 CSS Cheat Sheet

Selectors, properties and layouts on one page, with what each line does.

Every CSS rule has the same shape: selector { property: value; }. For example h1 { color: navy; font-size: 2rem; }. Each line ends with a semicolon, and the rules live in a .css file linked from the page.
🎯 Selectors

A selector picks which elements a CSS rule styles. It can pick by tag name, by class or by id. A colon picks elements in a special state, like a link under the mouse, or in a position, like the first list item.

p { }Every <p> element
.box { }Every element with class="box"
#header { }The one element with id="header"
* { }Every element on the page
h1, p { }Both h1 and p elements
div p { }Any p inside a div, at any depth
div > p { }Only a p that is a direct child of a div
a:hover { }A link while the mouse is over it
input:focus { }The input you are typing in (chosen by click or Tab key)
li:first-child { }The first list item
li:last-child { }The last list item
li:nth-child(2) { }The 2nd item
p::before { content: "★ "; }Adds content before each p (needs content)
p::after { content: " ✓"; }Adds content after each p

🌈 Colors

CSS can write one colour in several ways: a name, a hex code, or amounts of red, green and blue. The a in rgba means alpha: how see-through it is. Pick colours with strong contrast so text is easy to read.

color: redText colour by name
color: #ff0000Text colour as a hex code
color: rgb(255, 0, 0)Red, green, blue amounts (0–255)
color: rgba(0, 0, 0, 0.5)Colour + see-through amount (0 = clear, 1 = solid)
color: hsl(240, 100%, 50%)Hue, saturation, lightness
background-color: lightblueBackground fill colour
background: linear-gradient(red, blue)Background that fades from red to blue
opacity: 0.5Makes the whole element half see-through

✏️ Text & Fonts

These properties control how words look: size, font, weight and spacing. Always give a fallback font in case the first one is missing. Sizes in rem grow when a reader zooms, which helps people who need bigger text.

font-size: 16pxText size in pixels
font-size: 1.2rem1.2 × the page's root text size (grows if the reader zooms)
font-family: Arial, sans-serifFont name, then a fallback
font-weight: boldBold text (or a number from 100 to 900)
font-style: italicItalic text
text-align: centerAlso left, right or justify
text-decoration: noneRemoves the underline from links
text-transform: uppercaseALL CAPS (also lowercase, capitalize)
line-height: 1.6Space between lines (1.5–1.6 is easy to read)
letter-spacing: 2pxSpace between letters
word-spacing: 4pxSpace between words
white-space: nowrapKeeps the text on one line

📦 Box Model

Every element is a box. Inside is the content, then padding, then the border, then the margin outside. Padding is space inside the border; margin pushes other boxes away. border-box makes widths much easier to plan.

width: 200pxElement width
height: 100pxElement height
max-width: 800pxNever wider than this
min-height: 100pxNever shorter than this
padding: 10pxSpace inside the border (all 4 sides)
padding: 10px 20pxTop and bottom 10px, left and right 20px
margin: 20pxSpace outside the border (all 4 sides)
margin: 0 autoCentres a block that has a width
border: 2px solid blackBorder: width, style, colour
border-radius: 10pxRounded corners
border-radius: 50%A circle (when width = height)
box-sizing: border-boxPadding and border fit inside the width
overflow: hiddenHides anything that does not fit
box-shadow: 4px 4px 10px grayShadow: right, down, blur, colour

👁️ Display

display decides how a box sits on the page. Block boxes start on a new line. Inline boxes flow inside a sentence. Flex and grid turn a box into a layout for the boxes inside it.

display: blockStarts on a new line and takes the full width
display: inlineSits inside a line of text; width is ignored
display: inline-blockSits in the line but takes width and height
display: flexLines children up in a row or column
display: gridPlaces children in rows and columns
display: noneHides the element and removes its space
visibility: hiddenInvisible but still takes up space
cursor: pointerShows a hand when the mouse is over it

💪 Flexbox

Flexbox lines up items in one direction: a row or a column. That direction is the main axis; the other one is the cross axis. justify-content works along the main axis. align-items works across it.

display: flexTurns on Flexbox for the children
flex-direction: rowChildren left to right (default); the main axis runs across
flex-direction: columnChildren top to bottom; the main axis runs down
justify-content: flex-startPacks children at the start of the main axis
justify-content: centerCentres children along the main axis
justify-content: space-betweenFirst and last at the edges, equal gaps between
justify-content: space-evenlyEqual gaps everywhere, edges too
align-items: centerCentres children on the cross axis (up-down in a row)
align-items: flex-startChildren sit at the start of the cross axis
align-items: stretchChildren stretch to fill the cross axis (default)
gap: 1remSpace between children
flex-wrap: wrapChildren move to a new line when there is no room
flex: 1The child grows to share the free space
order: 2Changes where a child appears

🔲 CSS Grid

Grid places items in rows and columns at the same time, like a chessboard. fr means one share of the free space. Grid lines are numbered from 1, so an item can stretch from one line to another.

display: gridTurns on Grid for the children
grid-template-columns: 1fr 1frTwo equal columns
grid-template-columns: repeat(3, 1fr)Three equal columns
grid-template-columns: 200px autoA fixed column + one that fills the rest
grid-template-rows: 100px autoRow heights
gap: 1remSpace between all cells
column-gap / row-gapSpace between columns only / rows only
grid-column: 1 / 3From line 1 to line 3: covers columns 1 and 2
grid-column: 1 / -1From the first line to the last: the full width
place-items: centerCentres every item in its cell

📍 Positioning

Positioning moves an element away from its normal place. Use it for small jobs, like a badge on a card or a menu that stays on screen. For whole page layouts, Flexbox and Grid are usually the better choice.

position: staticDefault: normal page flow
position: relativeNudged from its normal place; its space stays
position: absolutePlaced inside the nearest positioned ancestor
position: fixedStays in one place on the screen while scrolling
position: stickyScrolls normally, then sticks (needs top)
top / right / bottom / leftDistance from that side, e.g. top: 10px
z-index: 10Layer order on positioned elements (higher = on top)

✨ Animations

A transition makes a change happen smoothly, for example when the mouse moves over a button. transform moves, turns or resizes an element without pushing others. Keep motion short and gentle, and respect readers who turn motion off.

transition: color 0.3s easeChanges the colour smoothly instead of at once
transition: all 0.3s easeSmooths every change (simple but slower)
transform: rotate(45deg)Turns 45 degrees
transform: scale(1.1)Grows to 110%
transform: translateX(20px)Moves 20px right
transform: translateY(-10px)Moves 10px up
@keyframes spin { from { transform: rotate(0deg); } to { transform: rotate(360deg); } }Defines a named animation
animation: spin 2s linear infiniteRuns it: name, time, speed curve, repeats
@media (prefers-reduced-motion: reduce) { }Calmer styles for readers who turn motion off

📱 Responsive Design

A responsive page fits every screen, from a small phone to a wide laptop. Write the phone styles first. Then add @media rules that only work on wider screens. Sizes in percent or vw grow and shrink with the screen.

/* phone styles first, no @media */Mobile first: the base rules are for small screens
@media (min-width: 700px) { }Extra rules for screens 700px wide or more (tablets)
@media (min-width: 1024px) { }Extra rules for laptops and desktops
img { max-width: 100%; }Images shrink to fit their box
width: 100%Fills the parent's width
font-size: clamp(1rem, 4vw, 2rem)Grows with the screen, never below 1rem or above 2rem
vw / vh1% of the screen's width / height
em / %Relative to the parent's text size / the parent's size

🧹 Good Habits

Good habits keep your CSS tidy as it grows. Keep styles in one linked file and leave short comments. When two rules clash, the more specific one wins; if they tie, the later one wins. Variables let you change a colour in one place.

<link rel="stylesheet" href="style.css">Links the CSS file (in the HTML <head>)
/* main menu */A comment: a note that the browser ignores
#menu beats .menu beats navSpecificity: when rules clash, id beats class, class beats tag
p { color: red; } p { color: blue; }Same specificity: the later rule wins (blue)
:root { --brand: #7c3aed; }A custom property (a CSS variable) for a colour you reuse
color: var(--brand);Uses that variable
