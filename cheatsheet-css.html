CSS Cheat Sheet

Every property, selector, and trick — one page, always ready. Bookmark this!

CSS Rule Structure: selector { property: value; }  —  For example: h1 { color: red; font-size: 24px; }
🎯 Selectors
p { }All <p> elements
.box { }All elements with class="box"
#header { }The element with id="header"
* { }Every element on the page
h1, p { }Both h1 AND p elements
div p { }Any p inside a div (descendant)
div > p { }Direct child p of a div only
a:hover { }Link when mouse hovers over it
input:focus { }Input when it's clicked/active
li:first-child { }The first list item only
li:last-child { }The last list item only
li:nth-child(2) { }The 2nd item specifically
p::before { }Insert content before every <p>
p::after { }Insert content after every <p>
🎨 Colors
color: redText color using a named color
color: #ff0000Text color using hex code
color: rgb(255, 0, 0)Text color using RGB values
color: rgba(0,0,0, 0.5)Color + transparency (0=clear, 1=solid)
color: hsl(240, 100%, 50%)Hue, saturation, lightness
background-color: blueBackground fill color
background: linear-gradient(red, blue)Gradient from red to blue
opacity: 0.5Makes whole element 50% transparent
✏️ Text & Fonts
font-size: 16pxText size in pixels
font-size: 1.2remText size relative to page root (scalable)
font-family: Arial, sans-serifFont name (always add a fallback)
font-weight: boldBold text (or 100–900)
font-style: italicItalic text
text-align: centerCenter, left, right, or justify
text-decoration: noneRemove underline from links
text-transform: uppercaseALL CAPS / lowercase / Capitalize
line-height: 1.6Space between lines (1.6 is comfortable)
letter-spacing: 2pxSpace between letters
word-spacing: 4pxSpace between words
white-space: nowrapPrevents text from wrapping to next line
📦 Box Model
width: 200pxSet element width
height: 100pxSet element height
max-width: 800pxWon't grow wider than this
min-height: 100pxWon't shrink shorter than this
padding: 10pxInside space (all 4 sides)
padding: 10px 20pxTop/bottom=10px, left/right=20px
margin: 20pxOutside space (all 4 sides)
margin: 0 autoCenter a block element horizontally
border: 2px solid blackBorder: width style color
border-radius: 10pxRounded corners
border-radius: 50%Perfect circle (on a square)
box-sizing: border-boxPadding/border fit INSIDE the width
overflow: hiddenHide anything that doesn't fit
box-shadow: 4px 4px 10px grayDrop shadow (x, y, blur, color)
👁️ Display
display: blockFull-width, new line before & after
display: inlineFlows with surrounding text
display: inline-blockInline but you can set width/height
display: flexFlexbox layout — most powerful!
display: gridGrid layout — for complex designs
display: noneHides element AND removes its space
visibility: hiddenInvisible but still takes up space
cursor: pointerShows a hand cursor on hover
💪 Flexbox
display: flexTurn on Flexbox on a container
flex-direction: rowChildren go left to right (default)
flex-direction: columnChildren go top to bottom
justify-content: flex-startAlign horizontally: start
justify-content: centerCenter children horizontally
justify-content: space-betweenSpace children evenly
align-items: flex-startAlign vertically: top
align-items: centerCenter children vertically
align-items: stretchStretch children to full height
gap: 1remSpace between flex children
flex-wrap: wrapOverflow wraps to next line
flex: 1Child grows to fill available space
flex-grow: 1Child grows proportionally
order: 2Control the order of children
🔲 CSS Grid
display: gridTurn on Grid on a container
grid-template-columns: 1fr 1frTwo equal-width columns
grid-template-columns: repeat(3, 1fr)Three equal columns
grid-template-columns: 200px autoFixed + flexible columns
grid-template-rows: 100px autoDefine row heights
gap: 1remSpace between all grid cells
column-gap: 2remSpace between columns only
row-gap: 1remSpace between rows only
grid-column: 1 / 3Item spans columns 1 to 3
grid-column: 1 / -1Item spans the full width
place-items: centerCenter all items in their cells
📍 Positioning
position: staticDefault — normal document flow
position: relativeMove from its normal position
position: absolutePlace relative to nearest positioned parent
position: fixedStays fixed on screen when scrolling
position: stickyScrolls normally, then sticks
top: 10pxDistance from the top
right: 0Distance from the right
bottom: 0Distance from the bottom
left: 50%Distance from the left
z-index: 10Layer order (higher = on top)
✨ Animations
transition: all 0.3s easeSmooth animation when property changes
transition: color 0.2sAnimate only the color change
transform: rotate(45deg)Rotate 45 degrees
transform: scale(1.1)Grow to 110% size
transform: translateX(20px)Move right 20px
transform: translateY(-10px)Move up 10px
animation: spin 1s infiniteRun a named animation forever
@keyframes spin { 0% { ... } to { ... } }Define an animation sequence
📱 Responsive Design
@media (max-width: 768px) { }Styles for tablets & phones
@media (max-width: 480px) { }Styles for small phones only
@media (min-width: 1024px) { }Styles for desktop only
width: 100%Fill the full parent width
max-width: 100%Never overflow the container
font-size: clamp(1rem, 4vw, 2rem)Scale font between min and max
vw / vh% of viewport width / height
Pro Tip: Always write CSS for mobile first (small screens), then add @media (min-width: ...) rules for bigger screens. This is called Mobile-First Design!
