Start here: pick your path

Each path is a plan that tells you what to do each week, in order. Pick one, then press Start Week 1.

  • Never coded before? Take Beginner Explorer (Grades 6–7).
  • Want to make websites? Take Junior Web Developer (Grades 7–9).
  • Like puzzles and maths? Take Python & AI Pioneer (Grades 8–10).
  • Finished Web Developer? Go on to Full-Stack or Cyber & Network Defender.
Grades 6–7 · 4 weeks

Beginner Explorer

No experience needed. Start with files and folders, then the terminal, then your first web page.

  • Week 1: How a computer keeps files and folders
  • Week 2: The terminal: moving around without a mouse
  • Week 3: Your first HTML page
  • Week 4: Project: the start of your own portfolio
See the 4-week plan
Grades 7–9 · 8 weeks

Junior Web Developer

Make things you can see: build pages with HTML, style them with CSS, and make them respond with JavaScript.

  • Weeks 1–2: HTML structure and forms
  • Weeks 3–4: The CSS box model, Flexbox and Grid
  • Weeks 5–6: JavaScript: the page reacts to clicks
  • Weeks 7–8: Project: a community library page
See the 8-week plan
Grades 8–10 · 8 weeks

Python & AI Pioneer

Learn Python step by step, work with lists and files, then see how AI models work and how to check what they say (Amānah).

  • Weeks 1–3: Python basics, decisions and loops
  • Weeks 4–5: Lists, dictionaries and CSV files
  • Weeks 6–7: How AI models work, clear prompts, checking answers
  • Week 8: Project: a Zakat calculator that checks its own work
See the 8-week plan
Grades 9–10 · 10 weeks

Full-Stack

Go behind the page: PHP on the server, a MySQL database, and the Laravel framework.

  • Weeks 1–3: PHP and safe form handling
  • Weeks 4–5: MySQL tables and JOINs
  • Weeks 6–8: Laravel: routes, pages and models
  • Weeks 9–10: Project: a student aid portal with sign-in
See the 10-week plan
Grades 9–12 · 8 weeks

Cyber & Network Defender

How the internet carries data and how to keep it safe: network layers, addresses, encryption and the most common website weaknesses.

  • Weeks 1–2: Network layers, TCP/IP and subnets
  • Weeks 3–4: DNS, HTTP and encryption (TLS)
  • Weeks 5–6: Common website weaknesses and password hashing
  • Weeks 7–8: Project: a security check of your own site
See the 8-week plan
