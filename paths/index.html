Start here: pick your path

Each path is a plan that tells you what to do each week, in order. Pick one, then press Start Week 1.

  • Never coded before? Take Beginner Explorer (Grades 6–7).
  • Want to make websites? Take Junior Web Developer (Grades 7–9).
  • Like puzzles and maths? Take Python & AI Pioneer (Grades 8–10).
  • Finished Web Developer? Go on to Full-Stack or Cyber & Network Defender.

  • Week 1: Computer Anatomy & File Tree Hygiene
