Grades 6–7 • 4 Weeks

Beginner Explorer

Zero experience needed! Move from file systems and keyboard navigation to writing your very first HTML page and terminal commands.

  • Week 1: Computer Anatomy & File Tree Hygiene
  • Week 2: Command Line Navigation without a mouse
  • Week 3: Your First Semantic HTML5 Web Page
  • Week 4: Capstone: My Digital Portfolio Scaffold

Junior Web Developer

The visual creator's track: transform empty text editors into responsive, animated, and interactive web applications using HTML, CSS & JavaScript.

  • Weeks 1–2: Semantic HTML5 Structure & Forms
  • Weeks 3–4: CSS Box Model, Flexbox & CSS Grid
  • Weeks 5–6: JavaScript DOM & Interactive Event Handlers
  • Weeks 7–8: Capstone: Community Library Hub Web App

Python & AI Pioneer

Master programming logic, clean algorithmic problem-solving, tabular data processing, prompt engineering, and ethical AI stewardship (Amānah).

  • Weeks 1–3: Python Syntax, Conditionals & Loops
  • Weeks 4–5: Lists, Dictionaries & CSV File Processing
  • Weeks 6–7: LLM Mechanics, Prompt Engineering & Verification
  • Week 8: Capstone: Automated Zakat & Audit Pipeline

Grades 9–10 • 10 Weeks

Enterprise Full-Stack

Graduate to production engineering: relational database schemas with MySQL, server-side PHP processing, and Laravel MVC application deployment.

  • Weeks 1–3: Server-side PHP & Secure Form Processing
  • Weeks 4–5: MySQL Relational Normalization & JOINs
  • Weeks 6–8: Laravel 11 MVC, Blade & Eloquent ORM
  • Weeks 9–10: Capstone: Student Aid Portal with Authentication

Cyber & Network Defender

Defend the digital frontier: OSI 7-layer architecture, packet inspection, CIDR subnetting, HTTP/3 & TLS 1.3 encryption, and OWASP Top 10 web defenses.

  • Weeks 1–2: OSI 7 Layers, TCP/IP & CIDR Subnetting
  • Weeks 3–4: DNS Hierarchy, HTTP/3 & TLS 1.3 Cryptography
  • Weeks 5–6: OWASP Top 10 Defenses & Password Hashing
  • Weeks 7–8: Capstone: Ethical Security Audit & System Hardening
