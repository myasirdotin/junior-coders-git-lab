Grades 6–7 4-Week Guided Journey

The Beginner Explorer Pathway 🌱

Specially crafted for students with zero prior coding background. In 4 structured weeks, you will understand how computer hardware and files work, navigate without a mouse using terminal commands, write your very first HTML page, and save milestone snapshots with Git.

Week 1 • Foundations Est. 3 hours

Hardware, Files & Path Addresses

Learn how computers think! Explore CPU, RAM, and disk storage. Understand the file system tree, file extensions (`.html`, `.txt`), absolute and relative paths, and digital file organization hygiene.

Required Reading: Terminal Textbook Ch 1–2 Start Week 1 →
Week 2 • Terminal Power Est. 3.5 hours

Dual-Shell Command-Line Fluency

Ditch the mouse and control your computer like a real software developer! Practice `cd`, `mkdir`, `dir`/`ls`, `cat`/`type`, and build clean project scaffolds in seconds using Windows CMD and Git Bash.

Practice: CMD Cheatsheet Rosetta Stone Open CMD Sheet →
Week 3 • First Web Page Est. 4 hours

Your First Semantic HTML Web Page

The web is built on HTML! Create your first `index.html` document with headings, paragraphs, bullet lists, photos, and links. Test everything instantly inside our zero-setup Web Studio.

Studio: Web Studio Live Preview Launch Web Studio →
Week 4 • Capstone & Git Est. 4 hours

Git Snapshots & Milestone Portfolio

Complete your Bronze Capstone Project! Scaffold a clean directory tree, create your portfolio HTML skeleton, initialize a Git repository, make 3 distinct commits, and verify your clean log history.

Award: Bronze Portfolio Certificate (+100 XP) View Project Rubric →
