Grades 9–10 10-Week Guided Journey

Enterprise Full-Stack Engineering 🏗️🔥

The ultimate mastery path for senior junior coders. Build database-backed applications that solve community needs: server-side PHP processing, relational schema normalization, 100% prepared statements (PDO), and production Laravel MVC architecture.

Weeks 1–3 • PHP Server Scripting 10 hours total

Server Request Lifecycles & Input Sanitization

Master server-side programming: associative arrays, HTTP GET and POST form submissions, session handling (`$_SESSION`), input sanitization, and object-oriented PHP.

Textbook: PHP Book (29 Ch) Explore PHP Track →
Weeks 4–5 • MySQL Relational Databases 8 hours total

Relational Normalization & Safe Queries

Design normalized database tables: 1st, 2nd, and 3rd normal forms. Write multi-table relational `JOIN` queries, aggregations (`GROUP BY`), and eliminate SQLi with PDO prepared statements.

Studio: In-Browser SQL Sandbox Open SQL Sandbox →
Weeks 6–8 • Laravel 11 MVC 12 hours total

Modern MVC Framework Architecture

The industry standard for PHP web applications. Routing, Controllers, Blade components, database migrations, and Eloquent Active Record models.

Textbook: Laravel Book (24 Ch) Read Laravel Book →
Weeks 9–10 • Gold Capstone 10 hours total

Capstone: Student Aid & Scholarship Portal

Build and document a full-stack Laravel application with user registration, document submission, income tier verification, and staff approval dashboards.

Award: Gold Full-Stack Engineer Certificate (+400 XP) View Project Rubric →
