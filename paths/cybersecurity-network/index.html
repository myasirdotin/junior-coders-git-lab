Grades 9–12 8-Week Guided Journey

Cybersecurity & Network Defender Pathway 🛡️🌐

Protect digital systems and understand how the internet operates at the wire level. Master the 7 OSI layers, TCP/UDP sockets, CIDR subnetting, DNS resolution, TLS 1.3 cryptography, and OWASP Top 10 defensive web engineering under the ethical banner of digital stewardship (Amānah).

🚀 Start Week 1: Networks Module 1
Weeks 1–2 • Network Architecture 7 hours total

OSI 7 Layers, TCP/IP & CIDR Subnetting

Journey from physical copper cables and fiber optics to packets and frames. Master encapsulation, MAC addressing vs IP routing, IPv4 CIDR subnet calculations (/24, /28), and analyze TCP 3-way handshakes with diagnostic tools (ping, traceroute, netstat).

Textbook: Networks Book Ch 1–5 Start Networks Module 1 →
Weeks 3–4 • Web Protocols & Cryptography 8 hours total

DNS Hierarchy, HTTP/3 & TLS 1.3 Encryption

Discover how browser URLs resolve through recursive and authoritative DNS servers. Understand the evolution of the web from HTTP/1.1 to HTTP/3 QUIC over UDP. Master asymmetric key exchange (RSA/ECC), digital certificates, and how TLS 1.3 guarantees data confidentiality and integrity.

Textbook: Networks Book Ch 6–10 Read Networks Book →
Weeks 5–6 • Defensive Web Engineering 8 hours total

OWASP Top 10 Defenses & Password Cryptography

Learn how ethical defense engineers protect web systems. Replace SQL injection vulnerabilities with 100% prepared statements (PDO), prevent Cross-Site Scripting (XSS) with contextual output encoding, implement CSRF tokens, and derive slow, salted password hashes with Argon2id and bcrypt.

Textbook: Cybersecurity Book Ch 1–8 Start Cybersecurity Module 1 →
Weeks 7–8 • Capstone & Digital Hygiene 8 hours total

Capstone: Ethical Security Audit & System Hardening

Audit a vulnerable community charity web application. Identify OWASP flaws, implement PDO parameterization, configure robust HTTP security headers (CSP, HSTS, X-Content-Type-Options), configure secure session cookies, draft an executive security report, and formulate a 3-2-1 backup disaster plan.
