Grades 7–9 8-Week Guided Journey

The Junior Web Developer Pathway 🌐🎨

The structured journey from writing your first tag to architecting responsive, dynamic, and accessible web applications. Learn how HTML, CSS, and JavaScript collaborate seamlessly to create rich digital experiences.

Weeks 1–2 • HTML5 Skeleton 8 hours total

Semantic Structure, Accessibility & Forms

Master headers, navs, sections, articles, accessible forms with proper labels, table architectures, and SEO essentials. Build an ethical landing page for a community initiative.

Textbook: HTML Book (17 Ch) Explore HTML Lessons →
Weeks 3–4 • CSS3 Layouts 8 hours total

The Box Model, Flexbox & CSS Grid

Learn visual design that wows users! Master padding, margin, border math, 1D Flexbox alignment, 2D CSS Grid templates, device viewports, and mobile-first media queries.

Textbook: CSS Book (22 Ch) Open CSS Layout Sheet →
Weeks 5–6 • JavaScript Logic 8 hours total

DOM Manipulation & Interactive Events

Make your pages alive! Select DOM elements with `querySelector`, attach event listeners (`click`, `input`), toggle visual states, and manipulate arrays dynamically in JavaScript.

Textbook: JavaScript Book (26 Ch) Launch Web Studio ⚡
Weeks 7–8 • Silver Capstone 8 hours total

Capstone: Neighborhood Library Hub

Build and deploy a complete web application featuring search filtering, category tabs, and saved user preferences via `localStorage`. Host it live on GitHub Pages!

Award: Silver Web Developer Certificate (+250 XP) View Project Rubric →
