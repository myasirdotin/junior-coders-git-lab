How to use a textbook

  1. 📖 Read one chapter at a time. Tap Chapters to jump to any part.
  2. 🔊 Listen if you like. The Read button reads the chapter aloud. Microsoft Edge has the most natural voices.
  3. 🧪 Practise straight away. Each book has lessons or a cheat sheet with exercises.

The site remembers the last chapter you opened in each book, on this device only.
