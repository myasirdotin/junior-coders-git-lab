AI roadmap

A step-by-step guide from web basics to understanding how AI works, and how to use it with care.

The six steps

Take them in order. Each one builds on the one before it.

Step 1

Start with the web

HTML gives a page its structure, CSS its look, and JavaScript its behaviour. Websites and the apps that use AI are built on these three, so they come first.

How the web works HTML lesson 1

Step 2

Understand what AI is

AI is maths and data. It finds patterns in a very large number of examples, a little like the way you learned to recognise a cat by seeing many cats.

  • Algorithm: a set of instructions, like a recipe.
  • Model: an AI that has been trained on data.
  • Training: teaching the AI by showing it examples.
  • Input and output: you give data in, and the AI gives a result out.
Step 3

Use AI as a helper

With your teacher's or parent's permission, an AI tool can explain code, help you find a mistake, or suggest ideas. Things you can ask:

  • “Explain what this line of code does.”
  • “Why is my CSS not working? Here is my code: …”
  • “Give me five project ideas for a beginner in HTML.”

Ask it to explain, not to do your work for you. You should be able to explain every line you hand in.

Step 4

Build something that uses AI

A program can talk to an AI service through an API, which is a way for two programs to send each other messages. JavaScript does this with fetch().

  • A quiz page that makes new practice questions.
  • A simple helper that answers questions about your school library.
  • A page that describes a picture in words for people who cannot see it.

An API needs a secret key from an adult's account. Never put a key in a page you share: that is part of Amānah.

Step 5

Learn Python

Most AI work is written in Python. If you know JavaScript, the ideas are the same: variables, loops, functions and decisions.

Step 6

Machine learning basics

Machine learning is how an AI learns from data: you give it examples with the right answers, and it works out the pattern. For example, telling a healthy plant leaf from a diseased one in a photo.

  • Dataset: the collection of examples used for training.
  • Classification: sorting things into groups.
  • Regression: predicting a number.
  • Neural network: a kind of model loosely inspired by the brain.

How to write clear AI prompts

A prompt is what you type to an AI. A vague question gets a vague answer. Compare each pair.

Weak

“Fix my code.”

Strong

“I'm a beginner learning HTML. My image isn't showing on the page. Here is my code: <img src="photo.jpg">. What is wrong, and how do I fix it?”

Weak

“Teach me CSS.”

Strong

“I'm in Class 7 and have just learned the CSS box model. Give me one small exercise to practise padding and margin, with an example from real life.”

Weak

“Make a website.”

Strong

“Help me plan a simple HTML page for my school science project about black holes. I need a heading, two paragraphs, one image and a list of five facts. Explain each part so I can write it myself.”

Four parts of a clear prompt

  1. Who you are“I'm a Class 7 student learning CSS…”
  2. What you need“…I need to centre a box…”
  3. Your situation“…I'm using Flexbox…”
  4. The form of the answer“…Show me a short example and explain it.”

Be a careful AI user

Using AI well is part of Amānah. These are the rules a careful user tries to follow.

  • Check the answer. AI can be wrong. Check important facts in a reliable source.
  • Do not copy blindly. Understand the code before you use it. Learning is the goal.
  • Protect privacy. Never share your address, passwords or photos with an AI tool.
  • Give credit. If AI helped with your project, say so, and say how.
  • Think about others. Ask whether what you are making could harm anyone. Use technology to help people.
