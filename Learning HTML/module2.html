🧩 Tags vs. Elements (From Chapter 4)

In web development, people often say "tag" and "element" interchangeably, but as our textbook clarifies, there is a clear distinction:

  • HTML Tag: The angle brackets code alone, such as <p> or </p>.
  • HTML Element: The entire complete sandwich from the opening tag, through the content, to the closing tag!
<p>This whole package is the Element</p>

⚡ Normal vs. Void (Empty) Tags

Most tags enclose content, but some tags stand completely alone because they don't contain any text. These are called Void Tags:

  • <hr>: Creates a thematic horizontal dividing line.
  • <br>: Drops the text down to a new line without a paragraph gap.
  • <img>: Displays an image loaded from a source file.

Void tags never have a closing </tag>.

💎 How Attributes Work: name="value"

Attributes are modifier keywords placed inside the opening tag that provide extra configuration settings:

<p title="Hover over me for a tooltip!"> Hello! </p>

Common universal attributes include:

  • title: Displays a helpful hover tooltip when a user places their mouse cursor over the element.
  • lang: Tells search engines and screen readers what language the content is in (e.g. lang="en").
  • id & class: Label elements for CSS styling and scripting.

🏆 Official Book Practice Exercises

🟢 Level 1: Recall (Easy)

Where are attributes always written—in the opening tag, closing tag, or between the tags? Give an example of a void tag.

Show Answer
Attributes are always written inside the opening tag. Void tags include <br>, <hr>, and <img>.

🟡 Level 2: Application (Medium)

Identify the syntax error in this code: <p title=Secret Mission>Click me</p>. How should it be written?

Show Answer
Attribute values must always be enclosed in quotes: <p title="Secret Mission">Click me</p>. Without quotes, spaces break attribute parsing.
