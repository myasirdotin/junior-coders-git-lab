Your First HTML Mission

HTML tells the browser what belongs on a page, like headings, paragraphs, pictures, and lists.

  1. Type a tag: Write simple HTML in the editor.
  2. Watch it appear: Your page shows up in the preview box.
  3. Try ideas: Change words, add a heading, or make a list.
  4. Start over anytime: Use Clear All for a fresh page.

Quick Start Code

<p>Welcome to my first web page.</p>
