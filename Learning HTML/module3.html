📰 The 6 Heading Levels (h1 through h6)

HTML provides exactly 6 levels of section headings. Think of them like a newspaper or textbook table of contents:

  • <h1>: The Main Title of the entire page. Only use ONE per page for optimal SEO!
  • <h2>: Major Section Topics (e.g. Chapter titles or main sections).
  • <h3>: Sub-sections inside an <h2>.
  • <h4>, <h5>, <h6>: Minor subheadings for deep outlines.

✅ Professional Best Practice

Always maintain a logical step-by-step ladder: <h1> $\rightarrow$ <h2> $\rightarrow$ <h3>. Never skip from <h1> straight to <h4>!

❌ Accessibility Mistake

Never choose a heading tag just because you want text to look big or small. Use CSS for font sizes, and headings for structural meaning.

📝 Paragraphs vs Line Breaks

When you press Enter in an HTML file, the browser ignores multiple spaces and newlines (called whitespace collapse). To create clean spacing:

  • <p>...</p>: Groups a block of sentences and automatically adds comfortable margin above and below.
  • <br>: Breaks to the next line immediately (ideal for poems, postal addresses, or lyrics).
  • <hr>: Draws a horizontal thematic divider line between major topic changes.

🏆 Official Book Practice Exercises

🟢 Level 1: Recall (Easy)

How many heading levels exist in HTML? Which heading tag represents the largest and most important title?

Show Answer
There are 6 heading levels (<h1> to <h6>). <h1> is the highest, most important title.

🟡 Level 2: Application (Medium)

Why should you have only ONE <h1> on a standard web page, even if the browser lets you put multiple?

Show Answer
Search engines (Google) use <h1> to index what the whole page is about. Screen readers for blind users also announce the <h1> first. Multiple <h1> tags create confusion.
