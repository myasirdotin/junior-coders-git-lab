💡 HTML Tips & Reminders

📝 Before You Start Coding

🔔 Always Plan First

  • Sketch your layout on paper before coding
  • List all the features you need to implement
  • Check existing files to understand the structure
  • Decide which tags you'll need (headings, lists, images, etc.)

📁 File Organization

  • Keep HTML, CSS, and JS files separate
  • Use descriptive file names (e.g., contact-form.html not page1.html)
  • Store images in an images/ folder
  • Create a css/ folder for stylesheets
  • Create a js/ folder for JavaScript files

🏷️ HTML Reminders

✅ Do This

  • Always close your tags: <html>...</html>
  • Use lowercase tags: <div> not <DIV>
  • Add alt text to images for accessibility
  • Use semantic tags: <header>, <nav>, <main>
  • Always include DOCTYPE declaration
  • Set lang attribute: <html lang="en">
  • Add meta charset: <meta charset="UTF-8">
  • Add viewport meta for mobile: <meta name="viewport" content="width=device-width">

❌ Avoid This

  • Don't skip the DOCTYPE declaration
  • Don't use deprecated tags like <font> or <center>
  • Don't forget the lang attribute in the html tag
  • Don't put block elements inside inline elements
  • Don't use uppercase tags
  • Don't forget to close your tags
  • Don't leave alt text empty for important images

🔗 Links & Navigation

✅ Good Links

<a href="about.html" 
   title="Learn about us">
    About Us
</a>

<a href="https://google.com" 
   target="_blank" 
   rel="noopener noreferrer">
    Google
</a>

❌ Bad Links

<a href="about.html">Click here</a>

<a href="page.html" 
   class="btn">Click</a>

🖼️ Images & Media

📋 Image Checklist

  • ✅ Always add alt attribute for accessibility
  • ✅ Specify width and height to prevent layout shift
  • ✅ Use appropriate image formats (JPG for photos, PNG for graphics)
  • ✅ Use relative paths: images/logo.png
  • ❌ Don't use absolute paths like C:\images\logo.png
  • ❌ Don't forget alt text for decorative images (use empty alt)

📋 Forms Best Practices

<form action="/submit" method="POST">
    <label for="name">Name:</label>
    <input type="text" id="name" 
           name="name" required>
    
    <label for="email">Email:</label>
    <input type="email" id="email" 
           name="email" required>
    
    <button type="submit">Submit</button>
</form>
  • Always use <label> with for attribute
  • Use appropriate type attributes (email, tel, number)
  • Add required attribute for mandatory fields

🔍 Debugging Checklist

When Your HTML Doesn't Work:

  1. Check for typos in tag names and attributes
  2. Verify all tags are properly closed
  3. Check if CSS file is linked correctly
  4. Check if JS file is linked correctly
  5. Open browser Developer Tools (F12) for errors
  6. Check file paths are correct
  7. Verify file names are spelled correctly
  8. Validate HTML at W3C Validator

🎯 Common Mistakes to Avoid

⚠️ Top 10 HTML Mistakes

  1. Missing DOCTYPE - Always start with <!DOCTYPE html>
  2. Forgetting to close tags - Every tag must be closed
  3. Wrong tag nesting - Close inner tags before outer
  4. Missing alt text - Always describe images
  5. Using deprecated tags - Avoid <font>, <center>, <u>
  6. Not using semantic tags - Use <header>, <nav>, <main>
  7. Forgetting quotes - Always quote attribute values
  8. Using inline styles - Use external CSS instead
  9. Not validating code - Use W3C validator
  10. Case sensitivity - Use lowercase for tags and attributes
