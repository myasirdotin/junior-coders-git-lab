✅ Good vs ❌ Bad Coding Practices

📋 HTML Best Practices

✅ Good Practice

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" 
      content="width=device-width">
    <title>My Page</title>
</head>

Always declare DOCTYPE, lang attribute, charset, and viewport meta tag.

❌ Bad Practice

<html>
<head>
    <title>My Page</title>
</head>

Missing DOCTYPE, language, charset, and viewport settings.

🎨 CSS Best Practices

✅ Good Practice

/* Use meaningful class names */
.button-primary {
    background-color: #3498db;
    padding: 10px 20px;
}

/* Use CSS variables */
:root {
    --primary-color: #3498db;
}

Use descriptive class names and CSS variables for consistency.

❌ Bad Practice

/* Vague names */
.b1 { background: blue; }

/* Inline styles */
<div style="background: blue">

Avoid vague class names and inline styles.

⚙️ JavaScript Best Practices

✅ Good Practice

// Use const/let instead of var
const API_URL = 'https://api.example.com';
let userName = 'John';

// Use === instead of ==
if (userName === 'John') { }

// Add comments
// Get user data from API
async function getUser() { }

Use const/let, strict equality, and add helpful comments.

❌ Bad Practice

// Using var (function scope)
var API_URL = 'https://api.example.com';

// Using == (type coercion)
if (userName == 'John') { }

// No comments
function x() { }

Avoid var, loose equality, and unclear naming.

🏷️ Image & Media Best Practices

✅ Good Practice

<img src="photo.jpg" 
     alt="A cat sitting on a couch"
     width="800" height="600">

<video controls>
    <source src="video.mp4" 
            type="video/mp4">
</video>

Always add alt text, specify dimensions, and provide fallback content.

❌ Bad Practice

<img src="photo.jpg">

<video src="video.mp4">

Missing alt text, dimensions, and accessibility features.

🔗 Link Best Practices

✅ Good Practice

<a href="about.html" 
   title="Learn about us">
    About Us
</a>

<a href="https://google.com" 
   target="_blank" 
   rel="noopener noreferrer">
    Google
</a>

Add title attributes and use rel="noopener noreferrer" for external links.

❌ Bad Practice

<a href="about.html">Click here</a>

<a href="https://google.com" 
   target="_blank">
    Google
</a>

Avoid vague link text and missing security attributes.

💡 Pro Tips

  • Always validate your HTML at W3C Validator
  • Use semantic HTML elements (<header>, <nav>, <main>, <footer>)
  • Keep your code organized with proper indentation
  • Use comments to explain complex code sections
  • Test your website in multiple browsers
