📊 Table Anatomy (From Chapter 10)

HTML tables arrange data neatly into horizontal rows and vertical columns. They are constructed using 4 fundamental tags:

  • <table>: The outer boundary wrapping the entire tabular grid.
  • <tr>: Table Row (horizontal strip from left to right).
  • <th>: Table Header cell (bold, centered column or row labels).
  • <td>: Table Data cell (standard information cells).

🧱 Semantic Table Sections & Spans

🏛️ Semantic Architecture

  • <thead>: Encloses the header rows at the top.
  • <tbody>: Holds the main body rows.
  • <tfoot>: Holds summary or total calculation rows.

📐 Merging Cells with Spans

  • colspan="2": Stretches a single cell horizontally across 2 columns.
  • rowspan="2": Stretches a single cell vertically down across 2 rows.

🏆 Official Book Practice Exercises

🟢 Level 1: Recall (Easy)

What is the difference between <th> and <td>? What does <tr> stand for?

Show Answer
<tr> stands for Table Row. <th> creates bold, centered header labels, while <td> creates regular table data cells.

🟡 Level 2: Application (Medium)

How do you make a single table cell stretch across 3 columns to display a full-width announcement?

Show Answer
Add the colspan="3" attribute to the <th> or <td> tag: <td colspan="3">Special Announcement</td>.
