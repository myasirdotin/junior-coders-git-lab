What is HTML?

HTML stands for HyperText Markup Language. Imagine you are building a house. HTML is the wood and bricks. It doesn't have paint yet, but it holds everything together!

The Magic Tags

We use "Tags" to tell the computer what to show. Most tags come in pairs like a sandwich:

<tag> Hello! </tag>
