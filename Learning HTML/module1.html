What is HTML?

HTML stands for HyperText Markup Language. It's not a "coding" language like the ones used for robots; it's a way to label content so a browser knows what is a heading, a paragraph, or a cat picture!

<h1>Welcome to my world!</h1>
<p>This is a paragraph.</p>
