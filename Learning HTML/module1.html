Reading Material

What Is HTML?

HTML stands for HyperText Markup Language. That sounds big, but the idea is simple: HTML uses labels called tags to help the browser understand what each piece of content is.

Key Point: HTML tags are like name labels. They tell the browser, "this is a heading," "this is a paragraph," or "this is an image."

1.1 The Skeleton of a Web Page

Most web pages start with the same basic structure:

<!DOCTYPE html> <html> <head> <title>My First Page</title> </head> <body> <h1>My First Heading</h1> <p>My first paragraph.</p> </body> </html>
Best Practice: Start with <!DOCTYPE html> so the browser knows to use modern HTML rules.
