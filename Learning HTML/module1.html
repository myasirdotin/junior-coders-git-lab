Module 1: Meet HTML

30 minutes | Week 1

Learning Objectives

  • Understand what HTML does on a web page
  • Learn the main parts of a simple HTML document
  • Know what <!DOCTYPE html> is for
  • Spot common tags and what job each one does

Overview

HTML is the language we use to tell a browser what belongs on a page. It helps us add titles, paragraphs, pictures, buttons, and more in an organized way.

Reading Material

What Is HTML?

HTML stands for HyperText Markup Language. That sounds big, but the idea is simple: HTML uses labels called tags to help the browser understand what each piece of content is.

Key Point: HTML tags are like name labels. They tell the browser, "this is a heading," "this is a paragraph," or "this is an image."

1.1 The Skeleton of a Web Page

Most web pages start with the same basic structure:

<!DOCTYPE html> <html> <head> <title>My First Page</title> </head> <body> <h1>My First Heading</h1> <p>My first paragraph.</p> </body> </html>
Best Practice: Start with <!DOCTYPE html> so the browser knows to use modern HTML rules.

1.2 What Each Part Does

<!DOCTYPE html> says, "This page uses HTML5."

<html> wraps the whole web page.

<head> holds page information such as the title and links to styles.

<title> chooses the words shown on the browser tab.

<body> contains the part people actually see on the screen.

Common Mistake: Do not put visible page content inside <head>. Headings, paragraphs, and images belong in <body>.

1.3 Tags Work in Pairs

Most HTML elements have an opening tag and a closing tag. The content goes in the middle:

<p>This is a paragraph.</p> <h1>This is a heading</h1> <!-- Some tags do not need a closing tag --> <img src="image.jpg" alt="Description"> <br> <hr>

Watch Out For These

  • Forgetting to close a tag - Most tags need an ending tag like </p>.
  • Mixing up tag order - Tags should be neatly nested, like putting smaller boxes inside bigger boxes.
  • Leaving out the doctype - Without <!DOCTYPE html>, your page may not behave the way you expect.
  • Trying to memorize everything - You do not need to know every tag today. Start small and practice often.
