🌍 What is HTML? (From the Textbook)

HTML stands for HyperText Markup Language. It is the code that powers 100% of websites across the globe. As explained in Chapter 1 of the textbook:

  • HyperText: Text that links to other documents with a click.
  • Markup: Using special labels called tags to mark up plain words into headings, paragraphs, images, and links.
  • Language: The computer code that browsers (like Chrome, Edge, and Safari) understand.

🏗️ Think Like an Architect

HTML is the wood, bricks, and steel skeleton of a house. CSS provides the paint and furniture. JavaScript powers the lights and elevators!

⚠️ Common Beginner Mistake

HTML is NOT a programming language with math algorithms—it is a structural markup language designed to organize content cleanly.

🏷️ The Tag Sandwich Rule

Most HTML elements work like a sandwich with an opening tag, the content, and a closing tag with a forward slash (/):

<h1> Hello World! </h1>

The forward slash / signals to the browser: "Stop styling this text as a heading now!"

🦴 The Essential HTML5 Boilerplate

Every single web page ever created requires 5 core structural parts:

  1. <!DOCTYPE html>: Announces modern HTML5 rendering standard.
  2. <html lang="en">: The root envelope enclosing all page code.
  3. <head>: The backstage "brain" holding settings, charset, and the tab title.
  4. <title>: The title text displayed on the browser tab.
  5. <body>: The visible stage where all your headings, paragraphs, and media live!

🏆 Official Book Practice Exercises

🟢 Level 1: Recall (Easy)

What file extension must every HTML document be saved with? Where does the text inside <title> appear?

Show Answer
Every HTML file must end with .html (e.g. index.html). The <title> text appears on the browser's top tab, not in the main page body.

🟡 Level 2: Application (Medium)

Why is my new webpage.html a bad choice for a file name? What is the standard convention recommended by developers?

Show Answer
File names with spaces can break on web servers (converting to my%20new%20webpage.html). Always use lowercase letters, no spaces, and hyphens: index.html or my-new-webpage.html.
