The Form Wrapper

A form is like an envelope. You put all your inputs inside the <form> tag so they can be sent together!

Inputs & Labels

Every input needs a Label so users know what to type. We connect them using the for attribute and the id.

  • <input type="text">: For names or messages.
  • <input type="password">: For secret codes!
  • <button type="submit">: To send the form.
