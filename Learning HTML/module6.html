Embedding Images

A website without pictures is boring! We use the <img> tag to show images. It doesn't have a closing tag!

<img src="pic.jpg" alt="Description">

The Alt Text Power

The alt attribute is super important. It describes the picture for people who cannot see it (like screen readers). It also shows up if the picture breaks!

Mission: Add a Photo

Try adding an image and give it a cool description in the alt attribute!
