🖼️ The <img> Element & Mandatory Attributes

The <img> tag is a void (empty) tag. It does not enclose words; instead, it points to an image file using two critical attributes:

<img src="astronaut.jpg" alt="Astronaut floating near Saturn rings" width="400">
  • src (Source): The file path or web URL where the image is stored.
  • alt (Alternative Text): Descriptive words explaining the image. If the connection fails or if a visually impaired student uses a screen reader, the browser reads this exact text!

🎨 Image Formats & Dimensions

📸 Modern Formats

  • WebP: Google's ultra-light modern format with tiny file sizes.
  • PNG: Sharp graphics with transparent backgrounds.
  • SVG: Vector graphics that stay crystal-clear at any zoom level!
  • JPG / JPEG: Best for rich photographs with many natural colors.

📐 Width & Height

Always specify width or height so the browser reserves layout space before the image downloads, preventing jarring screen jumps (CLS layout shift).

🖱️ Clickable Image Banners

Wrap any <img> inside an anchor tag <a> to transform the picture into a clickable button or portal:

<a href="https://nasa.gov" target="_blank">
  <img src="logo.png" alt="NASA Logo" width="120">
</a>

🏆 Official Book Practice Exercises

🟢 Level 1: Recall (Easy)

Which two attributes are strictly necessary for every standard image tag? Is <img> a container or void tag?

Show Answer
src (the image file path) and alt (the description for accessibility). <img> is a void tag (no closing tag).

🟡 Level 2: Application (Medium)

Why is writing alt="photo" or alt="image.jpg" considered bad practice by professional web developers?

Show Answer
The alt attribute must describe the actual subject and context of the image so a blind student using a screen reader understands what is on the screen (e.g. alt="Brown puppy running on green grass").
