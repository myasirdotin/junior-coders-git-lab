HTML Word Helper

Simple definitions for the HTML words you will see in class.

A
<a> (Anchor)
The tag that creates a link you can click.
alt Attribute
Words that describe an image so people and screen readers know what it shows.
Attribute
Extra details inside an opening tag, like a source, type, or label.
B
<body>
The part of the page that people can actually see.
<br>
A line break tag. It moves the next text onto a new line.
D
<div>
A general box used to group content together.
<!DOCTYPE html>
A line at the top of the file that tells the browser to use modern HTML.
E
Element
A piece of HTML made from a tag and its content.
H
<head>
The hidden setup area of the page, where things like the title go.
<h1> to <h6>
Heading tags that create titles from biggest to smallest.
<html>
The outer wrapper for the whole HTML page.
I
<img>
The tag used to place a picture on a page.
<input>
A tag that creates a box, button, or other form control.
L
<label>
A helpful name for a form input, such as "Name" or "Email."
<li>
One item inside a list.
M
<main>
The main content area of a page.
N
<nav>
A section that holds navigation links or menus.
P
<p>
A paragraph tag for regular text.
S
Semantic HTML
Using tags that explain what the content means, like <header> or <main>.
<section>
A clear section of a page, usually with its own heading.
<strong>
A tag that marks text as very important. It usually looks bold.
T
<table>
A tag used to build a table with rows and columns.
<title>
The words shown on the browser tab.
U
<ul>
A bulleted list.
