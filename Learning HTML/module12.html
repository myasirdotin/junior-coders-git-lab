🧠 What is Semantic HTML? (From Chapter 12)

Every HTML tag is either semantic or generic. A semantic tag carries meaning about the content it wraps — not just its visual position on screen.

❌ Non-Semantic (Generic)

Using <div> and <span> for everything. Browsers, Google, and screen readers cannot understand what the content is — they just see boxes.

<div id="header">...</div>
<div id="nav">...</div>
<div id="main">...</div>
<div id="footer">...</div>

✅ Semantic (Meaningful)

Using purpose-built HTML5 tags. Google boosts SEO rankings, screen readers announce "Navigation region" or "Main content" — everyone wins.

<header>...</header>
<nav>...</nav>
<main>...</main>
<footer>...</footer>

🗺️ The 7 Semantic Landmark Tags (Ch 12)

These are the building blocks of every modern, professional web page:

Tag Its Meaning Real Example
<header> Site or section's top area Logo, site name, top navigation
<nav> Navigation links group Home / About / Contact links
<main> Primary, unique page content The article, product, or lesson content
<article> Self-contained, standalone piece News article, blog post, product card
<section> Thematic group within content Chapters, feature groups, team bios
<aside> Related but secondary content Sidebar, related links, quick facts box
<footer> Bottom area of site or section Copyright, social links, contact info

💡 Rule: There should be only ONE <main> per page. All others can be used multiple times.

🏆 Official Book Practice Exercises

🟢 Level 1: Recall (Easy)

A page has one <header>, one <nav>, and two <section> elements. Is this valid semantic HTML? How many <main> elements are allowed per page?

Show Answer
Yes — the structure is valid. <section>, <article>, <aside> and others can appear multiple times. However, there must be exactly ONE <main> element per page. It marks the primary, unique content and must not appear inside <header>, <footer>, <nav>, or <aside>.

🟡 Level 2: Application — Div Soup Rescue (Medium)

A junior developer wrote this non-semantic code. Rewrite it using the correct semantic tags:

<div class="top">
  <div class="logo">My School</div>
  <div class="menu">
    <a href="#">Home</a>
    <a href="#">About</a>
  </div>
</div>
<div class="content">
  <div class="article">Today's News...</div>
</div>
<div class="bottom">© 2026</div>
Show Answer
<header> replaces div.top — no class needed!
<nav> replaces div.menu — it wraps the navigation links.
<main> replaces div.content — for the primary page content.
<article> replaces div.article — the news item is self-contained.
<footer> replaces div.bottom — for the copyright info.
