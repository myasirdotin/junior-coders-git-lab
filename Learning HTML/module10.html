Naming Elements!

Learn how to give tags names with Class and ID. 🏷️

Why give names?

Imagine you have 10 paragraphs, but you only want ONE to be red. How do you tell the computer which one? We use names!

  • Class: Like a team name. Many elements can have the same class. (e.g., class="team-red")
  • ID: Like a social security number or your name. It MUST be unique! (e.g., id="main-title")

Mission: Name Your Tags

Try giving a unique ID to the heading and a shared class to the paragraphs!
