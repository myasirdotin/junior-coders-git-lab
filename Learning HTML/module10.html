🏷️ Class vs ID: The Golden Rules

🔄 class="..." (Reusable Grouping)

  • Can be shared by multiple elements across the entire page.
  • An element can have multiple classes separated by a space: class="btn btn-primary active".
  • Targeted in CSS using a dot: .btn { ... }.

🆔 id="..." (Unique Fingerprint)

  • Must be strictly unique—only ONE element per page can carry that ID.
  • Used for in-page jump bookmarks (#header) and JavaScript scripting.
  • Targeted in CSS using a hash: #header { ... }.

📋 Standard Naming Conventions

To avoid bugs across different web browsers, follow these 4 developer rules:

  1. Use all lowercase letters (e.g. hero-banner).
  2. Use hyphens to separate words (kebab-case): product-card.
  3. Never use spaces inside class or ID names (spaces mean multiple classes!).
  4. Never begin a class or ID name with a number.

🏆 Official Book Practice Exercises

🟢 Level 1: Recall (Easy)

Can two elements on the same page share the same id? Can two elements share the same class?

Show Answer
No, an id must be 100% unique per page. Yes, multiple elements can share the same class.

🟡 Level 2: Application (Medium)

How do you assign three different classes (e.g. btn, large, primary) to a single button tag?

Show Answer
Separate each class name with a space inside the quotes: <button class="btn large primary">Click Me</button>.
