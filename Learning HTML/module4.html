📖 Reading Material

4.1 Unordered Lists

Unordered lists display items with bullet points:

  • Apples
  • Bananas
  • Oranges

4.2 Ordered Lists

Ordered lists display items with numbers:

  1. First step
  2. Second step
  3. Third step

4.3 Description Lists

Description lists are used for terms and their descriptions:

HTML
HyperText Markup Language
CSS
Cascading Style Sheets

4.4 Nested Lists

Lists can be nested inside each other:

  • Fruits
    • Apples
    • Bananas
  • Vegetables
    • Carrots
    • Broccoli

Common Mistakes

  • Forgetting to close
  • tags - Each list item needs proper closing.
  • Using lists for layout - Lists are for content, not page layout. Use CSS for layout.
  • Incorrect nesting - Nested lists must be inside an
  • element.
