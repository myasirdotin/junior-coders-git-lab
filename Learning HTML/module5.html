🔗 The Anchor Tag (<a>) and href

Without links, the internet would just be isolated documents on separate islands. The anchor tag (<a>) bridges pages together using the href (Hypertext REFerence) attribute:

<a href="https://wikipedia.org" target="_blank"> Visit Wikipedia </a>

🗺️ Relative vs. Absolute URLs

🌐 Absolute URLs (External)

Includes the full web address with protocol: https://google.com. Used whenever linking to a completely different external website.

📁 Relative URLs (Internal)

Points to files in the same project: about.html or ../index.html. Used for moving between pages on your own website.

🎯 New Tabs & In-Page Bookmarks

  • target="_blank": Instructs the browser to open the clicked link in a brand new tab, keeping your original page open.
  • In-Page Jump Links: Point href="#contact" to immediately smooth-scroll down to any element on the same page with id="contact"!
  • href="mailto:help@example.com": Automatically launches the user's default email app.

🏆 Official Book Practice Exercises

🟢 Level 1: Recall (Easy)

What does href stand for? Which attribute opens a link in a new tab?

Show Answer
href stands for Hypertext REFerence. target="_blank" tells the browser to open the destination page in a new window or tab.

🟡 Level 2: Application (Medium)

How do you create an in-page link that jumps directly down to a section titled "Back to Top" or "Contact Us"?

Show Answer
Give the target section an id (e.g. <h2 id="contact">), and point the link's href to that ID prefixed with a hash symbol: <a href="#contact">Jump to Contact</a>.
