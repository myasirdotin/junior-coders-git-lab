Common Mistakes

  • Using tables for page layout - Tables are for tabular data, not layout. Use CSS for layout.
  • Forgetting headers - Always use for column headers for accessibility.
  • Inconsistent columns - Each row should have the same number of columns (unless using colspan/rowspan).
