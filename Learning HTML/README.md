## 🚀 Getting Started

1. **Open the course**: Open `learninghtml.html` in your browser to see the full syllabus.
2. **Start learning**: Click on any module to begin the lesson.
3. **Practice**: Use the `index.html` playground to write and preview HTML code.
4. **Test yourself**: Complete the exercises in `exercises.html`.
5. **Reference**: Use `glossary.html` to look up HTML terms.

### Prerequisites

- A modern web browser (Chrome, Firefox, Safari, Edge)
- No server required - all files work locally
- Basic computer skills

## 📝 How to Use

### Using the Playground

1. Open `index.html` in your browser
2. Type HTML code in the editor on the right
3. Click "Render Preview" or press `Ctrl+Enter`
4. See your HTML rendered in real-time

### Following the Course

1. Start with `learninghtml.html` to see the syllabus
2. Click on Module 1 to begin

## 🔧 Troubleshooting

### Common Issues

**Q: My progress isn't saving**
- A: Make sure your browser allows localStorage. Check browser settings > Privacy > Site Data.
- Try clearing your browser cache and reloading the page.

**Q: The dark mode toggle isn't working**
- A: Ensure JavaScript is enabled in your browser settings.
- Try using a different modern browser.

**Q: The code preview shows errors**
- A: Check your HTML syntax. Make sure all tags are properly closed.
- Some HTML features may require an internet connection (e.g., external images).

**Q: The page looks broken or unstyled**
- A: Make sure all files are in the correct folder structure.
- Clear your browser cache (Ctrl+Shift+Delete) and reload.

**Q: I want to reset my progress**
- A: Open browser developer console (F12) and run: `localStorage.clear()`
- Then reload the page.
