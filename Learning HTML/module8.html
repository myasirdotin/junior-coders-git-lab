📋 The Three Flavors of HTML Lists (From Chapter 9)

HTML provides three distinct ways to group related items:

  • <ul>: Unordered List. Uses circular bullets. The order of items does not matter (e.g. groceries, features).
  • <ol>: Ordered List. Uses numbers or letters (1, 2, 3 or A, B, C). Order is strictly sequential (e.g. recipe steps, top 10 rankings).
  • <li>: List Item. The individual elements living inside <ul> or <ol>.

🌳 Nested Lists & Custom Numbering

🔢 Ordered List Attributes

  • type="A": Uppercase letters (A, B, C...)
  • type="i": Lowercase Roman numerals (i, ii, iii...)
  • start="5": Begins counting at number 5!

📂 Nested Multi-Level Lists

Place an entire new <ul> or <ol> inside an existing <li> element to build tree outlines and dropdown menus!

🏆 Official Book Practice Exercises

🟢 Level 1: Recall (Easy)

When should you use <ul> versus <ol>? Can a <li> exist by itself without a list container?

Show Answer
Use <ol> when sequence matters (numbered steps). Use <ul> when items are unordered (bullets). A <li> must ALWAYS live inside a parent <ul> or <ol>.

🟡 Level 2: Application (Medium)

How do you create a numbered list that starts counting from number 10 instead of number 1?

Show Answer
Use the start attribute: <ol start="10"><li>Tenth Item</li></ol>.
