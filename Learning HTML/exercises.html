🎯 3-Level Progressive Coding System

HTML Practice Missions

Every mission offers 3 steps: Follow (learn syntax), Modify (experiment & tweak), and Create (solve independently in Code Lab).

📖 Open HTML Textbook 📚 HTML Course Modules

🌱 Phase 1: Structure & Typography (Chapters 3–6)

Mission 1: First Page & Headings

Ch 3–5

Master document structure, heading ranks (h1–h6), and clean paragraph breaks.

  • Valid HTML5 boilerplate with title
  • Exactly one <h1> for the main headline
  • Section subheadings with <h2>
  • At least two readable paragraphs
💡 Need a Hint?
Remember to place all visible text inside the <body> container, not the <head>!

Mission 2: Poster Text Formatting

Ch 6

Style text semantically without CSS using bold importance, stress, highlights, and math formulas.

  • Highlight key words with <mark>
  • Mark critical warnings with <strong>
  • Include formulas using <sub> & <sup>
  • Show price updates using <del> & <ins>
💡 Need a Hint?
Use H<sub>2</sub>O for water and E=mc<sup>2</sup> for energy!

Mission 3: Links & Accessible Media

Ch 7–8

Connect to the web with hyperlinks and embed responsive images with screen-reader alt text.

  • External link with target="_blank"
  • Internal link navigating on the page
  • Images with descriptive alt attributes
  • Fixed width attribute to prevent layout shifts
💡 Need a Hint?
Always add rel="noopener noreferrer" when using target="_blank" for safety!

🛠️ Phase 2: Data Grids & User Input (Chapters 9–11)

Mission 4: Lists & Multi-Tier Outlines

Ch 9

Group information logically using bulleted unordered lists, numbered recipes, and nested sub-items.

  • Unordered list <ul> for ingredients
  • Ordered list <ol> for sequence steps
  • At least one nested list inside an item
  • No orphan text directly inside <ul>
💡 Need a Hint?
To nest a list, put the inner <ul> completely INSIDE an <li>...</li>!

Mission 5: Weekly Timetable & Tables

Ch 10

Display structured school schedules with header cells, rows, and multi-column cell merges.

  • Table with header row using <th>
  • At least 4 content rows with <td>
  • Use colspan to span lunch across columns
  • Border attribute or styled table frame
💡 Need a Hint?
Remember: <tr> creates a row, while <th> and <td> create individual cells!

Mission 6: Interactive Signup Form

Ch 11

Build an accessible user registration form with connected labels, validation, and submission controls.

  • Inputs with matching <label for="...">
  • Text, email, radio buttons, and checkbox
  • Multi-line message with <textarea>
  • Validation with required attribute
💡 Need a Hint?
The for attribute in the label MUST match the id of the input so clicking the text selects the box!

🏛️ Phase 3: Semantic Layouts & Living Project (Chapters 12 & 30)

Mission 7: Semantic Page Layout

Ch 12

Assemble a clean, SEO-friendly page using HTML5 structural landmarks instead of generic div containers.

  • Semantic <header> and <nav>
  • Central <main> with 2 <section>s
  • Sidebar info using <aside>
  • Footer with copyright notice
💡 Need a Hint?
A page should only have ONE <main> element to identify primary content for search engines!

Mission 8: Living Project (Personal Hub)

Ch 30 Capstone

Combine all HTML skills into your Personal Explorer Website: bio, media, timetable, and contact form.

  • Full semantic architecture
  • Profile picture & hobbies photo gallery
  • Weekly class timetable grid
  • Interactive contact message form
💡 Need a Hint?
This is your living project! You will style this exact page with CSS in the next module!
