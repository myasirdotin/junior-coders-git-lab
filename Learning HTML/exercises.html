HTML Practice Missions

Pick a mini project, load the starter code, and build something fun.

Starter Missions

Mission 1: My First Page

Create a simple page about yourself, your pet, or your favorite game.

Requirements:

  • Add the main page structure
  • Write a page title
  • Add one big heading
  • Write at least one paragraph

Mission 2: Poster Words

Make a page that uses headings and styled text like a mini poster.

Requirements:

  • Use <h1>, <h2>, and <h3>
  • Make one word bold with <strong>
  • Make one word emphasized with <em>
  • Highlight one word with <mark>

Mission 3: Favorite Things

Create a page with links and pictures that show what you like.

Requirements:

  • Add at least 2 links
  • Add at least 1 image with alt text
  • Write a short caption under the image

Builder Missions

Mission 4: Top 5 List

Make lists for favorite snacks, games, books, or weekend plans.

Requirements:

  • Create one unordered list
  • Create one ordered list
  • Add at least 4 items to each list
  • Try a nested list if you want a challenge

Mission 5: Weekly Schedule

Build a table for classes, chores, clubs, or game time.

Requirements:

  • Add a table with headings
  • Use at least 3 columns
  • Use at least 4 rows of information
  • Add a title above the table

Mission 6: Club Signup

Create a fun form for a reading club, art club, or coding club.

Requirements:

  • Add inputs for name and favorite activity
  • Add labels for each input
  • Add a message box
  • Add a submit button

Big Challenge Missions

Mission 7: Semantic Page

Create a complete page with clear sections like a real website.

Requirements:

  • Use <header>, <nav>, <main>, and <footer>
  • Add one section for your main idea
  • Add one extra section or sidebar
  • Give each area a heading

Mission 8: Super Fan Page

Make a full page about a hobby, animal, sport, or favorite character.

Requirements:

  • Use a full semantic structure
  • Add at least 2 content sections
  • Add a list, image, or table somewhere on the page
  • Finish with a footer message
