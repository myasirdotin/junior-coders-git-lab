Invisible Boxes!

Understanding Block vs. Inline elements. 📦

The Secret Boxes

Every element in HTML is actually a **box**! There are two main types:

  • Block Elements: These take up the whole line. Like <h1>, <p>, and <div>.
  • Inline Elements: These only take as much space as they need. Like <span>, <strong>, and <a>.

The "Div" Container

The <div> tag is one of the most used tags. It's a big, invisible block box used to group things together!
