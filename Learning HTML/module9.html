📦 The Two Display Behaviors of HTML

Every element in HTML belongs to one of two fundamental display categories:

🧱 Block-Level Elements

  • Always starts on a brand new line.
  • Automatically stretches 100% full width across the available screen.
  • Examples: <div>, <h1>–<h6>, <p>, <ul>, <section>.

🏷️ Inline Elements

  • Does NOT start on a new line; it sits right inside the sentence flow.
  • Only takes up as much width as its actual content text.
  • Examples: <span>, <a>, <strong>, <em>, <mark>.

🎁 <div> and <span>: The Universal Containers

When you want to bundle multiple elements together into a card or highlight a single phrase inside a paragraph:

  • <div> (Division): The universal block-level container. Used to wrap cards, sidebars, and hero banners.
  • <span>: The universal inline container. Used to wrap a few words so you can color or style them with CSS without breaking the sentence!

🏆 Official Book Practice Exercises

🟢 Level 1: Recall (Easy)

Name three block elements and three inline elements. Which tag starts on a new line: <div> or <span>?

Show Answer
Block elements: <div>, <p>, <h1>. Inline elements: <span>, <a>, <strong>. <div> starts on a new line.

🟡 Level 2: Application (Medium)

If you want to change the color of just one word inside a heading without breaking the heading into two lines, should you wrap it in a <div> or a <span>?

Show Answer
Use a <span>. Wrapping in a <div> would force the word onto its own line because divs are block-level!
