Grades 9–10

📡 Networks Cheat Sheet

Layers, addresses, ports, the web's protocols and the commands to test them on one page, in the same order as the Networks textbook.

Key idea: every message travels in layers. An IP address finds the computer, a port finds the program on it, TCP or UDP carries the data, and TLS keeps it private. On Windows PowerShell type curl.exe, not curl.
🧱 OSI & TCP/IP Models
7 ApplicationPrograms' protocols: HTTP, DNS, SSH, SMTP
6 PresentationFormat, compress, encrypt: JSON, gzip, JPEG (TLS is often placed here)
5 SessionOpening and keeping a conversation going
4 TransportTCP (segments, reliable) or UDP (datagrams, fast)
3 NetworkIP packets, routers, ICMP
2 Data LinkEthernet and Wi-Fi frames, MAC addresses
1 PhysicalBits as signals: cable, fibre, radio
TCP/IP: 4 layersApplication (7–5), Transport, Internet, Link (2–1)

🏠 Special IP Addresses
10.0.0.0/8Private: 10.0.0.0 – 10.255.255.255
172.16.0.0/12Private: 172.16.0.0 – 172.31.255.255
192.168.0.0/16Private: 192.168.0.0 – 192.168.255.255 (most homes)
NATThe router shares one public address with many private ones
127.0.0.1Loopback: this computer (localhost)
0.0.0.0"Every address on this computer" when a server listens; 0.0.0.0/0 is the default route
2001:db8::1IPv6: 128 bits in hex; :: stands for a run of zeros
::1IPv6 loopback, like 127.0.0.1
🤝 TCP, TLS 1.3 & HTTP/3
SYN → SYN-ACK → ACKTCP 3-way handshake before any data is sent
TCP vs UDPTCP resends and orders; UDP is faster, no resending
TLS 1.3 handshakeOne round trip (1-RTT) after the TCP handshake
ECDHE key exchangeBoth sides make the same secret; it is never sent
Certificate + CAA trusted Certificate Authority proves the site's identity
AES / ChaCha20Fast shared-key encryption for the actual data
HTTP/1.1 → HTTP/2HTTP/2 sends many streams over one TCP connection
HTTP/3 = QUIC on UDPTLS 1.3 built in; a lost packet delays only its own stream
🏷️ HTTP Methods
GETRead a resource (safe, idempotent)
POSTCreate something or start an action (not idempotent)
PUTReplace a resource completely (idempotent)
PATCHChange some fields of a resource
DELETERemove a resource (idempotent)
HEADLike GET, but headers only, no body
OPTIONSAsk what is allowed (CORS preflight)
🚦 HTTP Status Codes
200 OKSuccess, with a body
201 CreatedA new resource was made (often after POST)
204 No ContentSuccess, no body (often after DELETE)
301 Moved PermanentlyThe page has a new address for good
304 Not ModifiedYour cached copy is still fine; no body sent
400 Bad RequestThe request was malformed or invalid
401 UnauthorizedNot logged in (no valid login sent)
403 ForbiddenLogged in, but not allowed
404 Not FoundNothing at this address
429 Too Many RequestsToo many requests in a short time (rate limit)
500 Internal Server ErrorThe server's code failed
502 Bad GatewayA proxy got a bad answer from the server behind it
📖 DNS Records
AName → IPv4 address (32 bits)
AAAAName → IPv6 address (128 bits)
CNAMEAlias: this name points to another name
MXMail server for the domain, with a priority number
TXTText: SPF, DKIM, proof of site ownership
NSThe name servers in charge of the domain
PTRReverse lookup: IP address → name
TTL (a field, not a type)Seconds a resolver may keep any record in its cache
🛡️ Security & CORS Headers
Strict-Transport-SecurityHSTS: browser must use HTTPS for this site
Content-Security-PolicyCSP: which sources may load scripts and media
Access-Control-Allow-OriginCORS: which other sites may read the response
Set-Cookie: …; HttpOnlyJavaScript cannot read the cookie
Set-Cookie: …; SecureCookie is sent over HTTPS only
Cache-Control: max-age=3600May be cached for 3600 seconds
💻 Diagnostic Commands
ping example.orgIs it reachable? How long is the round trip?
tracert (Windows) / tracerouteList each router on the way
nslookup example.orgAsk DNS for a name's records
ipconfig (Windows) / ip addrYour IP address, subnet mask and gateway
netstat -anoOpen connections, listening ports and process IDs
curl.exe -i https://example.orgFetch a page and show the status line and headers
curl.exe -i -X POST http://localhost:8000/books.php -H "Content-Type: application/json" --data-binary "@book.json"Send JSON from a file with POST
Amānah (trust) rule: test only your own computer, your own server and sites you are allowed to test. Never send passwords over plain HTTP, and treat every shared Wi-Fi as public.
