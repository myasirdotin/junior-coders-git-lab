🏷️ HTTP Methods (Verbs)
GETRetrieve resource (Safe & Idempotent)
POSTCreate resource / trigger action (Not Idempotent)
PUTReplace resource completely (Idempotent)
PATCHPartial update of resource fields
DELETERemove resource (Idempotent)
OPTIONSCORS Preflight: check permitted methods/headers
HEADSame as GET, returns headers only (no body)
🚦 Common HTTP Status Codes
200 OKSuccessful request with body
201 CreatedResource successfully created (POST)
204 No ContentAction succeeded, no response body (DELETE)
301 MovedPermanent redirect (updates SEO index)
304 Not ModifiedCached version is valid, zero body transferred
400 Bad RequestMalformed syntax or invalid input
401 UnauthorizedAuthentication missing (login required)
403 ForbiddenAuthenticated, but lacks permission
404 Not FoundRequested URL does not exist
429 Rate LimitToo Many Requests sent in short window
500 Server ErrorCrash or unhandled exception in backend code
502 Bad GatewayReverse proxy received invalid upstream reply
📖 DNS Record Types
ADomain name ➔ IPv4 Address (32-bit)
AAAADomain name ➔ IPv6 Address (128-bit)
CNAMECanonical Name: alias pointing to another domain
MXMail Exchanger server and delivery priority
TXTText strings (SPF, DKIM, site ownership verification)
NSAuthoritative Name Server for the zone
PTRPointer record for Reverse DNS (IP ➔ Hostname)
TTLTime To Live: seconds resolvers may cache record
🛡️ Security & CORS Headers
Strict-Transport-SecurityHSTS: Enforce HTTPS connections exclusively
Access-Control-Allow-OriginCORS: Designate permitted client origins
Content-Security-PolicyCSP: Restrict authorized sources for scripts/media
Set-Cookie: HttpOnlyBlocks JavaScript from reading session cookies
Set-Cookie: SecureEnsures cookies only transmit over encrypted TLS
Cache-Control: max-ageSpecifies caching duration in seconds
💻 CLI Diagnostic Commands
ping <host>Test ICMP reachability and round-trip latency
tracert / tracerouteTrace every intermediate router hop across the globe
curl -i <url>Fetch URL and display status line & HTTP headers
curl -X POST -d '{}'Send custom HTTP POST request with JSON payload
nslookup <domain>Query DNS records from local or remote resolver
netstat -anoList active network sockets, PIDs, and listening ports
ipconfig / ip addrDisplay local IP addresses, subnet masks, and gateway
