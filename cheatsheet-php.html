PHP Cheat Sheet

The server-side language powering 80% of the web — your complete reference!

PHP Structure: All PHP code lives inside <?php ... ?> tags. Every statement ends with a semicolon. Variables start with $. Save files as .php.
🐘 Basics & Output
<?php ... ?>Open and close PHP block
echo "Hello";Print text to the page
print "Hi";Like echo but returns 1
// commentSingle-line comment
/* block */Multi-line comment
phpinfo();Show PHP server info
var_dump($x);Show type + value (debugging)
print_r($arr);Print array in readable format
📦 Variables & Types
$name = "Yasir";String variable
$age = 14;Integer variable
$price = 9.99;Float (decimal) variable
$active = true;Boolean variable
$nothing = null;Null (no value)
gettype($x)Returns type as a string
is_string($x)Check if variable is a string
is_int($x)Check if integer
(int) $xCast (convert) to integer
(string) $xCast to string
✏️ String Functions
"Hi " . $nameConcatenate strings with dot
strlen($s)Length of a string
strtolower($s)Convert to lowercase
strtoupper($s)Convert to UPPERCASE
ucfirst($s)Capitalise first letter
trim($s)Remove leading/trailing spaces
str_replace("a","b",$s)Replace text inside string
strpos($s,"php")Find position of substring
substr($s, 0, 5)Extract part of a string
explode(",", $s)Split string into array
implode(", ", $arr)Join array into string
nl2br($s)Convert newlines to <br>
📚 Arrays
$a = [1, 2, 3];Indexed array
$a = ["k" => "v"];Associative array (key => value)
$a[] = 4;Append to array
count($a)Number of elements
array_push($a, 5)Add to end
array_pop($a)Remove from end
array_shift($a)Remove from beginning
array_unshift($a, 0)Add to beginning
sort($a)Sort ascending
rsort($a)Sort descending
in_array(3, $a)Check if value exists
array_merge($a, $b)Merge two arrays
array_slice($a, 1, 3)Extract a portion
🔀 Control Flow
if ($x > 0) { }Conditional block
elseif ($x === 0) { }Else-if branch
else { }Default/fallback branch
switch ($x) { case 1: }Multi-branch switch
for ($i=0; $i<5; $i++) { }For loop
while ($x > 0) { }While loop
do { } while ($x);Do-while (runs at least once)
foreach ($arr as $v) { }Loop over array values
foreach ($a as $k => $v) { }Loop over key & value
break;Exit the loop early
continue;Skip to the next iteration
⚙️ Functions
function greet($name) { }Define a function
return $value;Return a value from a function
function add($a, $b = 0) { }Default parameter value
function (...$args) { }Variadic — accept any number of args
$fn = function() { };Anonymous function
$fn = fn($x) => $x * 2;Arrow function (PHP 7.4+)
array_map($fn, $arr)Apply function to every element
array_filter($arr, $fn)Keep elements where fn returns true
🏛️ OOP — Classes
class Dog { }Define a class
public $name;Public property
private $secret;Private property (class only)
__construct($x) { }Constructor — runs on new
$obj = new Dog();Create an object
$obj->nameAccess object property
$obj->bark()Call object method
$this->nameAccess own property inside class
class Pup extends Dog { }Child class inherits parent
parent::__construct()Call parent constructor
static $count = 0;Shared across all objects
Dog::$countAccess static property
📬 Forms & Superglobals
$_GET['name']Data from URL query string
$_POST['email']Data from HTML form (POST)
$_REQUEST['x']GET + POST combined
$_SESSION['user']Session data (persists across pages)
$_COOKIE['theme']Cookie stored in browser
$_FILES['photo']Uploaded file data
$_SERVER['REQUEST_METHOD']GET or POST?
isset($var)Check if variable exists & not null
empty($var)Check if empty, 0, null, or ""
htmlspecialchars($x)Escape output — prevent XSS!
🔢 Math & Dates
abs($x)Absolute value
round($x, 2)Round to 2 decimal places
ceil($x)Round up to integer
floor($x)Round down to integer
rand(1, 100)Random integer between 1 and 100
max(1, 5, 3)Largest value
min(1, 5, 3)Smallest value
pow(2, 8)2 to the power of 8 = 256
date("Y-m-d")Current date: 2026-05-28
time()Current Unix timestamp
strtotime("next Monday")Convert date string to timestamp
📁 File & Error Handling
file_get_contents($path)Read entire file into a string
file_put_contents($p, $d)Write string to a file
file_exists($path)Check if file exists
unlink($path)Delete a file
include 'file.php';Include a file (warning if missing)
require 'file.php';Include a file (fatal if missing)
try { } catch (Exception $e) { }Catch errors gracefully
throw new Exception("Oops");Throw a custom error
$e->getMessage()Get the error message
Security Rule: Always use htmlspecialchars() before echoing user input onto a page, and never put raw $_POST values directly into SQL queries — use prepared statements to prevent SQL injection!
