Grades 9–10

🐘 PHP Cheat Sheet

The server-side PHP you use most, from your first echo to safe logins, on one page.

PHP basics: code lives inside <?php ... ?> in a .php file, every statement ends with ; and every variable starts with $. PHP runs on the server (XAMPP: http://localhost/...), so the browser only sees the HTML it prints.
🖨️ Basics & Output
<?php ... ?>Open and close a PHP block
echo "Hello";Print text to the page
print "Hi";Like echo, but returns 1
// comment   /* block */One-line and multi-line comments
var_dump($x);Show type + value (for testing)
print_r($arr);Print an array in a readable way
phpinfo();Show server settings (never leave it on a live site)
📦 Variables & Types
$name = "Amina";String (text)
$age = 14;Integer (whole number)
$price = 9.99;Float (decimal)
$active = true;Boolean (true/false)
$nothing = null;Null (no value)
const MAX_BOOKS = 3;Constant: cannot change
gettype($x)   is_int($x)Type as text; check a type
(int) "42"   (string) 7Cast (convert) to another type
5 == "5" → trueLoose: compares values only
5 === "5" → falseStrict: value AND type (use this)
$name ?? "Guest"Use "Guest" if $name is missing or null
✏️ String Functions
"Hi " . $nameJoin strings with a dot
"Hi $name"   "{$name}'s"Variables inside double quotes
'Hi $name'Single quotes print $name as it is
strlen($s)Length of a string
strtolower($s)   strtoupper($s)lowercase / UPPERCASE
ucfirst($s)Capital first letter
trim($s)Remove spaces at both ends
str_replace("a", "b", $s)Replace text inside a string
str_contains($s, "php")true if the text is inside (PHP 8)
strpos($s, "php") !== falsePosition, or false if not found (0 is a real position!)
substr($s, 0, 5)Take part of a string
explode(",", $s)   implode(", ", $a)Text → array; array → text
📚 Arrays
$a = [1, 2, 3];Indexed array
$a = ["title" => "Clean Code"];Associative array (key => value)
$a[] = 4;Add to the end
count($a)Number of items
array_push($a, 5)   array_pop($a)Add / remove at the end
array_unshift($a, 0)   array_shift($a)Add / remove at the start
sort($a)   rsort($a)Sort up / down
in_array(3, $a)Is this value in the array?
array_key_exists("title", $a)Is this key in the array?
array_merge($a, $b)Join two arrays
array_slice($a, 1, 3)Copy out a part
🔀 Control Flow
if ($x > 0) { } elseif ($x === 0) { } else { }Decisions
&&   ||   !and, or, not
match ($grade) { 9, 10 => "Senior", default => "Junior" }Pick a value (strict ===, PHP 8)
switch ($x) { case 1: ... break; }Older multi-branch (do not forget break)
for ($i = 0; $i < 5; $i++) { }Count-controlled loop
while ($x > 0) { }Loop while true
do { } while ($x);Runs at least once
foreach ($books as $b) { }Loop over values
foreach ($a as $key => $value) { }Loop over keys and values
break;   continue;Leave the loop / skip to the next turn
⚙️ Functions
function greet($name) { return "Hi $name"; }Define a function that returns a value
function add($a, $b = 0) { }Default value for a parameter
function total(int ...$nums): int { }Any number of arguments, with types
$fn = function ($x) { return $x * 2; };Anonymous function
$fn = fn($x) => $x * 2;Arrow function (short form)
array_map($fn, $arr)Apply a function to every item
array_filter($arr, $fn)Keep items where $fn returns true

$b->title   $b->borrow()Use a property / call a method
$this->titleThe object's own property, inside the class

public static int $count = 0;   Book::$countShared by all objects
📬 Forms, Sessions & Superglobals
$_GET['q']Data from the URL (?q=...)
$_POST['email']Data from a POST form
$_SERVER['REQUEST_METHOD'] === 'POST'Was the form sent?
$_FILES['photo']An uploaded file
$_COOKIE['theme']Small value stored in the browser
session_start();First line of every page that uses sessions
$_SESSION['user_id'] = 7;Remember a value across pages
isset($_POST['name'])Exists and is not null
empty($x)True for "", "0", 0, null, false, []
trim($_POST['name'] ?? '')Read input safely with a fallback
echo htmlspecialchars($name);Escape before printing user input (stops XSS)
header('Location: thanks.php'); exit;Redirect, then stop the script
🔐 Passwords & Database (PDO)
$hash = password_hash($pass, PASSWORD_DEFAULT);Store this hash, never the password
password_verify($pass, $hash)true if the typed password matches
$pdo = new PDO("mysql:host=localhost;dbname=school_db;charset=utf8mb4", "root", "");Connect to MySQL
$stmt = $pdo->prepare("SELECT * FROM students WHERE id = ?");Prepared statement: ? is a placeholder
$stmt->execute([$id]);Send the value separately (stops SQL injection)
$row = $stmt->fetch();One row (false if none)
$rows = $stmt->fetchAll();All rows as an array
"... WHERE id = $id"Never build SQL from user input like this
🔢 Math & Dates
+   -   *   /   %   **Add, subtract, multiply, divide, remainder, power
intdiv(7, 2) → 3Whole-number division
round($x, 2)   ceil($x)   floor($x)Round to 2 places / up / down
abs($x)   max(1, 5, 3)   min(1, 5, 3)Absolute value, largest, smallest
rand(1, 10)Random number, e.g. pick a quiz question
random_int(1, 10)Secure random number (codes, tokens)
date("Y-m-d")Today's date as text, e.g. 2026-09-02
time()Seconds since 1 Jan 1970 (Unix timestamp)
strtotime("+14 days")Text → timestamp (e.g. a book's due date)
📁 Files & Errors
file_get_contents($path)Read a whole file into a string
file_put_contents($path, $text)Write a string to a file
file_put_contents($path, $line, FILE_APPEND)Add to the end instead of replacing
file_exists($path)   unlink($path)Check a file exists / delete it
require 'db.php';Load a file (stops if missing)
include 'nav.php';Load a file (only warns if missing)
try { } catch (Exception $e) { }Handle an error without crashing
throw new Exception("Not found");Raise your own error
$e->getMessage()The error's message
Amānah (trust) rule: every form value is untrusted. Escape it with htmlspecialchars() before printing, send it to the database only through prepared statements, store passwords only as password_hash() hashes (never md5 or sha1), and collect no personal data you do not need.
