Class 6

HTML Cheat Sheet

Every tag you need — one page, always ready. Bookmark this!

How to use this cheat sheet: When you forget a tag or what it does, look it up here. The left column shows the tag, the right column explains it in plain English.
🏗️ Document Structure
<!DOCTYPE html>Tells the browser: "This is HTML5!"
<html lang="en">The root wrapper for the whole page
<head>Hidden section: title, links, meta info
<title>The text shown on the browser tab
<meta charset="UTF-8">Supports all characters and languages
<meta name="viewport">Makes the page work on mobile phones
<body>Everything visible on the page goes here
✏️ Headings & Text
<h1> to <h6>Headings — h1 is biggest, h6 is smallest
<p>A paragraph of text
<strong>Bold text (important meaning)
<em>Italic text (emphasized meaning)
<br>Line break (no closing tag needed)
<hr>Horizontal rule — a dividing line
<mark>Highlighted text like a marker pen
<code>Inline code styling like this
<small>Smaller, fine-print text
<del>Strikethrough (deleted text)
<sup> / <sub>Super² and Sub₂scripts
<blockquote>An indented quote from somewhere else
🔗 Links & Images
<a href="url">Hyperlink — click to go somewhere
target="_blank"Open link in a new tab
<img src="file" alt="desc">Show an image (no closing tag)
alt="description"Text shown if image fails to load (required!)
width="200" height="100"Set image size in pixels
<figure>Container for image + caption
<figcaption>Caption text below an image
<video src="file">Embed a video player
<audio src="file">Embed an audio player
<iframe src="url">Embed another webpage inside yours
📝 Lists
<ul>Unordered list (bullet points •)
<ol>Ordered list (1. 2. 3. …)
<li>One item inside a list
<dl>Description / definition list
<dt>The term being defined
<dd>The definition of that term
📊 Tables
<table>Creates a table
<thead>The header section of the table
<tbody>The body (data) section
<tfoot>The footer section
<tr>Table Row
<th>Table Header cell (bold, centered)
<td>Table Data cell (regular)
colspan="2"Make a cell span 2 columns
rowspan="2"Make a cell span 2 rows
📬 Forms
<form>The container for all form inputs
<label for="id">Text label — connects to an input
<input type="text">Single-line text box
<input type="email">Email field with validation
<input type="password">Password field (hides text)
<input type="number">Number input with up/down arrows
<input type="checkbox">Tick box — select multiple
<input type="radio">Circle button — select one only
<input type="submit">Submit button for the form
<button>A clickable button (more flexible)
<select>Dropdown menu container
<option>One choice inside a <select>
<textarea>Multi-line text input box
placeholder="hint"Grey hint text inside an input
requiredMakes a field mandatory
🧠 Semantic Tags
<header>Top section — logo, title, nav
<nav>Navigation links (menu)
<main>The main unique content of the page
<section>A grouped topic or chapter
<article>A standalone piece of content (blog post)
<aside>Side content, related but not main
<footer>Bottom section — copyright, links
<div>Generic block container (no meaning)
<span>Generic inline wrapper (no meaning)
⚙️ Common Attributes
class="name"CSS styling group — reusable
id="name"Unique identifier — used once per page
style="..."Inline CSS (use sparingly)
href="url"Where a link points to
src="file"Source file (images, scripts)
alt="text"Alternative text for images
title="hint"Tooltip text on hover
disabledMakes an input non-clickable
hiddenHides an element completely
data-*="value"Custom data stored on any element
Remember: Good HTML is semantic — use tags that describe the meaning of your content, not just how it looks. Use <strong> for important text, not just bold. Use <h1> only once per page!
