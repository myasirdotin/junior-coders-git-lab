IP Addressing, CIDR & NAT 🗺️

Every device on the Internet needs an address. Master IPv4 octets, CIDR prefixes, and private home networks.

Addresses for Every Device 🏠

🧠 Real-life analogy: A school address has two parts: the street name and the house number. Every house on one street shares the street name. Each house has its own number. An IP address works the same way. One part names the network (the street). The other part names the host, which means one device on that network (the house).

An IP address is the number that tells routers where a packet should go. IP stands for Internet Protocol. Every device that talks on a network needs one.

The Anatomy of an IPv4 Address

An IPv4 address is 32 bits long. It is written as four numbers with dots between them. Each number is called an octet, because it is made of 8 bits. Each octet can go from 0 to 255.

Decimal:  192      . 168      . 1        . 100
Binary:   11000000.10101000.00000001.01100100

Worked example 1: turning a number into binary

Each of the 8 bits has a place value. Start at 128 and halve each time. Put a 1 under each value you need, and a 0 under the rest.

Place value: 128  64  32  16   8   4   2   1

192 = 128 + 64
             1   1   0   0   0   0   0   0  → 11000000

168 = 128 + 32 + 8
             1   0   1   0   1   0   0   0  → 10101000

100 = 64 + 32 + 4
             0   1   1   0   0   1   0   0  → 01100100

Eight 1s in a row add up to 128 + 64 + 32 + 16 + 8 + 4 + 2 + 1 = 255. That is why an octet can never be bigger than 255.

32 bits give 232 = 4,294,967,296 possible addresses, about 4.3 billion. That sounds like a lot, but the world has more devices than that.

IPv6 is the newer version. It uses 128 bits and is written in hexadecimal (base 16, using the digits 0–9 and the letters a–f), for example 2001:db8::25. It has enough addresses for every device for a very long time.

CIDR Subnet Math: The Slash Notation

A subnet is one smaller network, like one street. CIDR notation writes a slash and a number after the address, for example 192.168.1.0/24. The number says how many bits, counted from the left, belong to the network part. The bits that are left over belong to the hosts.

For /24: 32 − 24 = 8 host bits.

Total addresses = 28 = 256
Usable devices = 256 − 2 = 254 usable hosts
(The first address is the network address. The last is the broadcast address.)

Two addresses in every subnet are kept for special jobs:

  • The network address (all host bits 0) is the name of the whole subnet, like the street name.
  • The broadcast address (all host bits 1) sends a message to every device on the subnet at once, like a school-wide announcement.

A subnet mask is the same idea written another way. /24 is the mask 255.255.255.0: 24 ones followed by 8 zeros.

Worked example 2: working out a /26 subnet

A science lab uses 192.168.10.0/26. What are its addresses?

Host bits      = 32 − 26 = 6
Total          = 2^6 = 64 addresses
Usable hosts   = 64 − 2 = 62

Network address   192.168.10.0
First usable      192.168.10.1
Last usable       192.168.10.62
Broadcast         192.168.10.63
Subnet mask       255.255.255.192
Next subnet       192.168.10.64/26

Why .192 in the mask? The last octet has 2 network bits: 11000000 = 128 + 64 = 192.

Worked example 3: choosing a size

A school hall needs 50 computers. Which prefix is the smallest that fits?

Need 50 hosts + 2 special = 52 addresses

/27 → 2^5 = 32 addresses  ✘ too small
/26 → 2^6 = 64 addresses  ✔ 62 usable

Answer: /26

Each step down in the prefix number doubles the size. A /25 has 128 addresses, a /24 has 256.

Private Networks & NAT: Saving IPv4

Free IPv4 addresses ran out years ago. To save them, a standard called RFC 1918 set aside three private ranges. Anyone may use them inside their own building. Routers on the public Internet do not carry them.

10.0.0.0/8

About 16.7 million addresses. Used by large campuses and companies.

172.16.0.0/12

From 172.16.0.0 to 172.31.255.255, about 1 million addresses. Used by many universities and offices.

192.168.0.0/16

65,536 addresses. Used by most home Wi-Fi routers and small classrooms.

NAT (Network Address Translation) lets many private devices share one public IP address. Your router gets the public address from your ISP. When a device sends a packet out, the router swaps the private sender address for its public one. It writes down who asked, so it can pass the reply back to the right device. (It uses port numbers to keep track. You will meet ports in Module 4.)

Laptop  192.168.1.20 ─┐
Tablet  192.168.1.21 ─┼─[Router]── Internet
Printer 192.168.1.30 ─┘   public:
                          203.0.113.7

Websites see: 203.0.113.7 for all three

The addresses 203.0.113.x and 2001:db8:: are kept for examples in books, so they never belong to a real computer.

Worked Example 4: Find Your Own Address 🔎

On Windows, open Command Prompt or PowerShell and run:

ipconfig

Example output (shortened; yours will differ):

Wireless LAN adapter Wi-Fi:

   IPv4 Address. . . . . . : 192.168.1.20
   Subnet Mask . . . . . . : 255.255.255.0
   Default Gateway . . . . : 192.168.1.1
  • IPv4 Address is this device's private address.
  • Subnet Mask 255.255.255.0 means this network is a /24.
  • Default Gateway is the router: the door your packets use to leave this network.

On macOS, try ifconfig. On Linux, try ip addr. You will usually see an address starting with 192.168. or 10..

Common Misunderstanding ⚠️

"The address in ipconfig is the address websites see."

Usually not. ipconfig shows your private address, such as 192.168.1.20. Because of NAT, websites see your router's single public address instead. Many homes and school rooms share one public address.

"A /24 can hold 256 computers."

It has 256 addresses, but only 254 can be given to devices. The first is the network address and the last is the broadcast address.

🔐 Amānah: An IP address can hint at where a person is. Treat logs of visitors' addresses as private information. Keep them only as long as you truly need them.

🔴 Level 3: Challenge

A neighbourhood food bank has the private block 192.168.20.0/24. Plan three subnets for it:

  1. Volunteer guest Wi-Fi: 50 devices.
  2. Office: 25 devices.
  3. Warehouse scanners: 10 devices.

Choose the smallest prefix for each. Start with the biggest subnet. Write each network address and its usable range.

Show one possible answer
Guest Wi-Fi  50 → /26 (62 usable)
  192.168.20.0/26   .1 – .62    (bcast .63)
Office       25 → /27 (30 usable)
  192.168.20.64/27  .65 – .94   (bcast .95)
Warehouse    10 → /28 (14 usable)
  192.168.20.96/28  .97 – .110  (bcast .111)

Free for later: 192.168.20.112 – .255

Starting with the largest subnet keeps every block lined up neatly, with no gaps.
