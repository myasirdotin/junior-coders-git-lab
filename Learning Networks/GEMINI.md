# Learning Computer Networking & Web Protocols - Domain Guidelines & Standards

This directory contains the interactive student-facing modules, multi-tier exercises, network simulators, and reference materials for **Computer Networking & Web Protocols**.

---

## 1. Ethical Alignment (*'Ilm Nāfi'* & *Amānah*)

All modules in this track must strictly follow our core ethical foundation:
- **Beneficial Networks**: Frame network engineering as a vehicle for connecting families, supporting public healthcare, accelerating education, and coordinating humanitarian disaster relief (*'Ilm Nāfi'*).
- **Digital Stewardship & Trust (*Amānah*)**: User privacy and data security are sacred trusts. Enforce TLS encryption, secure cookie flags (`HttpOnly`, `Secure`), and proper CORS headers from day one.
- **Strictly Prohibited Topics**:
  - No packet sniffing tutorials designed for spying or eavesdropping.
  - No DDoS scripts or botnet tutorials.
  - No interest or loan models (*Ribā*), gambling tools (*Maysir*), or deceptive dark patterns.

---

## 2. Pedagogical Architecture

1. **Scaffolded Flow**: Physical Wire $\rightarrow$ Layer Abstractions $\rightarrow$ Addressing & Subnets $\rightarrow$ Transport & Sockets $\rightarrow$ DNS $\rightarrow$ HTTP/3 $\rightarrow$ TLS Cryptography $\rightarrow$ Real-World Diagnostics.
2. **Three-Tier Mastery Practice**:
   - 🟢 **Level 1 (Recall / Warmup)**: Ports, status codes, and OSI layers.
   - 🟡 **Level 2 (Application / Modification)**: Subnetting calculations and curl request assembly.
   - 🔴 **Level 3 (Creative Challenge / Architecture)**: CORS debugging, idempotent API design, and network diagnostics.
3. **Single Source of Truth**: Modules mirror the textbook chapters in `book-networks/`.
4. **Engineering Excellence (*Iḥsān*)**: Teach students clean network architecture, bandwidth stewardship, and resilient error recovery.
