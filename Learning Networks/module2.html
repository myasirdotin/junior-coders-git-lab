OSI & TCP/IP Layer Models 🧱

Learn how computer scientists tame complexity by breaking communication into standardized, cooperative layers.

The "Russian Nesting Dolls" (Encapsulation)

When you send data, each layer down the stack wraps your application message in its own header containing specialized routing and error-checking instructions.

[ Application Data: {"user": "Farooq", "donation": 100} ]
  ▼ Layer 4 (Transport): Adds TCP Port Header ➔ [Segment]
  ▼ Layer 3 (Network): Adds IP Address Header ➔ [Packet]
  ▼ Layer 2 (Data Link): Adds MAC Frame Header + CRC Trailer ➔ [Frame]
  ▼ Layer 1 (Physical): Transmits raw voltage or light ➔ [Bits 01001101...]

The OSI 7 Layers vs. The Real-World TCP/IP 4 Layers

The OSI 7-Layer Reference Model

  • 7. Application (HTTP, DNS, SSH)
  • 6. Presentation (Encryption, TLS, JSON)
  • 5. Session (Sockets, RPC)
  • 4. Transport (TCP, UDP)
  • 3. Network (IP, Routers)
  • 2. Data Link (Ethernet, MAC, Switches)
  • 1. Physical (Cables, Radio, Bits)

The Pragmatic TCP/IP 4-Layer Model

  • 1. Application Layer (Blends OSI 5, 6, and 7)
  • 2. Transport Layer (TCP segments, UDP datagrams)
  • 3. Internet Layer (IP routing across networks)
  • 4. Network Access Layer (Ethernet, Wi-Fi hardware)
