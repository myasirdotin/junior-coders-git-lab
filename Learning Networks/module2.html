Level 1

OSI & TCP/IP Layer Models 🧱

Learn how computer scientists tame complexity by breaking communication into standardized, cooperative layers.

Why Split Networking Into Layers? 🧱

🧠 Real-life analogy: Think of a school sending a parcel of donated books to a village library. The teacher writes a letter. The office packs it in a box and writes the address. The courier drives it to the right town. The truck driver only cares about roads. Nobody needs to do everyone's job. Each worker does one job and passes the parcel on.

Networking works the same way. The job is split into layers. Each layer does one job. It only talks to the layer just above it and the layer just below it.

This makes problems easier to fix. If one layer breaks, you know where to look. It also lets people improve one layer without rebuilding the others. For example, Wi-Fi replaced cables in many homes, but websites did not need to change.

Encapsulation: Wrapping the Message 🎁

Encapsulation means wrapping. On the way down, each layer adds its own label to the front of the message. This label is called a header. The data link layer also adds a trailer at the end. The trailer holds a check number (a CRC) that shows if the frame was damaged on the way.

Each wrapped bundle has its own name. Learn these names; you will see them often.

[ Data: {"donor": "Farooq", "books": 12} ]
  ▼ Layer 4 (Transport): adds a TCP header ➔ [Segment]
  ▼ Layer 3 (Network): adds an IP header ➔ [Packet]
  ▼ Layer 2 (Data Link): adds an Ethernet header and trailer ➔ [Frame]
  ▼ Layer 1 (Physical): sends it as electricity, light or radio ➔ [Bits 01001101...]

At the other end, the steps run in reverse. Each layer reads its own label, removes it and passes the rest up. This is called decapsulation (unwrapping).

Worked example 1: how big is the final frame?

A library app sends a 30-byte search request. Typical header sizes are: TCP 20 bytes, IP 20 bytes, Ethernet header 14 bytes and Ethernet trailer 4 bytes.

Data                      30 bytes
+ TCP header       20  →  50 bytes  (segment)
+ IP header        20  →  70 bytes  (packet)
+ Ethernet header  14
+ Ethernet trailer  4  →  88 bytes  (frame)

┌────┬────┬─────┬──────────┬───┐
│ETH │ IP │ TCP │ Data 30  │CRC│
│ 14 │ 20 │ 20  │          │ 4 │
└────┴────┴─────┴──────────┴───┘

So 30 bytes of real data become an 88-byte frame on the wire. Small messages carry a lot of labels for their size.

The OSI 7 Layers vs. the TCP/IP 4 Layers

There are two famous layer models. The OSI model has 7 layers. It is a reference model: people use it to explain and talk about problems. The TCP/IP model has 4 layers. It describes how the real Internet is built. Both are numbered from the bottom (the wire) to the top (the app).

The OSI 7-Layer Reference Model

  • 7. Application: what apps speak (HTTP, DNS, email)
  • 6. Presentation: data formats and character codes; encryption is often listed here
  • 5. Session: starting, keeping and ending a conversation
  • 4. Transport: TCP and UDP; which program gets the data
  • 3. Network: IP addresses and routers; finding a path
  • 2. Data Link: Ethernet, Wi-Fi frames, switches, MAC addresses
  • 1. Physical: cables, light, radio, raw bits

The TCP/IP 4-Layer Model

  • 4. Application: covers OSI layers 5, 6 and 7
  • 3. Transport: TCP segments, UDP datagrams
  • 2. Internet: IP routing across networks
  • 1. Link (Network Access): Ethernet and Wi-Fi hardware, covers OSI 1 and 2

A MAC address is a hardware ID given to each network card, such as 3C-52-82-1A-7F-09. Switches use MAC addresses to deliver frames inside a LAN. Routers use IP addresses to send packets between networks.

💡 Memory trick for OSI from the bottom (Physical, Data Link, Network, Transport, Session, Presentation, Application): "Please Do Not Take Sweets Past Assembly."

Fixing Problems Layer by Layer 🔧

Network engineers often check from the bottom up. If the cable is broken, nothing above it can work. So check the lowest layer first.

Worked example 2: "The library computer cannot open the catalogue"

Step 1 – Physical (L1)
  Is the cable plugged in? Is the port light on?
  Yes ✔

Step 2 – Data Link (L2)
  Is Wi-Fi connected / does the switch see it?
  Yes ✔

Step 3 – Network (L3)
  Can it reach a computer outside the school?
  ping 1.1.1.1 → replies ✔

Step 4 – Application (L7)
  Browser shows "500 Internal Server Error"
  ✘ Problem found: the catalogue program on
    the server has a fault.

The network was fine. The problem was at the top, in the server's program. Checking layers in order saved time.

Worked example 3: match the problem to the layer

  • A cable is cut or unplugged ➔ Physical (Layer 1)
  • A laptop can reach computers in its own room, but no other network ➔ Network (Layer 3), often a router setting
  • A website answers with 404 Not Found ➔ Application (Layer 7): the server is reachable but the page is missing

Common Misunderstanding ⚠️

"The Internet runs on the 7-layer OSI model."

Not quite. The real Internet is built on the TCP/IP family of protocols. The OSI model is a shared map. Engineers use its layer numbers to talk clearly, for example "that is a Layer 2 problem". Some real protocols, like TLS, do not fit neatly into one OSI layer.

"Each layer is a separate machine."

No. Your laptop runs all the layers itself, from the app at the top to the Wi-Fi radio at the bottom. A router mostly works with layers 1 to 3.

🏆 Practice: three levels

🟢 Level 1: Recall

Name the bundle at each layer: Transport layer = ______, Network layer = ______, Data Link layer = ______. Which OSI layer number adds IP addresses?

Show answer
Segment, packet, frame. IP addresses are added at Layer 3, the Network layer (the Internet layer in TCP/IP).

🟡 Level 2: Apply

A school attendance app sends 100 bytes of data. Using the header sizes from Worked example 1, how big are the segment, the packet and the frame?

Show answer
Data                 100 bytes
+ TCP 20       →     120 bytes (segment)
+ IP 20        →     140 bytes (packet)
+ Ethernet 14 + 4 →  158 bytes (frame)

🔴 Level 3: Challenge

You are helping at the community library help desk. Three reports arrive:

  1. "Computer 4 shows a red cross on the network icon, and the light on its cable port is off."
  2. "The library website opens, but the 'Reserve a book' page says 404 Not Found."
  3. "I can print to the printer in this room, but no website outside the library will open."

For each report, name the most likely layer and the first thing you would check.

Show one possible answer
  1. Layer 1 (Physical). Check that the cable is plugged in at both ends, or try a new cable.
  2. Layer 7 (Application). The network works; tell the website team the page link is missing or wrong.
  3. Layer 3 (Network). The LAN works, but traffic is not leaving it. Check the router and the Internet link.
