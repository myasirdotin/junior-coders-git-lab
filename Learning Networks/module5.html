DNS: The Global Phonebook 📖🔍

How human-friendly domain names like juniorcoders.org become machine-routable IP addresses in milliseconds.

The 4 Steps of a DNS Recursive Query

1. Local Cache: Checks browser and OS memory.
2. Recursive Resolver (1.1.1.1): Queries the Root cluster on your behalf.
3. Root Nameserver (.): Directs to the Top-Level Domain (TLD) server (e.g. .org).
4. TLD Nameserver (.org): Directs to the domain's Authoritative Nameserver.
5. Authoritative Nameserver: Delivers the definitive A Record (IP Address)!

Essential DNS Record Types

A Record

Maps a hostname to an IPv4 address (e.g. 104.21.55.2).

AAAA Record

Maps a hostname to an IPv6 address (128-bit).

CNAME Record

Canonical Name: aliases www.site.com to site.com.

MX Record

Mail Exchanger: specifies the servers that accept incoming emails.

Time To Live (TTL): Caching Efficiency

Every DNS record has a TTL value (in seconds). A TTL of 3600 instructs resolvers to store the answer in cache for 1 hour. This eliminates redundant queries and keeps the Internet lightning fast!
