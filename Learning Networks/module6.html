HTTP Deep Dive & Wire Format 📬

The core protocol of the World Wide Web. Learn what travels through the wire when you click a button or fetch an API.

The RFC 7230 Wire Format

Under the hood, HTTP/1.1 is plain text structured into three clean parts:

POST /api/v1/relief-supplies HTTP/1.1  <-- Request Line
Host: api.oasis-aid.org
User-Agent: Mozilla/5.0
Content-Type: application/json
Content-Length: 42

<-- Empty Line (\r\n) separates headers from body
{"item": "Blankets", "quantity": 500}  <-- Request Body

The 5 HTTP Status Code Classes

1xx Informational

101 Switching Protocols (WebSocket handshake).

2xx Success ✅

200 OK, 201 Created, 204 No Content.

3xx Redirection 🔀

301 Moved Permanently, 304 Not Modified.

4xx Client Error ⚠️

400 Bad Request, 401 Unauthorized, 404 Not Found.

5xx Server Error 💥

500 Server Error, 502 Bad Gateway.

From HTTP/1.1 to HTTP/2 and HTTP/3

  • HTTP/1.1: Sequential text pipeline with Head-of-Line blocking.
  • HTTP/2: Multiplexed binary streams over a single TCP connection with HPACK header compression.
  • HTTP/3 (QUIC): Built on UDP with zero Head-of-Line blocking and seamless Wi-Fi-to-cellular connection migration!
