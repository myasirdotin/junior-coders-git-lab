Networking & Protocols Glossary 📚

Essential vocabulary for junior network engineers, backend developers, and systems architects.

Amānah (Digital Trust / Confidentiality) 🛡️

The sacred ethical responsibility to encrypt sensitive communications, protect user credentials, prevent eavesdropping, and treat data as entrusted secrets.

Bandwidth 🌊

The maximum rate of data transfer across a given network path per second (measured in Mbps or Gbps). Distinct from latency.

CIDR (Classless Inter-Domain Routing) ✂️

A method for allocating IP addresses and IP routing using slash notation (e.g. /24) to designate the number of leading network bits.

CORS (Cross-Origin Resource Sharing) 🌐

An HTTP-header-based mechanism that allows a server to indicate any origins (domain, scheme, or port) other than its own from which a browser should permit loading resources.

DNS (Domain Name System) 📖

The distributed, hierarchical naming database that maps human-friendly domain names (e.g. example.org) to numerical IP addresses.

Encapsulation 📦

The process where each descending layer in a protocol stack wraps data received from the layer above inside its own protocol header and trailer.

HTTP/3 & QUIC 🏎️

The third major version of the Hypertext Transfer Protocol, running over UDP using the QUIC transport protocol to eliminate Head-of-Line blocking and enable connection migration.

Idempotency 🔁

A property of an HTTP method (such as GET, PUT, or DELETE) where making multiple identical requests has the same intended effect on the server as making a single request.

Latency (Ping / RTT) ⏱️

The round-trip time (in milliseconds) required for a packet of data to travel from the sender to the destination host and back.

MAC Address 🏷️

Media Access Control: a unique, permanent 48-bit physical identifier burned into a Network Interface Card (NIC) at the factory.

NAT (Network Address Translation) 🔄

A technique used by routers to remap multiple private IP addresses into a single public IP address when communicating over the global Internet.

Socket 🔌

The endpoint of a bidirectional inter-process communication flow across an IP network, formed by the combination of an IP Address and a Port Number.

TCP 3-Way Handshake 🤝

The three-step synchronization process (SYN ➔ SYN-ACK ➔ ACK) used to establish a reliable, sequenced connection between client and server.

TLS (Transport Layer Security) 🔐

The cryptographic protocol that secures Internet communications by providing privacy (encryption), integrity (tamper-proofing), and authentication (certificates).

TTL (Time To Live) ⏳

A field in IP packets or DNS records that limits lifespan or dictates how long a resolver may cache a record before querying the source again.

WebSocket ⚡

A computer communications protocol providing simultaneous, full-duplex communication channels over a single persistent TCP connection.
