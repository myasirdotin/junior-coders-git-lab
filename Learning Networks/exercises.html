Tier 1 • Exercise 2

HTTP Status Code Categorization

What do the status codes 201, 301, 401, 403, and 502 represent?

View Solution 
201 ➔ Created (Resource created successfully via POST)
301 ➔ Moved Permanently (Permanent redirection)
401 ➔ Unauthorized (Authentication required)
403 ➔ Forbidden (Authenticated, but permission denied)
502 ➔ Bad Gateway (Reverse proxy received invalid response)

Tier 2 • Exercise 3

CIDR Subnet Math for a Medical Clinic

A regional healthcare clinic is given the subnet 192.168.10.0/26. Calculate:

  1. Subnet mask
  2. Total IP addresses
  3. Number of usable client devices
  4. Broadcast address
View Solution 
1. Subnet mask: 255.255.255.192
2. Total IP addresses: 2^(32 - 26) = 2^6 = 64
3. Usable devices: 64 - 2 = 62 usable hosts (192.168.10.1 to 192.168.10.62)
4. Broadcast address: 192.168.10.63
Tier 2 • Exercise 4

Constructing a Secure Curl Request

Write a curl command that sends a POST request to https://api.oasis-aid.org/v1/water-wells with JSON body {"village": "Zaytuna"}, a Bearer token header, and prints response headers.

View Solution 
curl -i -X POST https://api.oasis-aid.org/v1/water-wells \
     -H "Content-Type: application/json" \
     -H "Authorization: Bearer token_amanah_786" \
     -d '{"village": "Zaytuna"}'

Tier 3 • Exercise 5

Debugging a Cross-Origin Preflight Failure

Your frontend running on https://portal.charity.org receives a CORS error when calling POST https://api.charity.org/v1/donations with an Authorization header. Explain why the preflight occurs and write the exact HTTP response headers your backend server must return for the preflight OPTIONS request.

View Solution 
Why preflight occurs:
The request uses custom headers (Authorization) and is cross-origin 
(portal.charity.org vs api.charity.org). The browser must verify permissions first!

Backend Preflight Response Headers:
HTTP/1.1 204 No Content
Access-Control-Allow-Origin: https://portal.charity.org
Access-Control-Allow-Methods: GET, POST, OPTIONS
Access-Control-Allow-Headers: Content-Type, Authorization
Access-Control-Max-Age: 86400
