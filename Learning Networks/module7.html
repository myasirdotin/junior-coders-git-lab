The Hybrid Cryptographic Engine

Modern HTTPS uses a brilliant blend of two mathematical approaches:

1. Asymmetric Cryptography (Public Key)

Uses a Public Key to encrypt and a Private Key to decrypt. Used only for the first few milliseconds to safely exchange secrets over an open network.

2. Symmetric Cryptography (AES-256)

Uses one shared session key to encrypt and decrypt. Blazingly fast, providing high-speed bulk data encryption for the rest of your session.

The 1-RTT TLS 1.3 Handshake

Client ➔ Server: ClientHello (Supported Ciphers + Key Share)
Server ➔ Client: ServerHello + X.509 Certificate + Finished
Both compute Session Keys independently ➔ Encrypted Wire Established in 1 RTT!

Same-Origin Policy & CORS Headers

Browsers block cross-origin requests by default to protect user sessions. The server grants explicit permission using headers:

Access-Control-Allow-Origin: https://app.oasis-aid.org
Access-Control-Allow-Methods: GET, POST, OPTIONS
Access-Control-Allow-Headers: Content-Type, Authorization
