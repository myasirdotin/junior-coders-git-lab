The Data Organizer!

Group your data together like a pro using Objects. 📂

What is an Object?

An **Object** is like a character profile in a video game. Instead of just having a name, you have a name, health, level, and powers all in one "folder".

👤

Hero Object

name: "Zelda",
level: 10,
isAlive: true

The Curly Brace Secret

We use curly braces { } to group data into **Keys** and **Values**.

const hero = {
  name: "Ali",
  age: 12,
  isCoding: true
};

// Access data using the "Dot"
console.log(hero.name); // Returns "Ali"
