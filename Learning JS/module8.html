📖 Reading Material

📚 What is an Object?

An object is a collection of related data and functionality. Think of it as a container that holds properties (data) and methods (functions). Objects are fundamental to JavaScript and are used to represent real-world entities like a person, a car, or a bank account.

8.1 Object Literals

The simplest way to create an object:

// Creating an object literal const person = { firstName: "John", lastName: "Doe", age: 30, isEmployed: true, hobbies: ["reading", "coding", "gaming"] }; // Accessing properties console.log(person.firstName); // "John" console.log(person["lastName"]); // "Doe" // Modifying properties person.age = 31; person["isEmployed"] = false; // Adding new properties person.email = "john@example.com"; // Deleting properties delete person.isEmployed; console.log(person); // { firstName: "John", lastName: "Doe", age: 31, hobbies: [...], email: "john@example.com" } // Nested objects const student = { name: "Alice", grade: 10, address: { street: "123 Main St", city: "Springfield", state: "IL", zip: "62701" }, getFullAddress() { return `${this.address.street}, ${this.address.city}, ${this.address.state} ${this.address.zip}`; } }; console.log(student.address.city); // "Springfield" console.log(student.getFullAddress()); // "123 Main St, Springfield, IL 62701"
💡 Dot vs Bracket Notation: Use dot notation (obj.property) for known, valid identifier names. Use bracket notation (obj["property"]) when the property name is stored in a variable or contains special characters.

8.2 Object Methods

Functions stored as object properties:

// Object with methods const calculator = { result: 0, add(value) { this.result += value; return this; }, subtract(value) { this.result -= value; return this; }, multiply(value) { this.result *= value; return this; }, divide(value) { if (value !== 0) { this.result /= value; } return this; }, reset() { this.result = 0; return this; }, getResult() { return this.result; } }; // Method chaining calculator.add(10).multiply(5).subtract(20).divide(3); console.log(calculator.getResult()); // 10 // Method that returns object for chaining const book = { title: "JavaScript Basics", author: "Jane Doe", pages: 300, isRead: false, markAsRead() { this.isRead = true; return this; }, addPages(count) { this.pages += count; return this; }, getInfo() { return `${this.title} by ${this.author}, ${this.pages} pages, ${this.isRead ? 'Read' : 'Unread'}`; } }; console.log(book.markAsRead().addPages(50).getInfo()); // "JavaScript Basics by Jane Doe, 350 pages, Read"

8.3 The this Keyword

Understanding how this works in objects:

// 'this' refers to the object calling the method const user = { name: "Sarah", age: 25, greet() { console.log(`Hi, I'm ${this.name} and I'm ${this.age} years old.`); }, birthday() { this.age++; console.log(`Happy birthday! ${this.name} is now ${this.age}.`); } }; user.greet(); // "Hi, I'm Sarah and I'm 25 years old." user.birthday(); // "Happy birthday! Sarah is now 26." // 'this' in nested functions - common pitfall! const team = { name: "Developers", members: ["Alice", "Bob", "Charlie"], // Problem: 'this' is lost in regular function callbacks listMembersWrong() { this.members.forEach(function(member) { console.log(`${this.name}: ${member}`); // this is undefined! }); }, // Solution: Use arrow functions or save 'this' reference listMembersCorrect() { // Option 1: Arrow function this.members.forEach((member) => { console.log(`${this.name}: ${member}`); }); // Option 2: Save reference // const self = this; // this.members.forEach(function(member) { // console.log(`${self.name}: ${member}`); // }); } }; team.listMembersCorrect(); // Developers: Alice // Developers: Bob // Developers: Charlie
⚠️ The 'this' Trap: Inside a regular function callback, this does NOT refer to the outer object. Use arrow functions or save this to a variable (like self or that) to preserve the context.

8.4 Object.keys(), Object.values(), Object.entries()

Useful methods for working with objects:

const car = { brand: "Toyota", model: "Camry", year: 2022, color: "Blue" }; // Get all keys (property names) console.log(Object.keys(car)); // ["brand", "model", "year", "color"] // Get all values console.log(Object.values(car)); // ["Toyota", "Camry", 2022, "Blue"] // Get all entries (key-value pairs) console.log(Object.entries(car)); // [["brand", "Toyota"], ["model", "Camry"], ["year", 2022], ["color", "Blue"]] // Iterating over objects for (const key of Object.keys(car)) { console.log(`${key}: ${car[key]}`); } for (const [key, value] of Object.entries(car)) { console.log(`${key} = ${value}`); } // Check if property exists console.log("brand" in car); // true console.log(car.hasOwnProperty("model")); // true console.log("price" in car); // false // Object freezing (make immutable) const config = { apiUrl: "https://api.example.com" }; Object.freeze(config); config.apiUrl = "https://other.com"; // Won't work in strict mode console.log(config.apiUrl); // "https://api.example.com"

8.5 JSON (JavaScript Object Notation)

Working with JSON data:

// JSON string (commonly received from APIs) const jsonString = '{"name":"John","age":30,"city":"New York","hobbies":["reading","coding"]}'; // Parse JSON string to JavaScript object const person = JSON.parse(jsonString); console.log(person.name); // "John" console.log(person.hobbies); // ["reading", "coding"] // Convert JavaScript object to JSON string const user = { name: "Alice", age: 25, address: { street: "123 Main St", city: "Springfield" } }; const userJson = JSON.stringify(user); console.log(userJson); // '{"name":"Alice","age":25,"address":{"street":"123 Main St","city":"Springfield"}}' // Pretty print JSON (for debugging) console.log(JSON.stringify(user, null, 2)); /* { "name": "Alice", "age": 25, "address": { "street": "123 Main St", "city": "Springfield" } } */ // Real-world example: Fetching data // Simulating API response const apiResponse = `{ "status": "success", "data": { "users": [ {"id": 1, "name": "Alice"}, {"id": 2, "name": "Bob"} ] } }`; const response = JSON.parse(apiResponse); console.log(response.status); // "success" console.log(response.data.users[0].name); // "Alice" // Storing data in localStorage (must be stringified) const settings = { theme: "dark", language: "en", notifications: true }; localStorage.setItem("userSettings", JSON.stringify(settings)); // Retrieving from localStorage (must be parsed) const savedSettings = JSON.parse(localStorage.getItem("userSettings")); console.log(savedSettings.theme); // "dark"
✅ JSON Tip: JSON only supports strings, numbers, booleans, null, arrays, and objects. Functions, undefined, and symbols are NOT valid JSON values and will be ignored by JSON.stringify().

8.6 Spread Operator with Objects

Copy and merge objects easily:

// Spread operator (...) copies properties const defaults = { theme: "light", language: "en", notifications: true }; const userPrefs = { theme: "dark", fontSize: 14 }; // Merge objects (userPrefs overrides defaults) const settings = { ...defaults, ...userPrefs }; console.log(settings); // { theme: "dark", language: "en", notifications: true, fontSize: 14 } // Shallow copy of an object const original = { a: 1, b: 2, nested: { c: 3 } }; const copy = { ...original }; copy.b = 20; copy.nested.c = 30; console.log(original.b); // 2 (unchanged) console.log(original.nested.c); // 30 (changed! shallow copy) // Adding properties to a new object const baseUser = { name: "John", age: 30 }; const extendedUser = { ...baseUser, email: "john@example.com", role: "admin" }; console.log(extendedUser); // { name: "John", age: 30, email: "john@example.com", role: "admin" } // Destructuring with rest const person = { firstName: "Jane", lastName: "Doe", age: 25, city: "NYC" }; const { firstName, ...rest } = person; console.log(firstName); // "Jane" console.log(rest); // { lastName: "Doe", age: 25, city: "NYC" }

8.7 Optional Chaining (?.)

Safely access nested properties:

const user = { name: "Alice", address: { street: "123 Main St", city: "Springfield" } }; // Traditional way (can cause errors) // console.log(user.contact.email); // Error if contact is undefined // Optional chaining (safe) console.log(user.address?.city); // "Springfield" console.log(user.contact?.email); // undefined (no error!) // With methods const api = { data: { fetch() { return "data"; } } }; console.log(api.data?.fetch?.()); // "data" console.log(api.missing?.fetch?.()); // undefined // Real-world example const response = { status: 200, data: { user: { profile: { name: "Bob" } } } }; // Safe access to deeply nested values const userName = response?.data?.user?.profile?.name; console.log(userName); // "Bob" const missing = response?.data?.user?.profile?.email; console.log(missing); // undefined (no error!)
