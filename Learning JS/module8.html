Step 1: Learn — What is an Object?

In everyday life, an entity has multiple descriptive traits. A student has a name, roll number, grade, and attendance record. An Object is a container in JavaScript that groups related data together using labeled keys and corresponding values inside curly braces { }.

🗂️

1. Key-Value Pairs

Each property has a unique name (key) followed by a colon and value:

const student = {
  name: "Zainab",
  grade: 8
};
🔍

2. Dot Notation

Access properties cleanly using a dot (.):

console.log(student.name);
// Returns: "Zainab"
⚙️

3. Object Methods

Functions stored inside an object that can act on its data:

greet() {
  return "Welcome " + this.name;
}

Step 2: See — Real-World Object Modeling

Example A: Academy Research Library Book Record 
const libraryBook = {
    isbn: "978-0131103627",
    title: "The Golden Age of Islamic Science",
    author: "Dr. Al-Hasan",
    totalCopies: 5,
    isAvailable: true
};

console.log("Title:", libraryBook.title);
console.log("Available copies:", libraryBook.totalCopies);
Example B: Student Dossier with Methods 
const student = {
    firstName: "Bilal",
    lastName: "Rasool",
    grade: 8,
    getFullName: function() {
        return this.firstName + " " + this.lastName;
    }
};

console.log("Full Name:", student.getFullName()); // "Bilal Rasool"
