JS Learning Playground

Write, run, and experiment with JavaScript code

How to Use

  1. Write Code: Use the editor on the right.
  2. See Result: Use console.log() to show output.
  3. Run: Click Run Code or press Ctrl+Enter.
  4. Clear: Click Clear All or press Ctrl+L in editor.
  5. Errors: Look for red messages in the output.

Quick Code:

let name = "Student";
console.log("Welcome, " + name);
Ctrl+Enter Run  ·  Ctrl+L Clear
