✅ Good vs ❌ Bad JavaScript Practices

⚙️ Variables Best Practices

✅ Good Practice

// Use const for constants
const API_URL = 'https://api.example.com';

// Use let for variables
let userName = 'John';

// Use meaningful names
const totalPrice = 100;
let isLoggedIn = true;

Use const/let with meaningful names.

❌ Bad Practice

// Using var (function scope)
var API_URL = 'https://api.example.com';

// Vague names
let x = 100;
let flag = true;

// No type indication
let data = 'John';

Avoid var and vague variable names.

🔄 Comparison Best Practices

✅ Good Practice

// Use strict equality
if (userName === 'John') { }

// Check for null/undefined
if (value !== null && value !== undefined) { }

// Use optional chaining
const city = user?.address?.city;

Use strict equality and safe comparisons.

❌ Bad Practice

// Using == (type coercion)
if (userName == 'John') { }

// Loose comparison
if (value != null) { }

// No null checking
const city = user.address.city;

Avoid loose equality and unsafe access.

📝 Functions Best Practices

✅ Good Practice

// Use arrow functions
const add = (a, b) => a + b;

// Use default parameters
function greet(name = 'Guest') {
    return `Hello, ${name}`;
}

// Add comments
// Calculate total price
function calculateTotal(items) { }

Use modern syntax and add comments.

❌ Bad Practice

// No parameters validation
function greet(name) {
    return `Hello, ${name}`;
}

// Anonymous functions everywhere
arr.map(function(x) { return x * 2; })

// No comments
function x() { }

Avoid unclear code without documentation.

🎯 Error Handling Best Practices

✅ Good Practice

// Use try-catch
try {
    const data = JSON.parse(jsonString);
} catch (error) {
    console.error('Error:', error);
}

// Validate inputs
function divide(a, b) {
    if (b === 0) {
        throw new Error('Cannot divide by zero');
    }
    return a / b;
}

Always handle errors and validate inputs.

❌ Bad Practice

// No error handling
const data = JSON.parse(jsonString);

// Ignore errors
try { } catch (e) { }

// No input validation
function divide(a, b) {
    return a / b;
}

Avoid code that crashes without warning.

💡 Pro Tips

  • Use const by default, let when needed
  • Use template literals for string formatting
  • Use arrow functions for callbacks
  • Use console.log() to debug your code
  • Use meaningful function and variable names
