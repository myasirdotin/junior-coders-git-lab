✅ Modern JavaScript Best Practices (2026)

Write clean, maintainable, secure, and performant code • Good vs Bad Examples

⚙️ Variables & Declarations

✅ Good Practice

// Prefer const, use let only when reassigning
const API_BASE_URL = 'https://api.example.com/v2';
const MAX_RETRIES = 3;

let currentUser = null;
let isProcessing = false;

// Descriptive names + proper scoping
const userProfile = {
    id: 123,
    name: 'Yasir',
    preferences: { theme: 'dark' }
};

Use const by default. Choose meaningful, self-documenting names.

❌ Bad Practice

// Global variables + var
var data;
var temp = 'something';

// Poor naming
let x = 42;
let flag = true;
let userData = [];

Avoid var, global pollution, and vague names.

🔄 Comparisons & Conditionals

✅ Good Practice

if (userName === 'Yasir') { ... }

// Nullish coalescing & optional chaining
const username = user?.profile?.name ?? 'Guest';
const itemsCount = cart?.items?.length || 0;

// Early returns
if (!user) return;
if (!isValidEmail(email)) return;

Use strict equality, optional chaining, and nullish coalescing.

❌ Bad Practice

if (userName == 'Yasir') { ... }   // type coercion

const username = user.address.city;   // potential crash

if (value) { ... }   // truthy/falsy bugs

Avoid loose operators and unsafe property access.

📝 Functions & Modules

✅ Good Practice

// Arrow functions + defaults + destructuring
const calculateTotal = (items = [], taxRate = 0.18) => {
    const subtotal = items.reduce((sum, item) => sum + item.price, 0);
    return subtotal * (1 + taxRate);
};

// Pure functions when possible
const formatName = ({ firstName, lastName }) => 
    `${firstName} ${lastName}`.trim().toUpperCase();

Keep functions small, pure, and well-documented.

❌ Bad Practice

function process(data) {
    // 200 lines of code
}

arr.map(function(item) { return item * 2 }); // avoid anonymous

Avoid large functions and magic numbers.

🛡️ Error Handling & Validation

✅ Good Practice

try {
    const data = JSON.parse(jsonString);
    validateUser(data);
} catch (error) {
    console.error('Parsing failed:', error.message);
    showUserFriendlyError(error);
}

// Custom errors
class ValidationError extends Error {
    constructor(message) {
        super(message);
        this.name = 'ValidationError';
    }
}

❌ Bad Practice

const data = JSON.parse(jsonString); // crashes app

try { ... } catch(e) {} // silent fail

📋 Arrays Best Practices

✅ Good Practice

const activeUsers = users
    .filter(u => u.isActive && u.lastLogin > cutoffDate)
    .sort((a, b) => b.score - a.score)
    .slice(0, 10);

// Immutable operations
const newArray = [...oldArray, newItem];
const updated = items.map(item => item.id === targetId 
    ? { ...item, status: 'completed' } 
    : item);

❌ Bad Practice

for (let i = 0; i < arr.length; i++) { ... } // old style

users.push(newUser); // mutating shared state

🗃️ Objects & Data Structures

✅ Good Practice

const config = {
    api: { timeout: 5000, retries: 3 },
    ui: { theme: 'dark', language: 'en' }
};

// Destructuring + spread
const { api, ui } = config;
const updatedConfig = { ...config, ui: { ...ui, theme: 'light' } };

❌ Bad Practice

const obj = new Object();
obj['key'] = value;

⚡ Asynchronous Code

✅ Good Practice

async function fetchUserData(id) {
    try {
        const response = await fetch(`/api/users/${id}`);
        if (!response.ok) throw new Error('Failed to fetch');
        
        return await response.json();
    } catch (err) {
        console.error(err);
        throw err; // let caller handle
    }
}

// Promise.all for parallel requests
const [user, posts] = await Promise.all([
    fetchUser(id),
    fetchPosts(id)
]);

❌ Bad Practice

.then().then().then() // callback hell

async function bad() {
    const data = await fetchData();
    // forgot to handle errors
}

🚀 Performance & Optimization

✅ Good Practice

// Debounce / Throttle heavy operations
const debouncedSearch = debounce(searchHandler, 300);

// Use Map/Set for lookups
const userMap = new Map(users.map(u => [u.id, u]));

// Avoid memory leaks - clean event listeners
useEffect(() => {
    return () => window.removeEventListener(...);
}, []);

❌ Bad Practice

for (let i = 0; i < 10000; i++) { ... } // inside render

innerHTML += '<div>...</div>' // repeated DOM manipulation

💡 Pro Tips for Professional Code

  • Always use ESLint + Prettier
  • Write small, focused functions (< 30 lines ideally)
  • Prefer immutability when working with state
  • Use meaningful comments only when code isn't self-explanatory
  • Implement proper TypeScript for large projects
  • Test edge cases and validate all external inputs
  • Keep bundle size small — lazy load when possible
  • Document public APIs and complex business logic
