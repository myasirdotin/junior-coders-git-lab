What is a Function?

A **Function** is like a toaster. You put something in (Bread), the machine does some work (Toasting), and gives you something back (Toast!).

Bread (Input)
➡️
🍞 TOASTER
(The Function)
➡️
Toast (Output)

How to build your Machine

We use the keyword function, give it a name, and use curly braces for the instructions.

function sayHello(name) {
  console.log("Hello " + name);
}

// Start the machine!
sayHello("Ali");
  • Parameters (name): The inputs your machine needs.
  • Calling: Using the machine name with () to start it.

The "Return" Secret 📤

Some machines don't just "do" something, they **give back** a result using the return keyword.

return 5 + 5; // The machine gives back 10
