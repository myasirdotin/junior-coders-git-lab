Step 1: Learn — What is a Function?

Imagine you run a bakery. Every time a customer orders toast, you wouldn't build a new stove from scratch. You use a Toaster!

In JavaScript, a Function is a named block of code designed to do one specific job. You write the instructions once, and you can reuse it hundreds of times!

Step 2: See — Function Architecture

Pattern 1

1. Defining with Parameters

Parameters act as internal placeholders for data: 

function greet(studentName) {
    console.log("Welcome, " + studentName);
}
Pattern 2

2. Calling / Invoking

Use parentheses () and pass in real arguments: 

greet("Ali");   // Logs "Welcome, Ali"
greet("Sara");  // Logs "Welcome, Sara"
Pattern 3

3. Returning a Result

The return keyword delivers the answer back: 

function addFive(num) {
    return num + 5;
}
let total = addFive(10); // total is 15!

Q1: Which JavaScript keyword is used to declare a function?
Correct! In JavaScript, functions are declared with the function keyword.
Q2: What is the purpose of the return statement?
Correct! return delivers the computed value back to the caller.
Q3: How many parameters does function multiply(x, y, z) { ... } accept?
Correct! x, y, and z are 3 distinct parameter slots.
Q4: What happens if a function finishes without encountering a return statement?
Correct! By default, JavaScript functions return undefined if no return value is specified.
