Module 4: Conditional Logic

⏱ 55 minutes | Week 2

Overview

Make decisions in your code using conditional statements. Learn how to control the flow of your program based on different conditions and logical expressions.

📖 Reading Material

📚 What is Conditional Logic?

Conditional logic allows your code to make decisions. It executes different blocks of code based on whether a condition is true or false. Think of it like a fork in the road - your program chooses which path to take!

4.1 Comparison Operators

Comparison operators are used to compare values and return a boolean result:

let x = 10; let y = 5; // Equal to console.log(x == y); // false console.log(10 == "10"); // true (loose equality - type conversion!) // Strict equal (no type conversion) console.log(x === 10); // true console.log(10 === "10"); // false (different types) // Not equal console.log(x != y); // true console.log(x !== "10"); // true (strict not equal) // Greater than / Less than console.log(x > y); // true console.log(x < y); // false console.log(x >= 10); // true console.log(y <= 5); // true
⚠️ Common Mistake: Always use === (strict equality) instead of == (loose equality). The loose equality performs type coercion which can lead to unexpected results!

4.2 Logical Operators

Logical operators allow you to combine multiple conditions:

let age = 25; let hasLicense = true; let hasCar = false; // AND (&&) - both conditions must be true console.log(age >= 18 && hasLicense); // true console.log(hasLicense && hasCar); // false // OR (||) - at least one condition must be true console.log(hasCar || hasLicense); // true console.log(age < 18 || hasCar); // false // NOT (!) - reverses the boolean value console.log(!hasCar); // true console.log(!(age < 18)); // true // Real-world example let canDrive = age >= 18 && hasLicense; console.log(`Can drive: ${canDrive}`); // "Can drive: true" let needsRide = !hasCar || !hasLicense; console.log(`Needs a ride: ${needsRide}`); // "Needs a ride: true"
💡 Short-Circuit Evaluation: JavaScript stops evaluating as soon as it knows the result. For &&, if the first value is false, it returns that value. For ||, if the first value is true, it returns that value!

4.3 if/else Statements

The if statement executes code only when a condition is true:

// Basic if statement let temperature = 30; if (temperature > 25) { console.log("It's hot outside!"); } // if/else statement let score = 75; if (score >= 80) { console.log("You passed with distinction!"); } else { console.log("You passed, but can do better."); } // if/else if/else chain let grade = 85; if (grade >= 90) { console.log("Grade: A"); } else if (grade >= 80) { console.log("Grade: B"); } else if (grade >= 70) { console.log("Grade: C"); } else if (grade >= 60) { console.log("Grade: D"); } else { console.log("Grade: F - Failed"); } // Multiple conditions let hour = 14; let day = "Monday"; if (hour >= 9 && hour <= 17 && day !== "Saturday" && day !== "Sunday") { console.log("The store is open."); } else { console.log("The store is closed."); }
✅ Best Practice: Always use curly braces {} even for single-line if statements. It makes your code more readable and prevents bugs when you add more lines later!

4.4 Truthy and Falsy Values

In JavaScript, values can be "truthy" or "falsy" when evaluated in a boolean context:

// Falsy values (evaluate to false) // 1. false // 2. 0 (zero) // 3. "" (empty string) // 4. null // 5. undefined // 6. NaN // Everything else is truthy! let name = ""; if (!name) { console.log("Name is required!"); // This runs } let user = null; if (!user) { console.log("User not logged in"); // This runs } let items = []; if (items.length) { console.log("Has items"); } else { console.log("Cart is empty"); // This runs } // Useful pattern: default values let input = ""; let defaultValue = "Guest"; let userName = input || defaultValue; console.log(userName); // "Guest"

4.5 Ternary Operator

The ternary operator is a shorthand for simple if/else statements:

// Syntax: condition ? valueIfTrue : valueIfFalse let age = 20; let status = age >= 18 ? "Adult" : "Minor"; console.log(status); // "Adult" // Equivalent to: // let status; // if (age >= 18) { // status = "Adult"; // } else { // status = "Minor"; // } // More examples let price = 100; let discount = price > 50 ? 0.1 : 0; // 10% discount if price > 50 let finalPrice = price * (1 - discount); console.log(finalPrice); // 90 // Nested ternary (use sparingly!) let score = 85; let result = score >= 90 ? "A" : score >= 80 ? "B" : score >= 70 ? "C" : "F"; console.log(result); // "B" // With functions let isLoggedIn = true; let message = isLoggedIn ? greetUser() : promptLogin();
✅ When to use Ternary: Use ternary operators for simple, single-value assignments. For complex logic or multiple statements, stick with if/else for better readability!

4.6 Switch Statement

The switch statement is useful when you have many conditions to check against the same value:

let day = "Monday"; switch (day) { case "Monday": console.log("Start of the work week"); break; case "Tuesday": case "Wednesday": case "Thursday": console.log("Midweek day"); break; case "Friday": console.log("TGIF! Weekend is near"); break; case "Saturday": case "Sunday": console.log("Weekend! Time to relax"); break; default: console.log("Invalid day"); } // Switch with numbers let month = 3; let monthName; switch (month) { case 1: monthName = "January"; break; case 2: monthName = "February"; break; case 3: monthName = "March"; break; // ... more cases default: monthName = "Unknown"; } console.log(monthName); // "March"
⚠️ Don't forget break! Without break, execution will "fall through" to the next case. This is sometimes useful (like for grouping cases), but often a bug!
