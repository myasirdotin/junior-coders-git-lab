JavaScript Exercises

Practice your JavaScript skills with these structured exercises

How to Use

Click on any exercise to view the problem and start coding. Use the Playground to test your solutions!

Exercise Categories:

  • Beginner: Variables, data types, basic operators
  • Intermediate: Arrays, loops, functions, objects
  • Advanced: DOM manipulation, events, algorithms

1. Variables and Math

Create variables and perform basic arithmetic operations

Example:

let num1 = 15;
let num2 = 7;
let sum = num1 + num2;
console.log("Sum:", sum);

2. String Manipulation

Work with strings: concatenation, methods, and formatting

Example:

let name = "John";
let greeting = "Hello, " + name;
console.log(greeting);
console.log(name.toUpperCase());

3. Conditional Logic

Use if/else statements and comparison operators

Example:

let age = 20;
if (age >= 18) {
    console.log("You are an adult");
} else {
    console.log("You are a minor");
}

4. Arrays and Loops

Practice array methods and different types of loops

Example:

let colors = ["red", "blue", "green"];
for (let i = 0; i < colors.length; i++) {
    console.log(colors[i]);
}
colors.push("yellow");

5. Functions

Create and use functions with parameters and return values

Example:

function add(a, b) {
    return a + b;
}
let result = add(5, 3);
console.log("Result:", result);

6. Objects

Work with object properties, methods, and nested structures

Example:

let car = {
    brand: "Toyota",
    color: "blue",
    speed: 100
};
console.log(car.brand);
console.log(car.color);

7. DOM Manipulation

Learn to interact with HTML elements using JavaScript

Example:

let element = document.createElement("p");
element.textContent = "Hello HTML!";
element.style.color = "blue";
document.body.appendChild(element);

8. Events

Handle user interactions and events

Example:

let btn = document.createElement("button");
btn.textContent = "Click Me";
btn.addEventListener("click", function() {
    console.log("Button clicked!");
});
document.body.appendChild(btn);

9. Algorithms

Solve problems using logic and algorithmic thinking

Example:

function isEven(number) {
    return number % 2 === 0;
}
console.log(isEven(4));
console.log(isEven(7));
