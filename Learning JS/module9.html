Step 1: Learn — How Events Work

An Event is a signal that something has occurred on the webpage. Think of an Event Listener as a polite watchman stationed at a door: he stands patiently waiting until someone rings the bell (a click) or knocks (a keydown), and then immediately runs a predetermined action (the handler function).

🖱️

The click Event

Fires when the user clicks or taps a button, link, or card.

button.addEventListener("click", () => {
  console.log("Button clicked!");
});
⌨️

The input Event

Fires continuously as the user types characters into an <input> box.

input.addEventListener("input", (e) => {
  console.log(e.target.value);
});
🛑

e.preventDefault()

Prevents the browser's default behavior, like stopping a form from reloading the page:

form.addEventListener("submit", (e) => {
  e.preventDefault();
});

Step 2: See — Live Event Handlers

Example A: Interactive Counter Button 
let count = 0;
const counterBtn = document.getElementById("btn-count");
const displayEl = document.getElementById("count-display");

counterBtn.addEventListener("click", function() {
    count++;
    displayEl.textContent = "Total Clicks: " + count;
});
Example B: Real-Time Live Mirror with input event 
const nameInput = document.getElementById("student-name");
const previewText = document.getElementById("name-preview");

nameInput.addEventListener("input", (event) => {
    previewText.textContent = "Welcome, " + event.target.value;
});
