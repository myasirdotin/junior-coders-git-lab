What is an Event?

An **Event** is something that happens on your page. It's like a doorbell—when a user "rings" it (clicks, types, or moves the mouse), JavaScript "answers" the door!

🖱️

Click Event

User clicks a button.

⌨️

Key Event

User types a key.

The "Ears" of Code

We use an Event Listener to tell JavaScript to "listen" for a specific event on a specific element.

const btn = document.getElementById("myBtn");

btn.addEventListener("click", function() {
  alert("Button was clicked!");
});
