💡 JavaScript Tips & Reminders

📝 Before You Start Coding

🔔 Always Plan First

  • Understand what the code should do
  • Break the problem into smaller steps
  • Check existing JS files to understand the structure
  • Plan your variables and functions

📁 File Organization

  • Keep all JavaScript in a separate js/ folder
  • Link JS file before closing </body> tag
  • Use one main JS file for simple projects
  • Use comments to organize your code

⚙️ JavaScript Reminders

✅ Do This

  • Use const for values that won't change
  • Use let for values that will change
  • Add console.log() to debug your code
  • Use meaningful variable and function names
  • Use template literals: `Hello ${name}`
  • Use arrow functions for simple callbacks
  • Use strict equality (===) instead of (==)
  • Add comments to explain complex code

❌ Avoid This

  • Don't use var - use const or let instead
  • Don't forget to link your JS file in the HTML
  • Avoid global variables (keep code encapsulated)
  • Don't forget semicolons at the end of statements
  • Don't use == - use === instead
  • Don't use reserved words as variable names
  • Don't forget to call your functions

📦 Variables & Data Types

✅ Good Practice

// Constants - cannot change
const API_URL = 'https://api.com';
const MAX_ITEMS = 10;

// Variables - can change
let userName = 'John';
let isLoggedIn = false;

// Meaningful names
const totalPrice = 100;
let numberOfItems = 5;

❌ Bad Practice

// Using var (old way)
var API_URL = 'https://api.com';

// Vague names
let x = 100;
let data = 'John';

// No type indication
let value = 'John';

⚡ Functions Best Practices

📋 Function Checklist

  • ✅ Use meaningful function names
  • ✅ Keep functions small and focused
  • ✅ Use default parameters
  • ✅ Use arrow functions for simple functions
  • ❌ Don't make functions too long
  • ❌ Don't use vague names like doSomething()

🔤 Function Examples

// Regular function
function greet(name) {
    return 'Hello ' + name;
}

// Arrow function
const greet = (name) => 'Hello ' + name;

// With default parameter
function greet(name = 'Guest') {
    return 'Hello ' + name;
}

🔄 Arrays & Objects

📋 Array Methods

const numbers = [1, 2, 3, 4, 5];

// Map - transform each item
numbers.map(x => x * 2);  // [2, 4, 6, 8, 10]

// Filter - keep matching items
numbers.filter(x => x > 2);  // [3, 4, 5]

// Find - get first match
numbers.find(x => x > 3);  // 4

// Reduce - combine all items
numbers.reduce((sum, x) => sum + x, 0);  // 15

📋 Object Methods

const person = {
    name: 'John',
    age: 25,
    city: 'New York'
};

// Get keys
Object.keys(person);  // ['name', 'age', 'city']

// Get values
Object.values(person);  // ['John', 25, 'New York']

// Get entries
Object.entries(person);  // [['name', 'John'], ...]

// Destructuring
const { name, age } = person;

🎯 DOM Manipulation

📋 Common DOM Methods

// Select elements
document.getElementById('myId');
document.querySelector('.myClass');
document.querySelectorAll('.myClass');

// Change content
element.textContent = 'New text';
element.innerHTML = 'Bold';

// Change styles
element.style.color = 'red';
element.style.display = 'none';

// Add/remove classes
element.classList.add('active');
element.classList.remove('hidden');

// Add event listeners
element.addEventListener('click', () => {
    console.log('Clicked!');
});

🔍 Debugging Checklist

When Your JavaScript Doesn't Work:

  1. Check for typos in variable and function names
  2. Verify all brackets and braces are closed
  3. Check if JS file is linked correctly in HTML
  4. Open browser Developer Tools (F12) for errors
  5. Use console.log() to see values
  6. Check if you're calling the function correctly
  7. Verify the order of script loading
  8. Check for missing semicolons

🎯 Common Mistakes to Avoid

⚠️ Top 10 JavaScript Mistakes

  1. Using var - Use const/let instead
  2. Using == instead of === - Use strict equality
  3. Not declaring variables - Always use const/let
  4. Forgetting to call functions - Functions need () to run
  5. Not checking for null/undefined - Use optional chaining (?.)
  6. Not using console.log() - Debug with logging
  7. Using global variables - Keep code encapsulated
  8. Not handling errors - Use try-catch blocks
  9. Mutating const variables - Use const for read-only
  10. Not understanding scope - Know let vs const vs var
