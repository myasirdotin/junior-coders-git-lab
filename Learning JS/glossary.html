JavaScript Glossary

Quick reference for essential JavaScript terms

A
Argument
The actual value passed to a function when it is called. Example: in greet("Alice"), "Alice" is the argument.
Array
An ordered collection of values stored in a single variable. Created with square brackets: let fruits = ["apple", "banana"]. Each item has a numeric index starting from 0.
Arrow Function
A shorter syntax for writing functions using =>. Example: const add = (a, b) => a + b. Arrow functions don't have their own this binding.
Assignment Operator
The = operator that assigns a value to a variable. Example: let x = 10. Not to be confused with === (equality comparison).
B
Boolean
A data type with only two possible values: true or false. Used in conditional logic and comparisons.
Break
A statement that exits a loop or switch statement immediately. Example: if (found) break;
Block Scope
Variables declared with let or const inside curly braces {} are only accessible within that block.
C
Callback Function
A function passed as an argument to another function, to be called later. Example: array.forEach(item => console.log(item)).
Closure
A function that retains access to variables from its outer (enclosing) scope, even after the outer function has returned. Used for data privacy and factory patterns.
Concatenation
Joining two or more strings together using the + operator or template literals. Example: "Hello" + " " + "World".
Conditional
A statement that executes different code based on whether a condition is true or false. Includes if, else if, else, and switch.
Console
A built-in object for logging output. console.log() prints values, console.error() prints errors, console.warn() prints warnings.
const
A keyword for declaring variables that cannot be reassigned. The value itself can still be mutated if it's an object or array. Example: const PI = 3.14159.
D
Data Type
The classification of data. JavaScript has primitive types: string, number, boolean, undefined, null, symbol, bigint, and the object type.
Destructuring
A syntax for extracting values from arrays or properties from objects into variables. Example: const { name, age } = person.
DOM (Document Object Model)
A programming interface for HTML documents. It represents the page as a tree of objects that JavaScript can read and manipulate to change content, structure, and styling dynamically.
E
Event
An action that occurs in the browser, such as a click, keypress, or page load. JavaScript can listen for events using addEventListener().
Event Delegation
A pattern where you add a single event listener to a parent element instead of multiple listeners on child elements. Works because events "bubble up" through the DOM.
Event Listener
A function that waits for a specific event to occur on an element. Added with element.addEventListener("click", handler).
Expression
Any piece of code that produces a value. Examples: 5 + 3, "hello".toUpperCase(), x > 10.
F
Falsy
Values that evaluate to false in a boolean context: false, 0, "", null, undefined, and NaN. Everything else is "truthy".
forEach()
An array method that executes a callback function for each element. Example: arr.forEach(item => console.log(item)). Cannot use break inside it.
Function
A reusable block of code that performs a specific task. Declared with function name() {} or as an arrow function const name = () => {}.
H
Higher-Order Function
A function that takes another function as an argument or returns a function. Examples: map(), filter(), reduce().
Hoisting
JavaScript's behavior of moving function declarations (but not expressions) to the top of their scope before execution. This allows calling a function before it's defined in the code.
I
Immutable
Cannot be changed after creation. Strings in JavaScript are immutable - string methods return new strings rather than modifying the original.
Index
The numeric position of an element in an array or character in a string. Starts at 0. Example: in ["a","b","c"], "b" is at index 1.
Iteration
The process of repeating a set of instructions. Each pass through a loop is one iteration.
J
JSON (JavaScript Object Notation)
A text format for storing and exchanging data. Looks like JavaScript objects but uses double quotes for keys. Parsed with JSON.parse(), created with JSON.stringify().
L
let
A keyword for declaring variables that can be reassigned. Block-scoped. Preferred over var. Example: let count = 0; count++;
localStorage
A Web API that stores key-value pairs in the browser with no expiration. Data persists even after the browser is closed. Use setItem() and getItem().
Loop
A control structure that repeats a block of code. Types include for, while, do...while, for...of, and for...in.
M
Method
A function that belongs to an object. Example: console.log() is a method of the console object. "hello".toUpperCase() is a string method.
Modulus (%)
An operator that returns the remainder of a division. Example: 10 % 3 returns 1. Commonly used to check if a number is even: n % 2 === 0.
N
NaN (Not a Number)
A special value indicating an invalid number result. Example: "hello" * 2 returns NaN. Check with isNaN() or Number.isNaN().
null
A value that represents the intentional absence of any value. Different from undefined, which means a variable was declared but not assigned.
O
Object
A collection of key-value pairs (properties and methods). Created with curly braces: let obj = { name: "John", age: 30 }.
Operator
A symbol that performs an operation on values. Includes arithmetic (+, -), comparison (===, >), logical (&&, ||), and assignment (=).
Optional Chaining (?.)
A syntax that safely accesses nested properties without errors if an intermediate value is null/undefined. Example: user?.address?.city returns undefined instead of throwing.
P
Parameter
A variable listed in a function's definition. When the function is called, the parameter receives the argument's value. Example: in function greet(name), name is the parameter.
Property
A key-value pair in an object. Example: in {name: "John"}, name is the property key and "John" is the value.
R
Return
A statement that sends a value back from a function and stops its execution. Example: return a + b;. Functions without return give undefined.
Rest Parameters (...)
A syntax that collects remaining arguments into an array. Example: function sum(...nums) { return nums.reduce((a,b) => a+b, 0); }
S
Scope
The area of code where a variable is accessible. JavaScript has global scope, function scope, and block scope (with let/const).
Spread Operator (...)
A syntax that expands an iterable (array/object) into individual elements. Example: [...arr1, ...arr2] merges arrays; {...obj1, ...obj2} merges objects.
String
A data type representing text. Created with quotes ("hello", 'hello') or backticks (`hello` for template literals). Strings are immutable.
Strict Equality (===)
A comparison operator that checks both value and type without type coercion. 1 === "1" is false. Always prefer over ==.
T
Template Literal
A string wrapped in backticks (`) that supports embedded expressions with ${} and multi-line text. Example: `Hello, ${name}!`
Ternary Operator
A shorthand for if/else that returns a value: condition ? valueIfTrue : valueIfFalse. Example: let status = age >= 18 ? "adult" : "minor".
this
A keyword that refers to the object that is executing the current method. In arrow functions, this is inherited from the enclosing scope.
Truthy
Any value that evaluates to true in a boolean context. All values are truthy except the falsy ones (false, 0, "", null, undefined, NaN).
typeof
An operator that returns a string indicating the type of a value. Example: typeof 42 returns "number", typeof "hi" returns "string".
U
undefined
A value automatically assigned to variables that have been declared but not yet assigned a value. Also the return value of functions without a return statement.
V
Variable
A named container for storing data values. Declared with let (reassignable) or const (not reassignable). Avoid var in modern JavaScript.
