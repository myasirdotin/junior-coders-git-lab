Module 1: Variables & Data Types

⏱ 45 minutes | Week 1

Overview

Learn how to store and manage data using variables. Understand different data types in JavaScript and how to work with them effectively.

📖 Reading Material

📚 What is a Variable?

A variable is like a labeled container that stores a value. Think of it as a box with a name tag - you can put something inside, take it out, or replace it with something else.

💡 Key Point: Variables in JavaScript are dynamically typed, meaning you don't need to declare what type of data the variable will hold. JavaScript figures it out automatically!

1.1 Declaring Variables

JavaScript provides three ways to declare variables:

// let - can be reassigned let name = "Ali"; name = "Ahmed"; // This is allowed // const - cannot be reassigned (constant) const pi = 3.14159; // pi = 3.14; // ERROR! Cannot reassign // var - old way (avoid using) var oldVariable = "deprecated";
✅ Best Practice: Always use const by default. Only use let when you know the value will change. Avoid var entirely!

1.2 Data Types

JavaScript has several built-in data types:

// String - text data let greeting = "Hello, World!"; // Number - integers and decimals let age = 25; let price = 19.99; // Boolean - true or false let isStudent = true; let hasLicense = false; // Undefined - variable declared but not assigned let notDefined; console.log(notDefined); // undefined // Null - intentional absence of value let emptyValue = null;
⚠️ Common Mistake: Don't confuse undefined and null. undefined means "not assigned yet", while null means "intentionally empty".

1.3 Checking Data Types

Use the typeof operator to check what type a variable is:

let name = "Sara"; console.log(typeof name); // "string" let age = 20; console.log(typeof age); // "number" let isActive = true; console.log(typeof isActive); // "boolean"
