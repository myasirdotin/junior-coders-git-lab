Step 1: Learn — What is a Variable?

When you play a math game, the computer needs to remember your score. When you register at a school library, the system needs to remember your name. In computer science, a Variable is a labeled storage container inside computer memory (RAM).

📦

The Reopenable Box: let

Use let when the value is expected to change over time — like a student's age, a book checkout counter, or today's temperature.

let age = 13;
age = 14; // Allowed!
🔒

The Sealed Vault: const

Use const for values that must remain fixed forever — like your national ID, the speed of light, or the annual Zakat rate (2.5%).

const zakatRate = 0.025;
// zakatRate = 0.05; ❌ Error!

Fundamental JavaScript Data Types

🧵 String (Text)

Enclosed in single or double quotes.

"Al-Hikmah School"

🔢 Number

Integers or decimals. Never in quotes.

42 • 99.50

✅ Boolean (Logic)

True or False flag.

true • false

🔍 typeof Inspector

Checks the type of any variable.

typeof "Ali" // "string"

Step 2: See — Worked Examples in Action

Study these 3 clear examples showing variable declaration, mathematical computation, and data type inspection.

📋 Example A: Student Admission Record 
// 1. Declare fixed school details with const
const schoolName = "Al-Hikmah Academy";
const studentId = 10482;

// 2. Declare editable student status with let
let studentName = "Amina Rasool";
let gradeLevel = 8;
let isEnrolled = true;

console.log("School:", schoolName);
console.log("Student:", studentName, "| Grade:", gradeLevel);
💰 Example B: Ethical Charity & Zakat Calculation 
// Zakat rate is a fixed ethical principle: 2.5%
const zakatRate = 0.025;

let annualSavings = 4000; // in dollars or local currency
let zakatDue = annualSavings * zakatRate;

console.log("Total Savings:", annualSavings);
console.log("Zakat Due (2.5%):", zakatDue); // Output: 100
🔍 Example C: Verifying Types with typeof 
console.log(typeof "Junior Coders"); // "string"
console.log(typeof 250);             // "number"
console.log(typeof true);            // "boolean"
console.log(typeof (10 > 5));         // "boolean"
