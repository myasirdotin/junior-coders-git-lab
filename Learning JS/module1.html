The Memory Vault!

JavaScript is the brain! Let's learn how to remember things using variables. 🧠

The "Labeled Box" Analogy

A **Variable** is like a box with a label. You put something inside (data), and give the box a name (label) so you can find it later!

📦

let name = "Ali";

The "let" box can be opened and changed later.

🔒

const age = 12;

The "const" vault is locked! It never changes.

What's Inside the Box?

JavaScript can store different kinds of "stuff". These are called **Data Types**.

Strings 🧵

Just text! Always goes inside quotes.

"Hello Junior Coders!"

Numbers 🔢

Whole numbers or decimals. No quotes needed!

42 or 19.99

Booleans ✅

Simple Yes/No or True/False.

true or false

The Variable Formula

let score = 10;
  1. Keyword (let/const): Are we making a box or a vault?
  2. Name (score): The label on our box.
  3. Assignment (=): Put the stuff inside!
  4. Value (10): The actual data we are storing.
