Step 1: Learn — What is a Loop?

Imagine running laps around a sports field. You don't say: "Run lap 1. Run lap 2. Run lap 3..."
Instead, you keep a counter in your mind: Start at Lap 1, keep running as long as Lap ≤ 5, and add 1 lap every time you cross the finish line.

1. Start
(let i = 1)
➔
2. Keep Going While?
(i ≤ 5)
➔
3. Step Increment
(i++)
⚠️ The Infinite Loop Hazard:

If you forget to update your counter (e.g. leaving out i++), the loop will run forever and freeze the browser tab! Always ensure your loop moves closer to its stop condition.

Step 2: See — Code in Action

Example A

Counting Up 1 to 5

for (let i = 1; i <= 5; i++) {
    console.log("Count:", i);
}
Example B

Stepping Through an Array

let students = ["Ali", "Sara", "Zayd"];
for (let i = 0; i < students.length; i++) {
    console.log(students[i]);
}
Example C

While Loop Condition

let energy = 3;
while (energy > 0) {
    console.log("Active!");
    energy--;
}

Step 6: Quiz — 5 Loop Checkpoints

Score 80% or higher to earn the Loop Master quiz badge (+30 XP)!

Q1: How many times will this loop run: for (let i = 0; i < 3; i++)?
Correct! It runs for i = 0, i = 1, and i = 2 (3 iterations total). When i reaches 3, 3 < 3 is false.
Q2: What does the shorthand expression i++ do?
Correct! i++ is the increment operator adding 1 each round.
Q3: What dangerous error occurs if a loop's condition never becomes false?
Correct! An infinite loop never terminates, consuming CPU until execution times out.
Q4: If an array has length === 4, what is the index of the final element?
Correct! Because arrays start at index 0, the last index is always length - 1 (4 - 1 = 3).
Q5: Which loop is ideal when you don't know the exact number of iterations beforehand?
Correct! A while loop continues dynamically while an external condition remains true.
