The "For" Loop

This is the most common loop. It has 3 parts: Start, Stop, and Step.

for (let i = 0; i < 5; i++) {
  console.log("Running lap " + i);
}
  • Start: i = 0
  • Stop: i < 5
  • Step: i++ (Add 1)

The "While" Loop

The while loop is simpler. It just keeps going **while** something is true.

while (battery > 0) { ... }

"Keep playing music while the battery is not empty!"
