Step 1: Learn — The 3 Families of Operators

In mathematics and programming, an Operator is a special character or keyword that takes one or more values (called operands) and computes a result.

➕

1. Arithmetic Operators

Used to perform calculations:

  • + Addition (and string joining!)
  • - Subtraction
  • * Multiplication
  • / Division
  • % Modulo (remainder after division: 10 % 3 = 1)
⚖️

2. Comparison Operators

Compares two values and always evaluates to true or false:

  • === Strict equality (checks value AND type!)
  • !== Strict inequality (not equal)
  • > Greater than • < Less than
  • >= Greater than or equal • <= Less or equal
🧩

3. Logical Operators

Combines multiple Boolean conditions:

  • && AND: True only if BOTH conditions are true
  • || OR: True if AT LEAST ONE condition is true
  • ! NOT: Flips true to false, or false to true
💡 Junior Coders Golden Rule: Always Use === Instead of == In JavaScript, loose equality (==) tries to secretly convert types (e.g. 5 == "5" is true). Strict equality (===) does honest, accurate comparisons without sneaky conversion. Craftsmen always use ===!

Step 2: See — Concrete Code Examples

Example A: Arithmetic & Modulo Even/Odd Checker 
// Modulo (%) gives the remainder of division
const rollNumber = 14;
const isEven = (rollNumber % 2) === 0;

console.log("Remainder when divided by 2:", rollNumber % 2); // 0
console.log("Is roll number even?", isEven);                 // true
Example B: Strict Equality vs Loose Equality 
const userPIN = 1234;
const inputStr = "1234";

console.log(userPIN === inputStr); // false (one is number, one is string!)
console.log(userPIN === 1234);     // true (both are identical numbers)
Example C: Science Fair Admission Criteria (Logical AND / OR) 
const hasParentPermission = true;
const hasCompletedProject = true;
const hasOverdueFines = false;

// Must have permission AND project completed AND no overdue fines:
const canParticipate = hasParentPermission && hasCompletedProject && !hasOverdueFines;

console.log("Student cleared for Science Fair:", canParticipate); // true
