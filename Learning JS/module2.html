Module 2: Math Operations

⏱ 40 minutes | Week 1

Overview

Master arithmetic operations and mathematical expressions in JavaScript. Learn how to perform calculations and use the Math object.

📖 Reading Material

📚 Arithmetic Operators

JavaScript supports all standard mathematical operations.

// Basic operators let sum = 10 + 5; // 15 (addition) let diff = 10 - 5; // 5 (subtraction) let product = 10 * 5; // 50 (multiplication) let quotient = 10 / 5; // 2 (division) // Special operators let remainder = 10 % 3; // 1 (modulus) let power = 2 ** 3; // 8 (exponentiation)
💡 PEMDAS: Parentheses → Exponents → Multiplication/Division → Addition/Subtraction

2.1 The Math Object

// Math constants console.log(Math.PI); // 3.14159... console.log(Math.E); // 2.71828... // Rounding console.log(Math.round(4.7)); // 5 console.log(Math.floor(4.7)); // 4 console.log(Math.ceil(4.2)); // 5 // Other useful methods console.log(Math.max(1, 5, 3)); // 5 console.log(Math.min(1, 5, 3)); // 1 console.log(Math.sqrt(16)); // 4 console.log(Math.abs(-5)); // 5 // Random numbers console.log(Math.random()); // 0 to <1 // Random integer between min and max let randomInt = (min, max) => Math.floor(Math.random() * (max - min + 1)) + min; console.log(randomInt(1, 6)); // Random 1-6
✅ Pro Tip: Use modulus (%) to check if a number is even: num % 2 === 0
