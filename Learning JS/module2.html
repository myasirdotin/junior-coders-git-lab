The Comparison Test ⚖️

Sometimes we need to ask questions like "Is this bigger than that?" or "Is this the same?". The answer is always true or false.

Is 10 greater than 5? 10 > 5 // true
Is 3 less than 1? 3 < 1 // false
Is it exactly the same? "Apple" === "Apple" // true

Super Logic! 🧠

We can combine questions using AND and OR.

&& (AND)

Both MUST be true.
"I want pizza AND ice cream."

|| (OR)

Only one needs to be true.
"I want pizza OR burgers."
