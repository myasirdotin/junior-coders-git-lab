Step 1: Learn — The Fork in the Road

By default, computer programs run step-by-step from top to bottom. But real life requires choices: "If it is raining, take an umbrella; otherwise, wear sunglasses." A Conditional statement allows your program to branch in different directions based on true/false conditions.

🔀

The Basic if / else

Evaluates a single condition inside parentheses ( ). If true, runs block A. Otherwise runs block B.

if (score >= 60) {
  result = "Pass";
} else {
  result = "Retake";
}
🪜

The Multi-Branch else if

Used when testing a sequence of possible conditions in priority order (e.g. Grades A, B, C, or Needs Improvement).

if (score >= 90) grade = "A";
else if (score >= 80) grade = "B";
else grade = "C";
🎛️

The Multi-Option switch

Ideal when matching an exact discrete value (like days of the week, traffic light colors, or user roles).

switch (role) {
  case "teacher": ...; break;
  default: ...;
}

Step 2: See — Worked Real-World Examples

Example A: Academic Distinction Tiering 
const examScore = 94;
let honorLevel = "";

if (examScore >= 90) {
    honorLevel = "Mumtaz (High Distinction)";
} else if (examScore >= 75) {
    honorLevel = "Jayyid Jiddan (Very Good)";
} else if (examScore >= 60) {
    honorLevel = "Pass";
} else {
    honorLevel = "Additional Study Required";
}

console.log("Result:", honorLevel);
Example B: Smart Greenhouse Water Conservation System 
const soilMoisturePercent = 28;
const isRainingOutside = false;
let irrigationValve = false;

// Water crops only when soil is dry AND not raining
if (soilMoisturePercent < 35 && !isRainingOutside) {
    irrigationValve = true;
    console.log("Valve OPEN: Watering community olive trees.");
} else {
    irrigationValve = false;
    console.log("Valve CLOSED: Conserving precious water resources.");
}
