The "If/Else" Story

Every decision in a computer starts with the word **IF**. It's like following a set of instructions for your day.

Is it Raining? 🌧️
YES (if)
Take Umbrella 🌂
NO (else)
Wear Sunglasses 😎

How to write it in Code

We use parentheses ( ) for the question and curly braces { } for the action.

if (isRaining) {
  console.log("Get your umbrella!");
} else {
  console.log("Enjoy the sun!");
}

The "Else If" (More Choices)

What if there are more than two choices? We use else if to add another check in the middle.

1. If it's morning... Eat Breakfast

2. Else if it's noon... Eat Lunch

3. Else (nothing else worked)... Eat Dinner
