Module 3: String Manipulation

⏱ 50 minutes | Week 2

Overview

Learn to work with text data in JavaScript. Master string concatenation, template literals, and essential string methods to manipulate and format text effectively.

📖 Reading Material

📚 What are Strings?

A string is a sequence of characters used to represent text. In JavaScript, strings are wrapped in quotes - either single ('), double ("), or backticks (`).

3.1 String Concatenation

Concatenation means joining two or more strings together:

// Using the + operator let firstName = "John"; let lastName = "Doe"; let fullName = firstName + " " + lastName; console.log(fullName); // "John Doe" // Using the += operator let greeting = "Hello"; greeting += " World!"; console.log(greeting); // "Hello World!" // Concatenating with numbers let message = "I am " + 25 + " years old"; console.log(message); // "I am 25 years old"
⚠️ Common Mistake: When concatenating numbers, JavaScript converts them to strings. "5" + 3 equals "53", not 8!

3.2 Template Literals

Template literals (introduced in ES6) provide an easier way to work with strings using backticks (`) and embedded expressions:

// Basic template literal let name = "Alice"; let greeting = `Hello, ${name}!`; console.log(greeting); // "Hello, Alice!" // Multi-line strings (no need for \n!) let message = `This is line 1 This is line 2 This is line 3`; console.log(message); // Embedding expressions let price = 99.99; let tax = 8.5; let total = `$${price} + $${tax} = $${price + tax}`; console.log(total); // "$99.99 + $8.5 = $108.49" // Calling functions inside template literals let getName = () => "Bob"; console.log(`Hello, ${getName()}!`); // "Hello, Bob!"
✅ Best Practice: Use template literals instead of concatenation for cleaner, more readable code, especially when working with variables or multi-line strings!

3.3 String Methods

JavaScript provides many built-in methods to manipulate strings:

let text = " Hello, JavaScript World! "; // Getting string length console.log(text.length); // 28 (includes spaces) // Changing case console.log(text.toUpperCase()); // " HELLO, JAVASCRIPT WORLD! " console.log(text.toLowerCase()); // " hello, javascript world! " // Trimming whitespace console.log(text.trim()); // "Hello, JavaScript World!" console.log(text.trimStart()); // "Hello, JavaScript World! " console.log(text.trimEnd()); // " Hello, JavaScript World!" // Finding substrings let sentence = "The quick brown fox"; console.log(sentence.indexOf("quick")); // 4 console.log(sentence.includes("brown")); // true console.log(sentence.startsWith("The")); // true console.log(sentence.endsWith("fox")); // true // Extracting parts of strings console.log(sentence.slice(4, 9)); // "quick" console.log(sentence.substring(4, 9)); // "quick" console.log(sentence.substr(4, 5)); // "quick" // Replacing content console.log(sentence.replace("fox", "dog")); // "The quick brown dog" console.log(sentence.replaceAll("o", "0")); // "The quick br0wn f0x" // Splitting strings into arrays let fruits = "apple,banana,cherry"; console.log(fruits.split(",")); // ["apple", "banana", "cherry"]
💡 Key Point: Strings are immutable in JavaScript. String methods don't change the original string - they return a new string!

3.4 Accessing Characters

You can access individual characters in a string using bracket notation:

let word = "Hello"; // Using bracket notation console.log(word[0]); // "H" console.log(word[1]); // "e" console.log(word[word.length - 1]); // "o" (last character) // Using charAt() method console.log(word.charAt(0)); // "H" console.log(word.charAt(4)); // "o" // Using charCodeAt() for ASCII values console.log(word.charCodeAt(0)); // 72 (ASCII code for 'H')
