What is an Array?

An **Array** is like a treasure chest with different compartments. Instead of having 5 separate boxes for your toys, you have one big chest with 5 slots!

How to write a List

We use square brackets [ ] and separate items with commas.

let fruits = ["Apple", "Banana", "Grape"];

// Get the first item
console.log(fruits[0]); // Returns "Apple"

Managing your Chest

Push ➕

Add an item to the **end** of the list.

fruits.push("Orange");

Pop ➖

Remove the **last** item from the list.

fruits.pop();
