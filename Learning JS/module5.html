Module 5: Arrays

⏱ 60 minutes | Week 3

Overview

Store and manage collections of data using arrays. Learn how to add, remove, and manipulate array elements, and use powerful array methods to transform your data.

📖 Reading Material

📚 What is an Array?

An array is a special variable that can hold multiple values in a single variable. Think of it as a list or collection of items. Each item in an array is called an element, and each element has a numeric index (position) starting from 0.

5.1 Creating Arrays

Arrays are created using square bracket notation:

// Empty array let emptyArray = []; // Array with values let fruits = ["apple", "banana", "cherry"]; let numbers = [1, 2, 3, 4, 5]; let mixed = [1, "hello", true, null, { name: "John" }]; // Accessing array elements console.log(fruits[0]); // "apple" console.log(fruits[1]); // "banana" console.log(fruits[2]); // "cherry" console.log(fruits.length); // 3 // Accessing last element console.log(fruits[fruits.length - 1]); // "cherry" // Modifying array elements fruits[1] = "blueberry"; console.log(fruits); // ["apple", "blueberry", "cherry"]
⚠️ Common Mistake: Array indices start at 0, not 1! The first element is at index 0, and the last element is at index length - 1.

5.2 Adding and Removing Elements

JavaScript provides several methods to add and remove elements from arrays:

let fruits = ["apple", "banana"]; // push() - add to end fruits.push("cherry"); console.log(fruits); // ["apple", "banana", "cherry"] // pop() - remove from end let removed = fruits.pop(); console.log(removed); // "cherry" console.log(fruits); // ["apple", "banana"] // unshift() - add to beginning fruits.unshift("orange"); console.log(fruits); // ["orange", "apple", "banana"] // shift() - remove from beginning let first = fruits.shift(); console.log(first); // "orange" console.log(fruits); // ["apple", "banana"] // splice() - add/remove at specific position let colors = ["red", "green", "blue"]; colors.splice(1, 0, "yellow"); // Add at index 1 console.log(colors); // ["red", "yellow", "green", "blue"] colors.splice(2, 1); // Remove 1 element at index 2 console.log(colors); // ["red", "yellow", "blue"]
💡 Memory Tip: push and pop work at the end of the array. unshift and shift work at the beginning. Think: "unshift" and "shift" both start with "s" for "start"!

5.3 Array Methods

JavaScript arrays come with many powerful built-in methods:

let numbers = [1, 2, 3, 4, 5]; // indexOf() - find position of element console.log(numbers.indexOf(3)); // 2 console.log(numbers.indexOf(10)); // -1 (not found) // includes() - check if element exists console.log(numbers.includes(3)); // true console.log(numbers.includes(10)); // false // slice() - copy portion of array (doesn't modify original) let subset = numbers.slice(1, 4); console.log(subset); // [2, 3, 4] console.log(numbers); // [1, 2, 3, 4, 5] (unchanged) // concat() - combine arrays let arr1 = [1, 2]; let arr2 = [3, 4]; let combined = arr1.concat(arr2); console.log(combined); // [1, 2, 3, 4] // join() - convert array to string let fruits = ["apple", "banana", "cherry"]; console.log(fruits.join(", ")); // "apple, banana, cherry" console.log(fruits.join(" - ")); // "apple - banana - cherry" // reverse() - reverse array order let nums = [1, 2, 3]; nums.reverse(); console.log(nums); // [3, 2, 1] // sort() - sort array (as strings by default!) let letters = ["b", "a", "c"]; letters.sort(); console.log(letters); // ["a", "b", "c"] // For numbers, use compare function let unsorted = [10, 5, 20, 1]; unsorted.sort((a, b) => a - b); // Ascending console.log(unsorted); // [1, 5, 10, 20] unsorted.sort((a, b) => b - a); // Descending console.log(unsorted); // [20, 10, 5, 1]

5.4 Finding Elements with filter() and find()

Two powerful methods for searching arrays:

let users = [ { name: "Alice", age: 25 }, { name: "Bob", age: 30 }, { name: "Charlie", age: 25 }, { name: "Diana", age: 35 } ]; // filter() - returns ALL matching elements as new array let youngUsers = users.filter(user => user.age === 25); console.log(youngUsers); // [{ name: "Alice", age: 25 }, { name: "Charlie", age: 25 }] let over30 = users.filter(user => user.age > 30); console.log(over30); // [{ name: "Diana", age: 35 }] // find() - returns FIRST matching element let firstYoung = users.find(user => user.age === 25); console.log(firstYoung); // { name: "Alice", age: 25 } let notFound = users.find(user => user.age === 100); console.log(notFound); // undefined // findIndex() - returns index of first match let index = users.findIndex(user => user.name === "Bob"); console.log(index); // 1 // some() - check if ANY element matches let hasTeenager = users.some(user => user.age < 20); console.log(hasTeenager); // false // every() - check if ALL elements match let allAdults = users.every(user => user.age >= 18); console.log(allAdults); // true
✅ Pro Tip: Use filter() when you want all matches, find() when you only need the first match. Both methods create new arrays/values without modifying the original!

5.5 Multi-dimensional Arrays

Arrays can contain other arrays, creating multi-dimensional structures:

// 2D array (array of arrays) let matrix = [ [1, 2, 3], [4, 5, 6], [7, 8, 9] ]; console.log(matrix[0]); // [1, 2, 3] console.log(matrix[0][1]); // 2 console.log(matrix[2][2]); // 9 // Iterating over 2D array for (let i = 0; i < matrix.length; i++) { for (let j = 0; j < matrix[i].length; j++) { console.log(matrix[i][j]); } } // Array of objects let students = [ { name: "Alice", grades: [90, 85, 92] }, { name: "Bob", grades: [78, 82, 88] } ]; console.log(students[0].grades[1]); // 85
