Lessons

Take them in order. Tick “Mark complete” at the end of a lesson and it is marked here.

  1. 1 Variables & MemoryMaster labeled memory boxes with let, const, strings, numbers, and booleans.
  2. 2 Operators & MathCalculate totals, compare values with strict equality (===), and combine boolean logic.
  3. 3 Conditionals & BranchingTeach your code to make intelligent decisions using if, else if, and switch.
  4. 4 Functions & Logic UnitsPackage code into reusable mini-machines with parameters, return values, and arrow functions.
  5. 5 Arrays & Ordered ListsStore multiple items in one place with zero-based indexing, push(), pop(), and length.
  6. 6 Loops & AutomationAutomate repetitive calculations. Traverse arrays, accumulate sums, and write safe for and while loops.
  7. 7 DOM & Element ControlConnect JS to HTML. Select elements by ID, update textContent securely, and restyle live elements.
  8. 8 Objects & MethodsGroup data into structured dossiers using key-value pairs, dot notation, and methods with this.
  9. 9 Events & User ActionsMake websites come alive. Listen for click, input, keystrokes, and manage real-time UI states.
