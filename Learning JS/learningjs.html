Class 7 JavaScript Practice

JavaScript Exercises for Students

These exercises are made for Class 7 students. Start with the easier ones and try to complete them step by step. Use the browser console or write the code in a new HTML file with a script tag.

Exercise 1

Hello, Student!

Create a variable called studentName and store your name. Then print: Hello, [your name]! using console.log().

Hint: Use a variable, then combine it with a string in one message.

Exercise 2

Simple Calculator

Create two numbers and add, subtract, multiply, and divide them. Show the answer in the console.

Hint: Start with let num1 = 10; and let num2 = 5;. Then use +, -, *, and /.

Exercise 3

Pass or Fail

Write a program that stores a mark. If the mark is 50 or above, print Pass. Otherwise print Fail.

Hint: Use an if statement and check whether the mark is greater than or equal to 50.

Exercise 4

Even or Odd

Ask the user for a number and tell them if it is even or odd.

Hint: Use the remainder operator: if number % 2 === 0, it is even.

Exercise 5

Button Click Challenge

Create a button in HTML and when the button is clicked, change the text or background color using JavaScript.

Hint: Use document.getElementById() and add an event listener for click.

Exercise 6

Counter Game

Create a counter that starts at 0. When you click a button, it increases by 1. Show the value on the page.

Hint: Keep a variable for the count, then update it every time the button is clicked.

How to complete these exercises:

  1. Read the task carefully.
  2. Write the JavaScript in a file or in the browser console.
  3. Run the program and check the output.
  4. If it does not work, check for spelling mistakes and missing brackets.
  5. Try changing one value and see what changes.

Bonus Challenge

Mini Project: Student Dashboard

Challenge 1

Create a small card with student name, class, and marks. Use JavaScript to show the total and average marks.

Challenge 2

Write a quiz score checker: if the score is over 80, show "Excellent"; if over 50, show "Good"; otherwise show "Keep Practising".

Challenge 3

Create a simple button that changes the text from "Start" to "Completed" when clicked.

Sample starter code

let studentName = "Ali";
let score = 78;

if (score >= 80) {
  console.log("Excellent");
} else if (score >= 50) {
  console.log("Good");
} else {
  console.log("Keep Practising");
}

console.log("Hello, " + studentName + "!");
