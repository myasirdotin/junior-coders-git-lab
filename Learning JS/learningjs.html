1. Variables & Data Types

Variables are containers for storing data values. JavaScript has several data types:

What is a Variable? A variable is a named container that holds a value. You can declare variables using let, const, or var.
// Declaring variables let name = "John"; // String let age = 25; // Number let isStudent = true; // Boolean const city = "New York"; // Constant (cannot be changed) console.log(name); // Output: John console.log(age); // Output: 25 console.log(isStudent); // Output: true
Data Types:
  • String: Text data (enclosed in quotes)
  • Number: Integers and decimals
  • Boolean: true or false
  • Undefined: Variable declared but not assigned
  • Null: Intentional absence of value

2. Math Operations

Perform mathematical calculations using arithmetic operators:

Arithmetic Operators:
  • + Addition
  • - Subtraction
  • * Multiplication
  • / Division
  • % Modulus (remainder)
  • ** Exponentiation (power)
// Example: Basic Math let num1 = 20; let num2 = 5; console.log("Addition:", num1 + num2); // 25 console.log("Subtraction:", num1 - num2); // 15 console.log("Multiplication:", num1 * num2); // 100 console.log("Division:", num1 / num2); // 4 console.log("Remainder:", num1 % num2); // 0 console.log("Power:", num1 ** 2); // 400
Order of Operations: JavaScript follows PEMDAS (Parentheses, Exponents, Multiplication, Division, Addition, Subtraction). Use parentheses to control the order!

3. String Manipulation

Work with text using string methods and concatenation:

String Concatenation: Combine strings using the + operator or template literals using backticks.
// String concatenation and methods let firstName = "John"; let lastName = "Doe"; let fullName = firstName + " " + lastName; console.log(fullName); // John Doe console.log(fullName.toUpperCase()); // JOHN DOE console.log(fullName.toLowerCase()); // john doe console.log(fullName.length); // 8 console.log(fullName.charAt(0)); // J console.log(fullName.substring(0, 4)); // John // Template Literals (modern way) let greeting = `Hello, ${firstName}! Welcome back.`; console.log(greeting);
Common String Methods:
  • .toUpperCase() - Convert to uppercase
  • .toLowerCase() - Convert to lowercase
  • .length - Get string length
  • .trim() - Remove whitespace
  • .includes() - Check if contains text

4. Conditional Logic

Make decisions in your code using if/else statements:

Conditional Statements: Use if, else if, and else to execute different code based on conditions.
// Grade assignment based on score let score = 85; let grade; if (score >= 90) { grade = "A"; } else if (score >= 80) { grade = "B"; } else if (score >= 70) { grade = "C"; } else if (score >= 60) { grade = "D"; } else { grade = "F"; } console.log("Score: " + score); console.log("Grade: " + grade); // B // Comparison operators console.log(15 > 10); // true console.log(5 == 5); // true console.log(10 !== 5); // true (not equal)
Comparison Operators:
  • == Equal to
  • === Strictly equal to (type matters)
  • != Not equal to
  • > Greater than
  • < Less than
  • >= Greater or equal

5. Arrays

Store multiple values in a single variable:

What is an Array? An array is a collection of values stored in a single variable. Each value has an index starting from 0.
// Creating and accessing arrays let fruits = ["Apple", "Banana", "Cherry", "Date"]; console.log(fruits[0]); // Apple (first element) console.log(fruits.length); // 4 // Array methods fruits.push("Elderberry"); // Add to end console.log(fruits); // ["Apple", "Banana", "Cherry", "Date", "Elderberry"] let first = fruits.shift(); // Remove from start console.log(first); // Apple fruits.unshift("Apricot"); // Add to start console.log(fruits); // ["Apricot", "Banana", "Cherry", "Date", "Elderberry"]
Common Array Methods:
  • .push() - Add to end
  • .pop() - Remove from end
  • .shift() - Remove from start
  • .unshift() - Add to start
  • .length - Get size
  • .includes() - Check if contains

6. Loops

Repeat code multiple times efficiently:

Loop Types: Use loops to execute code repeatedly. Common types: for, while, and forEach.
// For loop for (let i = 1; i <= 5; i++) { console.log("Count: " + i); } // For loop with array let fruits = ["Apple", "Banana", "Cherry"]; for (let i = 0; i < fruits.length; i++) { console.log(fruits[i]); } // forEach method fruits.forEach(function(fruit) { console.log("Fruit: " + fruit); }); // While loop let x = 1; while (x <= 3) { console.log("x = " + x); x++; }
For Loop Syntax: for (initialization; condition; increment) { code }

7. Functions

Create reusable blocks of code:

What is a Function? A function is a reusable block of code that performs a specific task. Functions can take parameters and return values.
// Simple function function greet(name) { return "Hello, " + name + "!"; } console.log(greet("Alice")); // Hello, Alice! console.log(greet("Bob")); // Hello, Bob! // Function with multiple parameters function add(a, b) { return a + b; } let result = add(10, 20); console.log("Result: " + result); // Result: 30 // Function with no parameters function getCurrentTime() { return new Date().toLocaleTimeString(); } console.log(getCurrentTime());
Function Syntax: function name(parameters) { return value; }

8. Objects

Group related data and functions together:

What is an Object? An object is a collection of properties (key-value pairs). Properties can be data or functions (methods).
// Creating an object let person = { firstName: "John", lastName: "Doe", age: 30, city: "New York", getFullName: function() { return this.firstName + " " + this.lastName; } }; // Accessing properties console.log(person.firstName); // John console.log(person["age"]); // 30 console.log(person.getFullName()); // John Doe // Modifying properties person.age = 31; person.email = "john@example.com"; // Add new property console.log(person);
Accessing Object Properties: Use dot notation (object.property) or bracket notation (object["property"]).

9. DOM & Events

Interact with HTML elements and handle user actions:

What is the DOM? The DOM (Document Object Model) is the interface to interact with HTML elements in the browser.
// Select elements let element = document.getElementById("myId"); let elements = document.getElementsByClassName("myClass"); let heading = document.querySelector("h1"); // Change element properties element.textContent = "New text"; element.style.color = "blue"; element.style.fontSize = "20px"; // Add/Remove classes element.classList.add("active"); element.classList.remove("inactive"); // Event listeners let button = document.querySelector("button"); button.addEventListener("click", function() { console.log("Button clicked!"); element.style.display = "none"; });
Common DOM Methods:
  • getElementById() - Get by ID
  • getElementsByClassName() - Get by class
  • querySelector() - Get by CSS selector
  • textContent - Get/set text
  • addEventListener() - Add event listener
