Step 1: Learn — What is the DOM?

When a browser loads an HTML file, it transforms the code into a live hierarchy of JavaScript objects called the Document Object Model (DOM). Think of HTML as the skeleton and JavaScript as the muscle: JavaScript reaches into the DOM tree to move, re-color, and update elements instantaneously without reloading the page.

🎯

1. Target (Selection)

Find the HTML element you want to control:

document.getElementById("title");
document.querySelector(".badge");
✏️

2. Change Content

Use textContent to update words securely:

el.textContent = "New Heading";
🎨

3. Restyle & Toggle

Update colors or add/remove CSS classes:

el.style.color = "#10b981";
el.classList.add("active");
🛡️ Ethical Security: textContent vs innerHTML Always prefer textContent over innerHTML when displaying user input. textContent treats text strictly as plain characters, shielding your application against Cross-Site Scripting (XSS) injection attacks (Amānah).

Step 2: See — Live DOM Operations

Example A: Updating a Live Announcement Banner 
// 1. Select the element from the DOM tree
const banner = document.getElementById("school-banner");

// 2. Change its text
banner.textContent = "Notice: Science Lab opens tomorrow at 8:00 AM.";

// 3. Change its color
banner.style.color = "#34d399";
Example B: Toggling CSS Classes with classList 
const badge = document.querySelector(".attendance-badge");

// Add the class 'present'
badge.classList.add("present");

// Check if it has a class
console.log(badge.classList.contains("present")); // true
