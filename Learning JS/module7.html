📖 Reading Material

📚 What is a Function?

A function is a reusable block of code that performs a specific task. Think of it as a mini-program within your program. You can call (execute) a function whenever you need it, without rewriting the same code over and over.

7.1 Function Declaration

The traditional way to create a function:

// Basic function declaration function greet() { console.log("Hello, World!"); } // Calling the function greet(); // "Hello, World!" // Function with parameters function greetUser(name) { console.log(`Hello, ${name}!`); } greetUser("Alice"); // "Hello, Alice!" greetUser("Bob"); // "Hello, Bob!" // Function with multiple parameters function addNumbers(a, b) { let sum = a + b; console.log(`${a} + ${b} = ${sum}`); } addNumbers(5, 3); // "5 + 3 = 8" // Function with return value function multiply(a, b) { return a * b; } let result = multiply(4, 5); console.log(result); // 20 console.log(multiply(3, 7)); // 21
💡 Parameter vs Argument: Parameters are the variables listed in the function definition. Arguments are the actual values passed when calling the function.

7.2 Default Parameters

You can set default values for parameters:

// Default parameter values function greet(name = "Guest") { console.log(`Hello, ${name}!`); } greet(); // "Hello, Guest!" greet("Alice"); // "Hello, Alice!" // Multiple default parameters function createProfile(name, age = 18, city = "Unknown") { return { name, age, city }; } console.log(createProfile("John")); // { name: "John", age: 18, city: "Unknown" } console.log(createProfile("Jane", 25, "NYC")); // { name: "Jane", age: 25, city: "NYC" } // Default with expressions function calculateArea(radius = 1) { return Math.PI * radius * radius; } console.log(calculateArea()); // 3.14159... console.log(calculateArea(5)); // 78.5398...

7.3 Arrow Functions

A shorter syntax for writing functions (ES6):

// Regular function function add(a, b) { return a + b; } // Arrow function equivalent const add = (a, b) => { return a + b; }; // Concise body (implicit return) const add = (a, b) => a + b; // Single parameter (parentheses optional) const square = x => x * x; console.log(square(5)); // 25 // No parameters const sayHello = () => console.log("Hello!"); sayHello(); // "Hello!" // Returning an object (wrap in parentheses) const createUser = (name, age) => ({ name, age }); console.log(createUser("Alice", 25)); // { name: "Alice", age: 25 } // Arrow functions with arrays let numbers = [1, 2, 3, 4, 5]; let doubled = numbers.map(num => num * 2); console.log(doubled); // [2, 4, 6, 8, 10] let evens = numbers.filter(num => num % 2 === 0); console.log(evens); // [2, 4]
✅ When to use Arrow Functions: Arrow functions are great for short callbacks and when you want to preserve the this context. However, they don't have their own this binding, so avoid them for object methods!

7.4 Function Expressions

Functions can be stored in variables:

// Function expression const greet = function(name) { return `Hello, ${name}!`; }; console.log(greet("Alice")); // "Hello, Alice!" // Anonymous function (no name) const anonymous = function() { console.log("I'm anonymous!"); }; // Named function expression const factorial = function fact(n) { if (n <= 1) return 1; return n * fact(n - 1); }; console.log(factorial(5)); // 120 // Difference: Function Declaration vs Expression // Declaration - hoisted (can call before definition) sayHello(); // Works! function sayHello() { console.log("Hello!"); } // Expression - NOT hoisted (can't call before definition) // sayHi(); // Error! const sayHi = function() { console.log("Hi!"); };
⚠️ Hoisting: Function declarations are hoisted (moved to top of scope), but function expressions are not. Always define expressions before using them!

7.5 Scope and Closures

Understanding where variables are accessible:

// Global scope let globalVar = "I'm global!"; function outer() { // Function scope let functionVar = "I'm in outer!"; function inner() { // Inner function scope let innerVar = "I'm in inner!"; console.log(globalVar); // Accessible console.log(functionVar); // Accessible console.log(innerVar); // Accessible } inner(); console.log(innerVar); // Error! Not accessible here } outer(); console.log(functionVar); // Error! Not accessible here // Block scope with let and const if (true) { let blockVar = "I'm in the block!"; const blockConst = "Me too!"; console.log(blockVar); // Accessible } console.log(blockVar); // Error! Not accessible outside block // Closure - function remembering its lexical scope function createCounter() { let count = 0; return function() { count++; return count; }; } const counter = createCounter(); console.log(counter()); // 1 console.log(counter()); // 2 console.log(counter()); // 3 // 'count' is still accessible due to closure!
💡 Closure: A closure is when a function "remembers" the variables from its outer scope, even when called outside that scope. This is powerful for creating private variables!

7.6 Higher-Order Functions

Functions that take other functions as arguments or return them:

// Function that takes a function as argument function operateOnArray(arr, operation) { let result = []; for (let item of arr) { result.push(operation(item)); } return result; } let numbers = [1, 2, 3, 4, 5]; let doubled = operateOnArray(numbers, n => n * 2); let squared = operateOnArray(numbers, n => n * n); console.log(doubled); // [2, 4, 6, 8, 10] console.log(squared); // [1, 4, 9, 16, 25] // Function that returns a function function createMultiplier(multiplier) { return function(number) { return number * multiplier; }; } const double = createMultiplier(2); const triple = createMultiplier(3); console.log(double(5)); // 10 console.log(triple(5)); // 15 // Built-in higher-order functions let words = ["hello", "world", "javascript"]; // map - transform each element let uppercased = words.map(word => word.toUpperCase()); console.log(uppercased); // ["HELLO", "WORLD", "JAVASCRIPT"] // filter - keep elements that pass test let longWords = words.filter(word => word.length > 5); console.log(longWords); // ["javascript"] // reduce - combine all elements into one let sum = numbers.reduce((total, num) => total + num, 0); console.log(sum); // 15 // find - get first matching element let firstEven = numbers.find(num => num % 2 === 0); console.log(firstEven); // 2
✅ Pro Tip: Master map, filter, and reduce - these are the most commonly used higher-order functions in JavaScript and will make your code cleaner and more expressive!

7.7 The Arguments Object

Access all arguments passed to a function:

// The arguments object (available in regular functions) function sumAll() { let total = 0; for (let arg of arguments) { total += arg; } return total; } console.log(sumAll(1, 2, 3)); // 6 console.log(sumAll(1, 2, 3, 4, 5)); // 15 // Rest parameters (modern approach) function sumAllRest(...numbers) { return numbers.reduce((total, num) => total + num, 0); } console.log(sumAllRest(1, 2, 3)); // 6 console.log(sumAllRest(1, 2, 3, 4, 5)); // 15 // Rest parameters with other parameters function greet(greeting, ...names) { names.forEach(name => { console.log(`${greeting}, ${name}!`); }); } greet("Hello", "Alice", "Bob", "Charlie"); // Hello, Alice! // Hello, Bob! // Hello, Charlie!

Common Mistakes

  • Forgetting to use return: A function returns undefined by default if there is no return statement.
  • Confusing function declarations with expressions: Declarations are hoisted, but expressions are not. This means you can call a declared function before its definition, but not an expression.
  • Using arrow functions as object methods: Arrow functions don't have their own this, so they won't refer to the object when used as methods.
  • Not understanding that parameters are local to the function: Parameters exist only inside the function scope and do not affect variables with the same name outside.
