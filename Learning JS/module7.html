What is the DOM?

The **DOM (Document Object Model)** is like a map of your website. It turns every tag into an object that JavaScript can talk to!

DOCUMENT
<body>
<h1>
<p>

JavaScript can "Select" and "Change" any of these!

Finding Elements

Before you can change something, you have to **find** it. We use document.getElementById to grab a specific item.

// 1. Find the title
const myTitle = document.getElementById("main-header");

// 2. Change its text!
myTitle.innerHTML = "JS is Awesome!";

The Magic Wand 🪄

innerHTML
Change the text or HTML inside.
style
Change colors, fonts, or sizes.
src
Change an image to a new one!
