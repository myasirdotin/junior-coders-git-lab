Level 0: The Big Picture

How the Web Works

Before we write code, let's understand how a website is actually built!

🦴

HTML

The Skeleton. It defines the structure. Where is the head? Where are the feet? Where is the text?

👕

CSS

The Clothes. It defines the look. What color is the shirt? Is the hair curly? How big is the font?

🧠

JavaScript

The Brain. It defines the action. What happens when I click? How do I show a message?

🔗 How do they talk to each other?

Imagine your website is a recipe. The HTML is the kitchen, but it needs to know where to find the spices (CSS) and the chef (JS).

The Glue

Inside your HTML file's <head>, we use a Link tag for CSS:

<link rel="stylesheet" href="style.css">

And at the bottom of your <body>, we use a Script tag for JS:

<script src="script.js"></script>

👀 How do I see my work?

Browsers (like Chrome or Edge) are like translators. They read your code files and turn them into the beautiful pages you see.

1. Save Your Files

Make sure your files end in .html, .css, or .js.

2. Open the HTML

Always open the HTML file. It will automatically go and grab the CSS and JS for you!
