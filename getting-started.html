How the web works

Before you write code, see how a web page is put together. It takes about five minutes to read.

Three languages, three jobs

Think of a web page as a person.

The skeleton

HTML

It gives the page its structure: where the heading is, where the picture goes, what is a list.

The clothes

CSS

It decides how the page looks: the colours, the size of the text, the space around things.

The brain

JavaScript

It decides what the page does: what happens when you click a button or type in a box.

How do the three files find each other?

The browser opens the HTML file first. Two short lines inside it say where the other two files are.

Inside the <head> of your HTML file, a link tag points to the CSS file:

<link rel="stylesheet" href="style.css">

At the bottom of the <body>, a script tag points to the JavaScript file:

<script src="script.js"></script>

How do I see my work?

A browser such as Chrome or Edge reads your files and turns them into the page you see.

  1. Save your filesGive each one the right ending: .html, .css or .js.
  2. Open the HTML fileAlways open the HTML file. It fetches the other two for you.
  3. Change and refreshChange something, save, and press refresh in the browser to see it.
