**LearnCode V-01** is a premium, interactive learning platform designed to take aspiring developers from zero to full-stack hero. It provides a structured, visual, and gamified experience for mastering the core pillars of web development.

---

## 🌟 Key Features

- **Structured Curriculum**: 29+ modules covering HTML5, Modern CSS, and JavaScript Logic.
- **Interactive Code Lab**: A built-in IDE for real-time experimentation with HTML, CSS, and JS.
- **Gamified Experience**: Earn XP, climb ranks (Recruit to Master), and track your progress through visual dashboards.
- **Responsive Design**: Optimized for both Desktop and Mobile learning.
- **Modern UI**: A "Glassmorphism" inspired dark theme with light mode support.
- **Educational Analogies**: Complex concepts explained through simple, relatable visual metaphors.

---

## 🗺️ Learning Roadmap

### 1. HTML Adventure (12 Modules)
- Master document structure, semantic tags, and accessibility.
- **Highlights**: Skeletal analogies, Form building, SEO best practices.

### 2. CSS Masterclass (8 Modules)
- Bring sites to life with modern layouts and animations.
- **Highlights**: Flexbox & Grid mastery, Responsive design, Theme variables.

### 3. JavaScript Logic (9 Modules)
- Add interactivity and "brains" to your web applications.
- **Highlights**: DOM Manipulation, Event Handling, ES6+ features.

---

## 🚀 Getting Started

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/yasir-rasool/junior-coders-git-lab.git
   ```
2. **Launch the Platform**:
   Simply open `index.html` in any modern web browser.
3. **Start the Journey**:
   Navigate to the **Basics** section to understand how the web works before diving into the code.

---

## 🛠️ Built With

- **HTML5**: For semantic structure and accessibility.
- **Vanilla CSS**: Custom styling with CSS variables and responsive grids.
- **JavaScript (ES6+)**: Custom "Core Platform Engine" for dynamic component injection and state management.
- **Google Fonts**: "Outfit" for a modern, clean typography.
