# CSS for Class 7: Curriculum Overview & Design Rubrics

---

## 1. Pedagogical Methodology 💡

Learning CSS can feel overwhelming when students simply copy and paste values without intuition. This curriculum builds a deep mental model through:
1. **Visual Contrast Discovery**: Comparing ugly/unformatted text vs beautifully styled typography and cards.
2. **Predictable Mental Models**: The Box Model is taught through tangible physical analogies (gift in a box, bubble wrap padding, cardboard border, shipping margin).
3. **Interactive Experimentation**: Every code snippet has direct "Try in Code Lab" buttons for live value tweaking.
4. **Project Scaffolding**: Students build genuine components (buttons, badges, cards, navigation bars) before assembling complete websites.

## 3. Design & Styling Assessment Rubric 🎯

| Criterion | Exemplary (4 pts) | Proficient (3 pts) | Developing (2 pts) | Beginning (1 pt) |
| :--- | :--- | :--- | :--- | :--- |
| **Visual Hierarchy & Typography** | Cohesive font pairings; clear scale differences; optimal line height. | Good typography; readable sizes and weights. | Minor readability issues; awkward spacing. | Poor contrast or unreadable fonts. |
| **Layout & Alignment (Flex/Grid)** | Clean alignment using Flexbox/Grid with zero overflow bugs. | Effective layout with minor alignment flaws. | Elements misaligned; unexpected wrapping. | Broken layout flow. |
| **Responsiveness** | Flawless appearance across mobile, tablet, and desktop viewports. | Responsive with minor mobile quirks. | Elements overlap or cause horizontal scrolling on mobile. | Not responsive; mobile view breaks. |
| **Micro-Interactions** | Smooth hover transitions and active states enhancing UX. | Hover feedback present on interactive elements. | Abrupt color jumps without transitions. | No hover feedback or interactive states. |
