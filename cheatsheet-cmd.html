⌨️ Terminal & Command Line Cheat Sheet

Command Prompt (CMD), PowerShell and Git Bash side by side, using the same commands as the Terminal textbook.

Three habits: check where you are (cd in CMD, pwd in PowerShell and Git Bash) before you change anything. Press Tab to finish a name and ↑ to bring back the last command. Ctrl + C stops a stuck command or a running server.
🔄 Three Terminals Side by Side

A terminal is a window where you type commands instead of clicking. Windows has CMD and PowerShell, and Git Bash comes with Git. They do the same jobs, but some words and symbols differ. So first check which prompt you see.

C:\Users\Amina>A CMD prompt
PS C:\Users\Amina>A PowerShell prompt: it starts with PS
amina@LAB-PC MINGW64 ~ $A Git Bash prompt: it ends with $
Win + R, then cmd or powershellOpens Command Prompt or PowerShell
dir /w · dir -Name · ls -lOptions: CMD uses /, PowerShell -Word, Git Bash -letter
css\style.css · css/style.cssWindows paths use \, Git Bash uses / (PowerShell accepts both)
dir /? · Get-Help dir · ls --helpHelp for a command (CMD · PowerShell · Git Bash)

🧭 Orientation & Location

Before you change anything, find out where you are. A terminal works inside one folder at a time, called the current folder. These commands show its name and what is inside it, even hidden items.

cd · pwdWhere am I? (cd alone in CMD, pwd in PowerShell and Git Bash)
dir · lsLists the folder (dir in CMD and PowerShell, ls in PowerShell and Git Bash)
dir /a · ls -Force · ls -aAlso shows hidden items like .git (CMD · PowerShell · Git Bash)
tree /fShows folders and files as a tree (CMD and PowerShell)
cls · clearClears the screen (cls in CMD and PowerShell, clear in PowerShell and Git Bash); files are safe
Ctrl + LClears the screen in PowerShell and Git Bash (not CMD)

🚶 Navigation & Moving

A path is the address of a folder, like a street address. cd means "change directory": it moves you into another folder. .. always means the folder one level up. Press Tab and the terminal finishes long names for you.

cd scienceSteps into a folder (type cd sci and press Tab)
cd ..Up one level, to the parent folder (keep the space)
cd ..\.. · cd ../..Up two levels (Windows · Git Bash)
cd \ · cd /To the top of the drive (Windows · Git Bash)
cd ~ · cd %USERPROFILE%To your home folder (PowerShell and Git Bash · CMD)
E: · cd /d E:\folderChanges drive in CMD
cd E:\folderChanges drive and folder at once in PowerShell
doskey /history · historyLists the commands you typed (CMD · PowerShell and Git Bash)

⚡ Creation & Scaffolding

Scaffolding means building the empty folders and files of a new project before you write code. One line can make many folders at once. Each terminal makes an empty file in its own way, so read the notes.

mkdir cssMakes a folder (all three terminals)
mkdir css js imagesSeveral folders in CMD and Git Bash
mkdir css, js, imagesSeveral folders in PowerShell (commas)
mkdir assets\images\iconsFolders inside folders (CMD and PowerShell)
mkdir -p assets/images/iconsFolders inside folders (Git Bash)
type nul > index.htmlEmpty file in CMD. It empties a file that already has that name, so dir first
New-Item index.htmlEmpty file in PowerShell (refuses if the file exists)
touch index.htmlEmpty file in Git Bash (leaves an existing file alone)

📦 Moving, Renaming & Copying

Renaming and moving are really the same job: the file gets a new name or a new address. Copying makes a second file and keeps the first. Some commands replace a file with the same name without asking, so look first.

ren old.txt new.txtRenames a file or folder (CMD and PowerShell)
move app.js js\Moves a file into a folder (CMD and PowerShell)
move app.js ..Moves it up one level
copy a.txt b.txtCopies a file (CMD and PowerShell; PowerShell overwrites without asking)
xcopy site backup /e /iCopies a whole folder (CMD)
copy site backup -RecurseCopies a whole folder (PowerShell)
mv old.txt new.txt · mv app.js js/Renames or moves in Git Bash
cp a.txt b.txt · cp -r site backupCopies a file / a folder in Git Bash

🛑 Deletion & Safety Nets

Files deleted in a terminal do not go to the Recycle Bin. They are gone. So always look first, then use the version that asks before it deletes. Caring for your files and other people's files is a trust (Amānah).

dir · lsLook first: check you are in the right folder and the name is right
del /p notes.txtDeletes a file after asking (CMD). There is no Recycle Bin
del notes.txt -ConfirmDeletes a file after asking (PowerShell)
rm -i notes.txtDeletes a file after asking (Git Bash; -i = interactive)
rmdir old-draftsRemoves an empty folder; refuses if anything is inside
rmdir /s old-draftsRemoves a full folder after a Y/N question (CMD). Never add /q
rmdir old-drafts (full folder)PowerShell asks before removing the "children" inside; read the path, then answer
rm -r -i old-draftsRemoves a full folder, asking about each item (Git Bash). Never add -f
Ctrl + CThe emergency brake: stops a running command

🔍 Reading & Searching

You can read a file without opening an editor. The > sign sends output into a file and replaces what was there. >> adds to the end instead. The pipe | passes one command's result to the next one.

type notes.txt · cat notes.txtPrints a file (CMD and PowerShell · Git Bash)
type long.txt | moreShows a long file one page at a time
Get-Content log.txt -Tail 5The last 5 lines (PowerShell; -Head 5 for the first)
echo Salaam > notes.txtWrites text into a file and replaces what was there
echo Second line >> notes.txtAdds text to the end of the file
findstr Wednesday visits.txtLines that contain a word (CMD)
Select-String Wednesday visits.txtLines that contain a word (PowerShell)
grep Wednesday visits.txtLines that contain a word (Git Bash)
type visits.txt | findstr WednesdayThe pipe | sends one command's output into the next

🛠️ Web Developer Workflow

Web developers use the terminal every day. You open your project in VS Code, check that your tools are installed, and start a small local server. A local server shows your site at a localhost address on your own computer.

code .Opens this folder in VS Code (. = this folder)
start . · explorer .Opens this folder in File Explorer (CMD and PowerShell · Git Bash)
git --versionChecks a tool is installed and shows its version
node --version · php --version · python --versionThe same check for other tools
composer --versionComposer's version (composer -v means "more detail", not version)
where git · Get-Command git · which gitWhere a program lives (CMD · PowerShell · Git Bash)
php -S localhost:8000Starts PHP's local server (capital S); visit http://localhost:8000
python -m http.server 8000Starts Python's simple local server
Ctrl + CStops the server and gives the prompt back

Amānah (trust) rule: the terminal does exactly what you type, with no Recycle Bin. List a folder before you delete, keep the confirmation questions on, never run commands copied from an unknown website, and do not change settings or install software on a school computer without your teacher.
