💻 Command Line & Terminal Cheat Sheet

Windows Command Prompt (CMD) & Git Bash side-by-side — navigation, project scaffolding, file management, and developer tools on one page!

The 3 Superpowers: 1. Press Tab to auto-complete file names. 2. Press ↑ (Up Arrow) to replay previous commands. 3. Press Ctrl + C to immediately stop any stuck command or local server!
🧭 1. Orientation & Location
cd (CMD) / pwd (Bash)Print current working directory
dir (CMD) / ls (Bash)List files and folders in directory
dir /a:h / ls -aShow hidden files (e.g. .git)
cls (CMD) / clear (Bash)Clear the terminal screen
Ctrl + LClear screen shortcut (PowerShell & Git Bash)
🚶 2. Navigation & Moving
cd <folder>Step inside a subfolder
cd ..Step back one level (Parent directory)
cd ../..Step back two levels at once
cd \ (CMD) / cd / (Bash)Jump straight to root directory
D: (CMD)Switch to Drive D (Windows CMD)
cd ~ (Bash)Jump directly to user home folder
⚡ 3. Creation & Scaffolding
mkdir <folder>Create a new directory
mkdir css js assetsCreate multiple directories at once
mkdir -p a/b/c (Bash)Create nested folder hierarchy
type nul > index.htmlCreate empty file (Windows CMD)
touch index.htmlCreate empty file (Git Bash / Linux)
echo hello > file.txtCreate file with text content
📦 4. Moving, Renaming & Copying
ren old.txt new.txtRename a file (Windows CMD)
mv old.txt new.txtRename or move file (Git Bash / Linux)
move script.js js\Move file into subfolder (Windows CMD)
mv script.js js/Move file into subfolder (Git Bash)
copy a.txt b.txtDuplicate/backup a file (Windows CMD)
cp a.txt b.txtDuplicate/backup a file (Git Bash)
🛑 5. Deletion & Safety Nets
del file.txt (CMD)Delete a single file (No Recycle Bin!)
rm file.txt (Bash)Delete a single file (Permanent!)
rmdir <empty-folder>Delete an empty directory
rmdir /s /q <folder>Force delete folder and contents (CMD)
rm -rf <folder>Force delete folder and contents (Bash)
Ctrl + CEmergency Brake: Stop stuck program
🛠️ 6. Web Developer Workflow
code .Open current folder in VS Code
php -S localhost:8000Start local PHP development server
git --versionVerify Git installation & version
node -v / npm -vVerify Node.js & npm package manager
php -v / composer -vVerify PHP interpreter & Composer
type f.txt / cat f.txtPrint file contents to terminal
🔄 Rosetta Stone: Windows CMD vs. Git Bash / Linux
Action Windows CMD Git Bash / macOS / Linux Notes
Current Directory cd pwd Print Working Directory
List Files dir ls Use ls -la for hidden files
Clear Screen cls clear Both support Ctrl + L
Create Empty File type nul > file touch file Instant 0-byte file creation
Rename File ren old new mv old new Bash uses move to rename
Copy File copy a b cp a b Duplicate file
Delete File del file rm file ⚠️ Bypasses Recycle Bin!
Read File Content type file cat file Print text to console
Search inside files findstr "key" grep "key" Filter text lines
Moral Stewardship (*Amānah*): Your command line is a high-speed tool. Always confirm where you are standing before deleting files, and never execute scripts pasted from unknown websites.
