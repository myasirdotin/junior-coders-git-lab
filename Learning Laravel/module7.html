Forms & Validation 📝

Collect user input safely and validate it like a pro!

HTML Forms in Laravel

Building forms in Laravel uses standard HTML, but with two important Laravel additions: @csrf for security, and @method for PUT/PATCH/DELETE requests (since HTML forms only support GET and POST natively).

<!-- A form to create a new student --> <form method="POST" action="{{ route('students.store') }}"> @csrf <!-- Required! Generates CSRF security token --> <label>Name:</label> <input type="text" name="name" value="{{ old('name') }}"> <!-- old() re-fills the field if validation fails --> @error('name') <p style="color:red;">{{ $message }}</p> @enderror <label>Email:</label> <input type="email" name="email" value="{{ old('email') }}"> @error('email') <p style="color:red;">{{ $message }}</p> @enderror <button type="submit">Save Student</button> </form>
🔑 Why old()?
When a form fails validation, Laravel redirects the user back to the form. old('name') retrieves the value the user typed so they don't have to retype everything — great UX!

Handling Form Submission in the Controller 🎮

public function store(Request $request) { // Step 1: Validate the incoming data $validated = $request->validate([ 'name' => 'required|min:2|max:100', 'email' => 'required|email|unique:students', 'grade' => 'nullable|in:A,B,C,D,F', ]); // Step 2: Save the validated data Student::create($validated); // Step 3: Redirect with a success message return redirect()->route('students.index') ->with('success', 'Student added!'); }

If validation fails, Laravel automatically redirects back to the form and puts the error messages in the session — no extra code needed!

Common Validation Rules 📋

RuleWhat it checks
requiredField must not be empty
stringMust be a text string
min:3At least 3 characters (or number ≥ 3)
max:255No more than 255 characters
emailMust be a valid email format
unique:tableValue must not already exist in table
numericMust be a number
in:A,B,CMust be one of these values
nullableField is optional (can be empty)
confirmedMust match a _confirmation field
dateMust be a valid date
imageMust be an image file (jpg, png, etc.)

Combine rules with a pipe |: 'required|email|max:150'

Displaying Flash Messages 💬

When you redirect with ->with('success', 'Student added!'), you can display that message in your Blade template:

@if (session('success')) <div style="background:#d1fae5; color:#065f46; padding:1rem; border-radius:0.5rem;"> ✅ {{ session('success') }} </div> @endif @if (session('error')) <div style="background:#fee2e2; color:#991b1b; padding:1rem; border-radius:0.5rem;"> ❌ {{ session('error') }} </div> @endif

🟡 Level 2: Fix the bug

A volunteer sign-up form has problems. Pressing the button shows "419 Page Expired". After you fix that, an empty name sends the user back with no message, and the typed text is gone. Fix all three problems.

<form method="POST" action="{{ route('volunteers.store') }}">
    <input type="text" name="name">
    <button type="submit">Sign up</button>
</form>
Show answer

"419 Page Expired" means the CSRF token is missing, so add @csrf. Use old('name') to keep the typed text. Use @error to show the message.

<form method="POST" action="{{ route('volunteers.store') }}">
    @csrf
    <input type="text" name="name" value="{{ old('name') }}">
    @error('name')
        <p>{{ $message }}</p>
    @enderror
    <button type="submit">Sign up</button>
</form>

🔴 Level 3: Challenge

On your own XAMPP computer, build a sign-up form for the school science fair. It should save each entry to MySQL.

  1. Run php artisan make:model FairEntry -m. In the migration, add student_name, project_title and an integer grade. Run php artisan migrate.
  2. In the model, list the three columns in $fillable.
  3. Make FairEntryController with two methods: create() shows the form, and store() saves it.
  4. Add two named routes: GET /fair/entries/create (fair.create) and POST /fair/entries (fair.store).
  5. In store(), validate: the name is required with 2 to 100 characters, the title is required with at most 150, and the grade is required and one of 6, 7, 8, 9, 10.
  6. Save the entry and redirect back to the form with the message "Your project is registered!".
  7. Build the form view with @csrf, old(), @error and the success message. Test it with empty and wrong values too.

// app/Http/Controllers/FairEntryController.php
public function create()
{
    return view('fair.create');
}

public function store(Request $request)
{
    $validated = $request->validate([
        'student_name'  => 'required|min:2|max:100',
        'project_title' => 'required|max:150',
        'grade'         => 'required|in:6,7,8,9,10',
    ]);

    FairEntry::create($validated);

    return redirect()->route('fair.create')
                     ->with('success', 'Your project is registered!');
}
