Laravel Glossary

Quick reference for the terms used in the Laravel track

A
Artisan
Laravel's command-line tool. You type commands such as php artisan serve (start the app) or php artisan make:controller BookController (create a file).
B
Blade
Laravel's template language: HTML with extra commands. Files end in .blade.php. {{ $name }} shows a value safely, and directives like @foreach and @if add logic.
C
Composer
A tool that downloads PHP packages and keeps them up to date. You use it to install Laravel: composer create-project laravel/laravel school-library.
Controller
A PHP class that handles requests. It asks the model for data and passes it to a view. Lives in app/Http/Controllers/.
CSRF token
A secret code added to every form by @csrf. Laravel checks it on each POST, so another website cannot trick a browser into sending your form. A missing token gives "419 Page Expired".
E
Eloquent
Laravel's tool for working with the database using PHP instead of SQL: Book::all(), Book::where('author', 'Amina Yusuf')->get(). Each table has a model.
.env file
The settings file of your app: database name, username, password and more. It holds secrets, so never share it or upload it publicly (Amānah: keep what you are trusted with safe).
M
Middleware
A check that runs before a route's code. The auth middleware sends guests to the login page: Route::get('/dashboard', ...)->middleware('auth');.
Migration
A PHP file that describes a database table. up() builds it and down() undoes it. Run them with php artisan migrate.
Model
A PHP class that stands for one database table. The Book model works with the books table. Lives in app/Models/.
MVC
Model, View, Controller: a way to split an app into three parts. The model handles data, the view shows it, and the controller connects them.
R
Request
Everything the browser sends to your app: the URL, the method (GET or POST) and any form data. In a controller, read a field with $request->input('name').
Route
A rule that says which code runs for a URL. Written in routes/web.php: Route::get('/books', [BookController::class, 'index']);.
Route parameter
A part of the URL in curly braces that Laravel captures: in /book/{id}, visiting /book/7 gives $id = 7.
S
Seeder
A class that fills the database with sample data for testing. Seeders live in database/seeders/ and run with php artisan db:seed.
Starter kit
Ready-made register, login and logout pages for a new app. Since Laravel 12 the official kits use React, Vue or Livewire. Laravel 11 and earlier mostly used Breeze.
V
Validation
Checking form data before saving it: $request->validate(['email' => 'required|email']). If a rule fails, Laravel sends the user back to the form with error messages.
View
The page the user sees, written in Blade and stored in resources/views/. A controller shows one with return view('books.index');.
