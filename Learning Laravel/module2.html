Level 1

Routing 🗺️

Define where every URL goes — the road map of your entire application!

What is Routing?

Every time a user visits a URL on your website, Laravel needs to know what to do. Should it show a page? Return some data? Run some code? That's exactly what routes are for!

The Street Signs Analogy 🚦

Routes are like street signs for your app. When a user visits /about, the route sign points them to the About controller. When they visit /contact, a different sign points them somewhere else. Without routes, requests would get lost and nothing would work!

Basic Routes in routes/web.php

All web routes live in the file routes/web.php. Laravel reads this file and matches every incoming URL to the code you've defined. Let's look at three common route types:

// routes/web.php
// A simple route that returns plain text
Route::get('/hello', function () {
    return 'Hello World!';
});

// A route that calls a Controller method
Route::get('/about', [AboutController::class, 'index']);

// A POST route for form submissions
Route::post('/contact', [ContactController::class, 'store']);
Route::get()

Handles GET requests — when a user visits a URL in the browser. Used for showing pages.

Route::post()

Handles POST requests — when a user submits a form. Used for saving data.

Route::put() / Route::delete()

For updating and deleting resources. Used heavily in REST APIs.

Route Parameters — Dynamic URLs 🎯

What if you want a URL that includes a student's ID? Like /student/5 or /student/12? Route parameters let you capture that value and use it in your code!

// The {id} is a route parameter — it captures whatever is in the URL
Route::get('/student/{id}', function ($id) {
    return 'Showing student number: ' . $id;
});

// Multiple parameters work too!
Route::get('/class/{classId}/student/{studentId}', [
    StudentController::class, 'show'
]);

If a user visits /student/7, Laravel will automatically set $id = 7 and pass it to your function or controller method. Magic!

Optional Parameters with ?

Add a question mark to make a parameter optional: Route::get('/student/{id?}', ...). Then set a default value in your function: function($id = null).

Named Routes — Give Your Routes a Name 🏷️

Instead of hard-coding URLs like "/about" everywhere in your code, you can give routes names and use those names instead. This is incredibly useful — if you ever change a URL, you only have to change it in one place!

// Give a route a name using ->name()
Route::get('/home', [HomeController::class, 'index'])->name('home');

Route::get('/student/{id}', [StudentController::class, 'show'])->name('student.show');

// In your Blade views, use route() to generate URLs by name
// Instead of: href="/home"
// Use: href="{{ route('home') }}"

// With parameters:
// href="{{ route('student.show', ['id' => 5]) }}"
😱

Without Named Routes

You write href="/student/show" in 20 places. You change the URL. Now you have to find and fix all 20 places!

😌

With Named Routes

You write route('student.show') everywhere. You change the URL in one place. Done!

Route Groups — Organize Related Routes 📦

When you have many routes that share the same URL prefix (like all admin pages starting with /admin/), you can group them together to keep things tidy.

// All routes inside this group start with /admin/
Route::prefix('admin')->group(function () {

    // This matches /admin/dashboard
    Route::get('/dashboard', [AdminController::class, 'dashboard']);

    // This matches /admin/users
    Route::get('/users', [AdminController::class, 'users']);

});

You can also group by middleware (we'll learn about this in the Authentication module) to protect certain routes from unauthenticated users.

Inspect Your Routes with Artisan ⚙️

Lost track of all the routes in your app? Laravel has a command that shows you every single route — its URL, method, and which controller it calls:

php artisan route:list

This displays a table in the terminal showing every route: the HTTP method (GET, POST, etc.), the URI (the URL pattern), and the action (which controller method handles it). Incredibly useful for debugging!

Pro Tip 💡

Try running php artisan route:list --compact for a shorter, cleaner output. Or filter by keyword: php artisan route:list --name=student to only show student-related routes.

🟡 Level 2: Fix the bug

This route should show "Showing book number: 3" for /book/3. Instead, /book/3 shows a "404 Not Found" page. Fix it. Then give the route the name book.show.

Route::get('/book/id', function ($id) {
    return 'Showing book number: ' . $id;
});
Show answer

The route parameter needs curly braces. Without them, the route only matches the exact text /book/id.

Route::get('/book/{id}', function ($id) {
    return 'Showing book number: ' . $id;
})->name('book.show');

In a Blade view you can now link to it with {{ route('book.show', ['id' => 3]) }}.
