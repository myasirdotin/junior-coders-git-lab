Eloquent ORM 🗣️

Talk to your database in plain PHP — no SQL required!

What is Eloquent?

Eloquent is Laravel's built-in ORM (Object-Relational Mapper). It lets you interact with your database tables using PHP classes instead of raw SQL queries. Each database table has a corresponding Model class.

The Filing Cabinet Analogy 🗄️

Think of your database as a giant filing cabinet. Each drawer is a table (like "students"). Eloquent is your super-smart assistant — instead of manually searching through files (writing SQL), you just say "get me all students with grade A" and your assistant does the digging for you!

Creating a Model 🏗️

Generate a model with the Artisan command. By convention, if your table is called students, your model is called Student (singular, CamelCase).

# Create a model php artisan make:model Student # Create a model AND a migration at the same time php artisan make:model Student -m

The generated model is clean and minimal — Eloquent handles everything automatically:

<?php namespace App\Models; use Illuminate\Database\Eloquent\Model; class Student extends Model { // Eloquent automatically uses the 'students' table // It also handles created_at and updated_at timestamps // List columns that can be mass-assigned (saved via forms) protected $fillable = ['name', 'grade', 'email']; }

CRUD with Eloquent ⚡

Eloquent makes all four database operations (Create, Read, Update, Delete) clean and intuitive:

📖 Read

// Get ALL students $students = Student::all(); // Find a student by their primary key (id) $student = Student::find(1); // Find or throw a 404 error if not found $student = Student::findOrFail(5); // Query with conditions $topStudents = Student::where('grade', 'A') ->orderBy('name') ->get();

✏️ Create

// Method 1: create() — uses $fillable for safety Student::create([ 'name' => 'Ali Khan', 'grade' => 'A', 'email' => 'ali@school.com', ]); // Method 2: new + save() $s = new Student(); $s->name = 'Sara'; $s->save();

🔄 Update

$student = Student::find(1); $student->grade = 'A+'; $student->save(); // Or in one line: Student::where('name', 'Ali')->update(['grade' => 'A+']);

🗑️ Delete

$student = Student::find(1); $student->delete(); // Or delete by condition: Student::where('grade', 'F')->delete();

Relationships 🔗

Eloquent makes database relationships elegant. A student can belong to a class, a class can have many students:

// In Student model — student belongs to one Classroom public function classroom() { return $this->belongsTo(Classroom::class); } // In Classroom model — classroom has many Students public function students() { return $this->hasMany(Student::class); } // Usage — get a student's classroom name $student = Student::find(1); echo $student->classroom->name; // Get all students in classroom 1 $class = Classroom::find(1); $students = $class->students;

🟡 Level 2: Fix the bug

The librarian wants to correct the title of book 3. The code runs with no error, but the database never changes. Why? Fix it. Also make it show a 404 page if book 3 does not exist.

$book = Book::find(3);
$book->title = 'Our Solar System';
Show answer

Changing $book->title only changes the object in PHP. You must call save() to write it to the database. findOrFail() gives a 404 page when the id is missing.

$book = Book::findOrFail(3);
$book->title = 'Our Solar System';
$book->save();

    id BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,

);
