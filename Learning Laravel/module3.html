Controllers 🧠

The brains of your application — where the real logic happens!

What is a Controller?

In the MVC pattern, the Controller is the manager that connects everything together. It receives a request, decides what to do, talks to the right Model, and returns the right View.

The Restaurant Manager Analogy 🍽️

A controller is like a manager at a restaurant. When an order (request) comes in, the manager decides which chef (model) to call and which plate (view) to serve it on. The manager doesn't cook the food themselves — they coordinate everything and make sure the right dish reaches the right customer!

Creating a Controller with Artisan 🏗️

You never have to create controller files by hand. Artisan creates them for you with the right structure already in place:

# Creates app/Http/Controllers/StudentController.php
php artisan make:controller StudentController

This creates the file app/Http/Controllers/StudentController.php. Let's look at what's inside and add some methods:

<?php

namespace App\Http\Controllers;

use Illuminate\Http\Request;
use App\Models\Student;

class StudentController extends Controller
{
    // Show a list of all students
    public function index()
    {
        $students = Student::all();
        return view('students.index', ['students' => $students]);
    }

    // Show one specific student
    public function show($id)
    {
        $student = Student::find($id);
        return view('students.show', compact('student'));
    }
}

Let's break that down line by line:

  • namespace — Tells PHP where this class lives in the folder structure.
  • use App\Models\Student — Imports the Student model so we can use it.
  • extends Controller — Our controller inherits helpful features from Laravel's base Controller.
  • public function index() — A method that handles a request. "index" is the standard name for "show a list".
  • Student::all() — Asks the Student model to fetch ALL students from the database.
  • return view('students.index', [...]) — Sends data to the Blade template and returns the HTML.

The 7 RESTful Methods 📋

Real-world web apps perform 4 basic operations on data: Create, Read, Update, Delete (CRUD). Laravel controllers use 7 standard method names that map to these operations:

Method Name HTTP Verb What It Does Example URL
index() GET List all items /students
show() GET Show one item /students/5
create() GET Show "create new" form /students/create
store() POST Save new item to database /students
edit() GET Show "edit" form /students/5/edit
update() PUT/PATCH Save edited data /students/5
destroy() DELETE Delete an item /students/5

What Can a Controller Return? 📤

Controllers are flexible — they can return different types of responses depending on what you need:

// Return a Blade view (most common)
return view('students.index', ['students' => $students]);

// Return a Blade view using compact() — cleaner syntax!
return view('students.show', compact('student'));

// Return JSON data (for APIs)
return response()->json(['name' => 'Ali', 'age' => 12]);

// Redirect to another page
return redirect()->route('students.index');

// Redirect back with a success message
return redirect()->back()->with('success', 'Student added!');
compact() is a PHP shortcut!

compact('student') is exactly the same as ['student' => $student]. It automatically looks for a variable named $student and puts it in the array. Much cleaner when passing multiple variables!

Receiving Form Data with Request 📨

When a form is submitted, the data arrives in the Request object. Laravel can automatically inject it into your controller method — you just type-hint it in the parameters:

use Illuminate\Http\Request;

public function store(Request $request)
{
    // Get a specific field from the form
    $name = $request->input('name');
    $age = $request->input('age');

    // Save it to the database
    Student::create([
        'name' => $name,
        'age' => $age,
    ]);

    return redirect()->route('students.index')->with('success', 'Student added!');
}

Resource Controllers — One Command Does It All! 🚀

If you need all 7 RESTful methods, use the --resource flag. Laravel creates the controller with all 7 methods already defined:

# Creates a controller with all 7 RESTful methods pre-built
php artisan make:controller StudentController --resource

# In routes/web.php, register all 7 routes with ONE line!
Route::resource('students', StudentController::class);

That single Route::resource() line creates all 7 routes automatically! Run php artisan route:list and you'll see them all listed.

🔴 Level 3: Challenge

On your own XAMPP computer, build a controller for a school food drive. You do not need a database for this task.

  1. Use Artisan to create DriveController.
  2. Add an index() method. It returns "Food drive: please bring rice, lentils or flour to the school hall."
  3. Add a show($day) method. It returns "Collection day X", where X comes from the URL.
  4. Add an items() method. It returns JSON with a list: rice, lentils, flour.
  5. In routes/web.php, add three routes: /drive, /drive/day/{day} and /drive/items.
  6. Start the server and visit all three pages.
Show one possible answer
// app/Http/Controllers/DriveController.php
class DriveController extends Controller
{
    public function index()
    {
        return 'Food drive: please bring rice, lentils or flour to the school hall.';
    }

    public function show($day)
    {
        return 'Collection day ' . $day;
    }

    public function items()
    {
        return response()->json(['items' => ['rice', 'lentils', 'flour']]);
    }
}

// routes/web.php
use App\Http\Controllers\DriveController;

Route::get('/drive', [DriveController::class, 'index']);
Route::get('/drive/day/{day}', [DriveController::class, 'show']);
Route::get('/drive/items', [DriveController::class, 'items']);

Put the use line near the top of web.php. Without it, Laravel cannot find the controller.
