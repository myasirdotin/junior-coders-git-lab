Migrations 🏗️

Version-control your database schema — never lose track of changes!

What are Migrations?

Migrations are like version control for your database. Instead of manually creating tables in phpMyAdmin, you write PHP code that describes your tables. Your whole team runs the same migrations and everyone gets the identical database structure.

📐 The Building Blueprint Analogy

Imagine building a school. Instead of telling each construction worker what to build verbally, you give them all the same blueprint. Migrations are your database blueprints — precise, shareable, and version-controlled with Git!

Creating a Migration ⚙️

# Create a migration for a new table php artisan make:migration create_students_table # Create a migration AND a model together php artisan make:model Student -m # Create a migration to add a column to an existing table php artisan make:migration add_email_to_students_table --table=students

This generates a file in database/migrations/. Open it and you'll see two methods: up() (what to do) and down() (how to undo it).

Writing a Migration 📝

<?php use Illuminate\Database\Migrations\Migration; use Illuminate\Database\Schema\Blueprint; use Illuminate\Support\Facades\Schema; return new class extends Migration { public function up(): void { Schema::create('students', function (Blueprint $table) { $table->id(); // auto-increment id $table->string('name'); // VARCHAR(255) $table->string('email')->unique(); // unique email $table->string('grade')->nullable(); // optional $table->integer('age')->default(14); // default value $table->timestamps(); // created_at, updated_at }); } public function down(): void { Schema::dropIfExists('students'); } };

Running Migrations ▶️

# Run all pending migrations php artisan migrate # Rollback the last batch of migrations php artisan migrate:rollback # Rollback and re-run all migrations (fresh start) php artisan migrate:fresh # Fresh + seed the database with test data php artisan migrate:fresh --seed # See which migrations have run php artisan migrate:status
⚠️ Warning: migrate:fresh DROPS all tables and rebuilds from scratch. Never run it on a production database — all real data will be lost!
