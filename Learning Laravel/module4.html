Blade Templates 🌿

Beautiful, dynamic HTML — write less, show more!

What is Blade?

You already know HTML. Blade is HTML with superpowers! It lets you embed dynamic PHP values, use loops, conditionals, and even reuse entire page layouts — all with a super clean, readable syntax.

The Smart Template Analogy 📄

Blade is like a smart HTML template. You write HTML but with special codes that let PHP values appear automatically. Think of a school report card template — the template is always the same, but each student's name and grades fill in the blanks differently every time!
Where do Blade files live?

All Blade templates go in resources/views/. They have the extension .blade.php. So a file called resources/views/students/index.blade.php is called with view('students.index') in your controller.

Displaying Variables — The {{ }} Syntax 🖨️

The most common thing you'll do in Blade is display a PHP variable on the page. Use double curly braces:

<!-- Safely echo a variable (HTML is escaped — no XSS risk!) -->
<h1>{{ $student->name }}</h1>
<p>Age: {{ $student->age }}</p>

<!-- Echo raw HTML (use carefully — only for trusted content!) -->
<div>{!! $htmlContent !!}</div>

<!-- Echo with a default value if variable is null -->
<p>{{ $student->grade ?? 'Not graded yet' }}</p>
🛡️

{{ $var }} — Safe

Blade automatically escapes HTML characters. If someone tries to inject <script> tags, they'll show as text, not run as code. Always use this!

⚠️

{!! $var !!} — Unescaped

This renders raw HTML. Only use it when you 100% control the content — like HTML you generated yourself in PHP. Never use it with user input!

Control Structures — Logic in Your Templates 🔀

Blade has clean, readable directives for all common PHP logic. Notice how they start with @ — that's how you know it's a Blade directive!

If / Else / Elseif

@if ($student->grade === 'A')
    <p style="color: green;">Excellent work! 🌟</p>
@elseif ($student->grade === 'B')
    <p style="color: blue;">Good job! Keep it up!</p>
@else
    <p style="color: orange;">Keep studying! You can do it!</p>
@endif

Foreach Loop

<!-- Loop through a collection of students -->
<ul>
  @foreach ($students as $student)
    <li>
      {{ $student->name }} — Grade: {{ $student->grade }}
    </li>
  @endforeach
</ul>

<!-- @forelse is like foreach but handles the empty case! -->
@forelse ($students as $student)
    <p>{{ $student->name }}</p>
@empty
    <p>No students found!</p>
@endforelse

For Loop and While Loop

<!-- Standard for loop -->
@for ($i = 0; $i < 5; $i++)
    <p>Row number: {{ $i }}</p>
@endfor

<!-- While loop -->
@while ($count > 0)
    <p>Count: {{ $count-- }}</p>
@endwhile

Layout Inheritance — Write HTML Once, Use Everywhere! 🏛️

Every page on a website shares common elements — a header, footer, navigation. With Blade layouts, you write those shared parts once and every page automatically gets them!

Step 1: Create a Layout Template

Create resources/views/layouts/app.blade.php:

<!-- resources/views/layouts/app.blade.php -->
<!DOCTYPE html>
<html>
<head>
    <title>{{ $title ?? 'My School App' }}</title>
</head>
<body>
    <nav> ... your navigation here ... </nav>

    <!-- This is the SLOT where child pages inject their content -->
    @yield('content')

    <footer> ... your footer here ... </footer>
</body>
</html>

Step 2: Child Page Extends the Layout

Create resources/views/students/index.blade.php:

<!-- Tell Blade which layout to use -->
@extends('layouts.app')

<!-- Fill in the 'content' slot -->
@section('content')
    <h1>All Students</h1>
    @foreach ($students as $student)
        <p>{{ $student->name }}</p>
    @endforeach
@endsection
@extends('layouts.app') — "Use this layout!"
@section('content') ... @endsection — "Here's my unique content"
@yield('content') in layout — "Insert that content here!"
Browser receives the complete merged HTML page

Includes and Components 🧩

Break your templates into small, reusable pieces using @include. Great for things like navigation bars, alert messages, and cards that appear on multiple pages!

<!-- Include a partial Blade file -->
@include('partials.nav')
@include('partials.footer')

<!-- Include with extra variables -->
@include('partials.student-card', ['student' => $student])

<!-- Only include if a condition is true -->
@includeIf('partials.alert')
The @csrf Directive — Never Forget This! 🔒

Any HTML form that submits data to Laravel MUST include @csrf inside it. This generates a hidden security token that proves the form is legitimate and protects against cross-site request forgery attacks. Laravel will reject forms without it!
<form method="POST" action="/students">
    @csrf <!-- ALWAYS include this in forms! -->
    <input type="text" name="name">
    <button type="submit">Save</button>
</form>

Passing Data from Controller to View 📦

Remember how controllers call view()? The second argument is the data you want to pass to the template. There are two clean ways to do this:

// Method 1: Array syntax
return view('students.index', [
    'students' => Student::all(),
    'title' => 'All Students',
]);

// Method 2: compact() — cleaner for multiple variables
$students = Student::all();
$title = 'All Students';
return view('students.index', compact('students', 'title'));

In your Blade template, those variables are then available directly:

<!-- resources/views/students/index.blade.php -->
<h1>{{ $title }}</h1>
@foreach ($students as $s)
    <p>{{ $s->name }}</p>
@endforeach
