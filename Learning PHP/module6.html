Forms & POST/GET

Receive data from your users! 📬

📬 Why Do Forms Need PHP?

HTML forms collect user input (like a name or a message). But on their own, HTML forms cannot do anything with that data — they just collect it. PHP is what receives, reads, and processes the data that the form sends!

🧠 Analogy: An HTML form is like a paper survey handed to a student. PHP is the teacher who collects the surveys, reads the answers, and does something with them — like saving them or giving a response.

📮 GET vs POST — Two Ways to Send Data

When a form is submitted, it sends data to the server using one of two methods:

🔍 GET method

  • 📎 Data appears in the URL (the web address)
  • 👀 Visible to everyone
  • 🔖 Can be bookmarked
  • 📦 Only short data (very long URLs can be cut off)
  • ✅ Good for: search boxes, filters

example.com/search?q=PHP

📤 POST method

  • 📨 Data travels inside the request, not the URL
  • 🙈 Not visible in URL
  • 🔖 Cannot be bookmarked
  • 📦 Can carry much more data (the server sets a limit)
  • ✅ Good for: login forms, passwords

🏗️ A Complete Form + PHP Handler

Here is how a typical contact form works with PHP. The HTML form collects data, and the PHP code processes it:

Step 1 — The HTML Form (contact.html):

<!-- HTML Form --> <form action="handler.php" method="POST"> <label>Your Name:</label> <input type="text" name="username" required> <label>Your Message:</label> <textarea name="message"></textarea> <button type="submit">Send!</button> </form>

Step 2 — The PHP Handler (handler.php):

<?php // Read data that was sent via POST $name = $_POST["username"]; $message = $_POST["message"]; // htmlspecialchars() makes the text safe to show (see below) echo "Hello, " . htmlspecialchars($name) . "!"; echo "Your message: " . htmlspecialchars($message); ?>

⚠️ Important: The name attribute in the HTML input (e.g. name="username") must match the key you use in PHP (e.g. $_POST["username"]). They must be identical!

🌐 Superglobals: $_GET and $_POST

Superglobals are special PHP variables that are always available everywhere in your script. The most important ones for forms are:

<?php // Reading GET data from URL: example.com/page.php?city=Srinagar $city = $_GET["city"]; echo htmlspecialchars($city); // Srinagar // Reading POST data from a submitted form $email = $_POST["email"]; echo htmlspecialchars($email); // $_SERVER — information about the server and request echo $_SERVER["REQUEST_METHOD"]; // GET or POST echo htmlspecialchars($_SERVER["PHP_SELF"]); // Current file name ?>

🛡️ Form Validation — Checking User Input

Never trust user input! You must always check that the data you receive is safe and complete. Here are the key tools:

<?php // Check if the form was actually submitted if ($_SERVER["REQUEST_METHOD"] == "POST") { // isset() — check if a variable exists if (isset($_POST["username"])) { // empty() — check if the field is blank if (empty($_POST["username"])) { echo "Error: Name cannot be empty!"; } else { // htmlspecialchars() — turn < and > into harmless text $name = htmlspecialchars($_POST["username"]); echo "Welcome, " . $name . "!"; } } } ?>
🔍

isset()

Returns true if a variable exists and is not NULL. Like checking if a package was delivered.

📭

empty()

Returns true if the value is blank, zero, or null. Like checking if a box is empty.

🛡️

htmlspecialchars()

Converts dangerous characters like < and > into safe text. This stops attackers from sneaking their own code (like a script) into your page. That attack is called XSS (cross-site scripting).

🎯 Complete Self-Handling Form

A common trick is to have one PHP file handle both showing the form and processing it. The page checks if the form was submitted:

<?php $greeting = ""; if ($_SERVER["REQUEST_METHOD"] == "POST") { $name = htmlspecialchars(trim($_POST["name"])); if (!empty($name)) { $greeting = "Hello, " . $name . "! Welcome to PHP!"; } else { $greeting = "Please enter your name!"; } } ?> <!DOCTYPE html> <html> <body> <!-- Show the greeting message if there is one --> <p><?php echo $greeting; ?></p> <!-- No action: the form sends its data back to this same page --> <form method="POST"> <input type="text" name="name" placeholder="Your name"> <button type="submit">Greet Me!</button> </form> </body> </html>

🟡 Level 2: Apply

A search box sends ?city=... in the URL. Write PHP that prints Please type a city. when the box is empty. Otherwise it prints Showing libraries in and the city, made safe and trimmed.

Show answer
<?php
// empty() is safe even when "city" was not sent at all
if (empty($_GET["city"])) {
    echo "Please type a city.";
} else {
    $city = htmlspecialchars(trim($_GET["city"]));
    echo "Showing libraries in " . $city;
}
?>

🔴 Level 3: Challenge

Build a one-page sign-up form for a park clean-up day.

  1. Make one PHP file that shows a form with method="POST" and two fields: name and email.
  2. When the form is sent, trim() both fields.
  3. If the name is empty, show Please enter your name.
  4. Check the email with filter_var($email, FILTER_VALIDATE_EMAIL). It gives back false when the email is not valid.
  5. If both are fine, thank the volunteer by name. Escape the name with htmlspecialchars().
  6. Run it on your own XAMPP (save it in the htdocs folder and open it in the browser).
Show one possible answer
<?php
$message = "";
$name = "";

if ($_SERVER["REQUEST_METHOD"] == "POST") {
    $name  = trim($_POST["name"]);
    $email = trim($_POST["email"]);

    if (empty($name)) {
        $message = "Please enter your name.";
    } elseif (filter_var($email, FILTER_VALIDATE_EMAIL) === false) {
        $message = "Please enter a valid email address.";
    } else {
        $message = "Thank you, " . htmlspecialchars($name) . "! See you at the clean-up.";
    }
}
?>
<!DOCTYPE html>
<html>
<body>
    <h1>Park Clean-up Volunteers</h1>
    <p><?php echo $message; ?></p>
    <form method="POST">
        <label>Name: <input type="text" name="name" value="<?php echo htmlspecialchars($name); ?>"></label>
        <label>Email: <input type="email" name="email"></label>
        <button type="submit">Sign up</button>
    </form>
</body>
</html>

We only collect what we need: a name and an email. If a form ever asks for a password, never save the password itself. Save password_hash($password, PASSWORD_DEFAULT) and check it later with password_verify().
