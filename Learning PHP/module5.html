Arrays

Collections of Data! 📋

📋 What is an Array?

An array is like a shopping list. Instead of having a separate variable for each item, you put multiple values inside one variable — in order, numbered from zero.

🧠 Real-life analogy: Imagine a train. Each carriage (wagon) holds one passenger. The first carriage is number 0, the second is 1, and so on. The array is the entire train!

🔢 Indexed Arrays

Indexed arrays store values with automatic numeric keys starting at 0. This is the most common type of array.

<?php // Creating an indexed array $fruits = ["apple", "banana", "mango"]; // Accessing items by their index (position) echo $fruits[0]; // apple (first item — index 0) echo $fruits[1]; // banana (second item — index 1) echo $fruits[2]; // mango (third item — index 2) // Counting items echo count($fruits); // 3 // Adding a new item to the end $fruits[] = "strawberry"; // $fruits is now ["apple", "banana", "mango", "strawberry"] ?>

🗝️ Associative Arrays

Associative arrays use named keys instead of numbers. This is perfect when your data has labels — like a student's profile with a name, age, and grade.

<?php // Creating an associative array $student = [ "name" => "Ali", "age" => 12, "grade" => "A", "city" => "Lahore" ]; // Accessing values by key name echo $student["name"]; // Ali echo $student["grade"]; // A echo $student["city"]; // Lahore // Updating a value $student["grade"] = "A+"; // Adding a new key $student["school"] = "DPS"; ?>

🏢 Multi-dimensional Arrays

Arrays can contain other arrays inside them! This is called a multi-dimensional array. Think of it like a spreadsheet — rows and columns of data.

<?php // A class of students — each student is an array inside $class $class = [ ["name" => "Ali", "score" => 90], ["name" => "Sara", "score" => 85], ["name" => "Zaid", "score" => 78], ]; // Accessing nested values echo $class[0]["name"]; // Ali (first student, name) echo $class[1]["score"]; // 85 (second student, score) // Loop through all students foreach ($class as $s) { echo $s["name"] . ": " . $s["score"] . "<br>"; } ?>

🛠️ Essential Array Functions

PHP has many built-in functions to manage arrays. Here are the most useful ones:

<?php $nums = [5, 3, 9, 1, 7]; // count() — how many items? echo count($nums); // 5 // array_push() — add to the end array_push($nums, 42); // [5,3,9,1,7,42] // array_pop() — remove from the end $last = array_pop($nums); // $last = 42 // sort() — sort from smallest to largest sort($nums); // $nums is now [1, 3, 5, 7, 9] // in_array() — check if a value exists var_dump(in_array(7, $nums)); // bool(true) var_dump(in_array(99, $nums)); // bool(false) // array_merge() — join two arrays $a = [1, 2]; $b = [3, 4]; $c = array_merge($a, $b); // [1, 2, 3, 4] // array_keys() and array_values() $car = ["brand" => "Toyota", "color" => "Red"]; $keys = array_keys($car); // ["brand", "color"] $vals = array_values($car); // ["Toyota", "Red"] ?>
Function What it does
count() Returns the number of items in an array
array_push() Adds one or more items to the end
array_pop() Removes and returns the last item
sort() Sorts array values in ascending order
in_array() Checks if a value exists in an array
array_merge() Combines two or more arrays into one
array_keys() Returns all the keys of an array
array_values() Returns all the values of an array

🔁 Looping Through Arrays with foreach

The foreach loop and arrays are best friends! Use it to automatically visit every item in an array.

<?php // Example: Build a shopping list $cart = [ "Rice" => 200, "Bread" => 60, "Milk" => 120, "Apples" => 350, ]; $total = 0; foreach ($cart as $item => $price) { echo $item . ": Rs " . $price . "<br>"; $total += $price; } echo "---<br>Total: Rs " . $total; // Output: // Rice: Rs 200 // Bread: Rs 60 // Milk: Rs 120 // Apples: Rs 350 // --- // Total: Rs 730 ?>
