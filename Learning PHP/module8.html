Build cleaner, reusable code with Classes and Objects!

🧱 What is Object-Oriented Programming?

OOP is a way of organizing your code using blueprints (classes) to create things (objects) that have their own properties and actions.

🚗 The Car Blueprint Analogy

A class is like a car blueprint — it describes what every car has (color, speed, brand) and what a car can do (accelerate, brake, honk). An object is an actual car built from that blueprint. You can build many cars (objects) from the same blueprint (class) — each one is its own individual car!

📐 Defining a Class

Use the class keyword to define a class. Properties are variables that belong to the object. Methods are functions that belong to the object. Inside a class, $this means "this object". In our example, students earn XP (experience points) for each module.

<?php class Student { // Properties public $name; public $grade; public $xp = 0; // Constructor — runs automatically when object is created public function __construct($name, $grade) { $this->name = $name; $this->grade = $grade; } // Method public function completeModule() { $this->xp += 100; echo $this->name . " earned 100 XP! Total: " . $this->xp; } } ?>

🏭 Creating Objects

Use the new keyword to create an object from a class. Access properties and methods with the arrow -> operator.

<?php // Create two different Student objects from the same class $ali = new Student("Ali", "9th"); $sara = new Student("Sara", "10th"); // Access a property echo $ali->name; // Ali echo $sara->grade; // 10th // Call a method $ali->completeModule(); // Ali earned 100 XP! Total: 100 $ali->completeModule(); // Ali earned 100 XP! Total: 200 $sara->completeModule(); // Sara earned 100 XP! Total: 100 ?>

🔐 Access Modifiers

Access modifiers are keywords that decide who can use a property or method. PHP has three:

🌍

public

Accessible from anywhere — inside the class, outside it, in child classes.

🏠

protected

Only accessible inside the class and classes that extend it (child classes).

🔒

private

Only accessible inside the exact class it's defined in. Totally hidden.

👨‍👩‍👧 Inheritance — Extending Classes

A child class can extend a parent class to inherit all its properties and methods, then add its own unique behaviour.

<?php class Person { public $name; public function greet() { echo "Hi, I am " . $this->name; } } // Student inherits everything from Person class Student extends Person { public $grade; public function study() { echo $this->name . " is studying in grade " . $this->grade; } } $s = new Student(); $s->name = "Yasir"; $s->grade = "9th"; $s->greet(); // Hi, I am Yasir $s->study(); // Yasir is studying in grade 9th ?>
💡 Why OOP?

OOP keeps your code organized, reusable, and easy to maintain. Instead of writing the same logic over and over, you define it once in a class and create as many objects as you need. Laravel and most modern PHP projects are built this way. (A framework is a ready-made toolkit for building websites.)

🟡 Level 2: Apply

Write a Book class with a public $title and a private $available = true. Add a method borrow() that sets $available to false, and a method isAvailable() that returns it. Why make $available private?

Show answer
<?php
class Book {
    public $title;
    private $available = true;

    public function __construct($title) {
        $this->title = $title;
    }

    public function borrow() {
        $this->available = false;
        echo $this->title . " has been borrowed.<br>";
    }

    public function isAvailable() {
        return $this->available;
    }
}

$book = new Book("Clean Code");
$book->borrow();
var_dump($book->isAvailable());   // bool(false)
?>

Private means only the class itself can change $available. Other code must use borrow(), so the book cannot be marked wrongly by mistake.

🔴 Level 3: Challenge

Model a charity donation box.

  1. Make a class DonationBox with private $cause and private $total = 0.
  2. The constructor takes the cause, for example "Clean Water".
  3. Add donate($amount). Add the amount only if it is more than 0. Otherwise print a polite message.
  4. Add report(). It returns a sentence like Clean Water: Rs 6500 collected.
  5. Make a child class ClassroomBox that extends DonationBox with a public $room, and a method label() that returns the room plus the report.
  6. Try it in the PHP Console.
Show one possible answer
<?php
class DonationBox {
    private $cause;
    private $total = 0;

    public function __construct($cause) {
        $this->cause = $cause;
    }

    public function donate($amount) {
        if ($amount > 0) {
            $this->total += $amount;
        } else {
            echo "Please enter an amount above zero.\n";
        }
    }

    public function report() {
        return $this->cause . ": Rs " . $this->total . " collected";
    }
}

class ClassroomBox extends DonationBox {
    public $room;

    public function label() {
        return "Room " . $this->room . " - " . $this->report();
    }
}

$box = new ClassroomBox("Clean Water");
$box->room = "8B";
$box->donate(1500);
$box->donate(5000);
$box->donate(0);          // Please enter an amount above zero.
echo $box->label();       // Room 8B - Clean Water: Rs 6500 collected
?>

The child class cannot touch the private $total directly. It uses the public report() method instead. That is encapsulation: the box guards its own data.
