PHP Glossary

Quick reference for the terms used in the PHP track

A
Array
A variable that holds a list of values: $books = ["Clean Code", "Algorithm Design"];. Items are numbered from 0, so $books[0] is "Clean Code".
Associative array
An array whose items have named keys instead of numbers: ["Clean Code" => "Yes", "Ethical Technology" => "No"]. Read one with $books["Clean Code"].
B
Boolean
A value that is either true or false, usually the result of a comparison such as $gpa >= 3.8.
C
Class
A blueprint for objects: it lists properties (data) and methods (functions). class Book { ... }.
Comment
A note for humans that PHP ignores: // one line or /* several lines */.
Concatenation
Joining strings with the dot operator: "Hello, " . $name.
Condition
A test that is true or false, used by if, while and for: if ($daysLate > 0).
Constructor
The special method __construct() that runs when an object is created with new, usually to set its properties.
CSRF
Cross-Site Request Forgery: tricking a logged-in user's browser into submitting a form they did not intend. Prevented with a secret token checked on every POST.
E
echo
Prints text or values to the page: echo "Total: $total";. Several values can be separated with commas.
else / elseif
Alternatives for an if: if (...) { } elseif (...) { } else { }. Only the first true branch runs.
F
file_put_contents / file_get_contents
Write a whole file or read a whole file in one call. Use FILE_APPEND to add to the end instead of replacing.
for loop
Repeats code a known number of times: for ($i = 1; $i <= 5; $i++) { ... }.
foreach loop
Goes through every item of an array: foreach ($books as $title) or, with keys, foreach ($books as $title => $available).
Function
A named, reusable block of code: function square($n) { return $n * $n; }. Call it with square(7).
G
$_GET
Data sent in the page address after ?, for example search.php?q=php gives $_GET["q"]. Fine for searches, not for passwords.
H
htmlspecialchars()
Converts <, >, & and quotes into safe text so user input cannot inject HTML or scripts (XSS protection). Use it on everything you print that came from a user.
I
if statement
Runs code only when a condition is true: if ($gpa >= 3.8) { echo "Honour roll"; }.
include / require
Pull another PHP file into this one, for example a shared header. require stops the script if the file is missing.
Integer / Float
Whole numbers (13) and decimal numbers (3.85).
M
Method
A function that belongs to a class: $book->summary().
N
new
Creates an object from a class: $book = new Book("Clean Code", 464);.
null
"No value". A variable that has not been given anything, or a missing form field, is null.
O
Object
One thing made from a class, with its own property values: one particular book.
Operator
A symbol that does something with values: + - * / (maths), . (join strings), == === != < > >= (compare), && || (and / or).
P
password_hash()
Turns a password into a scrambled hash before saving it. Check a login with password_verify(). Never store the real password (Amānah: the user's secret is a trust).
PHP tag
<?php starts PHP code inside a file; the closing ?> is optional at the end of a pure PHP file.
$_POST
Data from a form submitted with method="post": $_POST["name"]. Used for anything private or that changes data.
Property
A variable that belongs to an object: $book->title. Declared in the class with public $title;.
R
return
Sends a value back from a function and ends it: return $n * $n;.
S
Server-side
Code that runs on the web server before the page is sent. The visitor only sees the HTML it produced, never the PHP.
Session
Data the server remembers about one visitor between pages, such as who is logged in: session_start(); $_SESSION["user"] = "Zayd";.
String
Text in quotes. Double quotes fill in variables ("Hi, $name"); single quotes print exactly what is typed.
Superglobal
Variables PHP provides everywhere, written in capitals: $_GET, $_POST, $_SESSION, $_FILES, $_SERVER.
T
$this
Inside a class, the object the method was called on: $this->title.
V
Validation
Checking user input before using it: is it filled in, a number, an email, within limits? Always validate on the server even if the browser already checked.
Variable
A named box for a value: $student = "Bilal";. Names start with $ and are case-sensitive.
W
while loop
Repeats while a condition stays true: while ($count < 3) { $count++; }. Make sure something inside changes the condition, or it never stops.
X
XSS
Cross-Site Scripting: an attacker types a <script> into a form and it runs for other visitors. Prevented by escaping output with htmlspecialchars().
