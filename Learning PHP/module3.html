Control Flow

Tell PHP what to do and when! 🚦

🚦 Making Decisions with if / else

In real life, you make decisions all the time: "If it is raining, I will take an umbrella. Otherwise, I will wear sunglasses." PHP can make decisions the same way!

<?php $age = 15; if ($age >= 18) { echo "You can vote!"; } elseif ($age >= 13) { echo "You are a teenager!"; } else { echo "You are a kid!"; } // Output: You are a teenager! ?>

Let us understand the structure:

  • if (condition) — Check the first condition (a question whose answer is true or false). If it is true, run the block (the code inside the curly braces).
  • elseif (condition) — If the first condition failed, check another one.
  • else — If none of the above are true, run this block.
  • Curly braces { } wrap the code that belongs to each branch.

🔢 Comparison operators (symbols that compare two values) you'll use in conditions:

  • == — Equal to (value only)
  • === — Identical (value AND type)
  • != — Not equal to
  • > — Greater than
  • < — Less than
  • >= — Greater than or equal to
  • <= — Less than or equal to

🎛️ The Switch Statement

When you have many possible values for one variable, a switch is cleaner than many elseif blocks. Think of it like the buttons in a lift — each button (case) takes you somewhere different!

<?php $day = "Monday"; switch ($day) { case "Monday": echo "Start of school week 😅"; break; case "Friday": echo "Almost the weekend! 🎉"; break; case "Saturday": case "Sunday": echo "Weekend! Time to relax! 😎"; break; default: echo "Just another weekday."; } // Output: Start of school week 😅 ?>

⚠️ Don't forget break! Without it, PHP will keep running through all the cases below, even if they don't match. This is called "fall-through".

🔁 The for Loop

Loops let you repeat code many times without writing it over and over. A for loop is perfect when you know exactly how many times to repeat.

🧠 Analogy: Imagine a teacher saying: "Write your name 10 times." You would not write 10 separate lines. You would just count and keep writing until you reached 10.

<?php // Print numbers 1 to 5 for ($i = 1; $i <= 5; $i++) { echo "Number: " . $i . "<br>"; } // Output: Number: 1, Number: 2 ... Number: 5 // Count down from 5 to 1 for ($i = 5; $i >= 1; $i--) { echo $i . "... "; } // Output: 5... 4... 3... 2... 1... ?>

The for loop has 3 parts inside the brackets:

  1. Start: $i = 1 — begin counting from 1
  2. Condition: $i <= 5 — keep going while i is 5 or less
  3. Step: $i++ — add 1 to i after each loop

⏳ The while Loop

A while loop keeps running as long as a condition is true. Use it when you don't know in advance how many times to loop.

<?php // Simulate a number guessing game $secret = 7; $guess = 1; while ($guess != $secret) { echo "Guessing: " . $guess . "<br>"; $guess++; } echo "Found it! The secret was " . $secret; // Prints: Guessing: 1, 2, 3, 4, 5, 6 — then "Found it! The secret was 7" ?>

⚠️ Infinite Loop Warning! If your condition never becomes false, the loop never stops. The page never finishes loading, until PHP gives up at its time limit. Always make sure your loop variable changes inside the loop!

📋 The foreach Loop

The foreach loop is specially designed for arrays (lists of items). It automatically goes through each item one by one — perfect for looping over data!

<?php $fruits = ["Apple", "Banana", "Mango", "Strawberry"]; foreach ($fruits as $fruit) { echo "I love " . $fruit . "!<br>"; } // Output: // I love Apple! // I love Banana! // I love Mango! // I love Strawberry! // With associative arrays, each value has a name called a key (key => value). // Module 5 explains these fully. $student = ["name" => "Sara", "age" => 13, "grade" => "A"]; foreach ($student as $key => $value) { echo $key . ": " . $value . "<br>"; } // Output: name: Sara, age: 13, grade: A ?>

💡 PHP loops work just like JavaScript loops! If you know JavaScript, you already understand the logic. The main difference is PHP uses $ for variables and has the handy foreach for arrays.

🎯 Real Example: The Grade Calculator

Let's combine everything we've learned to build a grade checker:

<?php $scores = [88, 72, 95, 61, 78]; foreach ($scores as $score) { if ($score >= 90) { echo $score . ": Grade A ⭐<br>"; } elseif ($score >= 75) { echo $score . ": Grade B 👍<br>"; } elseif ($score >= 60) { echo $score . ": Grade C 📚<br>"; } else { echo $score . ": Grade F — Keep practising! 📖<br>"; } } ?>

🏆 Practice: three levels

🟢 Level 1: Recall

How many times does this loop run: for ($i = 1; $i <= 4; $i++)? And what does break do inside a switch?

Show answer
It runs 4 times (for 1, 2, 3 and 4). break stops the switch so PHP does not run the next cases too.

🟡 Level 2: Apply

The library counts how many books come back each day: [12, 7, 15, 4, 10]. Use foreach and if / else to print Busy day when 10 or more books came back, and Quiet day otherwise.

Show answer
<?php
$returned = [12, 7, 15, 4, 10];

foreach ($returned as $books) {
    if ($books >= 10) {
        echo $books . " books: Busy day<br>";
    } else {
        echo $books . " books: Quiet day<br>";
    }
}
?>

Busy days are 12, 15 and 10. Quiet days are 7 and 4.

🔴 Level 3: Challenge

Your class is collecting water bottles for a charity drive. The target is 100 bottles. Each day the class brings 15 bottles.

  1. Make $target = 100, $total = 0 and $day = 0.
  2. Use a while loop that keeps going while $total is less than the target.
  3. Inside the loop, add 1 to $day, add 15 to $total, and print the day and the total.
  4. After the loop, print how many days it took.
  5. Try it in the PHP Console. There, use "\n" for a new line; on a web page use <br>.
Show one possible answer
<?php
$target = 100;
$total  = 0;
$day    = 0;

while ($total < $target) {
    $day++;
    $total = $total + 15;
    echo "Day " . $day . ": " . $total . " bottles\n";
}

echo "Target reached in " . $day . " days!";
?>

The total goes 15, 30, 45, 60, 75, 90, 105. The target is reached in 7 days.
