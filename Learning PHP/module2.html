Variables & Data Types

Store and use information like a pro! 📦

📦 What is a Variable?

A variable is like a labelled box. You put a value inside, give it a name, and you can use that value anytime later. In PHP, all variables start with a dollar sign $.

🧠 Real-life analogy: Imagine a filing cabinet with labelled folders. The folder named $studentName contains "Ali". Whenever you need the student's name, you just open that folder!

<?php // Creating variables $name = "Ali"; $age = 13; $score = 98.5; echo $name; // prints: Ali echo $age; // prints: 13 echo $score; // prints: 98.5 ?>

📏 Variable naming rules:

  • Must start with $ followed by a letter or underscore
  • Can contain letters, numbers, and underscores
  • Cannot start with a number: $1name is invalid!
  • Are case-sensitive: $Age and $age are different

🗂️ PHP Data Types

PHP supports several types of data. Think of these like different kinds of containers — a glass holds liquid, a box holds solids:

<?php // String — text surrounded by quotes $city = "Karachi"; // Integer — whole numbers (no decimal point) $students = 30; // Float — numbers with a decimal point $gpa = 3.75; // Boolean — only true or false $passed = true; // NULL — an empty box (no value) $result = null; // Array — a list of multiple values $grades = [90, 85, 92]; ?>
💬

String

Any text inside quotes. "Hello", "Ali", "123 Main St"

🔢

Integer

Whole numbers. 5, -10, 1000 — no decimals allowed!

📊

Float

Decimal numbers. 3.14, 9.99, -0.5

✅

Boolean

Only two values: true or false. Like a light switch — on or off!

🔍 Inspecting Variables with var_dump()

Not sure what type a variable is? Use var_dump() — it shows both the value AND the type. Super useful for debugging!

<?php $score = 95; $name = "Fatima"; $pass = true; var_dump($score); // int(95) var_dump($name); // string(6) "Fatima" var_dump($pass); // bool(true) ?>

You can also force a variable to become a certain type. This is called type casting:

<?php $number = "42"; // This is a string "42" $asInt = (int) $number; // Now it is the integer 42 var_dump($asInt); // int(42) ?>

🔗 Joining Strings (Concatenation)

In PHP, you join (concatenate) strings using the dot operator .. Think of it like gluing two pieces of paper together!

<?php $firstName = "Ahmed"; $lastName = "Khan"; // Joining with dot operator $fullName = $firstName . " " . $lastName; echo $fullName; // Ahmed Khan // Variables inside double quotes also work! echo "Hello, $firstName!"; // Hello, Ahmed! ?>

💡 Double vs Single Quotes:

  • Double quotes "...": Variables inside are replaced with their values
  • Single quotes '...': Everything is treated as plain text — variables are NOT expanded

🛠️ Useful String Functions

PHP has hundreds of built-in functions to work with strings. Here are the most useful ones for beginners:

<?php $text = " Hello, World! "; // Count how many characters are in the string echo strlen("Junior"); // 6 // Convert to ALL UPPERCASE echo strtoupper("hello"); // HELLO // Convert to all lowercase echo strtolower("WORLD"); // world // Remove spaces from the beginning and end echo trim($text); // "Hello, World!" // Replace one piece of text with another echo str_replace("World", "PHP", "Hello, World!"); // Hello, PHP! // Get a part of a string (start at position 0, take 5 characters) echo substr("Junior Coder", 0, 6); // Junior ?>
Function What it does Example Output
strlen() Length of string strlen("Ali") → 3
strtoupper() Uppercase the string "hello" → "HELLO"
strtolower() Lowercase the string "HELLO" → "hello"
trim() Remove surrounding spaces " hi " → "hi"
str_replace() Find and replace text "cat" → "dog"
substr() Extract part of a string "Hello" → "Hel"

🧪 Try It Yourself!

Look at the code below. Can you figure out what each echo will print? Write your answers on paper first, then check with a PHP runner!

<?php $animal = "elephant"; $count = 5; echo strtoupper($animal); // What prints? echo strlen($animal); // What prints? echo $count . " " . $animal . "s"; // What prints? echo substr($animal, 0, 3); // What prints? ?>

🎯 Answers:

  • strtoupper($animal) → ELEPHANT
  • strlen($animal) → 8 (e-l-e-p-h-a-n-t)
  • $count . " " . $animal . "s" → 5 elephants
  • substr($animal, 0, 3) → ele
