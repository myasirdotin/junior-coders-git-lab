🍽️ What is PHP?

PHP stands for PHP: Hypertext Preprocessor (yes, the name contains itself — programmers are funny like that!). It is a server-side programming language, which means it runs on the web server — not in your browser.

🧠 Think of it like a restaurant:

PHP is like a waiter in a restaurant. You (the browser) order food. The waiter (PHP) goes to the kitchen (the database), gets the food, cooks it up, and brings it back to you. You never see what happens in the kitchen — you just get the result!

🌐

HTML

The structure of the page — the walls and doors of the restaurant

🎨

CSS

The looks — the decorations and colour of the restaurant

⚙️

PHP

The kitchen — where all the real work happens behind the scenes!

🔄 How PHP Works

When you visit a PHP-powered website, here is what happens step by step:

🖥️ Browser sends a Request
🌍 Web Server receives it
⚙️ PHP runs and builds the page
📄 HTML Response is sent back
🖥️ Browser shows the final page

The browser never sees PHP code — it only receives the HTML that PHP created. This is what makes PHP powerful and secure!

✍️ Your First PHP Code

All PHP code is written inside special tags: <?php to open and ?> to close. Everything in between is PHP!

<?php // This is a comment — PHP ignores it echo "Hello, Junior Coder!"; $name = "Yasir"; echo "Welcome, " . $name; ?>

Let us break down each line:

  • <?php — Opens the PHP block. Everything after this is PHP code.
  • // This is a comment — PHP ignores lines starting with //. Great for notes!
  • echo "Hello, Junior Coder!"; — echo prints text to the screen. Always end with a semicolon ;
  • $name = "Yasir"; — Creates a variable called $name and stores the text "Yasir".
  • echo "Welcome, " . $name; — The dot . joins two pieces of text together.
  • ?> — Closes the PHP block.

💡 Important Rules:

  • Every PHP statement ends with a semicolon ; — never forget it!
  • PHP is case-sensitive for variable names: $name and $Name are different!
  • PHP files are saved with the .php extension, not .html

⚔️ PHP vs JavaScript — What's the Difference?

You might already know JavaScript. Here is how PHP compares:

⚡ JavaScript

  • 🖥️ Runs in the browser
  • 👀 User can see the code
  • 🎯 Makes pages interactive
  • 🔄 Responds to clicks & events
  • 📁 Cannot read server files

🐘 PHP

  • 🌍 Runs on the server
  • 🔒 Code is hidden from users
  • 🗄️ Connects to databases
  • 📂 Can read & write files
  • 📬 Processes form data

Many websites use both! PHP builds the page on the server, and JavaScript makes it interactive in the browser.

🏃 Getting PHP Running

To run PHP, you need a web server with PHP installed. Here are two popular options for beginners:

🪟

XAMPP

Free tool for Windows & Mac. Installs Apache + PHP + MySQL all at once!

🐧

LAMP Stack

Linux + Apache + MySQL + PHP — the classic server setup used worldwide.

☁️

Online Editors

Sites like 3v4l.org let you run PHP in the browser for free!
