⚙️ What is a Function?

A function is a named block of code that performs a specific task. Instead of writing the same code multiple times, you write it once inside a function and then call it whenever you need it.

🧠 Real-life analogy: Think of a function like a vending machine. You press a button (call the function), put in coins (pass values), and get a snack out (receive a result). You don't need to know how the machine works — you just use it!

<?php // Step 1: DEFINE the function (build the vending machine) function greet() { echo "Hello, welcome to PHP!"; } // Step 2: CALL the function (press the button) greet(); // Output: Hello, welcome to PHP! greet(); // Call it again — it works every time! ?>

📥 Functions with Parameters

Parameters are like inputs you give to a function. They let the function do its job with different data each time you call it.

<?php // Function with one parameter: $name function greet($name) { echo "Hello, " . $name . "!"; } greet("Ali"); // Output: Hello, Ali! greet("Sara"); // Output: Hello, Sara! greet("Yasir"); // Output: Hello, Yasir! // Multiple parameters function addNumbers($a, $b) { echo $a + $b; } addNumbers(10, 5); // Output: 15 addNumbers(100, 200); // Output: 300 ?>

🎯 Default Parameter Values

You can give a parameter a default value. If the caller doesn't provide a value, the default is used automatically. It's like a pizza shop that uses mozzarella cheese by default unless you ask for something else!

<?php // $language has a default value of "PHP" function introduce($name, $language = "PHP") { echo "Hi! I am " . $name . " and I love " . $language . "!<br>"; } introduce("Ali"); // Hi! I am Ali and I love PHP! introduce("Sara", "Python"); // Hi! I am Sara and I love Python! ?>

📤 Returning Values

Instead of just printing, functions can return a value back to where they were called from. This lets you use the result in other calculations or save it in a variable.

<?php // This function RETURNS the result instead of printing it function multiply($a, $b) { return $a * $b; } $result = multiply(4, 5); echo $result; // Output: 20 // You can also use the return value directly echo multiply(3, 7); // Output: 21 // A more practical example function getGrade($score) { if ($score >= 90) return "A"; if ($score >= 75) return "B"; if ($score >= 60) return "C"; return "F"; } echo getGrade(88); // Output: B echo getGrade(95); // Output: A ?>

🔭 Variable Scope — Where Variables Live

In PHP, variables created inside a function are only available inside that function. They do not exist outside. This is called local scope. Scope means the part of your code where a variable can be seen. A variable made outside every function is called a global variable.

<?php $planet = "Earth"; // Global variable function showPlanet() { // $planet is NOT available here without 'global' echo $planet; // PHP warns: Undefined variable $planet } function showPlanetFixed() { global $planet; // Import the global variable echo $planet; // Now it works! } showPlanetFixed(); // Output: Earth ?>

💡 Best Practice: Rather than using global, it is better to pass variables as parameters and return results. This makes your code cleaner and easier to understand.

🏗️ Useful Built-in PHP Functions

PHP comes with thousands of functions already built in. Here are some you'll use all the time:

<?php // Math functions echo abs(-10); // 10 (absolute value) echo round(4.6); // 5 (round to nearest whole number) echo max(3, 8, 1); // 8 (largest value) echo min(3, 8, 1); // 1 (smallest value) echo rand(1, 100); // Random number between 1 and 100 echo pow(2, 8); // 256 (2 to the power of 8) // Type checking var_dump(is_int(42)); // bool(true) var_dump(is_string("Hi")); // bool(true) var_dump(is_null(null)); // bool(true) ?>

🔴 Level 3: Challenge

Build a small report-card helper for a teacher.

  1. Write average($a, $b, $c). It returns the average of three scores, rounded with round().
  2. Write gradeFor($score). It returns "A" for 90 or more, "B" for 75 or more, "C" for 60 or more, and "Keep practising" otherwise.
  3. Write report($name, $a, $b, $c). It uses the two functions above and returns one sentence.
  4. Print report("Maryam", 88, 79, 91).
  5. Try it in the PHP Console.
Show one possible answer
<?php
function average($a, $b, $c) {
    return round(($a + $b + $c) / 3);
}

function gradeFor($score) {
    if ($score >= 90) return "A";
    if ($score >= 75) return "B";
    if ($score >= 60) return "C";
    return "Keep practising";
}

function report($name, $a, $b, $c) {
    $avg = average($a, $b, $c);
    return $name . ": average " . $avg . ", grade " . gradeFor($avg);
}

echo report("Maryam", 88, 79, 91);   // Maryam: average 86, grade B
?>
