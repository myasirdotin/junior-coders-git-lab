File System

Read and Write Files with PHP! 📁

📁 Why Work with Files?

Sometimes you want data to persist — to stay saved even after the browser is closed or the server restarts. A simple way to do this in PHP is to save data to text files on the server.

🧠 Analogy: Think of your PHP script as a student and the file system as a notebook. PHP can open the notebook, read what's written, add new notes, or erase old ones — and the notebook keeps everything even after the student goes home!

📖

Read a File

Load existing content from a file into your PHP script

✏️

Write to a File

Save new content (or replace old content) in a file

➕

Append to a File

Add new content to the end of an existing file

⚡ The Easy Way: file_get_contents & file_put_contents

PHP gives us two super convenient functions for basic file operations. These are the easiest to use and perfect for beginners:

<?php // WRITE: Create a file and save content into it // If the file doesn't exist, PHP creates it automatically! file_put_contents("notes.txt", "Hello, this is my first file!"); // READ: Load all the content from the file as a string $content = file_get_contents("notes.txt"); echo $content; // Output: Hello, this is my first file! // APPEND: Add content to the END of the file (use FILE_APPEND flag) file_put_contents("notes.txt", "\nA second line!", FILE_APPEND); // Read again to see both lines echo file_get_contents("notes.txt"); // Hello, this is my first file! // A second line! ?>

🔧 The Advanced Way: fopen, fwrite, fread, fclose

For more control over file operations, use the fopen() family of functions. Think of it like actually picking up a pen and writing step by step.

<?php // Step 1: OPEN the file // "w" = write (creates file or clears existing content) // "r" = read (file must already exist) // "a" = append (add to end of file) // "r+" = read and write $file = fopen("diary.txt", "w"); // Step 2: WRITE content to the file fwrite($file, "Day 1: I started learning PHP!\n"); fwrite($file, "Day 2: I understand file handling!\n"); // Step 3: CLOSE the file (very important!) fclose($file); // Now READ the file back $reader = fopen("diary.txt", "r"); $data = fread($reader, filesize("diary.txt")); fclose($reader); echo $data; // Output: // Day 1: I started learning PHP! // Day 2: I understand file handling! ?>

⚠️ Always close files! Not closing a file with fclose() can cause data corruption or leave the file locked. Think of it like always putting the lid back on a pen!

🔍 Checking and Deleting Files

Before reading a file, it's smart to check if it actually exists. And sometimes you need to delete files too:

<?php // Check if a file exists before reading if (file_exists("notes.txt")) { $content = file_get_contents("notes.txt"); echo $content; } else { echo "File not found!"; } // Delete a file (be careful — this is permanent!) if (file_exists("old-log.txt")) { unlink("old-log.txt"); echo "File deleted!"; } // Get the size of a file in bytes echo filesize("notes.txt"); // e.g. 31 bytes ?>

🎯 Practical Example: Save Form Data to a File

Let's put it all together! Here is how you can build a simple form that saves messages to a text file — like a basic guestbook:

<?php $logFile = "messages.txt"; if ($_SERVER["REQUEST_METHOD"] == "POST") { $name = htmlspecialchars(trim($_POST["name"])); $message = htmlspecialchars(trim($_POST["message"])); $date = date("Y-m-d H:i:s"); if (!empty($name) && !empty($message)) { // Save to file: one entry per line $entry = "[$date] $name: $message\n"; file_put_contents($logFile, $entry, FILE_APPEND); echo "<p>Message saved! ✅</p>"; } } // Display all saved messages if (file_exists($logFile)) { echo "<pre>"; echo file_get_contents($logFile); echo "</pre>"; } ?> <form method="POST"> <input type="text" name="name" placeholder="Your name"> <input type="text" name="message" placeholder="Your message"> <button type="submit">Save Message</button> </form>

🔒 Safety Notes about File Permissions

🛡️ Security is important! Here are key safety rules:

  • Never let users control the filename — always use a filename you define in code
  • Always use htmlspecialchars() on user input before saving to files
  • Store sensitive files outside the web-accessible folder so they can't be downloaded directly
  • On Linux/Mac servers, files need the correct permissions (chmod 644) to be writable by PHP
  • Use file_exists() before reading to avoid errors
Function What it does
file_get_contents() Read entire file as a string
file_put_contents() Write (or overwrite) a file
fopen() Open a file for reading/writing
fwrite() Write to an opened file
fread() Read content from an opened file
fclose() Close an opened file
file_exists() Check if a file exists
unlink() Delete a file permanently
