## 🎯 Course Overview

Before graphic user interfaces (GUIs), windows, and mice existed, software engineers communicated with computers through text commands. Today, the Command Prompt and Terminal remain the fastest, most powerful way to:

1. **Navigate the operating system** at lightning speed without touching a mouse.
2. **Scaffold web applications** with multiple folders and files in a matter of seconds.
3. **Run developer toolchains** including Git, Node.js, PHP, Composer, and local web servers.
4. **Automate tasks** and manage server environments like a seasoned engineer.

This textbook equips students to be dual-fluent in both the **Windows Command Prompt (CMD)** and the **Unix / Git Bash / macOS Terminal**, building confidence from day one.

## 🌟 Islamic Ethical Framework (*Amānah & Iḥsān*)

In accordance with our core guidelines:
- **Digital Trust (*Amānah*)**: Destructive terminal commands (`del`, `rm -rf`) cannot be undone by the Recycle Bin. Power in the terminal comes with moral responsibility and carefulness.
- **Never Blindly Paste**: We instill the habit of never running obfuscated or unknown scripts from unverified internet sources.
- **Excellence (*Iḥsān*)**: Craft clean, well-organized directory trees and master shortcuts to avoid wasting time on repetitive tasks.
- **Beneficial Knowledge (*'Ilm Nāfi'*)**: Harness terminal automation to build useful tools that benefit families, schools, and communities.
