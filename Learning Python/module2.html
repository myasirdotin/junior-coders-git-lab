Teach your computer how to make wise decisions using if, elif, and else statements.

The Railway Switch Analogy

A train switch directs the train down Track A if the light is green, or Track B if the light is red. In Python, an if statement checks whether a condition evaluates to True or False.

water_liters = 4

if water_liters < 5:
    print("Warning: Community reservoir is low!")
else:
    print("Reservoir levels are optimal.")

Run the code above and you get this output (what the program shows on screen):

Warning: Community reservoir is low!

4 is less than 5, so the condition is True. Python runs the first message and skips the else part.

⚖️ Asking Questions: Comparison Operators

A condition is a question with a yes-or-no answer. In Python, yes is True and no is False. These are the Boolean values from Module 1.

You build a condition with a comparison operator:

  • == is equal to (two equals signs)
  • != is not equal to
  • < less than, > greater than
  • <= less than or equal to, >= greater than or equal to

Worked example 1: printing the answers

print(8 > 5)
print(3 == 4)
print("Fig" == "Fig")
print(10 != 7)

Output:

True
False
True
True

Text can be compared too. "Fig" == "Fig" is True because both strings match exactly, letter by letter.

📐 The Colon and the Indent

Every if, elif and else line ends with a colon :. The colon means "the steps for this choice come next".

The steps underneath are pushed in by 4 spaces. This push-in is called an indent. Python uses the indent to know which lines belong to which choice.

elif is short for "else if". It asks a second question only when the first answer was False. You can have as many elif lines as you need. Python checks them from top to bottom and stops at the first True one.

Worked example 2: reading badges at the library

minutes_read = 45

if minutes_read >= 60:
    print("Gold reader badge!")
elif minutes_read >= 30:
    print("Silver reader badge!")
else:
    print("Keep going, every page counts.")

print("Thank you for reading today.")

Output:

Silver reader badge!
Thank you for reading today.

45 is not 60 or more, so the first test is False. 45 is 30 or more, so the second test is True. The last line has no indent, so it runs every time.

Logical Connectors: and, or, not

Combine multiple checks to make nuanced choices:

and (Both must be True)

has_permission and is_safe

or (Either one True)

is_weekend or is_holiday

not (Invert Truth)

not has_errors

🔗 Worked Example 3: Borrowing a Book

The library lets a member borrow a book only if they have fewer than 3 books at home. Both things must be true, so we use and.

is_member = True
books_out = 2

if is_member and books_out < 3:
    print("You may borrow another book.")
else:
    print("Please return a book first.")

is_raining = False
print(not is_raining)

Output:

You may borrow another book.
True

not flips a Boolean. not False becomes True.

⚠️ Common mistake: one = instead of two

A single = stores a value. A double == compares two values. This line is wrong:

if score = 10:

Python stops and says:

SyntaxError: invalid syntax. Maybe you meant '==' or ':=' instead of '='?

Write if score == 10: instead. Also watch out for a missing colon, or a line under if with no indent. The second one gives an IndentationError.

🧪 Your Turn: Smart Greenhouse Thermostat

Write an if-elif-else chain that checks the greenhouse temperature in °C. Above 35: open the vents. Below 15: turn on the soil warming pads. Anything else: ideal growing conditions. Test it with temp = 32.

Show answer
temp = 32

if temp > 35:
    print("Action: Open ventilation vents and activate shade cloth.")
elif temp < 15:
    print("Action: Turn on eco-friendly soil warming pads.")
else:
    print("Action: Ideal growing conditions for seedlings!")

Action: Ideal growing conditions for seedlings!

🏆 Practice: three levels

🟢 Level 1: Recall

Which operator checks whether two values are equal: = or ==? And what does print(7 <= 7) show?

Show answer
== checks for equality (a single = stores a value). print(7 <= 7) shows True, because 7 is equal to 7.

🟡 Level 2: Apply

A park clean-up can start only when at least 5 volunteers have come and they can stay for at least 2 hours. Store volunteers = 6 and hours = 3, then print the right message.

Show answer
volunteers = 6
hours = 3

if volunteers >= 5 and hours >= 2:
    print("The park clean-up can start.")
else:
    print("We need more help first.")

Output: The park clean-up can start.

🔴 Level 3: Challenge

Build a ticket checker for the town science centre.

  1. Store a visitor's age in a variable.
  2. Under 5: print Ticket: free.
  3. Under 18: print Ticket: student price.
  4. Everyone else: print Ticket: adult price.
  5. Test it with the ages 3, 9 and 40.
Show one possible answer
age = 9

if age < 5:
    print("Ticket: free")
elif age < 18:
    print("Ticket: student price")
else:
    print("Ticket: adult price")

With age = 9 the output is Ticket: student price. The order matters: the smallest age check comes first.
