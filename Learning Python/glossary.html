Python & ML Glossary 📚

Essential vocabulary for junior data scientists and software engineers.

Amānah (Digital Trust / Sacred Custodianship) 🛡️

The moral obligation to safeguard user data, respect privacy boundaries, and reject abusive or deceptive algorithmic designs.

Classification 🏷️

A supervised machine learning task where the model learns to sort new observations into distinct discrete categories (e.g. Clean vs Contaminated water).

Context Manager (with) 📁

A Python structure that safely handles setup and teardown of resources, guaranteeing that files are properly closed even if an exception occurs.

Dataset 🗄️

A collection of structured historical data points used to train, validate, and test machine learning algorithms.

Features ($X$) 🔍

The measurable input attributes or properties of data used by a machine learning model to make predictions (e.g. leaf spots, soil humidity).

F-String ✨

Formatted string literals in Python (prefixed with f"...") that allow embedding expressions inside curly braces {expression}.

Label ($y$) 🎯

The target output or ground truth answer that a supervised machine learning model is trained to predict.

Overfitting 🚫

When a model memorizes the training data too closely, performing with near 100% training accuracy but failing miserably on new, unseen data.

PEP 8 📐

The official Python Enhancement Proposal style guide outlining clean formatting standards (such as 4-space indentation and snake_case variable naming).

Regression 📈

A supervised machine learning task where the model predicts a continuous numerical quantity (such as temperature, rainfall, or energy generation in kWh).
