Python Best Practices & AI Ethics 🛡️✨

Crafting software and intelligence with diligence, beauty, and moral stewardship (Iḥsān).

1. Use 4 Spaces for Indentation (Never Tabs)

PEP 8 specifies that spaces are the preferred indentation method. Never mix tabs and spaces.

✅ Good: 4 spaces per indentation level
❌ Bad: Mixing tabs and random spacing

2. Follow snake_case for Variables and Functions

Use lowercase words joined by underscores. Reserve PascalCase exclusively for Classes.

✅ Good: student_score = 95, def calculate_zakat():
❌ Bad: studentScore = 95, def CalculateZakat():

3. Always Use Context Managers for Files

Always open files using with open(...) as f: to prevent orphaned file locks and data leaks.

✅ Good: with open("log.txt") as f: content = f.read()
❌ Bad: f = open("log.txt"); content = f.read() # forgotten f.close()

4. Never Scrape or Train on Private Data Without Consent (Amānah)

Personal identifiers, family details, and private conversations are entrusted secrets. Respect data privacy unconditionally.

5. Always Audit Datasets for Demographic & Environmental Bias

Check whether underrepresented communities or alternative sensor conditions are adequately represented before training production models.
