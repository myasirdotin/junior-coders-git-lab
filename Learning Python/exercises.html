Tier 2 • Exercise 3

Zakat Eligibility & Calculation Function

Write a function compute_zakat(cash, gold_value, liabilities). Net wealth is cash + gold_value - liabilities. If net wealth $\ge 5000$, return 2.5% of net wealth; otherwise return 0.0.

View Solution 
def compute_zakat(cash, gold_value, liabilities):
    net_wealth = (cash + gold_value) - liabilities
    if net_wealth >= 5000:
        return net_wealth * 0.025
    return 0.0

print(f"Zakat Due: ${compute_zakat(6000, 2000, 1000):.2f}")  # $175.00
Tier 2 • Exercise 4

Solar Microgrid Averaging

Given a dictionary of 5 community solar arrays with their daily kWh generation, use a for loop to calculate total generation, average generation, and identify the highest performing array.

View Solution 
arrays = {"Array-North": 42.5, "Array-East": 38.0, "Array-South": 55.2, "Array-West": 48.1}
total = sum(arrays.values())
average = total / len(arrays)
best = max(arrays, key=arrays.get)

print(f"Total: {total:.1f} kWh | Average: {average:.1f} kWh | Top Array: {best} ({arrays[best]} kWh)")

Tier 3 • Exercise 5

The Clean Water Guardian Classifier

Build an end-to-end classifier that evaluates 6 water well sensor records (features: turbidity, pH, dissolved solids) and returns safety classifications while generating an audit log file on disk.

View Solution 
def classify_water(sample):
    if sample["turbidity"] < 5.0 and 6.5 <= sample["ph"] <= 8.5 and sample["tds"] < 500:
        return "Safe Potable 💧"
    return "Needs Filtration ⚠️"

wells = [
    {"id": "W-1", "turbidity": 2.1, "ph": 7.2, "tds": 320},
    {"id": "W-2", "turbidity": 8.4, "ph": 6.1, "tds": 650},
    {"id": "W-3", "turbidity": 1.5, "ph": 7.8, "tds": 280}
]

for w in wells:
    status = classify_water(w)
    print(f"Well {w['id']}: {status}")
