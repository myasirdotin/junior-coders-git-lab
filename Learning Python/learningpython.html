Lessons

Take them in order. Tick “Mark complete” at the end of a lesson and it is marked here.

  1. 1 Python Foundations & VariablesDiscover why Python is the language of AI. Learn the memory box mental model, data types (int, float, str, bool), and f-strings.
  2. 2 Conditional Logic & DecisionsEquip programs with decision-making power. Master if, elif, else, comparison operators, and boolean combinations (and, or, not).
  3. 3 Loops & RepetitionHarness automated iteration with for in range, while loops, break, and continue. Process repetitive tasks in milliseconds.
  4. 4 Collections: Lists & DictionariesGroup complex data! Master lists, zero-indexing, slicing, key-value dictionaries, and unique sets for real-world records.
  5. 5 Functions & ModularityWrite reusable, clean code (Iḥsān). Define functions with def, pass parameters, return values, and import standard modules.
  6. 6 Files & Tabular DatasetsRead and write persistent files safely with context managers (with open). Parse structured CSV tables and JSON API feeds.
  7. 7 What is Machine Learning?Move beyond hardcoded rules. Master features ($X$), labels ($y$), training vs test splits, overfitting, and loss minimization.
  8. 8 Supervised AI & Ethical StewardshipBuild a functional decision classifier. Apply ethical AI principles: data privacy (Amānah), bias auditing, and the Capstone Project.
