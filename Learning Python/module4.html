The Digital Caravan 🐫📋

Group complex data together using lists for ordered sequences and dictionaries for labeled records.

🧺 Why Collections?

🧠 Real-life analogy: A list is like a row of numbered lockers in the school corridor. You find things by their locker number. A dictionary is like a library card. Each line has a label ("Title", "Author") and a value next to it.

So far, each variable held one value. Real data comes in groups: a class of students, a shelf of books, a record about one donor.

A collection is one variable that holds many values. Python's two most used collections are the list and the dictionary (often called a dict).

Two Essential Collections

Lists 📋 (Ordered by index: 0, 1, 2)

Great for sequences and queues.

fruits = ["Fig", "Olive", "Pomegranate"]
print(fruits[0])  # Fig

Dictionaries 📖 (Key-Value Lookups)

Great for labeled objects and real-world entities.

donor = {"name": "Bilal", "pledge": 100}
print(donor["name"])  # Bilal

📋 Working with Lists

Each item in a list has a position number called an index. Counting starts at 0, not 1. So the first item is fruits[0].

A negative index counts from the end. fruits[-1] is the last item.

A list can change. You can swap an item, or add a new one at the end with .append(). A function that belongs to a value, called with a dot, is named a method.

Useful helpers:

  • len(my_list) gives the number of items (the length).
  • sum(my_list) adds up a list of numbers.
  • "Fig" in fruits asks "is this value in the list?" and gives True or False.

Worked example 1: the orchard list

fruits = ["Fig", "Olive", "Pomegranate"]
print(fruits[0])
print(fruits[-1])
print(len(fruits))

fruits.append("Date")
fruits[1] = "Green Olive"
print(fruits)
print("Fig" in fruits)

scores = [8, 9, 7, 10]
print(sum(scores) / len(scores))

Output:

Fig
Pomegranate
3
['Fig', 'Green Olive', 'Pomegranate', 'Date']
True
8.5

The last line works out an average (the total divided by how many there are): 34 ÷ 4 = 8.5.

📖 Working with Dictionaries

A dictionary stores key-value pairs. The key is the label, such as "name". The value is the data, such as "Bilal". A colon joins each key to its value, and curly brackets wrap the whole record.

You read a value with its key in square brackets. To change a value, store a new one under the same key. To add a pair, store a value under a new key.

Worked example 2: updating a donor record

donor = {"name": "Bilal", "pledge": 100}
print(donor["name"])

donor["pledge"] = 150      # change a value
donor["city"] = "Lahore"   # add a new pair
print(donor)
print(len(donor))

Output:

Bilal
{'name': 'Bilal', 'pledge': 150, 'city': 'Lahore'}
3

len() on a dictionary counts its pairs. A for loop over a dictionary gives you each key in turn: for key in donor:.

🗂️ A List of Records

Real datasets are often a list of dictionaries. Each dictionary is one record (one row of data). The list holds all the records. You will see this shape again in Modules 6, 7 and 8.

When an f-string uses double quotes, write the key inside it with single quotes: {student['name']}. Mixing the two kinds of quotes keeps Python from getting confused.

Worked example 3: the reading club

students = [
    {"name": "Amina", "books_read": 6},
    {"name": "Yusuf", "books_read": 3},
    {"name": "Hana", "books_read": 9},
]

for student in students:
    print(f"{student['name']} read {student['books_read']} books.")

Output:

Amina read 6 books.
Yusuf read 3 books.
Hana read 9 books.

⚠️ Common mistake: asking for something that is not there

The list ["Fig", "Olive", "Pomegranate"] has 3 items, so its indexes are 0, 1 and 2. Asking for fruits[3] fails with:

IndexError: list index out of range

Dictionaries have the same trap. Asking for a key that does not exist, such as donor["phone"], fails with KeyError: 'phone'. Check the spelling of your keys: "Name" and "name" are different.

Create a dictionary for one library book with a title, an author, the number of pages and whether it is available (True or False). Use if/else from Module 2 to choose a status message, then print two lines about the book.

Show answer
book_record = {

if book_record["available"]:

🏆 Practice: three levels

🟢 Level 1: Recall

planets = ["Mercury", "Venus", "Earth"]. What does planets[2] give? After planets.append("Mars"), what does len(planets) give?

Show answer
planets[2] is "Earth", because indexes start at 0. After the append the list has 4 items, so len(planets) is 4.

🟡 Level 2: Apply

A food bank stores its stock in kilograms: pantry = {"rice": 20, "lentils": 12, "flour": 8}. A donor brings 5 kg of lentils and 10 kg of dates. Update the dictionary, then use a loop to print every item and the total weight.

Show answer
pantry = {"rice": 20, "lentils": 12, "flour": 8}
pantry["lentils"] += 5
pantry["dates"] = 10

total = 0
for item in pantry:
    print(f"{item}: {pantry[item]} kg")
    total += pantry[item]

print(f"Total: {total} kg")

Output: rice: 20 kg, lentils: 17 kg, flour: 8 kg, dates: 10 kg, then Total: 55 kg.

🔴 Level 3: Challenge

Three schools planted trees for a green city project.

  1. Make a list of three dictionaries. Each has a "school" and a "trees" key. Use 14, 22 and 9 trees.
  2. Loop through the list and print one line per school.
  3. Add up all the trees inside the same loop.
  4. Print the total, then the average per school, rounded to 1 decimal place.
Show one possible answer
tree_log = [
    {"school": "Al-Noor School", "trees": 14},
    {"school": "Crescent Academy", "trees": 22},
    {"school": "Green Valley School", "trees": 9},
]

total_trees = 0
for record in tree_log:
    print(f"{record['school']}: {record['trees']} trees")
    total_trees += record["trees"]

print(f"Total trees planted: {total_trees}")
print(f"Average per school: {round(total_trees / len(tree_log), 1)}")

The last two lines print Total trees planted: 45 and Average per school: 15.0.
