Classification: Sorting with Intelligence

A classifier is a program that sorts each sample into one group from a short, fixed list. Each group is called a class. For example, it can sort water samples into Safe to drink or Needs filtering.

It uses two features of each water sample:

  • Cloudiness: how cloudy the water looks, given as a score. Scientists call this turbidity. Lower is clearer.
  • pH level: how acidic or how basic (alkaline) the water is, on a scale from 0 to 14. 7 is neutral. Drinking water is usually between 6.5 and 8.5.
def evaluate_water_safety(cloudiness, ph_level):
    if cloudiness < 5.0 and ph_level >= 6.5 and ph_level <= 8.5:
        return "Safe to drink 💧"
    return "Filter Required ⚠️"

Calling it for three samples:

print(evaluate_water_safety(1.2, 7.1))
print(evaluate_water_safety(8.0, 7.0))
print(evaluate_water_safety(2.0, 5.9))

Output:

Safe to drink 💧
Filter Required ⚠️
Filter Required ⚠️

The second sample is too cloudy. The third is too acidic (its pH is below 6.5).

Here a person wrote the rule by hand. A machine learning model would learn numbers like 5.0 and 6.5 from many labelled samples instead. Either way, we must test how often it is right.

⚠️ Important: this is a simplified teaching rule. Real water testing checks many more things, such as germs and harmful chemicals, in a proper laboratory. Never decide that water is safe to drink using a school program.

🎯 Is the Model Any Good? Accuracy

Accuracy is the share of test samples the model got right, as a percentage. To work it out, compare each prediction with the true answer from the test set (the samples kept back in Module 7).

We need to walk through two lists side by side. range(len(actual)) gives the index numbers 0, 1, 2 and so on. The same index then picks matching items from both lists.

Worked example: counting correct predictions

actual = ["Safe", "Safe", "Contaminated"]
predicted = ["Safe", "Contaminated", "Contaminated"]

for i in range(len(actual)):
    print(f"Sample {i}: true={actual[i]}, model={predicted[i]}")

Output:

Sample 0: true=Safe, model=Safe
Sample 1: true=Safe, model=Contaminated
Sample 2: true=Contaminated, model=Contaminated

Two of the three match, so this model's accuracy is 2 ÷ 3 × 100, about 66.7%.

"Contaminated" means the water has something harmful mixed into it.

The Islamic AI Ethics Framework

1. Digital Trust (Amānah)

User privacy is a sacred trust. Never scrape or train models on personal data without permission.

2. Beneficial Knowledge ('Ilm Nāfi')

Channel AI toward positive human challenges: health, clean water, education, and community solidarity.

3. Strictly Prohibited (Ḥarām)

No interest/usury models (Ribā), gambling prediction (Maysir), deepfake deception, or predatory algorithms.

🧪 Your Turn: Test Set Accuracy Calculator

Calculate the accuracy of a water-safety model across 5 test samples. Count the matches with a loop, then turn the count into a percentage.

Show answer
actual = ["Safe", "Contaminated", "Safe", "Safe", "Contaminated"]
predicted = ["Safe", "Contaminated", "Safe", "Safe", "Safe"]  # 1 error on last sample

correct = 0
for i in range(len(actual)):
    if actual[i] == predicted[i]:
        correct += 1

accuracy = correct / len(actual) * 100
print(f"Accuracy: {accuracy}% ({correct}/{len(actual)} correct)")

Output:

Accuracy: 80.0% (4/5 correct)

Look at the one mistake: the model called contaminated water "Safe". For water, that is the most dangerous kind of error. Accuracy alone does not show which mistakes a model makes, so always look at the errors too.

🔴 Level 3: Challenge

A fair model works equally well for everyone. Check whether a water-safety model is fair to two villages.

  1. Write a function accuracy(actual, predicted) that returns the accuracy as a percentage.
  2. Village A: actual ["Safe", "Safe", "Contaminated", "Safe"], predicted ["Safe", "Safe", "Contaminated", "Safe"].
  3. Village B: actual ["Safe", "Contaminated", "Contaminated", "Safe"], predicted ["Safe", "Safe", "Safe", "Safe"].
  4. Print both accuracies. If they differ, print a warning that the model needs more data from the weaker village before anyone uses it.
Show one possible answer
def accuracy(actual, predicted):
    """Returns the percentage of predictions that match the true labels."""
    correct = 0
    for i in range(len(actual)):
        if actual[i] == predicted[i]:
            correct += 1
    return correct / len(actual) * 100

village_a = accuracy(["Safe", "Safe", "Contaminated", "Safe"],
                     ["Safe", "Safe", "Contaminated", "Safe"])
village_b = accuracy(["Safe", "Contaminated", "Contaminated", "Safe"],
                     ["Safe", "Safe", "Safe", "Safe"])

print(f"Village A: {village_a}%")
print(f"Village B: {village_b}%")

if village_a != village_b:
    print("Warning: the model is not equally accurate. Collect more samples from the weaker village first.")

Output: Village A: 100.0%, Village B: 50.0%, then the warning. The model missed both contaminated samples in Village B. Using it there could harm people, which goes against Amānah.
