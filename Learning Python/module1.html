The Digital Memory Vault! 🐍📦

Welcome to Python! Learn how computers store and remember values using variables and types.

The "Sticky Label" Analogy

In Python, a variable is like a sticky label attached to a piece of data stored in computer memory. You assign the label using the single equals sign =.

🏷️

student_name = "Amina"

Stores text (string) in memory with the tag student_name.

🔢

books_donated = 15

Stores a whole number (integer) ready for math.

The Four Core Data Types

Python automatically understands what kind of data you give it:

Strings (str) 🧵

Text wrapped in quotes.

"Al-Khwarizmi"

Integers (int) 🔢

Whole numbers, positive or negative.

42 or -7

Floats (float) ⚖️

Decimals for measurements.

3.14159 or 19.50

Booleans (bool) ✅

True or False binary truth states.

True or False

The F-String Formula

Combine text and variables cleanly without clumsy plus signs:

name = "Tariq"
xp = 150
print(f"Coder {name} has earned {xp} XP!")
