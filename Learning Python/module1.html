The Digital Memory Vault! 🐍📦

Welcome to Python! Learn how computers store and remember values using variables and types.

👋 Your First Python Line: print()

🧠 Real-life analogy: print() is like a notice board in the school hall. Whatever you pin on it, everyone can see.

Python reads your code from top to bottom. It runs one line at a time.

print() is a function. A function is a ready-made tool that does one job. The job of print() is to show something on the screen.

You put what you want to show inside the round brackets. Text must go inside quotes. Numbers do not need quotes.

Worked example 1: printing text and numbers

print("Assalamu alaikum, Junior Coders!")
print(7 + 5)
print("7 + 5")

Output:

Assalamu alaikum, Junior Coders!
12
7 + 5

Look at the last two lines. Without quotes, Python does the sum and shows 12. With quotes, Python treats "7 + 5" as plain text and shows it exactly.

A line that starts with # is a comment. Python skips it. Comments are notes for people who read your code.

The "Sticky Label" Analogy

In Python, a variable is like a sticky label attached to a piece of data stored in computer memory. You assign the label using the single equals sign =.

🏷️

student_name = "Amina"

Stores text (string) in memory with the tag student_name.

🔢

books_donated = 15

Stores a whole number (integer) ready for math.

📝 How the = Sign Works

In maths class, = means "is equal to". In Python, a single = means "store this value".

Python works out the right side first. Then it sticks the label on the left side to that value.

A variable can change. That is why it is called a variable: its value can vary.

Worked example 2: updating a variable

# The school water station starts with 10 bottles
water_bottles = 10

# A parent brings 5 more bottles
water_bottles = water_bottles + 5

print(water_bottles)

Output:

15

The second line reads the old value (10), adds 5, and stores the new value (15) under the same label.

Naming rules for variables

  • Use small letters and join words with an underscore: student_name. This style is called snake_case.
  • No spaces. student name will not work.
  • A name cannot start with a digit. 1st_place is not allowed, but place_1 is fine.
  • Choose clear names. books_donated tells the reader much more than b.
  • Capital letters matter. Score and score are two different variables.

The Four Core Data Types

Python automatically understands what kind of data you give it:

Strings (str) 🧵

Text wrapped in quotes.

"Al-Khwarizmi"

Integers (int) 🔢

Whole numbers, positive or negative.

42 or -7

Floats (float) ⚖️

Decimals for measurements.

3.14159 or 19.50

Booleans (bool) ✅

True or False binary truth states.

True or False

🔍 Checking a Type and Doing Maths

You can ask Python what type a value is with type(). Python answers with a short word: str, int, float or bool.

print(type("Amina"))
print(type(15))
print(type(19.5))
print(type(True))

Output:

<class 'str'>
<class 'int'>
<class 'float'>
<class 'bool'>

Numbers can be used for maths. These are the main maths signs, called operators:

  • + add, - subtract
  • * multiply (a star, not the letter x)
  • / divide. The answer is always a float, such as 3.75 or 2.0.

Some divisions give long decimals. round(value, 1) rounds a number to 1 decimal place. Change the 1 to 2 for two decimal places.

Worked example 3: sorting donated books

books_donated = 15
books_per_shelf = 4

print(books_donated + 5)
print(books_donated - 3)
print(books_donated * 2)
print(books_donated / books_per_shelf)
print(round(10 / 3, 1))

Output:

20
12
30
3.75
3.3

Notice that 10 / 3 is really 3.3333... and goes on for ever. round() keeps it short and readable.

The F-String Formula

Combine text and variables cleanly without clumsy plus signs:

name = "Tariq"
xp = 150
print(f"Coder {name} has earned {xp} XP!")

✨ Reading an f-string

The f before the opening quote tells Python: "this text has holes to fill". Each pair of curly brackets { } is a hole. Python puts the variable's value into it.

Worked example 4: the f-string above, run

name = "Tariq"
xp = 150
print(f"Coder {name} has earned {xp} XP!")

Output:

Coder Tariq has earned 150 XP!

You can also put a small calculation inside the brackets, for example {xp + 50}.

⚠️ Common mistake: joining text and a number with +

Python will not glue a string and an integer together with +. This line stops the program:

age = 12
print("Age: " + age)

The last line of the error says:

TypeError: can only concatenate str (not "int") to str

"Concatenate" means "join together". The fix is an f-string: print(f"Age: {age}"). It prints Age: 12.

Another common slip is forgetting the quotes around text. print(Amina) makes Python look for a variable called Amina, and you get a NameError.

🟡 Level 2: Apply

Maryam has 24 pages left in her library book. She reads 8 pages a day. Store these numbers in variables, then use one f-string to print how many days she needs.

Show answer
student = "Maryam"
pages_left = 24
pages_per_day = 8
print(f"{student} will finish in {pages_left / pages_per_day} days.")

Output: Maryam will finish in 3.0 days. The answer is 3.0 because / always gives a float.
