The Persistent Archive 📁📊

Save information permanently to disk. Read and write text files, CSV tables, and JSON datasets.

🗄️ Why Save to a File?

🧠 Real-life analogy: Variables are like writing on a whiteboard. When the lesson ends, the board is wiped. A file is like a notebook in your drawer. It is still there tomorrow.

When a Python program ends, all its variables are lost. To keep data, the program must save it in a file on the disk (the computer's long-term storage).

Working with a file has three steps: open it, read or write, then close it.

The second argument of open() is the mode. It says what you plan to do:

  • "r" read: look at what is already in the file.
  • "w" write: start a fresh file. If the file already exists, its old contents are erased.
  • "a" append: add new lines to the end and keep the old ones.

encoding="utf-8" lets the file store letters from any language, such as Arabic, Urdu or Malay. It is a good habit to always include it.

Context Managers: with open(...)

Always use the with statement when working with files in Python. A context manager is a helper that sets things up for you and tidies up afterwards. It guarantees that the file is safely closed when you are finished, preventing data corruption.

with open("solar_log.txt", "w", encoding="utf-8") as file:
    file.write("Harvested 45.2 kWh today\n")

The with line opens the file and gives it the short name file. The indented lines use it. When the indent ends, Python closes the file for you.

\n inside a string means "new line". write() does not add one by itself, so put \n at the end of each line you write.

Worked example 1: write a log, then read it back

with open("solar_log.txt", "w", encoding="utf-8") as file:
    file.write("Monday: 45.2 kWh\n")
    file.write("Tuesday: 38.7 kWh\n")

with open("solar_log.txt", "r", encoding="utf-8") as file:
    content = file.read()

print(content)

Output:

Monday: 45.2 kWh
Tuesday: 38.7 kWh

file.read() gives the whole file as one string. (kWh means kilowatt-hours, a unit of electrical energy.) An empty line appears at the end. The file ends with \n, and print() adds one more.

Worked example 2: add a line, then read line by line

with open("solar_log.txt", "a", encoding="utf-8") as file:
    file.write("Wednesday: 50.1 kWh\n")

with open("solar_log.txt", "r", encoding="utf-8") as file:
    for line in file:
        print(line.strip())

Output:

Monday: 45.2 kWh
Tuesday: 38.7 kWh
Wednesday: 50.1 kWh

A for loop over a file gives one line at a time. Each line still ends with \n. .strip() removes spaces and new-line marks from both ends, so no blank lines appear.

CSV vs JSON Formats

CSV (Spreadsheet Rows)

Comma-separated text table. Use Python's csv.DictReader to process rows as dictionaries.

JSON (Web Data & APIs)

Hierarchical key-value structures. Directly converts to Python dictionaries with json.load().

📊 Reading a Dataset

A dataset is a collection of records, often kept in a CSV file. The first line of a CSV file is the header. It names each column.

csv.DictReader turns each row into a dictionary. The header words become the keys. First, write import csv at the top, as you learned in Module 5.

Everything read from a text file is a string, even "42". To do maths, change it into a number with int() for whole numbers or float() for decimals.

Worked example 3: rainfall in three villages

import csv

# Make a small CSV file to practise with
with open("rainfall.csv", "w", encoding="utf-8") as file:
    file.write("village,rain_mm\n")
    file.write("Hillside,42\n")
    file.write("Riverbend,17\n")
    file.write("Palm Grove,30\n")

total = 0
with open("rainfall.csv", "r", encoding="utf-8") as file:
    reader = csv.DictReader(file)
    for row in reader:
        rain = int(row["rain_mm"])
        total += rain
        print(f"{row['village']}: {rain} mm")

print(f"Total rain: {total} mm")

Output:

Hillside: 42 mm
Riverbend: 17 mm
Palm Grove: 30 mm
Total rain: 89 mm

Without int(), the line total += rain would try to add a string to a number and stop with a TypeError.

Worked example 4: saving a dictionary as JSON

JSON (JavaScript Object Notation) is a text format that looks almost exactly like Python dictionaries and lists. json.dump() saves a dictionary to a file. json.load() reads it back as a dictionary.

import json

club = {"name": "Astronomy Club", "members": 18, "telescopes": ["Small", "Large"]}

with open("club.json", "w", encoding="utf-8") as file:
    json.dump(club, file)

with open("club.json", "r", encoding="utf-8") as file:
    loaded = json.load(file)

print(loaded["name"])
print(loaded["members"] + 2)
print(loaded["telescopes"][1])

Output:

Astronomy Club
20
Large

Unlike CSV, JSON keeps numbers as numbers. That is why loaded["members"] + 2 works without int().

⚠️ Common mistake: using "w" when you meant "a"

Mode "w" wipes the file before writing. If you open your journal with "w" each day, only today's entry survives. Use "a" to add to the end.

A second trap is reading a file that does not exist yet, or misspelling its name:

FileNotFoundError: [Errno 2] No such file or directory: 'missing_notes.txt'

Check the spelling, and make sure the file was written first.

🔴 Level 3: Challenge

The school library ran a book donation week. Build a small report.

  1. Write donations.csv with the header donor,books and three rows: Amina 5, Yusuf 12, Hana 8.
  2. Write a function load_donations(filename) that reads the CSV and returns a list of dictionaries, with books changed to an int.
  3. Loop through the list, add up the books, and thank anyone who gave 10 or more.
  4. Save the total to summary.json with json.dump().
Show one possible answer
import csv
import json

with open("donations.csv", "w", encoding="utf-8") as file:
    file.write("donor,books\n")
    file.write("Amina,5\n")
    file.write("Yusuf,12\n")
    file.write("Hana,8\n")

def load_donations(filename):
    """Reads a donations CSV file and returns a list of records."""
    records = []
    with open(filename, "r", encoding="utf-8") as file:
        reader = csv.DictReader(file)
        for row in reader:
            records.append({"donor": row["donor"], "books": int(row["books"])})
    return records

donations = load_donations("donations.csv")
total_books = 0
for record in donations:
    total_books += record["books"]
    if record["books"] >= 10:
        print(f"Special thanks to {record['donor']} for {record['books']} books!")

print(f"Books donated in total: {total_books}")

with open("summary.json", "w", encoding="utf-8") as file:
    json.dump({"total_books": total_books}, file)
print("Summary saved to summary.json")

Output: Special thanks to Yusuf for 12 books!, Books donated in total: 25, Summary saved to summary.json.
