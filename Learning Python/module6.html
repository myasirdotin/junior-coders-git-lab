Save information permanently to disk. Read and write text files, CSV tables, and JSON datasets.

Context Managers: with open(...)

Always use the with statement when working with files in Python. It guarantees that the file is safely closed when you are finished, preventing data corruption.

with open("solar_log.txt", "w", encoding="utf-8") as file:
    file.write("Harvested 45.2 kWh today\n")

CSV vs JSON Formats

CSV (Spreadsheet Rows)

Comma-separated text table. Use Python's csv.DictReader to process rows as dictionaries.

JSON (Web Data & APIs)

Hierarchical key-value structures. Directly converts to Python dictionaries with json.load().

🧪 Your Turn: Logging Science Lab Observations

Write an entry to an experimental observation log:

# Append a new observation to log
observation = "Sample #4: Olive seedling growth +1.2 cm under morning sunlight.\n"

with open("seedling_journal.txt", "a", encoding="utf-8") as journal:
    journal.write(observation)

print("Observation safely recorded in seedling_journal.txt!")
