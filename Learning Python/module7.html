The Great Paradigm Shift

Classical Programming

Input Data + Human Rules ➔ Answers

You explicitly write every single if-else condition.

Machine Learning

Input Data + Answers ➔ Model (Discovered Rules!)

The computer finds the mathematical patterns automatically.

The 4 Essential ML Terms

1. Dataset 📚

Historical collection of recorded examples.

2. Features (X) 🔍

The measurable inputs (e.g. leaf spots, temperature).

3. Label (y) 🎯

The target answer we want to predict (e.g. "Healthy").

4. Model 🧠

The trained mathematical function that makes predictions.

The Golden Rule: Never Test on Training Data

To avoid overfitting (memorizing answers without real understanding), we split data into:

  • Training Set (80%): Given to the model to learn relationships.
  • Testing Set (20%): Kept secret to honestly evaluate model performance on unseen data.

🟡 Level 2: Apply

Use the plant dataset from the Your Turn box. Write a loop that counts how many samples have the label "Healthy", then print the count.

Show answer
healthy_count = 0
for sample in dataset:
    if sample["label"] == "Healthy":
        healthy_count += 1

print(f"Healthy samples: {healthy_count}")

Output: Healthy samples: 2. Counting labels is a useful first check: if one label is very rare, the model has few examples to learn from.

🔴 Level 3: Challenge

Let the data choose a rule. A school garden recorded how many hours of sunlight each seedling got, and whether it grew well.

  1. Make a list of four records: 8 hours "Grew well", 3 hours "Weak", 7 hours "Grew well", 2 hours "Weak".
  2. Use a loop to find the average sunlight of the "Grew well" seedlings and of the "Weak" seedlings.
  3. Set threshold to the point halfway between the two averages.
  4. Predict a new seedling with 6 hours of sunlight: "Grew well" if it is above the threshold, otherwise "Weak".
Show one possible answer
garden = [
    {"sun_hours": 8, "label": "Grew well"},
    {"sun_hours": 3, "label": "Weak"},
    {"sun_hours": 7, "label": "Grew well"},
    {"sun_hours": 2, "label": "Weak"},
]

good_total = 0
good_count = 0
weak_total = 0
weak_count = 0
for seedling in garden:
    if seedling["label"] == "Grew well":
        good_total += seedling["sun_hours"]
        good_count += 1
    else:
        weak_total += seedling["sun_hours"]
        weak_count += 1

threshold = (good_total / good_count + weak_total / weak_count) / 2
print(f"Learned threshold: {threshold} hours")

new_hours = 6
if new_hours > threshold:
    print("Prediction: Grew well")
else:
    print("Prediction: Weak")

Output: Learned threshold: 5.0 hours and Prediction: Grew well. Nobody typed the number 5. The program found it from the data. That is the core idea of machine learning, in a very small form.
