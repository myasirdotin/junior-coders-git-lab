The Master Craftsman's Tools 🧩🛠️

Write reusable, elegant, and maintainable logic using Python functions (Iḥsān).

The Blender Analogy

A blender takes inputs (fruit, water, ice), processes them internally, and returns a delicious smoothie. Once built, you simply call the function whenever needed without rewriting the engine!

def calculate_zakat(wealth):
    if wealth >= 5000:
        return wealth * 0.025
    return 0.0

Anatomy of a Function

  1. def: The keyword announcing a new function definition.
  2. Function Name: Meaningful snake_case identifier (e.g., filter_clean_water).
  3. Parameters: Inputs inside the parentheses (a, b).
  4. return: Hands the computed result back to the caller.

🧪 Your Turn: Temperature Unit Converter

Write a function converting Celsius to Fahrenheit:

def to_fahrenheit(celsius):
    """Calculates Fahrenheit from Celsius."""
    return (celsius * 9/5) + 32

c_temp = 25
f_temp = to_fahrenheit(c_temp)
print(f"{c_temp}°C is equal to {f_temp:.1f}°F")
