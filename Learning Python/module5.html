The Master Craftsman's Tools 🧩🛠️

Write reusable, elegant, and maintainable logic using Python functions (Iḥsān).

The Blender Analogy

A blender takes inputs (fruit, water, ice), processes them internally, and returns a delicious smoothie. Once built, you simply call the function whenever needed without rewriting the engine!

def calculate_zakat(wealth):
    if wealth >= 5000:
        return wealth * 0.025
    return 0.0

A function is a named set of steps. You write it once, then use it again and again. You have already used ready-made functions such as print(), len() and round(). Now you will build your own.

🔨 Define Once, Call Many Times

Making a function has two parts:

  1. Define it with def. This only builds the tool. Nothing runs yet.
  2. Call it by writing its name with round brackets. This is when the steps run.

The value you send in when you call is called an argument. Inside the function, it arrives in the parameter, which works like a variable.

Worked example 1: a welcome desk

def greet(name):
    print(f"Welcome to the science fair, {name}!")

greet("Amina")
greet("Bilal")

Output:

Welcome to the science fair, Amina!
Welcome to the science fair, Bilal!

The steps were written once but ran twice. To welcome a third visitor, you add one short line.

Anatomy of a Function

  1. def: The keyword announcing a new function definition.
  2. Function Name: Meaningful snake_case identifier (e.g., filter_clean_water).
  3. Parameters: Inputs inside the parentheses (a, b).
  4. return: Hands the computed result back to the caller.

📤 Getting an Answer Back with return

return sends a value back to the line that called the function. Then the function stops at once. You can store the answer in a variable or print it.

Worked example 2: calling calculate_zakat

print(calculate_zakat(8000))
print(calculate_zakat(3000))

gift = calculate_zakat(12000)
print(f"Zakat due: {gift}")

Output:

200.0
0.0
Zakat due: 300.0

8000 is at least 5000, so the function returns 2.5% of it (8000 × 0.025 = 200). 3000 is below the limit, so the first return is skipped and the function returns 0.0.

Note: 5000 is a made-up number for practice. The real limit for zakat (the nisab) depends on the current price of gold or silver. For real payments, use a trusted zakat calculator or ask a scholar.

⚠️ Common mistake: using print when you meant return

This function shows the sum but does not hand it back:

def add_badly(a, b):
    print(a + b)

total = add_badly(2, 3)
print(total)

Output:

5
None

None is Python's word for "no value". A function with no return gives back None. Write return a + b so the caller gets the answer. Another slip: writing the name without brackets, such as greet instead of greet("Amina"). Without brackets, the function does not run.

🧰 Defaults, Docstrings and Modules

A parameter can have a default value. It is used when the caller leaves that argument out.

A docstring is a short note in triple quotes """...""" on the first line inside a function. It tells readers what the function does.

Worked example 3: shelf labels for the library

def make_label(item, shelf="General"):
    """Builds a shelf label for a library book."""
    return f"{item} -> Shelf: {shelf}"

print(make_label("Atlas of the Stars", "Science"))
print(make_label("Story of Ibn Battuta"))

Output:

Atlas of the Stars -> Shelf: Science
Story of Ibn Battuta -> Shelf: General

A module is a file full of ready-made functions. Python comes with many. You bring one into your program with import, then use its functions with a dot. This is what "modularity" means: building programs from separate, reusable parts.

Worked example 4: the math module

import math

print(math.sqrt(49))
print(round(math.pi, 2))

Output:

7.0
3.14

math.sqrt() finds a square root. math.pi is the number pi. Put import lines at the very top of your file. In Module 6 you will import the csv and json modules the same way.

One more rule: a variable made inside a function only exists inside it. This is called local scope. To get a value out, return it.

🧪 Your Turn: Temperature Unit Converter

Write a function to_fahrenheit(celsius) that returns the temperature in Fahrenheit. The formula is: multiply by 9, divide by 5, then add 32. Give it a docstring, call it with 25, and print the result rounded to 1 decimal place.

Show answer
def to_fahrenheit(celsius):
    """Calculates Fahrenheit from Celsius."""
    return (celsius * 9/5) + 32

c_temp = 25
f_temp = to_fahrenheit(c_temp)
print(f"{c_temp}°C is equal to {round(f_temp, 1)}°F")

Output:

25°C is equal to 77.0°F

🟡 Level 2: Apply

Write a function average(numbers) that takes a list of quiz marks and returns their average. Use sum() and len() from Module 4. Print the average of [7, 8, 10] rounded to 1 decimal place.

Show answer
def average(numbers):
    """Returns the average of a list of numbers."""
    return sum(numbers) / len(numbers)

print(round(average([7, 8, 10]), 1))

Output: 8.3 (25 ÷ 3 = 8.333..., rounded).

🔴 Level 3: Challenge

A relief team is planning drinking water for two camps for one week. This task uses 3 litres per person per day.

  1. Write a function water_needed(people, days) with a docstring. It returns people * days * 3.
  2. Give days a default value of 7.
  3. Call it for North camp (120 people) and River camp (75 people).
  4. Print one f-string line per camp.
Show one possible answer
def water_needed(people, days=7):
    """Litres of drinking water for a camp, at 3 litres per person per day."""
    return people * days * 3

print(f"North camp needs {water_needed(120)} litres.")
print(f"River camp needs {water_needed(75)} litres.")

Output: North camp needs 2520 litres. and River camp needs 1575 litres.
