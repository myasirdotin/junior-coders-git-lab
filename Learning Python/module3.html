The Conveyor Belt Analogy

A factory conveyor belt delivers boxes one by one. For each box that arrives, the robotic arm performs a specific inspection. When the belt stops, the job is complete.

for day in range(1, 8):
    print(f"Day {day}: Striving in coding practice!")

The name day is the loop variable. Each time round, it holds the next number. The indented line under the for line is the loop body: the steps that repeat. Each trip round the loop is called an iteration.

🔢 How range() Counts

range(start, stop) makes the numbers from start up to but not including stop.

So range(1, 8) above gives 1, 2, 3, 4, 5, 6, 7. That is 7 days, one for each day of the week.

If you give only one number, counting starts at 0. range(3) gives 0, 1, 2.

A third number sets the step (how much to jump each time). range(2, 11, 2) gives 2, 4, 6, 8, 10.

Worked example 1: a short practice week

for day in range(1, 4):
    print(f"Day {day}: Striving in coding practice!")
print("All done!")

for number in range(3):
    print(number)

Output:

Day 1: Striving in coding practice!
Day 2: Striving in coding practice!
Day 3: Striving in coding practice!
All done!
0
1
2

print("All done!") has no indent. It is outside the loop, so it runs once, after the loop ends.

📜 Looping Over a Sequence

A sequence is a group of values kept in order. Two sequences you can loop over right away:

  • A list: values inside square brackets, split by commas, such as ["Amina", "Bilal", "Sara"]. You will learn much more about lists in Module 4.
  • A string: a word or sentence is a sequence of letters.

A for loop hands you each item in turn, from first to last.

Worked example 2: thanking every volunteer

volunteers = ["Amina", "Bilal", "Sara"]

for name in volunteers:
    print(f"JazakAllah khair, {name}!")

for letter in "Salam":
    print(letter)

Output:

JazakAllah khair, Amina!
JazakAllah khair, Bilal!
JazakAllah khair, Sara!
S
a
l
a
m

If you add a fourth name to the list, the loop thanks four people. You do not change the loop at all.

Two Types of Loops

for Loop

Use when you know in advance how many times to repeat (or iterating through a collection).

for item in items:

while Loop

Use when repeating until an unknown future event occurs (repeats while condition is True).

while battery > 10:

💧 Worked Example 3: A while Loop

A while loop checks its condition before every iteration. It keeps going while the condition is True. It stops the first time the condition is False.

tank = 10

while tank > 0:
    print(f"Water left: {tank} litres")
    tank = tank - 4

print("Tank is empty. Time to refill!")

Output:

Water left: 10 litres
Water left: 6 litres
Water left: 2 litres
Tank is empty. Time to refill!

After the third trip, tank becomes -2. Now tank > 0 is False, so the loop stops.

Keeping a running total with +=

Loops are often used to add things up. total += 5 is a short way to write total = total + 5. In the same way, -= takes away.

Always set the total to 0 before the loop starts. You will use this in the Your Turn task below.

⚠️ Common mistake: a loop that never ends

If the loop body never changes the variable in the condition, the condition stays True for ever. This is called an infinite loop:

tank = 10
while tank > 0:
    print("Water left")   # tank never changes!

The program prints the same line again and again and never finishes. Make sure every while loop moves towards its stop. Here, add tank = tank - 4.

A smaller slip: forgetting that range(1, 5) stops at 4, not 5.

🧪 Your Turn: Rainwater Tracker

The school garden measured rain on 5 days: 12.5, 0.0, 18.2, 5.4 and 22.0 mm. Put them in a list. Use a for loop and += to add them up. Print the running total after each reading, then print a summary. Use round(total, 1) from Module 1 to keep the numbers tidy.

Show answer
rain_readings = [12.5, 0.0, 18.2, 5.4, 22.0]
total_water = 0

for reading in rain_readings:
    total_water += reading
    print(f"Recorded +{reading} mm -> Total: {round(total_water, 1)} mm")

print(f"Summary: Collected {round(total_water, 1)} mm of clean rain!")

Output:

Recorded +12.5 mm -> Total: 12.5 mm
Recorded +0.0 mm -> Total: 12.5 mm
Recorded +18.2 mm -> Total: 30.7 mm
Recorded +5.4 mm -> Total: 36.1 mm
Recorded +22.0 mm -> Total: 58.1 mm
Summary: Collected 58.1 mm of clean rain!

Why round()? Computers store some decimals with a tiny error. For example, print(0.1 + 0.2) shows 0.30000000000000004. Rounding hides this tiny error.

🏆 Practice: three levels

🟢 Level 1: Recall

Which numbers does range(2, 6) give? And which loop, for or while, is best when you do not know in advance how many times to repeat?

Show answer
range(2, 6) gives 2, 3, 4, 5 (the stop number 6 is not included). A while loop is best when you repeat until something changes.

🟡 Level 2: Apply

Bilal read 12, 20, 8 and 15 pages on four days. Store the numbers in a list. Use a loop and += to print the total pages for the week.

Show answer
pages = [12, 20, 8, 15]
total = 0

for p in pages:
    total += p

print(f"Total pages read this week: {total}")

Output: Total pages read this week: 55

🔴 Level 3: Challenge

The school charity box collects 15 coins every week for a well-building project. How many weeks until it holds at least 100 coins?

  1. Start with coins = 0 and weeks = 0.
  2. Use a while loop that runs while coins < 100.
  3. Inside the loop, add 15 to coins and 1 to weeks.
  4. After the loop, print the number of weeks and the coins collected.
Show one possible answer
coins = 0
weeks = 0

while coins < 100:
    coins += 15
    weeks += 1

print(f"After {weeks} weeks the box holds {coins} coins.")

Output: After 7 weeks the box holds 105 coins. After 6 weeks it holds only 90, so a seventh week is needed.
