# CSS Learning Platform

Welcome to the CSS Learning Platform! This interactive platform is designed to help beginners learn CSS (Cascading Style Sheets) through hands-on practice and structured lessons.

## 📁 Project Structure

```
Learning CSS/
├── index.html          # Main playground with live CSS preview
├── learningcss.html    # Course syllabus and learning path
├── exercises.html      # Practice exercises with hints and solutions
├── glossary.html       # CSS terminology reference
├── module1.html        # Module 1: Introduction to CSS
├── module2.html        # Module 2: Colors & Text (coming soon)
├── module3.html        # Module 3: The Box Model (coming soon)
├── module4.html        # Module 4: Display & Positioning (coming soon)

├── js/
│   └── script.js       # JavaScript for interactivity
└── README.md           # This file
```

## 🚀 Features

### 1. Interactive Playground
- **Dual Editor**: Write HTML and CSS separately
- **Live Preview**: See your changes in real-time
- **Example Loading**: Load pre-built examples to study
- **Keyboard Shortcuts**: 
  - `Ctrl+Enter` - Render preview
  - `Ctrl+L` - Clear all

### 2. Structured Learning Path
8 comprehensive modules covering:
- CSS basics and syntax
- Colors and text styling
- The box model
- Display and positioning
- Flexbox layouts
- CSS Grid
- Responsive design with media queries

### 3. Practice Exercises
- Hands-on coding challenges
- Progressive difficulty
- Built-in hints and solutions
- Direct link to playground for practice

### 4. CSS Glossary
- Alphabetical reference of CSS terms
- Search functionality
- Clear, beginner-friendly definitions

## 🎯 How to Use

### Getting Started
1. Open `index.html` in your web browser
2. Start with the "Learning CSS" section to follow the structured curriculum
3. Use the playground to practice what you learn
4. Complete exercises to test your understanding

### Using the Playground
1. Write HTML in the top editor
2. Write CSS in the bottom editor
3. Click "Render Preview" or press `Ctrl+Enter`
4. See your styled content in the preview area

### Following the Course
1. Visit `learningcss.html` to see the full curriculum
2. Start with Module 1 and progress sequentially
3. Each module includes:
   - Learning objectives
   - Reading material
   - Code examples
   - Common mistakes
   - Practice exercises
   - Quiz to test understanding

## 📖 Course Outline

### Week 1: CSS Basics
- **Module 1**: Introduction to CSS
  - What is CSS?
  - CSS syntax
  - Selectors
  - Adding CSS to HTML

- **Module 2**: Colors & Text
  - Color values and formats
  - Font properties
  - Text decoration and alignment

### Week 2: Box Model & Layout
- **Module 3**: The Box Model
  - Content, padding, border, margin
  - Box-sizing property

- **Module 4**: Display & Positioning
  - Display types (block, inline, flex, grid)
  - Position property
  - Z-index

### Week 3: Flexbox Layout
- **Module 5**: Introduction to Flexbox
  - Flex container and items
  - Main and cross axes
  - Basic flex properties

- **Module 6**: Advanced Flexbox
  - Flex wrapping
  - Flex grow, shrink, basis
  - Complex flex layouts

### Week 4: Grid & Responsive Design
- **Module 7**: CSS Grid
  - Grid container and items
  - Rows and columns
  - Grid areas

- **Module 8**: Responsive Design
  - Media queries
  - Mobile-first approach
  - Breakpoints
