The Color Palette

Computers see colors in three main ways. It's like mixing paint in a lab!

Names

Simple: red, blue, gold.

Hex Codes

A # and six characters: two each for red, green and blue. #ff0000 is red!

RGB

Red, Green, Blue, each from 0 to 255: rgb(255, 0, 0).

🏆 Practice: three levels

🟢 Level 1: Recall

Write the colour red in three different ways: as a colour name, as a hex code and as an rgb() value.

Show answer

red, #ff0000 and rgb(255, 0, 0). All three give the same red.

🟡 Level 2: Apply

A heading for a charity bake sale starts as h2 { color: black; }. Change it so the text is the hex colour #0f766e (teal), uses a clean sans-serif font, is bold and sits in the centre.

Show answer
h2 {
    color: #0f766e;
    font-family: Arial, sans-serif;
    font-weight: bold;
    text-align: center;
}

If Arial is missing on a computer, the browser uses any sans-serif font instead.

🔴 Level 3: Challenge

Style the title card for a school science fair poster.

  1. Make the title .fair-title a hex colour of your choice, 32px, and centred.
  2. Give the subtitle .fair-subtitle an rgb() colour and a serif font.
  3. Underline the date .fair-date and make it bold.
Show one possible answer
.fair-title {
    color: #1d4ed8;
    font-size: 32px;
    text-align: center;
}

.fair-subtitle {
    color: rgb(22, 163, 74);
    font-family: Georgia, serif;
}

.fair-date {
    text-decoration: underline;
    font-weight: bold;
}
