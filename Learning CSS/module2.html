Module 2: Colors & Text

⏱ 35 minutes | Week 1

Learning Objectives

  • Learn different ways to specify colors in CSS
  • Understand font properties and how to use web fonts
  • Learn how to style and align text
  • Master text decoration and transformation

Overview

Colors and typography are fundamental to web design. In this module, we'll explore how to bring life to your web pages using various color formats and text styling techniques.

📖 Reading Material

📚 CSS Colors

Colors can be specified using predefined color names, or RGB, HEX, HSL, RGBA, HSLA values.

💡 Key Point: Using RGBA or HSLA allows you to add transparency (alpha) to your colors, which is great for overlays and complex designs.

2.1 Font Properties

The font-family property should hold several font names as a "fallback" system.

p { font-family: "Lucida Console", "Courier New", monospace; }

2.2 Text Alignment

The text-align property is used to set the horizontal alignment of a text.

h1 { text-align: center; }
