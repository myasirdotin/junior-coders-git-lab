CSS Exercises

Practice your CSS skills with hands-on challenges

🎨 Color & Background

Create a div with a gradient background and centered text.

Use linear-gradient() for the background.
Use flexbox to center the text both vertically and horizontally.
.box {
  background: linear-gradient(135deg, #0891b2, #7c3aed);
  color: white;
  display: flex;
  justify-content: center;
  align-items: center;
  height: 200px;
}

📦 Box Model

Create a card with padding, border, and margin. Add a shadow effect.

Use padding for inner spacing and margin for outer spacing.
Use box-shadow property with multiple values for the shadow.
.card {
  padding: 20px;
  margin: 20px;
  border: 2px solid #e2e8f0;
  border-radius: 10px;
  box-shadow: 0 4px 6px rgba(0,0,0,0.1);
}

📐 Flexbox Layout

Create a navigation bar with logo on left and links on right.

Use display: flex on the container.
Use justify-content: space-between to push items apart.
.navbar {
  display: flex;
  justify-content: space-between;
  align-items: center;
  padding: 15px 30px;
  background: #1e293b;
}

🔲 CSS Grid

Create a 3x3 grid of squares with different colors.

Use display: grid on the container.
Use grid-template-columns: repeat(3, 1fr) for 3 equal columns.
.grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 10px;
}
.item {
  height: 100px;
  background: #0891b2;
}

📱 Responsive Design

Make a container that changes background color on mobile screens.

Use a media query with max-width.
Target screens smaller than 768px for mobile.
.container {
  background: blue;
  padding: 20px;
}
@media (max-width: 768px) {
  .container {
    background: red;
  }
}

✨ Hover Effects

Create a button that changes color and scales up on hover.

Use the :hover pseudo-class.
Use transform: scale() and transition for smooth animation.
.button {
  padding: 12px 24px;
  background: #0891b2;
  color: white;
  border: none;
  border-radius: 6px;
  transition: all 0.3s ease;
}
.button:hover {
  background: #0e7490;
  transform: scale(1.05);
}
