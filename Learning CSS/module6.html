The "Greedy" Item 🍔

Want one item to take up all the extra space? Use flex-grow! The number is how many shares of the leftover space the item gets.

🏆 Practice: three levels

🟢 Level 1: Recall

In your own words: what does flex-wrap: wrap; do, and what does flex-grow: 1; do?

Show answer

flex-wrap: wrap lets items move down to a new line when the row is full. flex-grow: 1 lets an item stretch to fill the extra space in the row.

🟡 Level 2: Apply

Make a search row with a text box .search-box and a button .search-button. The text box should stretch to fill the row. The button should keep its own size. Keep 10px of space between them.

Show answer
.search-row {
    display: flex;
    gap: 10px; /* space between the items */
}

.search-box {
    flex-grow: 1;
}

The button has no flex-grow, so it keeps its normal size.

🔴 Level 3: Challenge

Build a gallery for a bookshop that sells six books.

  1. Make .book-shelf a flex container that wraps.
  2. Add 15px of space between the cards and centre them.
  3. Make each .book card 150px wide with padding and a border.
  4. Make the window narrow and check that the cards drop to a new line.
Show one possible answer
.book-shelf {
    display: flex;
    flex-wrap: wrap;
    gap: 15px;
    justify-content: center;
}

.book {
    width: 150px;
    padding: 12px;
    border: 2px solid #a855f7;
    text-align: center;
}
