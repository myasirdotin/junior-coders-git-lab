Module 6: Advanced Flexbox

⏱ 40 minutes | Week 3

Learning Objectives

  • Learn how to handle wrapping with flex-wrap
  • Understand the flex-grow, flex-shrink, and flex-basis properties
  • Master the flex shorthand property
  • Learn how to use align-self to align individual items

Overview

Moving beyond the basics, we'll explore how to control how flex items grow, shrink, and wrap to create more complex and robust layouts.

📖 Reading Material

📚 Flex Wrapping

By default, flex items will all try to fit onto one line. You can change that and allow the items to wrap as needed with the flex-wrap property.

.container { display: flex; flex-wrap: wrap; }
💡 Key Point: The flex shorthand is recommended over individual flex-grow, flex-shrink, and flex-basis properties.

6.1 Flex Grow, Shrink & Basis

These properties define how items should grow or shrink to fill the available space.

.item { flex: 1 0 200px; /* grow, shrink, basis */ }

6.2 Align Self

The align-self property allows the default alignment (or the one specified by align-items) to be overridden for individual flex items.

.item-top { align-self: flex-start; }
