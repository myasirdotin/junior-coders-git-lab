Overview

CSS (Cascading Style Sheets) is the language used to style and layout web pages. While HTML provides the structure, CSS controls how that structure looks - colors, fonts, spacing, and much more.

📖 Reading Material

📚 What is CSS?

CSS stands for Cascading Style Sheets. It describes how HTML elements should be displayed on screen, on paper, or in other media. CSS saves a lot of work - it can control the layout of multiple web pages all at once.

💡 Key Point: CSS separates content (HTML) from presentation (styles). This makes your code cleaner, more maintainable, and allows you to change the look of an entire website by editing just one file.

1.1 CSS Syntax

A CSS rule consists of a selector and a declaration block:

selector { property: value; property: value; }

Example:

h1 { color: blue; font-size: 24px; }
✅ Best Practice: Always put each declaration on its own line with a semicolon at the end. This makes your CSS easier to read and maintain.

1.2 CSS Selectors

Selectors are used to "find" (or select) the HTML elements you want to style.

Element Selector - Selects all elements of a specific type:

p { color: red; }

Class Selector - Selects all elements with a specific class (preceded by a dot):

.highlight { background-color: yellow; }

ID Selector - Selects the element with a specific id (preceded by #):

#main-title { text-align: center; }
⚠️ Common Mistake: IDs should be unique - only one element per page should have a specific ID. Classes can be reused on multiple elements.

Common Mistakes

  • Forgetting semicolons - Each CSS declaration must end with a semicolon.
  • Misspelling properties - CSS is case-insensitive, but misspelling property names will cause them to be ignored.
  • Using the wrong selector - Remember: classes use ., IDs use #, elements use just the tag name.
  • Not closing braces - Every opening brace { must have a closing brace }.
