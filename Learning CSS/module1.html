🔗 The Glue (How to Link)

To let your HTML know which CSS "spice" to use, you must link them in the <head> section:

<link rel="stylesheet" href="style.css">

Note: If your CSS file is in a different folder, make sure the path is correct!

Writing CSS "Rules"

Every CSS instruction is like a command for the computer. It looks like this:

h1 {
  color: blue;
  font-size: 24px;
}
  • Selector (h1): Who are we talking to?
  • Property (color): What are we changing?
  • Value (blue): What should it look like?

The Three Secret Selectors

1. Tag Selector: Styles ALL tags of that type (e.g., p { ... }).
2. Class Selector: Styles specific groups. Use a dot (e.g., .my-style { ... }).
3. ID Selector: Styles ONE unique item. Use a hashtag (e.g., #header { ... }).
