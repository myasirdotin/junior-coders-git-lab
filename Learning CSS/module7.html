Module 7: CSS Grid

⏱ 50 minutes | Week 4

Learning Objectives

  • Understand the concept of Grid containers and items
  • Learn how to define rows and columns
  • Master the fr unit and repeat() function
  • Learn how to position items using grid-area and grid-template-areas

Overview

CSS Grid Layout is the most powerful layout system available in CSS. It is a 2D system, meaning it can handle both columns and rows.

📖 Reading Material

📚 The Grid Container

To make an HTML element into a grid container, set its display property to grid or inline-grid.

.container { display: grid; grid-template-columns: 200px auto 200px; }
💡 Key Point: Unlike Flexbox, which is primarily 1D, Grid is designed for 2D layouts.

7.1 The fr Unit

The fr unit allows you to set the size of a track as a fraction of the free space of the grid container.

.container { display: grid; grid-template-columns: 1fr 2fr 1fr; }

7.2 Grid Gap

The gap property (or grid-gap) defines the size of the gutters between grid items.

.container { display: grid; gap: 20px; }
