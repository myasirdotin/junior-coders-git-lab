CSS Glossary

Your reference guide for CSS terms and concepts

A

Align-items

A flexbox property that defines how flex items are aligned on the cross axis. Common values: flex-start, flex-end, center, stretch, baseline.

Ancestor

An element that contains another element. For example, in

, the div is an ancestor of the p element.

B

Block-level element

An element that starts on a new line and takes up the full width available. Examples: div, p, h1-h6, ul, li.

Box Model

The CSS concept that describes how elements are rendered as rectangular boxes. Consists of content, padding, border, and margin.

C

Cascade

The algorithm that determines which CSS rules apply when multiple rules could apply to an element. Based on specificity, source order, and importance.

Child

An element that is directly contained within another element. For example, in

, the p is a child of the div.

Class Selector

A selector that targets elements with a specific class attribute. Written with a dot prefix (e.g., .my-class).

D

Descendant

An element that is nested within another element, at any level. A child is a direct descendant, but elements can be descendants through multiple levels.

Display

A property that defines how an element is rendered. Common values: block, inline, inline-block, flex, grid, none.

F

Flexbox

A one-dimensional layout method for arranging items in rows or columns. Provides efficient space distribution and alignment capabilities.

Float

A property that positions an element to the left or right of its container, allowing other content to wrap around it.

G

Grid

A two-dimensional layout system that divides space into rows and columns, making it easy to create complex layouts.

I

ID Selector

A selector that targets an element with a specific id attribute. Written with a hash prefix (e.g., #my-id). IDs should be unique on a page.

Inline element

An element that does not start on a new line and only takes up as much width as necessary. Examples: span, a, img, strong, em.

J

Justify-content

A flexbox property that defines how flex items are distributed along the main axis. Common values: flex-start, flex-end, center, space-between, space-around.

M

Margin

The space outside an element's border. It creates space between elements and can be set on all four sides independently.

Media Query

A CSS technique that applies styles based on device characteristics, such as screen width, height, or orientation. Essential for responsive design.

P

Padding

The space between an element's content and its border. It creates internal spacing within an element.

Position

A property that specifies how an element is positioned in the document. Values: static, relative, absolute, fixed, sticky.

Pseudo-class

A selector that targets elements in a specific state. Examples: :hover, :focus, :first-child, :nth-child().

Pseudo-element

A selector that styles specific parts of an element. Examples: ::before, ::after, ::first-line, ::first-letter.

S

Selector

A pattern that identifies which HTML elements should be styled. Types include element selectors, class selectors, ID selectors, and attribute selectors.

Specificity

A measure of which CSS rule has precedence when multiple rules could apply. Calculated based on selector types: IDs > classes > elements.

T

Transition

A property that defines how a property change should be animated over time. Allows smooth changes between states.

V

Viewport

The visible area of a web page. In responsive design, the viewport meta tag controls how the page is scaled on different devices.

Z

Z-index

A property that controls the stacking order of positioned elements. Higher values appear in front of lower values.
