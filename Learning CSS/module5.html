Module 5: Introduction to Flexbox

⏱ 45 minutes | Week 3

Learning Objectives

  • Understand the concept of Flexbox containers and items
  • Learn how to create a flex container
  • Master flex-direction and justify-content
  • Learn how to align items with align-items

Overview

Flexbox is a one-dimensional layout method for arranging items in rows or columns. It makes it much easier to design flexible responsive layout structure.

📖 Reading Material

📚 The Flex Container

To start using Flexbox, you need to first define a flex container.

.container { display: flex; }
💡 Key Point: Flexbox deals with alignment in two axes: the main axis (defined by flex-direction) and the cross axis.

5.1 Justify Content

The justify-content property is used to align the flex items along the main axis.

.container { display: flex; justify-content: space-between; }

5.2 Align Items

The align-items property is used to align the flex items along the cross axis.

.container { display: flex; align-items: center; }
