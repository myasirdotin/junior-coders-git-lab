Module 3: The Box Model

⏱ 40 minutes | Week 2

Learning Objectives

  • Understand the four parts of the CSS box model
  • Learn how to control padding, borders, and margins
  • Calculate the total width and height of an element
  • Understand the box-sizing property

Overview

The CSS box model is essentially a box that wraps around every HTML element. It consists of: margins, borders, padding, and the actual content.

📖 Reading Material

📚 Components of the Box Model

  • Content - The content of the box, where text and images appear
  • Padding - Clears an area around the content. The padding is transparent
  • Border - A border that goes around the padding and content
  • Margin - Clears an area outside the border. The margin is transparent
💡 Key Point: Total element width = width + left padding + right padding + left border + right border + left margin + right margin.

3.1 Box Sizing

The box-sizing: border-box; property includes padding and border in the element's total width and height.

.box { box-sizing: border-box; width: 300px; padding: 20px; border: 5px solid black; }
