✅ Good vs ❌ Bad CSS Practices

🎨 Selectors Best Practices

✅ Good Practice

/* Use specific class names */
.button-primary {
    background-color: #3498db;
}

/* Use descendant selectors */
nav .menu-item {
    padding: 10px;
}

Use specific, meaningful class names.

❌ Bad Practice

/* Too generic */
.a { background: blue; }

/* Overly specific */
html body div.container ul li a {
    color: red;
}

Avoid vague names and overly complex selectors.

📐 Layout Best Practices

✅ Good Practice

/* Use Flexbox for layout */
.container {
    display: flex;
    justify-content: space-between;
}

/* Use CSS variables */
:root {
    --primary-color: #3498db;
}

Use modern layout methods and CSS variables.

❌ Bad Practice

/* Using tables for layout */
table { width: 100%; }

/* Inline styles */
<div style="float: left">

Avoid tables for layout and inline styles.

📏 Spacing Best Practices

✅ Good Practice

/* Use consistent spacing */
.card {
    padding: 20px;
    margin-bottom: 16px;
}

/* Use rem for font sizes */
body {
    font-size: 1rem;
}

Use consistent spacing and relative units.

❌ Bad Practice

/* Inconsistent spacing */
.card {
    padding: 10px;
    margin: 5px 10px 3px 8px;
}

/* Using pixels for everything */
body { font-size: 14px; }

Avoid inconsistent values and fixed pixels.

🎭 Responsive Design Best Practices

✅ Good Practice

/* Use media queries */
@media (max-width: 768px) {
    .container {
        flex-direction: column;
    }
}

/* Use relative units */
width: 50%;
max-width: 100%;

Build responsive layouts with media queries.

❌ Bad Practice

/* Fixed widths */
.container { width: 960px; }

/* No mobile support */
@media print { }

Avoid fixed widths and ignoring mobile.

💡 Pro Tips

  • Use CSS variables for consistent theming
  • Use Flexbox and Grid for layouts
  • Keep your CSS organized and commented
  • Test responsive design on multiple devices
  • Use browser DevTools to debug CSS
