The "Display" Superpower

The display property tells a box how to behave. It's like choosing a character type!

Block 🧱

Takes up the whole width. Like a brick in a wall.

display: block;

Inline 🧵

Only takes as much space as it needs. Like words in a sentence.

display: inline;

None 🫥

Poof! The element is gone. It doesn't even take up space.

display: none;

The "Position" Teleport

Want to move a box to a specific spot? Use the position property!

Relative: Moves the box slightly from where it normally sits. position: relative; top: 10px;
Absolute: The box "breaks free" and flies to a specific spot inside its parent! position: absolute; right: 0;
Fixed: The box sticks to the screen even when you scroll. Like our navigation bar! position: fixed; top: 0;
