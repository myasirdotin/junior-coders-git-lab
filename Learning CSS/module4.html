Learn the secrets of invisibility and teleportation in CSS! 🪄

The "Display" Superpower

The display property tells a box how to behave. It's like choosing a character type!

Block 🧱

Takes up the whole width. Like a brick in a wall.

display: block;

Inline 🧵

Only takes as much space as it needs. Like words in a sentence.

display: inline;

None 🫥

Poof! The element is gone. It doesn't even take up space.

display: none;

The "Position" Teleport

Want to move a box to a specific spot? Use the position property!

Relative: Moves the box slightly from where it normally sits. position: relative; top: 10px;
Absolute: The box "breaks free" and flies to a specific spot. It measures from the nearest box around it that has a position set (often position: relative). position: absolute; right: 0;
Fixed: The box stays in the same place on the screen even when you scroll. Like a "back to top" button in the corner! position: fixed; top: 0;

Display & Invisibility Sandbox 🪄

Try modifying display values (like changing inline to block or none) to see how the elements adjust their visual layouts!

🏆 Practice: three levels

🟢 Level 1: Recall

Which display value does each job? (a) Takes the whole width. (b) Takes only the space it needs. (c) Hides the box and removes its space.

Show answer

(a) block, (b) inline, (c) none.

🟡 Level 2: Apply

A .book-card holds a small .new-badge. Put the badge in the top-right corner of the card. Give the card 20px of padding and a gray border.

Show answer
.book-card {
    position: relative; /* the badge measures from this box */
    padding: 20px;
    border: 2px solid gray;
}

.new-badge {
    position: absolute;
    top: 0;
    right: 0;
    background: gold;
    padding: 4px 8px;
}

Without position: relative on the card, the badge would measure from a box further out, often the whole page.

    display: inline;
    padding: 4px;

    display: none;
