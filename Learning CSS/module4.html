Module 4: Display & Positioning

⏱ 45 minutes | Week 2

Learning Objectives

  • Understand the display property and its values
  • Learn the difference between block and inline elements
  • Master the position property (static, relative, absolute, fixed, sticky)
  • Understand the z-index property for layering

Overview

Layout in CSS is governed by how elements are displayed and where they are positioned in the document flow.

📖 Reading Material

📚 The Display Property

The display property is the most important CSS property for controlling layout.

  • block - Takes up the full width available
  • inline - Takes up only as much width as necessary
  • none - Removes the element from the page
💡 Key Point: inline-block elements are like inline elements but they can have a width and a height.

4.1 Positioning

The position property specifies the type of positioning method used for an element.

.fixed-nav { position: fixed; top: 0; width: 100%; }

4.2 Z-Index

The z-index property specifies the stack order of an element.

.overlay { z-index: 10; }
