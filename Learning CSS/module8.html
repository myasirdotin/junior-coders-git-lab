Module 8: Responsive Design

⏱ 45 minutes | Week 4

Learning Objectives

  • Understand the concept of responsive web design
  • Learn how to use the viewport meta tag
  • Master media queries for different screen sizes
  • Understand the "mobile-first" approach

Overview

Responsive web design makes your web page look good on all devices (desktops, tablets, and phones). It is about using HTML and CSS to automatically resize, hide, shrink, or enlarge a website.

📖 Reading Material

📚 The Viewport

The viewport is the user's visible area of a web page. You should include the following <meta> element in all your web pages:

<meta name="viewport" content="width=device-width, initial-scale=1.0">
💡 Key Point: Responsive design is not just about desktop to mobile; it's about any screen size in between.

8.1 Media Queries

Media queries allow you to apply different styles for different media types or screen sizes.

@media screen and (max-width: 600px) { .sidebar { display: none; } }

8.2 Mobile-First Approach

Mobile-first means designing for the smallest screen first and then adding more complex styles as the screen size increases.

/* Default styles (Mobile) */ .container { width: 100%; } /* Tablet and larger */ @media (min-width: 768px) { .container { width: 750px; } }

Practice

Try these exercises in the Playground:

  1. Create a simple layout that changes from 1 column on mobile to 3 columns on desktop
  2. Hide a specific element only on mobile devices
  3. Use relative units like %, em, and rem instead of px
  4. Build a responsive navigation menu that turns into a "hamburger" menu
