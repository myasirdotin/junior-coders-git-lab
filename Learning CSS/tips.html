💡 CSS Tips & Reminders

📝 Before You Start Styling

🔔 Always Plan First

  • Sketch your layout on paper before coding
  • List all the styles you need to apply
  • Check existing CSS files to understand the structure
  • Decide on a color palette and typography

📁 File Organization

  • Keep all CSS in a separate css/ folder
  • Use one main stylesheet (e.g., style.css)
  • Use comments to organize your CSS
  • Group related styles together

🎨 CSS Reminders

✅ Do This

  • Use external stylesheet for consistent styling
  • Use CSS classes for reusability
  • Use meaningful class names
  • Use CSS variables for colors and sizes
  • Test responsive design on different screen sizes
  • Use Flexbox and Grid for layouts
  • Use relative units (rem, em, %) instead of pixels
  • Add comments to explain complex styles

❌ Avoid This

  • Don't use inline styles (put in CSS file instead)
  • Don't use the same ID multiple times
  • Avoid using !important unless necessary
  • Don't forget to add fallback fonts
  • Don't use fixed pixel values for everything
  • Don't use tables for layout
  • Don't leave unused CSS rules

📐 Layout Best Practices

✅ Use Flexbox

.container {
    display: flex;
    justify-content: space-between;
    align-items: center;
    gap: 20px;
}

✅ Use CSS Grid

.grid {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 20px;
}

🎭 Colors & Typography

📋 Color Checklist

  • ✅ Use CSS variables for colors
  • ✅ Choose accessible color combinations
  • ✅ Use a consistent color palette
  • ❌ Don't use too many different colors
  • ❌ Don't use low contrast text

🔤 Font Best Practices

/* Use system fonts for fast loading */
font-family: -apple-system, BlinkMacSystemFont, 
    "Segoe UI", Roboto, sans-serif;

/* Use relative font sizes */
font-size: 1rem; /* 16px */
font-size: 100%;

/* Set line-height for readability */
line-height: 1.6;

📏 Spacing System

🎯 Use a Spacing Scale

:root {
    --space-xs: 4px;
    --space-sm: 8px;
    --space-md: 16px;
    --space-lg: 24px;
    --space-xl: 32px;
    --space-2xl: 48px;
}

Using a consistent spacing scale makes your design cohesive.

📱 Responsive Design

📋 Media Query Examples

/* Mobile first approach */
.container {
    width: 100%;
    padding: 16px;
}

/* Tablet */
@media (min-width: 768px) {
    .container {
        width: 750px;
        margin: 0 auto;
    }
}

/* Desktop */
@media (min-width: 1024px) {
    .container {
        width: 960px;
    }
}

🔍 Debugging Checklist

When Your CSS Doesn't Work:

  1. Check for typos in property names
  2. Verify the selector is correct
  3. Check if CSS file is linked correctly in HTML
  4. Open browser Developer Tools (F12) for errors
  5. Check if the property is supported in your browser
  6. Verify specificity - is another rule overriding?
  7. Check if you're using the right unit (px, rem, em)
  8. Validate CSS at W3C CSS Validator

🎯 Common Mistakes to Avoid

⚠️ Top 10 CSS Mistakes

  1. Using inline styles - Use external CSS instead
  2. Not using CSS variables - Makes updates harder
  3. Ignoring mobile - Always test responsive
  4. Using !important - Creates specificity issues
  5. Fixed widths only - Use max-width and percentages
  6. Not resetting styles - Use a CSS reset
  7. Forgetting fallback fonts - Always provide alternatives
  8. Not organizing CSS - Use comments and sections
  9. Using px for everything - Use rem/em for accessibility
  10. Not testing in multiple browsers - Cross-browser testing is essential
