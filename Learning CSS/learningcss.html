Class 7 Practice Zone

CSS Practice Exercises

Follow the steps carefully. Write the code in your notebook or in a practice file, then open the page in your browser to check the result.

Exercise 1

Style a simple card

Create a box with a border, padding, background color, and rounded corners. Add a heading and one paragraph inside it.

Hint: Start with border, padding, and background. Then give it rounded corners with border-radius.

Exercise 2

Use text styles

Change the color, font size, and text alignment of a heading. Try using a different font weight and letter spacing.

Hint: Use color, font-size, and text-align first. Then try font-weight and letter-spacing.

Exercise 3

Build two boxes

Make two boxes side by side. Give them different colors and set equal width and height. Use margin and padding properly.

Hint: Use a container and set the boxes to display side by side with equal width. Add margin to create space.

Exercise 4

Create a button

Style a button with a background color, rounded corners, padding, and hover effect. Make it look interactive.

Hint: Try background-color, border-radius, padding, and :hover for the effect.

How to do the exercises:

  1. Read the instruction carefully.
  2. Write the CSS in a new file or inside a practice section.
  3. Save the file and open it in a browser.
  4. Check if the result matches your idea.
  5. Change one property at a time to see what happens.

Mini project

School Poster Challenge

Task 1

Create a poster with a heading, a short paragraph, and a colorful button.

Task 2

Use different background colors, padding, and border-radius to make the design look neat.

Task 3

Add a hover effect to the button so it feels interactive when the mouse moves over it.

Starter idea

.poster {
  background: #fef3c7;
  padding: 30px;
  border-radius: 16px;
  border: 3px solid #d97706;
}

.button {
  background: #7c3aed;
  color: white;
  padding: 10px 20px;
  border-radius: 12px;
}

.button:hover {
  background: #5b21b6;
}
