# CSS Learning Context & Standards

The single source of truth for all CSS styling concepts, layout architectures, responsive design techniques, and visual exercises is the official textbook in `book-css/` (**CSS for Class 6 & 7: Styling the Web with Precision & Elegance**).

---

## 1. Ethical Alignment (*'Ilm Nāfi'* & *Ḥayā'*)

All CSS templates, visual cards, component styling, and mini-projects must adhere to our Islamic ethical foundation:
- **Modesty & Visual Decency (*Ḥayā'*)**: UI themes, avatar placeholders, hero images, and layout designs must remain dignified, modest, and family-friendly.
- **Strictly Prohibited Domains**:
  - **No Entertainment / Movie Streaming Clones**: Never create or style clones of commercial streaming platforms (such as Netflix or Hulu), cinema booking interfaces, or entertainment gossip portals.
  - **No Gambling or Nightclub Themes**: Prohibit dark UI designs themed around casinos, betting, or illicit entertainment venues.
  - **No Deceptive UX Styling (*Gharar*)**: Prohibit deceptive patterns, hidden fee badges, or fake countdown styles.
- **Encouraged Wholesome Scenarios**:
  - Clean card layouts for educational courses, digital libraries, and community service projects.
  - Ethical e-commerce product grids (halal honey, books, crafts).
  - Responsive dashboards for student learning progress, prayer schedules, and charitable initiatives.
  - Science discovery galleries, planetarium schedules, and clean civic portal designs.

## 3. Educational Priorities & Quality Standards (*Iḥsān*)
When developing or modifying pages in this directory:
1. **Source of Truth**: Draw visual examples, analogies, and code directly from `book-css/`.
2. **Modern Layout First**: Teach modern Flexbox and CSS Grid; avoid outdated float-based layouts.
3. **Responsive & Mobile-First**: Ensure layouts scale cleanly across mobile, tablet, and desktop viewports.
4. **Pedagogical Structure**: Every module contains:
   - Clear learning goals with real-world analogies.
   - Interactive live CSS editor and instant visual preview.
   - Multi-tier exercises: 🟢 Easy (Recall), 🟡 Medium (Application), 🔴 Challenge (Creative Problem-Solving).
   - Instant-feedback comprehension quiz.
   - Direct link to corresponding textbook chapter (`../book-css/#ch*`).
5. **Theme Consistency**: Inherit centralized platform styling and variables from `../styles/main.css`.
