## 🎯 Course Overview

Behind every click, API call, and video stream is the global nervous system of the Internet. This textbook demystifies how data travels across the planet—from raw physical pulses of light to high-level protocols like HTTP/3, WebSockets, and modern cryptographic handshakes.

In this textbook, students will:

1. **Master Core Networking Foundations**: Packets, switches, routers, MAC vs IP, LAN vs WAN, and the physical wire.
2. **Deconstruct Layer Models**: Mental models and layer responsibilities of the OSI 7-Layer and TCP/IP 4-Layer architectures.
3. **Understand Addressing & Subnetting**: IPv4, IPv6, CIDR notation, subnet calculations, private IP ranges, and NAT.
4. **Compare Transport Protocols**: TCP (handshakes, reliability, flow control) vs UDP (speed, datagrams, streaming).
5. **Explore the Domain Name System (DNS)**: Hierarchy of root servers, TLDs, authoritative nameservers, and resource records.
6. **Master HTTP & Web Architectures**: HTTP/1.1 vs HTTP/2 vs HTTP/3 (QUIC), status codes, headers, wire format, cookies, and caching.
7. **Secure the Wire with Cryptography (*Amānah*)**: Symmetric vs asymmetric encryption, TLS 1.3 handshakes, certificates, and CORS.
8. **Diagnose & Build Real Distributed Systems**: Command-line tools (`ping`, `traceroute`, `curl`, `netstat`), DevTools Network tab, and real-time WebSockets.

## 🌟 Islamic Ethical Framework (*Amānah & Iḥsān*)

All lessons in this curriculum adhere to our core ethical standards:

- **Digital Privacy as a Sacred Trust (*Amānah*)**: Communications across the wire must be guarded. Plaintext data handling without encryption when handling user secrets violates this sacred trust.
- **Beneficial Knowledge (*'Ilm Nāfi'*)**: Network skills must be channeled toward connecting communities, advancing education, providing emergency humanitarian relief, and ensuring fair access.
- **Strictly Halal Contexts**: No projects or simulations involving interest/usury (*Ribā*), gambling/betting platforms (*Maysir*), fraudulent traffic generation, or invasive spyware.
- **Craftsmanship & Diligence (*Iḥsān*)**: Build resilient, high-uptime, bandwidth-efficient networks with clean architecture and comprehensive error handling.
