Grades 8–10 Pro Collaboration Track

Tooling, Git & GitHub Mastery 🐙🛠️

Software is rarely built by one person alone. Master the professional collaboration tools that power modern engineering: Git branches, commit history, merge conflict resolution, pull request etiquette, and continuous deployment.

📋 Prerequisites

  • Basic familiarity with Terminal commands (`cd`, `mkdir`, `dir`/`ls`).
  • Understanding of files and text editors (VS Code recommended).
  • Foundations track completed or equivalent comfort with file trees.
  • Commitment to respectful peer code reviews and honesty (*Ṣidq*).

🎯 What You Will Learn

  • The 3 Git trees: Working Directory, Staging Index, and Commit History.
  • Atomic commits, meaningful semantic messages, and diff comparisons.
  • Feature branching workflows: creating, switching, and merging branches.
  • Resolving merge conflicts calmly and methodically without data loss.
  • Remote repositories on GitHub: clones, pushes, pulls, PRs, and GitHub Pages.

🗺️ Clear Progression Map

From local snapshot tracking to collaborative open-source team workflows.

Step 01
Local Snapshots
git init, git add, git commit -m, git status, and inspecting git log.
Step 02
Branches & Isolation
Creating feature branches, testing safely, switching contexts, and fast-forward merges.
Step 03
Conflict Resolution
Understanding conflict markers, comparing three-way diffs, and completing merges.
Step 04
GitHub & Deploy
SSH keys, pushing remotes, pull requests, peer review, and hosting on GitHub Pages.
