Python Programming & Data Logic 🐍

Python is the world’s most versatile programming language for school learners, scientific computing, and artificial intelligence. Learn algorithmic problem-solving with clean syntax, structured collections, file automation, and ethical data handling (*Amānah*).

📋 Prerequisites

  • Basic arithmetic (addition, subtraction, multiplication, division, modulo).
  • Familiarity with files and typing (Foundations track recommended).
  • No prior software installation needed—practice directly in our browser console.

🎯 What You Will Learn

  • Variables, primitive types (int, float, str, bool), and expressions.
  • Decision making: `if`, `elif`, `else`, comparison & logical operators.
  • Repetition and loops: `for` item loops, `range()`, and `while` logic.
  • Data collections: Lists, tuples, sets, and key-value Dictionaries.
  • Functions, modular code reuse, and reading/writing CSV & JSON files.

🗺️ Clear Progression Map

A carefully scaffolded four-stage ascent from first print statement to independent data pipelines.

Step 01
Syntax & Flow
Input/output, variables, mathematical operators, and conditional branches.
Step 02
Loops & Functions
For/while loops, accumulator patterns, parameter passing, and return values.
Step 03
Collections & Dicts
List slicing, indexing, sorting, key-value mappings, and data filtering.
Step 04
Files & Automation
Parsing CSV tables, JSON records, error handling (`try/except`), and ethics.
