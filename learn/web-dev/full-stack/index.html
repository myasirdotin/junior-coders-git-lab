Full-Stack Web Engineering 🏗️

Graduate from static frontend pages to dynamic, database-backed enterprise applications. Learn server-side programming with modern PHP, database normalization with MySQL, and production MVC architecture with Laravel.

📋 Prerequisites

  • Solid grasp of HTML structure, CSS layouts, and basic JavaScript.
  • Comfort with Terminal commands (`cd`, `mkdir`, `php -S`).
  • Understanding of how client-server requests travel over the Internet.
  • Commitment to user data privacy as a sacred trust (*Amānah*).

🎯 What You Will Learn

  • Server-side request lifecycles: HTTP GET/POST forms and superglobals.
  • Relational schema design, primary/foreign keys, and SQL JOINs.
  • Database security: eliminating SQL injection with 100% prepared statements (PDO).
  • Laravel MVC: routes, controllers, Blade templates, migrations, and Eloquent ORM.
  • Authentication, session management, and password hashing (`password_hash`).

🗺️ Clear Progression Map

The complete server-side roadmap from raw PHP scripts to production MVC frameworks.

Step 01
PHP Fundamentals
Syntax, associative arrays, form processing, sanitation, and OOP.
Step 02
MySQL Relational Data
CREATE TABLE, CRUD queries, relational JOINs, and indexes.
Step 03
Database Defense (PDO)
Parameterized queries, prepared statements, and session security.
Step 04
Laravel MVC Enterprise
Artisan CLI, Blade components, database migrations, and Eloquent relationships.
