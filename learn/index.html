School Computer Science Curriculum 🚀

Structured, project-driven learning tracks designed for school students in Grades 6–10. Every track begins with clear mental analogies, reinforces zero-setup code practice, and culminates in a capstone project.

All Learning Tracks

Choose Your Domain

Select any subject below to review prerequisites, module breakdowns, interactive exercises, and textbook companion guides.

📁
Grades 6–7 • Starting Point

Foundations

Digital literacy, file systems, dual-shell terminal navigation (Windows CMD & Bash), and Git version control basics.

  • File hierarchies & folder hygiene
  • Terminal commands without a mouse
  • Git checkpoints, branches & commits
  • Responsible digital citizenship (*Amānah*)
Explore Foundations Track →
🌐
Grades 7–9 • Creative Track

Web Development

Structure with HTML5, style with modern CSS (Flexbox & Grid), build logic with JavaScript, and explore full-stack PHP/Laravel.

  • Semantic HTML5 & accessible forms
  • Modern CSS Box Model, Flexbox & Grid
  • JavaScript DOM, arrays & interactivity
  • Optional Full-Stack backend path (PHP + MySQL)
Explore Web Dev Track →
🐍
Grades 8–10 • Logic & Data

Python Programming

From your first `print()` statement to data structures, functions, file parsing, and algorithmic problem-solving in Python 3.

  • Variables, conditionals & loops
  • Lists, dictionaries & modular functions
  • Real-world file processing (CSV & JSON)
  • Clean code craftsmanship (*Iḥsān*)
Explore Python Track →
🤖
Grades 8–10 • Future Ready

AI Lab & Literacy

Demystifying machine intelligence: prompt engineering, model limitations, hallucinations, ethical verification, and AI stewardship.

  • How machine learning models process data
  • Precision prompt engineering & role modeling
  • Fact-checking & identifying hallucinations
  • Data privacy, bias & ethical AI (*Amānah*)
Explore AI Lab Track →
🛡️
Grades 7–10 • Essential Defense

Cybersecurity & Safety

Defensive computing, password entropy math, OWASP web vulnerabilities (SQLi & XSS), phishing detective, and personal OpSec.

  • The CIA Triad & password entropy math
  • SQL injection & XSS prevention
  • Phishing detection & social engineering
  • Digital hygiene & 3-2-1 backup resilience
Explore Cybersecurity Track →
🐙
Grades 8–10 • Pro Workflows

Tooling & Git Mastery

The collaboration workflows professional developers use daily: Git branching, pull requests, merge conflict resolution, and deployment.

  • Git commits, diffs & time-travel rollbacks
  • Feature branching & merging strategies
  • Remote repos & GitHub collaborative workflows
  • Static web deployment on GitHub Pages
Explore Tooling Track →

Our Educational Philosophy: Technology as a Sacred Trust (*Amānah*)

At BEI Coders, programming is not just syntax—it is a tool for beneficial knowledge (*'Ilm Nāfi'*). We teach students to write honest code, protect user privacy, reject deceptive patterns, and practice excellence (*Iḥsān*) in every line they craft.

🛡️ Digital Trust (*Amānah*) ✨ Craftsmanship (*Iḥsān*) 🌱 Beneficial Knowledge (*'Ilm Nāfi'*) 🚫 No Dark UX or Deception
