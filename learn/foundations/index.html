Grades 6–7 Core Starting Point

Computer Foundations & Digital Literacy 📁

Before writing complex code, every great developer understands how computers organize information. Learn to navigate directories without a mouse, manage files cleanly, use dual-shell terminals, and save code milestones with Git.

📋 Prerequisites

  • No previous programming experience required!
  • Basic typing and mouse skills on Windows, Mac, or Linux.
  • Curiosity to understand how files and computers actually work.
  • Commitment to honest, respectful digital communication (*Adab*).

🎯 What You Will Learn

  • The mental model of the computer file tree and path addresses.
  • Navigating folders & creating project structures via Terminal (CMD/Bash).
  • Understanding text files, file extensions (.html, .css, .py), and encodings.
  • Fundamental Git version control: checkpoints, commits, and rollbacks.
  • Digital stewardship (*Amānah*): keeping data tidy, safe, and backed up.

🗺️ Clear Progression Map

Follow this step-by-step route to progress from beginner to confident system user.

Step 01
File Systems & Paths
Drives, folders, absolute vs relative paths, and naming conventions.
Step 02
Terminal Power
cd, dir/ls, mkdir, touch/type, and building project scaffolding in seconds.
Step 03
Git Version Control
Snapshots, staging area, commit messages, and history inspection.
Step 04
Digital Hygiene & OpSec
Strong passwords, backup routines (3-2-1 rule), and ethical computing.
