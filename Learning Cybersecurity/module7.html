Cryptography & Secure Channels 🔐📡

Differentiate encoding, encryption, and hashing. Protect communications on hostile public networks.

Encoding vs. Encryption vs. Hashing

1. Encoding (Base64)

Changes data format for safe transport. NOT security! Anyone can reverse it instantly without a key.

2. Encryption (AES / RSA)

Scrambles data for secrecy. Reversible with the correct mathematical key.

3. Hashing (SHA-256)

Fixed-size digital fingerprint. Strictly one-way. Impossible to reverse.

The Cryptographic Avalanche Effect

In secure cryptographic hash functions (like SHA-256), changing a single letter flips more than 50% of the output bits completely, preventing attackers from guessing patterns:

"Salam"  ➔ a9f2bc88d74e...
"Salam!" ➔ 1b045e2c349a... (Completely different 256-bit output!)

Public Wi-Fi Hazards & VPN Protection

On open coffee shop or airport Wi-Fi, malicious actors can sniff radio packets or launch "Evil Twin" rogue access points. Protect yourself with:

  • HTTPS (TLS 1.3): Encrypts payload data so eavesdroppers only see garbled ciphertext.
  • Virtual Private Network (VPN): Creates an encrypted tunnel that shields DNS queries and destination IPs from the local router.
