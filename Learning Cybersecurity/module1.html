Welcome to Cybersecurity! Learn how to think like an ethical defender and safeguard digital human dignity.

The Three Pillars of Security (CIA Triad)

Every security decision, policy, and line of code is designed to protect one or more of these three fundamental pillars:

1. Confidentiality (Secrecy) 🔐

Only authorized individuals can view the data. Unauthorized peeking or leaking is blocked.

Example: Encrypting student medical files.

2. Integrity (Accuracy) 📜

Data cannot be modified, tampered with, or forged without immediate detection.

Example: Cryptographic signatures on exam grades.

3. Availability (Uptime) ⚡

Systems, services, and databases remain accessible when users legitimately need them.

Example: DDoS mitigation during final exams.

The "Castle Defense" (Defense in Depth)

A castle never depends on a single wooden gate. It has a moat, stone ramparts, portcullises, and a secure inner keep:

[ Layer 1: Edge Cloudflare DDoS Shield ]
  ▼ [ Layer 2: HTTPS TLS 1.3 Transport Encryption ]
    ▼ [ Layer 3: Web App Firewall & Anti-CSRF ]
      ▼ [ Layer 4: Multi-Factor Authentication (2FA) ]
        ▼ [ Layer 5: Salted Argon2id Hashing & Database Isolation ]

Digital Stewardship (*Amānah*): White Hat vs Black Hat

Knowledge of security vulnerabilities carries moral responsibility. In Islam, private communications are a sacred trust (**Amānah**). Probing or testing a system without written consent from the owner is unauthorized intrusion. Ethical defenders only test systems they own or have official authorization to defend.
