Cybersecurity Glossary 🛡️

Essential terminology for ethical software engineers, defensive developers, and digital stewards.

Amānah (Digital Stewardship / Sacred Trust) 🤲

The moral mandate that user credentials, private correspondence, financial data, and personal records entrusted to a developer must be safeguarded with maximum technical care, never misused, and never exposed.

Authentication vs. Authorization 🔑

Authentication (AuthN) verifies who a user is (e.g. through passwords, passkeys, TOTP). Authorization (AuthZ) verifies what permissions that verified identity has (e.g. role-based access control, admin privileges).

Brute-Force Attack 🔨

A trial-and-error method where an attacker systematically attempts every possible password combination until finding the correct one. Mitigated via rate-limiting, account lockouts, and Argon2/bcrypt key derivation.

CIA Triad 🔺

The three cornerstones of information security: Confidentiality (privacy against unauthorized reading), Integrity (accuracy against unauthorized tampering), and Availability (timely access for authorized users).

CSRF (Cross-Site Request Forgery) 🎭

An attack that tricks a victim's authenticated browser into executing unwanted actions on a trusted web application using existing session cookies. Defended by unpredictable anti-CSRF tokens and SameSite=Strict cookie attributes.

Defense in Depth 🏰

A layered security strategy where multiple concentric defense mechanisms (firewalls, rate limiters, input validation, least-privilege databases, encryption at rest) are employed so the failure of any single layer does not compromise the system.

Entropy (Password Strength) 🎲

A mathematical measurement in bits ($E = L \times \log_2(N)$) of the unpredictability and randomness of a secret string, determining how many guesses an attacker would need in the worst case to crack it.

EXIF Metadata 📷

Hidden data automatically embedded in photos taken by smartphones and cameras, frequently containing precise GPS coordinates, device serial numbers, and timestamps that leak user location unless stripped prior to storage.

Hash Function (Cryptographic) 🥩

A one-way mathematical algorithm (e.g. SHA-256) that maps arbitrary data into a fixed-length string. It is deterministic, computationally irreversible, and exhibits an avalanche effect (any 1-bit input change alters ~50% of output bits).

HSTS (HTTP Strict Transport Security) 🔒

A response header (Strict-Transport-Security: max-age=31536000; includeSubDomains; preload) instructing browsers to exclusively communicate with a site over HTTPS, eliminating SSL-stripping man-in-the-middle attacks.

IDOR (Insecure Direct Object Reference) 🗂️

A broken access control vulnerability where an application exposes a direct database key or record ID in URLs or payloads (e.g., /invoice?id=1042) without verifying if the requesting user actually owns that resource.

MFA (Multi-Factor Authentication) 📱

An authentication technique requiring two or more distinct evidence factors: something you know (password), something you have (hardware key / TOTP app), or something you are (biometrics).

MitM (Man-in-the-Middle) 🕵️

An attack where an adversary secretly intercepts and relays communications between two parties who believe they are communicating directly, prevented by mutual TLS and certificate verification.

Phishing 🎣

Social engineering deceptive attempts—often via fraudulent emails, spoofed domains, or lookalike portals—to manipulate individuals into surrendering passwords, financial tokens, or confidential data.

Prepared Statement (Parameterized Query) 🛡️

A database query design where SQL code structure is pre-compiled and transmitted separately from user input parameters, rendering SQL injection technically impossible.

Principle of Least Privilege (PoLP) 🗝️

The foundational security rule that any user account, database connection, API token, or background process must possess only the bare minimum set of permissions necessary to execute its legitimate task.

Ransomware ☣️

Extortion malware that encrypts files on a victim's machine or network, demanding payment for decryption keys. Mitigated through the 3-2-1 backup rule, network segmentation, and disciplined patch management.

Salt (Cryptographic) 🧂

A unique, cryptographically random string generated per user and concatenated with their password before hashing, defeating precomputed rainbow table attacks and preventing identical passwords from producing identical hashes.

XSS (Cross-Site Scripting) ⚡

A security vulnerability allowing attackers to inject malicious JavaScript into web pages viewed by other users. Defended by contextual output encoding (e.g. htmlspecialchars()) and Content Security Policy (CSP).

Zero-Day Vulnerability ⏳

A software vulnerability that is discovered and exploited by adversaries before the vendor or developer is aware of it or has released an official patch.
