Welcome to the official **Python & Applied Machine Learning Textbook** of the Junior Coders curriculum!

---

## 🎯 Course Overview

Python is the world's most popular programming language for Artificial Intelligence, Data Science, and automation. Known for its elegant, English-like syntax and vast ecosystem, Python empowers students to move from fundamental computational thinking to building intelligent systems that learn from data.

In this textbook, students will:

1. **Master Core Python**: Variables, control flow, functions, collections, and clean file I/O.
2. **Think Like a Data Scientist**: Load, parse, clean, and analyze structured datasets (CSV & JSON).
3. **Understand Machine Learning from First Principles**: Learn how models discover patterns in data without explicit hardcoded rules.
4. **Build Supervised Learning Classifiers**: Train decision boundaries, evaluate accuracy, and detect overfitting.
5. **Practice Ethical AI & Digital Stewardship (*Amānah*)**: Protect privacy, audit algorithms for bias, and build technology for societal benefit (*'Ilm Nāfi'*).

## 🌟 Islamic Ethical Framework (*Amānah & Iḥsān*)

All lessons in this curriculum adhere to our core ethical standards:

- **Data Privacy as a Sacred Trust (*Amānah*)**: User data and sensitive records must be protected. Never scrape or train models on private personal data without explicit informed consent.
- **Beneficial Knowledge (*'Ilm Nāfi'*)**: Build models that solve real human challenges—such as agricultural plant disease detection, clean energy monitoring, and equitable charity distribution.
- **Strictly Halal Contexts**: No models for loan interest/usury (*Ribā*), sports betting/gambling (*Maysir*), deepfakes, or intrusive surveillance.
- **Transparency & Accountability**: Strive for explainable AI where decisions can be understood and audited rather than harmful black boxes.
