🔺 The CIA Triad & Ethics
ConfidentialityData readable only by authorized entities (TLS, AES-256).
IntegrityData cannot be tampered with or corrupted (SHA-256 HMAC).
AvailabilityServices operational when needed (DDoS mitigation, backups).
AmānahSacred trust: customer data must be actively defended.
Least PrivilegeGrant entities only the minimum required access rights.
Defense in DepthConcentric security rings; failure of one layer is survivable.
🥩 Cryptography Categorization
EncodingRepresentation transform (Base64, URL). Zero security.
One-Way HashIrreversible checksum (SHA-256). Used for integrity & signatures.
Key DerivationSlow, memory-hard hashing for passwords (Argon2id, bcrypt).
Symmetric EncSingle shared secret for encrypt & decrypt (AES-256-GCM).
Asymmetric EncPublic key encrypts, private key decrypts (RSA-4096, ECC/Ed25519).
🎲 Password Entropy ($E = L \times \log_2(N)$)
< 40 bitsVery Weak ➔ Cracked in seconds on consumer GPU.
40 – 60 bitsModerate ➔ Cracked in hours to days by hash rigs.
60 – 80 bitsStrong ➔ Resistant to online and offline attacks (decades).
80+ bitsMilitary/Fortress ➔ 4+ random words passphrase (millennia).
Passphrase RuleLength beats complexity: correct-horse-battery-staple
🛡️ OWASP Top Vulnerabilities & Fixes
SQL InjectionFix: 100% Prepared Statements / Parameterized Queries.
Cross-Site ScriptingFix: Contextual HTML entity encoding + strict CSP.
CSRFFix: Synchronizer tokens + SameSite=Strict cookies.
Broken AuthFix: Argon2id hashing, rate limiting, and MFA/TOTP.
IDORFix: Authorize tenant ownership on every database fetch.
Security MisconfigFix: Disable debug displays, close unused ports, enforce HTTPS.
💻 Safe SQL Prepared Statements

PHP PDO (Safe)

$stmt = $pdo->prepare("SELECT * FROM users WHERE email = ?");
$stmt->execute([$email]);
$user = $stmt->fetch();

Node.js mysql2 (Safe)

const [rows] = await db.execute(
  'SELECT * FROM users WHERE email = ?',
  [email]
);

Python sqlite3 (Safe)

cursor.execute("SELECT * FROM users WHERE email = ?", (email,))
🔑 Proper Password Hashing

PHP Argon2id Storage & Verification

// Secure registration hash:
$hash = password_hash($password, PASSWORD_ARGON2ID);

// Secure login verification:
if (password_verify($inputPassword, $hash)) {
  // Identity authenticated
}
❌ NEVER: md5($pwd) or sha1($pwd) or hash('sha256', $pwd)
🌐 HTTP Defensive Headers
Strict-Transport-Securitymax-age=31536000; includeSubDomains
Content-Security-Policydefault-src 'self'; script-src 'self'
X-Frame-OptionsDENY (Prevents iframe clickjacking)
X-Content-Type-Optionsnosniff (Blocks MIME sniffing attacks)
Referrer-Policystrict-origin-when-cross-origin
Permissions-Policycamera=(), microphone=(), geolocation=()
🍪 Session Cookie Fortification
HttpOnlyInaccessible to JavaScript; prevents XSS session theft.
SecureCookie transmitted exclusively over encrypted HTTPS/TLS.
SameSite=StrictBlocked on cross-site requests; immune to CSRF exploits.
Path=/Restricts cookie scope to intended application path.
Max-Age=3600Explicit session expiration duration in seconds.
🧼 Digital Hygiene Checklist
Password ManagerUnique 20+ character passwords for every single service.
MFA / TOTPAuthenticator apps or FIDO2 hardware keys on all core accounts.
3-2-1 Backups3 copies, 2 media types, 1 offsite encrypted cold-storage copy.
EXIF ScrubbingStrip GPS coordinates & camera metadata from image uploads.
Public Wi-FiNever browse sensitive services on unencrypted public Wi-Fi without VPN.
Software UpdatesApply operating system and browser security patches immediately.
