# Junior Coders Git Lab - Project Instructions

This project is an educational platform for learning HTML, CSS, and JavaScript.

## Specialized Agents
The following custom subagents are available to help with specific modules:
- `@html-tutor`: Expert in HTML fundamentals and accessibility.
- `@css-tutor`: Expert in styling, layout, and responsive design.
- `@js-tutor`: Expert in JavaScript logic and DOM manipulation.

## Learning Modules
- **Learning HTML**: 8 modules covering basics to semantic HTML.
- **Learning CSS**: 8 modules covering styling to Grid/Responsive design.
- **Learning JS**: 9 modules covering variables to DOM/Events.

## Folder Instructions
Each learning folder contains a `GEMINI.md` file with specific coding standards and priorities for that domain.
