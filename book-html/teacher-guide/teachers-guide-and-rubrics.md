# HTML for Class 6 & 7: Curriculum Overview & Project Rubrics

---

## 1. Pedagogical Methodology 💡

This textbook follows a progressive 5-stage scaffolding methodology:
1. **Warm-Up Discovery**: A relatable, screen-free analogy before any syntax is presented.
2. **Concept Foundation**: Clear, jargon-free explanations with visual diagrams.
3. **Line-by-Line Code Breakdown**: Ensuring students understand *why* each tag exists.
4. **Hands-on Scratchpad/Playground Trial**: Instant experimentation in the interactive sandbox.
5. **5 Levels of Mastery Questions**:
   - Level 1: Recall (Memory)
   - Level 2: Comprehension (Explanation)
   - Level 3: Application (Writing Code)
   - Level 4: Analysis (Debugging & Error Finding)
   - Level 5: Creation (Mini Projects & Capstones)

## 3. Capstone Project Assessment Rubric 🎯

| Criterion | Exemplary (4 pts) | Proficient (3 pts) | Developing (2 pts) | Beginning (1 pt) |
| :--- | :--- | :--- | :--- | :--- |
| **Semantic Structure** | Perfect use of `<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`. | Mostly semantic, minor unnecessary `<div>` use. | Mixed semantics; relies heavily on plain `<div>`. | Missing semantic tags; broken hierarchy. |
| **Code Cleanliness** | Consistent 2/4-space indentation; all tags closed; lowercase tags. | Well indented; all tags closed properly. | Inconsistent indentation; minor syntax issues. | Unclosed tags; disorderly layout. |
| **Accessibility & Media** | All images have meaningful `alt` text; form fields have `<label>`s. | Most images have `alt`; labels present. | Missing several `alt` attributes. | No `alt` attributes; inaccessible forms. |
| **Completeness** | All required sections, links, and forms functional and polished. | All sections present with minor bugs. | Incomplete content in 1–2 sections. | Missing major required sections. |
