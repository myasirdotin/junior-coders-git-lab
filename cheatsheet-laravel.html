🚀 New Project & Setup

Laravel is a PHP framework: a ready-made project structure with tools for routes, databases, forms and logins. Composer, PHP's package manager, downloads it into a new folder. Private settings such as the database password live in the .env file, which is never shared.

composer create-project laravel/laravel library-appNew plain Laravel 12 project
composer global require laravel/installerInstall the Laravel installer once
laravel new library-portalNew project; can add a starter kit (Livewire, React or Vue) with login
DB_CONNECTION=mysql
DB_DATABASE=library_app
DB_USERNAME=root
DB_PASSWORD=		Database settings in .env (never commit .env)
npm install && npm run buildBuild the CSS/JS (starter kits need Node.js)

⚙️ Artisan Commands

Artisan is Laravel's command-line helper, run with php artisan inside the project folder. It creates files in the right place with the right starting code, runs migrations and starts a local test server. Type php artisan list to see every command.

php artisan serveStart the local server (http://127.0.0.1:8000)
php artisan make:model Book -mModel + migration
php artisan make:model Book -mcrModel + migration + resource controller
php artisan make:controller BookController --resourceController with the 7 CRUD methods
php artisan make:migration create_loans_tableNew migration file
php artisan make:request StoreBookRequestA class that holds validation rules
php artisan migrateRun new migrations
php artisan migrate:rollbackUndo the last batch
php artisan migrate:fresh --seedDrop ALL tables, rebuild, add seed data (practice only)
php artisan make:seeder BookSeeder   db:seedMake / run seeders
php artisan route:listList every route
php artisan tinkerTry PHP and Eloquent in the terminal
php artisan optimize:clearClear all cached config, routes and views

🗺️ Routing

A route connects a web address to the code that answers it. Routes live in routes/web.php, one for each address and HTTP method, such as GET to view a page and POST to save a form. Naming a route lets your links keep working if the address changes.

Route::get('/about', fn () => view('about'));Basic GET route
Route::get('/books', [BookController::class, 'index']);Route to a controller method
Route::post('/books', [BookController::class, 'store']);POST: save a form
Route::put('/books/{book}', [BookController::class, 'update']);Update (also Route::patch, Route::delete)
Route::resource('books', BookController::class);All 7 CRUD routes at once
Route::get('/books/{book}', [BookController::class, 'show']);{book} = route model binding
Route::get('/search/{term?}', fn ($term = null) => ...);Optional parameter
->name('books.index')Give a route a name
route('books.show', $book)Make a URL from a route name
->middleware('auth')Only for logged-in users

🎮 Controllers

A controller is a class that groups the actions for one kind of thing, such as books. A route calls a controller method, which gets data from the model and returns a view or a redirect. A resource controller uses seven standard methods for create, read, update and delete.

index()   create()List all / show the "add" form
store(Request $request)Validate + save a new row
show(Book $book)Laravel finds the Book (404 if missing)
edit(Book $book)Show the "edit" form
update(Request $request, Book $book)Validate + update
destroy(Book $book)Delete: $book->delete();
return view('books.index', ['books' => $books]);Send data to a Blade view
return redirect()->route('books.index');Go to a named route
return back();Go back to the previous page
->with('success', 'Book saved.')Flash a one-time message

🗣️ Eloquent ORM

Eloquent lets you work with database rows as PHP objects instead of writing SQL. Each model class, like Book, matches one table, like books. $fillable lists the columns a form may fill, which protects every other column from being changed.

protected $fillable = ['title', 'author', 'isbn', 'copies'];Columns allowed in create() / update()
Book::all()Every row (a collection)
Book::find($id)   Book::findOrFail($id)By id: null / 404 if missing
Book::where('copies', '>', 0)->get()Filter, then get the matches
->orderBy('title')->first()Sort / just the first one
->count()How many match
->paginate(10)10 per page; {{ $books->links() }} in Blade
Book::create($validated)Insert a row from checked data
$book->update($validated)Update a row
$book->title = 'New'; $book->save();Change one field and save
$book->delete()Delete the row

🌿 Blade Templates

Blade is Laravel's template language for views, the pages users see. {{ }} prints a value safely escaped, which stops harmful scripts (XSS) from running. Directives that start with @ add decisions, loops and shared layouts, so every page can share one header and footer.

{{ $book->title }}Print, HTML-escaped (safe)
{!! $html !!}Print raw HTML (trusted content only)
{{ $note ?? 'None' }}Print with a fallback
@if / @elseif / @else / @endifDecisions
@foreach ($books as $book) ... @endforeachLoop over a collection
@forelse ... @empty ... @endforelseLoop with a "nothing here" message
@extends('layouts.app')   @section('content') ... @endsectionUse a layout and fill its slot
@yield('content')Where the slot goes, in the layout
@include('partials.nav')Insert a small view
<x-layout> ... </x-layout>Blade component (used by starter kits)
@csrfSecurity token: in every POST form
@method('PUT')   @method('DELETE')Send PUT/PATCH/DELETE from a form
value="{{ old('title') }}"Refill a field after a failed check
@error('title') {{ $message }} @enderrorShow the field's error
@auth ... @endauth   @guest ... @endguestOnly logged-in users / only visitors

✅ Validation Rules

Validation checks form data before you save it. You list rules for each field, and Laravel checks them all. If one fails, the user goes back to the form with error messages and their typed input. Only the checked data, $validated, should reach the database.

$validated = $request->validate([
  'title' => 'required|string|max:150',
  'isbn' => 'required|unique:books,isbn',
  'copies' => 'required|integer|min:1',
]);
(on failure)Laravel goes back with errors and old input
required   nullableMust be filled / may be empty
string   integer   numeric   booleanKind of value
email   dateA valid email / date
min:3   max:255Text: characters; numbers: the value
in:Fiction,Science,EthicsOne of these values
unique:members,emailNot already in that table column
Rule::unique('books', 'isbn')->ignore($book)Unique, except this row (when updating)
confirmedMust match password_confirmation
image   max:2048An image file, up to 2048 KB

🔐 Auth & Middleware

Authentication means checking who a user is, usually with an email and a password. Middleware is a check that runs before a route's code; auth lets only logged-in users through. Renew the session at login and logout so an old, stolen session id becomes useless.

Auth::check()   Auth::user()   Auth::id()Logged in? / the user / their id
if (Auth::attempt($credentials)) { $request->session()->regenerate(); }Log in, then give a new session id
Auth::logout();
$request->session()->invalidate();
$request->session()->regenerateToken();
return redirect('/');
<form method="POST" action="{{ route('logout') }}"> @csrfLogout is a POST form, never a link
->middleware('auth')Route needs a login
->middleware('guest')Only for visitors (login, register)
'password' => Hash::make($plain)Store passwords hashed, never plain
session('key')   session(['key' => 'value'])Read / store a session value

🗂️ Migration Column Types

A migration is a PHP file that describes a change to the database, such as creating a table. It works like version control for your tables: everyone runs the same files and gets the same structure. Each $table method adds one column or rule.

$table->id();Auto-numbered BIGINT primary key
$table->string('title', 150);VARCHAR (255 if no length)
$table->text('summary');Long text
$table->integer('copies');Whole number
$table->decimal('amount', 8, 2);Exact decimal (money)
$table->boolean('available');true/false (TINYINT)
$table->date('due_on');Date only
$table->timestamps();created_at + updated_at
->nullable()   ->default(1)   ->unique()May be NULL / default / no duplicates
$table->foreignId('book_id')->constrained();Foreign key to books.id
->constrained()->cascadeOnDelete();Delete loans when the book is deleted

🔗 Eloquent Relationships

Relationships tell Eloquent how tables connect through foreign keys. You write a short method in each model, such as loans() in Book, then use it like a property. with() loads related rows in one extra query instead of one query per row (the N+1 problem).

return $this->hasMany(Loan::class);In Book: a book has many loans
return $this->belongsTo(Book::class);In Loan: a loan belongs to one book
return $this->hasOne(LibraryCard::class);One-to-one (a member has one card)
return $this->belongsToMany(Category::class);Many-to-many (with a pivot table)
$book->loansUse a relationship like a property
$book->loans()->whereNull('returned_on')->get()Query through a relationship
Loan::with(['book', 'member'])->get()Eager loading: avoids the N+1 problem
