Laravel Cheat Sheet

Routes, Eloquent, Blade, Artisan — everything in one place. Bookmark this!

Laravel Flow: Browser → Route → Controller → Model (database) → View (Blade) → Browser gets HTML back.
⚙️ Artisan Commands
php artisan serveStart the local development server
php artisan make:controller StudentControllerGenerate a controller
php artisan make:model Student -mModel + migration together
php artisan make:migration create_students_tableGenerate a migration file
php artisan migrateRun pending migrations
php artisan migrate:rollbackUndo the last migration batch
php artisan migrate:fresh --seedRebuild DB and seed test data
php artisan make:seeder StudentSeederGenerate a seeder file
php artisan db:seedRun all seeders
php artisan route:listList all registered routes
php artisan tinkerInteractive PHP shell (great for testing!)
php artisan cache:clearClear application cache
🗺️ Routing
Route::get('/url', fn() => 'Hello');Basic GET route
Route::post('/students', [Controller::class, 'store']);POST route to controller
Route::put('/students/{id}', [C::class, 'update']);PUT (full update)
Route::patch('/students/{id}', [C::class, 'update']);PATCH (partial update)
Route::delete('/students/{id}', [C::class, 'destroy']);DELETE route
Route::resource('students', StudentController::class);All 7 CRUD routes at once!
Route::get('/s/{id}', fn($id) => $id);Route parameter
Route::get('/s/{id?}', fn($id=null) => ...)Optional parameter
->name('students.index')Name a route for easy referencing
route('students.index')Generate URL from named route
->middleware('auth')Protect route — login required
🎮 Controllers
index()List all records → view
create()Show the "add new" form
store(Request $request)Validate + save new record
show($id)Show one record
edit($id)Show the "edit" form for one record
update(Request $request, $id)Validate + update a record
destroy($id)Delete a record
return view('name', ['key' => $val])Send data to a Blade view
return redirect()->route('name')Redirect to named route
return redirect()->back()Go back to previous page
->with('success', 'Done!')Flash a session message
🗣️ Eloquent ORM
Student::all()Get all records as a collection
Student::find($id)Find by primary key
Student::findOrFail($id)Find or throw 404 error
Student::first()Get just the first record
Student::where('grade','A')->get()Filter then get all matches
->orderBy('name','asc')Sort results
->limit(10)->get()Get at most 10 records
->paginate(10)Paginate results (10 per page)
Student::create([...])Create + save in one step
$s->save()Save changes to an object
$s->delete()Delete one record
Student::where(...)->delete()Delete matching records
$fillable = ['name','email']Columns safe for mass-assignment
🌿 Blade Templates
{{ $variable }}Echo (HTML-escaped — safe!)
{!! $html !!}Echo raw HTML (trusted content only)
{{ $x ?? 'default' }}Echo with fallback value
@if / @elseif / @else / @endifConditional block
@foreach ($items as $item)Loop over collection
@forelse ... @empty ... @endforelseLoop with empty-state fallback
@for / @while / @endfor / @endwhileStandard for/while loops
@extends('layouts.app')Inherit a layout template
@section('content') ... @endsectionFill a layout slot
@yield('content')Mark where slot goes in layout
@include('partials.nav')Include a partial template
@csrfSecurity token — required in every form!
@method('PUT')Spoof PUT/PATCH/DELETE in forms
@error('field') {{ $message }} @enderrorShow validation error
@auth / @endauthShow only to logged-in users
@guest / @endguestShow only to visitors
✅ Validation Rules
requiredMust not be empty
stringMust be a text string
emailValid email format
min:3 / max:255Min/max character length
unique:studentsValue must not exist in table
unique:students,email,{$id}Unique except for this record
numericMust be a number
integerMust be a whole number
in:A,B,CMust be one of these values
nullableField can be empty/null
confirmedMust match field_name_confirmation
imageMust be jpg, png, gif, etc.
dateMust be a valid date
booleanMust be true or false (1/0)
🔐 Auth & Middleware
Auth::check()Is someone logged in?
Auth::user()Get the logged-in User object
Auth::id()Get the logged-in user's ID
auth()->user()->nameHelper function access
Auth::logout()Log the user out
->middleware('auth')Route requires login
->middleware('guest')Route only for visitors (e.g. login page)
php artisan breeze:install bladeInstall Breeze auth starter kit
session('key')Read a session value
session(['key' => 'value'])Store in session
session()->forget('key')Remove from session
🗂️ Migration Column Types
$table->id()Auto-increment BIGINT primary key
$table->string('name')VARCHAR(255)
$table->string('name', 100)VARCHAR with custom length
$table->text('bio')Long text (TEXT)
$table->integer('age')Whole number (INT)
$table->decimal('price', 8, 2)Money/decimal values
$table->boolean('active')True/false (TINYINT)
$table->date('dob')Date only
$table->timestamps()created_at + updated_at
->nullable()Column can be NULL
->default('pending')Default value
->unique()No duplicates allowed
$table->foreignId('student_id')->constrained()Foreign key with constraint
🔗 Eloquent Relationships
hasOne(Profile::class)One-to-one (User has one Profile)
belongsTo(User::class)Inverse of hasOne/hasMany
hasMany(Post::class)One-to-many (User has many Posts)
belongsToMany(Role::class)Many-to-many (pivot table)
$user->postsAccess relationship as property
$user->posts()->where(...)->get()Query through relationship
with('posts')Eager load (prevents N+1 problem!)
Student::with('classroom')->get()Load students + their classroom
Route Resource Shortcuts: Route::resource('students', StudentController::class) creates 7 routes automatically: index, create, store, show, edit, update, and destroy — saving you from writing each one individually!
