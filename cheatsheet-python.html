if condition:Execute block if True (indented 4 spaces)

🔁 Loops & Sequences
for i in range(5):Loops 5 times (0, 1, 2, 3, 4)
for x in collection:Iterate through items in sequence
while condition:Repeat as long as condition is True
breakExit the loop immediately
continueSkip to the next loop iteration
len(sequence)Returns count of elements
📋 Lists & Dictionaries
lst = [1, 2, 3]Ordered, mutable list (0-indexed)
lst.append(item)Add item to end of list
lst.pop(0)Remove and return item at index
lst[start:stop]Slice list elements
d = {"k": "v"}Dictionary: key-value mapping
d["key"]Access value by key
d.get("key", default)Safe access avoiding KeyError
s = {1, 2, 2, 3}Set: unique unordered items (yields {1,2,3})
