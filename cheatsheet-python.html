🐍 Python Cheat Sheet

Python basics, data, files and the first ideas of machine learning on one page, in the same order as the Python textbook.

Two habits: indent every block by 4 spaces (Python uses the indentation, not brackets), and remember that input() always gives back text: turn it into a number with int() or float() before doing maths.

📋 Lists, Tuples, Dictionaries & Sets
books = ["Atlas", "Quran", "Maths"]List: ordered, can change, index starts at 0
books.append("Physics")Add an item to the end
books.pop(0)Remove and give back the item at index 0
books[1:3]Slice: items 1 and 2 (stop is not included)
point = (3, 4) x, y = pointTuple: fixed values; unpack into variables

🧠 Machine Learning Words
Features (X)Input measurements (e.g. humidity, leaf spots)
Label (y)The right answer to learn (e.g. "Healthy")
Train / test splitOften 80% to train, 20% kept aside to test
ClassificationPredicting a category
RegressionPredicting a number (kWh, rainfall)
AccuracyCorrect predictions ÷ total × 100%
OverfittingMemorising the training data instead of learning the pattern
🛡️ AI Ethics & Trust (Amānah)
AmānahPeople's data is a trust: collect little, keep it safe
'Ilm Nāfi'Beneficial knowledge: clean water, health, charity
Bias checkTest that every group is fairly represented in the data
Honest resultsReport accuracy on test data, not on training data
IḥsānExcellence: clean code and decisions you can explain
Amānah (trust) rule: a program that learns from data learns from people. Use only the data a project needs, remove names before you analyse it, and never build models for interest-based lending, betting or anything else that harms people.
