📱 Kotlin & Android Cheat Sheet

Kotlin basics and Jetpack Compose screens on one page, in the same order as the Android Apps textbook.

Two habits: use val unless the value must change (then var), and never use !!: handle a missing value with ?. and ?:. Plain Kotlin runs in your browser at Kotlin Playground; screen code runs in Android Studio.
📦 Variables & Types
val name = "Amina"Read-only: cannot be given a new value
var borrowed = 0Can change later: borrowed = 3
val pages: Int = 120Type written out (usually Kotlin works it out)
Int, Double, Boolean, String, CharWhole number, decimal, true/false, text, one letter
"Salaam, $name!"String template: puts a value inside text
"${books.size} books"Template with an expression in ${ }
7 / 2  → 3    7 % 2 → 1Whole-number division and remainder
7 / 2.0 → 3.5One decimal makes the answer a decimal
"42".toInt()Text to number (crashes on "abc")
"abc".toIntOrNull() → nullSafe version: null when it is not a number
🚦 Decisions
if (copies > 0) { … } else { … }Run one block or the other
val label = if (ok) "Yes" else "No"if can give back a value
==   !=   <   <=   >   >=Compare values (== compares the contents of text too)
&&   ||   !And, or, not
when (mark) {
  in 90..100 -> "A"
  in 75..89 -> "B"
  else -> "Keep going"
}		when picks the first matching branch; 90..100 is a range
when (day) { "Fri" -> … }Match exact values
🔁 Lists & Loops
val subjects = listOf("Maths", "Physics")A list that cannot change
val tasks = mutableListOf<String>()An empty list you can change
tasks.add("Read ch 4") / tasks.remove(x)Add or remove an item
subjects[0]    subjects.sizeFirst item (index 0) and how many items
for (s in subjects) { … }Visit every item
for (i in 1..5)1, 2, 3, 4, 5
for (i in 0 until 5)0 to 4 (stops before 5)
for (i in 10 downTo 0 step 2)10, 8, 6, 4, 2, 0
while (left > 0) { … }Repeat while the condition is true
🧩 Functions & Lambdas
fun add(a: Int, b: Int): Int { return a + b }Function with parameters and a return type
fun area(w: Int, h: Int) = w * hSingle-expression function
fun greet(name: String = "friend")Default value for a parameter
greet(name = "Bilal")Named argument
val double = { x: Int -> x * 2 }A lambda: a small function stored in a value
books.filter { it.available }Keep matching items (it = each item)
books.map { it.title }Turn each item into something new
books.count { !it.available }Count matching items
repeat(3) { println("Hi") }Trailing lambda: the last lambda goes after the ( )
🏗️ Classes & Null Safety
class Student(val name: String)A class with a property
data class Book(val id: Int, val title: String)Data class: ready-made printing, comparing and copying
book.copy(title = "New title")A copy with one value changed
val note: String? = null? means "may be missing (null)"
note?.lengthSafe call: null instead of a crash
note ?: "No note"Elvis operator: a fallback when the value is null
books.find { it.id == 3 }First match, or null (type Book?)
enum class Level { EASY, HARD }A fixed set of choices

@Composable fun BookCard(book: Book) { … }A function that draws part of the screen
Text("Hello")Show text
Text(title, fontSize = 20.sp)Text size in sp (grows with the phone's font setting)
style = MaterialTheme.typography.titleLargeUse the theme's text styles
Image(painterResource(R.drawable.shelf), contentDescription = "Bookshelf")Show a picture; describe it for screen readers
stringResource(R.string.app_name)Text kept in res/values/strings.xml
@Preview(showBackground = true)See a composable in Android Studio without running
📐 Layout & Modifiers
Column { … }   Row { … }   Box { … }Stack down, side by side, on top of each other
Spacer(Modifier.height(8.dp))Empty space (dp for sizes)
Modifier.padding(16.dp).fillMaxWidth()Modifiers chain; order matters
Modifier.size(48.dp)48dp: the smallest comfortable touch target
Modifier.clickable { … }Make any element tappable

🔘 State & Input
var count by remember { mutableIntStateOf(0) }State: change it and the screen redraws
var name by rememberSaveable { mutableStateOf("") }Also survives turning the phone
import androidx.compose.runtime.getValue
import androidx.compose.runtime.setValue		Needed for by
Button(onClick = { count++ }) { Text("Add") }A button; its label is a trailing lambda
OutlinedTextField(value = name, onValueChange = { name = it }, label = { Text("Name") })A text box tied to state
isError = name.isBlank()Show the box in the error colour
Checkbox(checked = done, onCheckedChange = { done = it })A tick box
📜 Lists & Screens
LazyColumn { items(books, key = { it.id }) { BookRow(it) } }A long list that scrolls; draws only what is visible
Scaffold(topBar = { … }) { innerPadding -> … }Screen frame with a top bar
@Serializable object HomeA screen route
@Serializable data class BookDetail(val id: Int)A route that carries a value
NavHost(navController, startDestination = Home) { composable<Home> { … } }All screens and where the app starts
navController.navigate(BookDetail(3))Go to a screen
navController.popBackStack()Go back one screen
💾 Saving & Permissions
val Context.dataStore by preferencesDataStore(name = "settings")A small store on the phone (DataStore)
val SAVED = stringSetPreferencesKey("saved_ids")A key to save under
dataStore.data … .collectAsState(initial = emptySet())Read: the screen updates when the data changes
scope.launch { dataStore.edit { it[SAVED] = ids } }Write in the background (rememberCoroutineScope())
<uses-permission android:name="android.permission.POST_NOTIFICATIONS"/>Declare a permission in AndroidManifest.xml (notifications: Android 13+)
rememberLauncherForActivityResult(ActivityResultContracts.RequestPermission()) { granted -> … }Ask at the moment you need it; keep working if the answer is no
🛠️ Android Studio (Windows keys)
Shift + F10Run the app
Alt + EnterQuick fix: add a missing import, fix an error
Ctrl + SpaceSuggest code (autocomplete)
Ctrl + Alt + LTidy the code layout
Ctrl + /Comment or uncomment a line
Shift, ShiftSearch everywhere
Log.d("Library", "Saved $id")Print a message to Logcat while testing
Amānah (trust) rule: an app is trusted with people's phones. Ask only for the permissions a feature needs, explain why first, collect no personal data you do not need, and add no ads or tracking to a student app.
