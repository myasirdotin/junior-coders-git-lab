INSERT & SELECT

Add and Read Your Data! 📖

Adding Data with INSERT INTO

Your table is created — now let's put students in it! The INSERT INTO command adds a new row to your table.

-- Insert one student into the students table INSERT INTO students (name, age, grade) VALUES ('Ali Hassan', 13, 'A');

Notice: We didn't include id in our column list — because it's AUTO_INCREMENT, MySQL assigns it automatically! We also didn't include enrolled_at, so it will be NULL (empty) unless we add it.

Inserting Multiple Rows at Once

You can add several students in a single query — just separate each set of values with a comma:

INSERT INTO students (name, age, grade, enrolled_at) VALUES ('Ali Hassan', 13, 'A', '2024-09-01'), ('Sara Khan', 12, 'A+', '2024-09-01'), ('Bilal Ahmed', 14, 'B+', '2024-09-02'), ('Aisha Malik', 13, 'A', '2024-09-02'), ('Usman Tariq', 12, 'B', '2024-09-03');

This is much faster than running 5 separate INSERT statements!

Reading Data with SELECT

The SELECT command is the most powerful in SQL. You use it to read and retrieve data from your tables.

SELECT * — Get Everything

-- The * means "all columns" SELECT * FROM students;

Result:

id name age grade enrolled_at
1 Ali Hassan 13 A 2024-09-01
2 Sara Khan 12 A+ 2024-09-01
3 Bilal Ahmed 14 B+ 2024-09-02
4 Aisha Malik 13 A 2024-09-02
5 Usman Tariq 12 B 2024-09-03

SELECT Specific Columns

You don't have to get everything. Pick only the columns you need:

-- Only get name and grade SELECT name, grade FROM students;

Result:

name grade
Ali HassanA
Sara KhanA+
Bilal AhmedB+
Aisha MalikA
Usman TariqB

Filtering with WHERE

The WHERE clause (a clause is one part of a SQL command) lets you filter rows — only get the students that match your condition.

-- Only get students with grade 'A' SELECT * FROM students WHERE grade = 'A'; -- Only get students older than 12 SELECT * FROM students WHERE age > 12; -- Get a specific student by ID SELECT * FROM students WHERE id = 2;

Result for WHERE grade = 'A':

id name age grade
1 Ali Hassan 13 A
4 Aisha Malik 13 A

Sorting with ORDER BY

Use ORDER BY to sort your results. ASC means smallest to largest (ascending), DESC means largest to smallest (descending).

-- Sort students by age, youngest first SELECT * FROM students ORDER BY age ASC; -- Sort by name alphabetically (A to Z) SELECT * FROM students ORDER BY name ASC; -- Sort by name in reverse (Z to A) SELECT * FROM students ORDER BY name DESC;

Limiting Results with LIMIT

What if you have 1,000 students but only want to see the first 5? Use LIMIT:

-- Show only the first 5 students SELECT * FROM students LIMIT 5; -- Combine with ORDER BY to get the top 3 oldest students SELECT * FROM students ORDER BY age DESC LIMIT 3;

LIMIT is very useful for website pages that show results in batches — this technique is called pagination.
