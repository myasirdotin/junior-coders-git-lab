MySQL Glossary

Quick reference for database and SQL terms used in the MySQL track

A
Aggregate function
A function that works on many rows and returns one value: COUNT(), SUM(), AVG(), MIN(), MAX(). Usually paired with GROUP BY.
Alias (AS)
A temporary name for a column or table: SELECT SUM(amount) AS total. The result column is then called total.
AUTO_INCREMENT
A column setting that gives each new row the next number automatically, so you never have to invent an id yourself.
C
Column
One field of a table, such as name or gpa. Every row has a value (or NULL) for each column.
Constraint
A rule the database enforces on a column: NOT NULL, UNIQUE, PRIMARY KEY, FOREIGN KEY, DEFAULT.
CREATE TABLE
The statement that defines a new table, its columns and their data types: CREATE TABLE books (id INT PRIMARY KEY, title VARCHAR(100));
D
Database
An organised collection of related tables, for example school_db with its students, books and loans.
Data type
What kind of value a column holds: INT (whole numbers), DECIMAL, VARCHAR(n) (text up to n characters), DATE, BOOLEAN.
DELETE
Removes rows: DELETE FROM loans WHERE id = 3; Without a WHERE it removes every row, so always check the condition first.
DISTINCT
Removes duplicate values from a result: SELECT DISTINCT city FROM students; lists each city once.
F
Foreign key
A column that points to the primary key of another table, linking the two. loans.student_id refers to students.id.
G
GROUP BY
Collapses rows that share a value into one row each, so aggregate functions can summarise them: one row per cause, per class, and so on.
H
HAVING
A filter applied after GROUP BY, for conditions on aggregates: HAVING SUM(amount) > 8000. WHERE cannot do this.
I
Index
A lookup structure the database keeps on a column so searches on it are fast, like the index at the back of a book. Primary keys are indexed automatically.
INNER JOIN
The default JOIN: returns only rows that have a match in both tables.
INSERT
Adds a row: INSERT INTO books (title, category) VALUES ('Clean Code', 'Programming');
J
JOIN
Combines rows from two tables using a matching column: FROM loans JOIN students ON loans.student_id = students.id.
L
LEFT JOIN
Keeps every row of the left table even when the right table has no match; the missing side shows NULL. Used to find things with no match, such as books never borrowed.
LIMIT
Caps how many rows come back: ORDER BY gpa DESC LIMIT 3 gives the top three.
N
Normalization
Designing tables so each fact is stored once. Instead of repeating the teacher's name in every student row, store classes in their own table and link with class_id.
NULL
"No value". Not zero and not an empty string. Test it with IS NULL or IS NOT NULL, never with = NULL.
O
ORDER BY
Sorts the result: ORDER BY name (A to Z) or ORDER BY gpa DESC (highest first).
P
Primary key
The column (usually id) whose value is unique for every row, so each row can be found and linked to reliably.
Q
Query
A request to the database written in SQL. SELECT statements are the most common queries.
R
Relational database
A database made of tables that are linked to each other through keys, such as MySQL, MariaDB, PostgreSQL and SQLite.
Row
One record in a table, for example one student or one loan. Also called a record or a tuple.
S
Schema
The design of a database: which tables exist, their columns, data types and keys.
SELECT
Reads data: SELECT name, gpa FROM students WHERE grade = 9 ORDER BY gpa DESC;
SQL
Structured Query Language, the standard language for talking to relational databases. MySQL, SQLite and others all understand it.
SQL injection
An attack where user input is pasted straight into a query so it changes the SQL. Prevented with prepared statements (placeholders), never by trusting input.
Subquery
A query inside another query, used as a value or a list: WHERE gpa > (SELECT AVG(gpa) FROM students).
T
Table
A grid of rows and columns that stores one kind of thing, such as students or books.
Transaction
A group of statements that must all succeed or all be undone together, so the data never ends up half-changed.
U
UNIQUE
A constraint that forbids two rows from having the same value in a column, for example an email address.
UPDATE
Changes existing rows: UPDATE students SET city = 'Lahore' WHERE id = 5; Always include a WHERE.
W
WHERE
Filters rows before they are returned or changed: WHERE gpa >= 3.8, WHERE city = 'Lahore'.
