SQL is Not Case-Sensitive — But Convention Matters!

Good news: SQL doesn't care whether you type in UPPERCASE or lowercase. Both of these do exactly the same thing:

select * from students; -- works fine SELECT * FROM students; -- also works, and is the standard

By convention, we write SQL keywords in UPPERCASE (like SELECT, FROM, WHERE) and our own names (table names, column names) in lowercase. This makes your code much easier to read!

Step 1: Create a Database

Before you can create tables, you need a database to put them in. Think of it as creating a new filing cabinet.

-- Create a new database called school CREATE DATABASE school; -- Tell MySQL to use this database for all our commands USE school;

You only need to create a database once. After that, you just USE it every time you start a session.

-- See all databases on this server SHOW DATABASES;

MySQL Data Types

When you create a table, you must tell MySQL what type of data each column will hold. Here are the most important ones:

Data Type What it Stores Example
INT Whole numbers 13, 100, -5
VARCHAR(n) Short text (max n characters) 'Ali', 'Class A'
TEXT Long text (no size limit) A whole essay or description
DATE A date (no time) '2024-09-01'
DATETIME Date and time together '2024-09-01 08:30:00'
BOOLEAN / TINYINT(1) True (1) or False (0) 1, 0
DECIMAL(m,d) Precise decimal numbers DECIMAL(5,2) → 999.99
FLOAT Approximate decimal numbers 3.14, 9.81

Step 2: Create a Table

Now let's create our students table! Here is a complete example with all the important parts explained:

CREATE TABLE students ( id INT AUTO_INCREMENT PRIMARY KEY, name VARCHAR(100), age INT, grade VARCHAR(5), enrolled_at DATE );

Breaking it Down

  • id INT AUTO_INCREMENT PRIMARY KEY — MySQL automatically assigns 1, 2, 3... to each new row. It's the unique identifier.
  • name VARCHAR(100) — A text column that can hold up to 100 characters.
  • age INT — A whole number for the student's age.
  • grade VARCHAR(5) — A short text like 'A', 'B+', or 'A+'.
  • enrolled_at DATE — The date the student enrolled, e.g. '2024-09-01'.

Exploring Your Database

After creating tables, you can check what exists with these helpful commands:

-- See all tables in the current database SHOW TABLES; -- See the structure (columns, types) of a table DESCRIBE students; -- Or shorthand: DESC students;

Running DESCRIBE students will show you a table like this:

Field Type Key Extra
id int PRI auto_increment
name varchar(100)
age int
grade varchar(5)
enrolled_at date

Removing a Table Safely

If you want to delete a table, use DROP TABLE. Always add IF EXISTS to avoid an error if the table doesn't exist:

-- Safe way to delete a table (won't error if it doesn't exist) DROP TABLE IF EXISTS students; -- Dangerous! Will throw an error if table doesn't exist DROP TABLE students;

⚠️ Warning: DROP TABLE permanently deletes the table AND all the data in it. There is no undo! Always double-check before running this command.
