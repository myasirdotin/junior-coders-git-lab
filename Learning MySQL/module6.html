Aggregate and Analyze Your Data! 📊

Aggregate Functions — Math on Your Data

Aggregate functions perform calculations on a group of rows and return a single result. They're like a calculator built right into SQL!

Function What it Does Example Use
COUNT() Count the number of rows How many students are enrolled?
SUM() Add up all values in a column Total score of all students
AVG() Calculate the average Average age of students
MIN() Find the smallest value Lowest score in class
MAX() Find the largest value Highest score in class

COUNT() — Count Your Rows

-- How many students are in the table? SELECT COUNT(*) FROM students; -- Result: 5 -- How many students have grade 'A'? SELECT COUNT(*) FROM students WHERE grade = 'A'; -- Result: 2

SUM(), AVG(), MIN(), MAX()

-- Total score of all students in the grades table SELECT SUM(score) FROM grades; -- Result: 360 (95 + 88 + 99 + 78) -- Average score across all grades SELECT AVG(score) FROM grades; -- Result: 90 -- Lowest and highest score SELECT MIN(score), MAX(score) FROM grades; -- Result: 78 | 99 -- Average age of all students SELECT AVG(age) FROM students; -- Result: 12.8

GROUP BY — Analyze by Category

GROUP BY groups rows that share the same value in a column, then lets you run aggregate functions on each group. It's how you answer questions like "How many students are in each grade?"

-- Count how many students have each grade SELECT grade, COUNT(*) AS total_students FROM students GROUP BY grade;

Result:

grade total_students
A 2
A+ 1
B+ 1
B 1
-- Average score per subject in the grades table SELECT subject, AVG(score) AS avg_score FROM grades GROUP BY subject;

HAVING — Filter After GROUP BY

HAVING is like WHERE, but it filters after GROUP BY has run. You need it to filter on aggregate results (like COUNT, SUM).

WHERE HAVING
Filters individual rows BEFORE grouping Filters groups AFTER GROUP BY runs
-- Only show grades that have MORE than 1 student SELECT grade, COUNT(*) AS total FROM students GROUP BY grade HAVING COUNT(*) > 1;

Result (only grade 'A' has 2 students — the rest have 1):

grade total
A 2

LIKE — Pattern Matching

The LIKE operator searches for a pattern in text. Use % as a wildcard (matches any characters).

-- Find all students whose name STARTS with 'A' SELECT * FROM students WHERE name LIKE 'A%'; -- Matches: Ali Hassan, Aisha Malik -- Find students whose name ENDS with 'Khan' SELECT * FROM students WHERE name LIKE '%Khan'; -- Matches: Sara Khan -- Find students whose name CONTAINS 'ali' anywhere SELECT * FROM students WHERE name LIKE '%ali%'; -- Matches: Ali Hassan, Aisha Malik
LIKE Pattern Cheat Sheet:
  • 'A%' — starts with A
  • '%n' — ends with n
  • '%ali%' — contains "ali" anywhere
  • 'A_i' — A, then any one character, then i (e.g. "Ali")

IN — Match a List of Values

The IN operator checks if a value matches any value in a list. It's cleaner than writing multiple OR conditions.

-- Get students with grade A or A+ SELECT * FROM students WHERE grade IN ('A', 'A+'); -- Same thing with OR (harder to read!) SELECT * FROM students WHERE grade = 'A' OR grade = 'A+';

BETWEEN — Range Filtering

The BETWEEN operator filters values within a range (inclusive — it includes the start and end values).

-- Get students aged 11 to 13 (includes 11 and 13) SELECT * FROM students WHERE age BETWEEN 11 AND 13; -- Get grades recorded in September 2024 SELECT * FROM students WHERE enrolled_at BETWEEN '2024-09-01' AND '2024-09-30';

Subqueries — A Query Inside a Query

A subquery is a SELECT statement nested inside another query. It's like asking two questions at once!

-- Find all students older than the average age SELECT * FROM students WHERE age > ( SELECT AVG(age) FROM students ); -- The inner query calculates average age (12.8) -- The outer query gets students older than 12.8 (so age 13 or 14) -- Find students who have at least one grade recorded SELECT * FROM students WHERE id IN ( SELECT student_id FROM grades );

The inner query (in parentheses) runs first, then the outer query uses its result. Very powerful once you master it!

Putting it All Together

Here's a "real world" query combining everything from this module. This finds subjects where the average score is above 85:

SELECT subject, COUNT(*) AS students_tested, AVG(score) AS avg_score, MAX(score) AS top_score FROM grades GROUP BY subject HAVING AVG(score) > 85 ORDER BY avg_score DESC;

Result:

subject students_tested avg_score top_score
Math 2 97 99
Science 1 88 88

(English avg is 78, so it's excluded by the HAVING filter)
