UPDATE & DELETE

Modify and Remove Data! ✏️

What is CRUD?

In databases, almost every operation fits into one of four categories — together they form CRUD:

Letter Operation SQL Command What it Does
C Create INSERT INTO Add new rows
R Read SELECT Retrieve data
U Update UPDATE ... SET Modify existing rows
D Delete DELETE FROM Remove rows

You already know C (INSERT) and R (SELECT) from Module 3. Today we learn U and D!

UPDATE — Changing Existing Data

The UPDATE command modifies data that's already in the table. Use SET to specify what to change, and WHERE to say which row(s) to change.

-- Change Ali's grade to A+ UPDATE students SET grade = 'A+' WHERE id = 1;

You can update multiple columns at the same time by separating them with commas:

-- Update both age and grade for the student named 'Ali Hassan' UPDATE students SET age = 14, grade = 'B' WHERE name = 'Ali Hassan';

⚠️ DANGER: Always Use WHERE with UPDATE!

This is the most important safety rule in SQL. Look at what happens without WHERE:

-- ⚠️ CATASTROPHIC! Updates EVERY student's grade to 'F'! UPDATE students SET grade = 'F'; -- There is no undo for this in most systems!

⚠️ Without a WHERE clause, UPDATE changes EVERY single row in the table. Imagine setting every student's grade to 'F' by accident! Always double-check that your WHERE clause is correct before running an UPDATE.

The safe version targets one student using their unique id:

-- Safe: only changes student with id = 1 UPDATE students SET grade = 'F' WHERE id = 1; -- only Ali Hassan is affected

DELETE — Removing Rows

The DELETE FROM command removes rows from a table. Again — always use WHERE!

-- Remove only the student with id = 3 (Bilal Ahmed) DELETE FROM students WHERE id = 3; -- Remove all students with grade 'B' DELETE FROM students WHERE grade = 'B';

After deleting Bilal (id=3), our table now looks like this:

id name age grade
1 Ali Hassan 14 B
2 Sara Khan 12 A+
3 Bilal Ahmed 14 B+
4 Aisha Malik 13 A
5 Usman Tariq 12 B

Notice: id 3 is gone, but the other ids stay the same. AUTO_INCREMENT does NOT reassign numbers.

TRUNCATE TABLE — Clear Everything

If you want to remove ALL rows from a table but keep the table structure itself, use TRUNCATE TABLE. It's much faster than DELETE without WHERE.

-- Remove all rows from students table (keeps the table structure) TRUNCATE TABLE students; -- After this, students table is empty but still exists SELECT * FROM students; -- Returns: (empty result)

⚠️ TRUNCATE also resets the AUTO_INCREMENT counter back to 1. Use with extreme care — there's no undo!
