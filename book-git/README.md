---

## 🎯 Course Overview

In modern software development, writing code is only half the adventure. Professional developers must know how to:
1. **Save milestones** and rewind mistakes without losing work.
2. **Branch off** to test wild ideas without crashing the live website.
3. **Collaborate with teammates** across the world on GitHub without overwriting each other's code.
4. **Publish live websites** instantly for the whole world to enjoy using **GitHub Pages**.

This book guides you from your very first `git init` to opening professional Pull Requests and building team repositories.

## 🌟 Islamic Ethical Framework (*Amānah & Adab*)

In accordance with our core guidelines:
- **Protecting Secrets as a Sacred Trust (*Amānah*)**: Never commit `.env` files, passwords, or API keys to GitHub.
- **Dignified Communication (*Adab*)**: Write helpful, respectful commit messages and pull request reviews.
- **Beneficial Knowledge (*'Ilm Nāfi'*)**: Use version control to build tools that serve families, schools, and communities.
