Class 8

JavaScript Cheat Sheet

Syntax, arrays, DOM, events — everything in one place. Bookmark this!

Quick Rules: Use const by default. Use let when you need to reassign. Always use === (strict equality) not ==. End statements with a semicolon ;
📦 Variables
const name = "Ali"Cannot be reassigned — use by default
let score = 0Can be reassigned — use when value changes
var old = "avoid"Old style — avoid in modern code
const PI = 3.14Constants are UPPERCASE by convention
🧪 Data Types
"Hello" / 'World'String — text inside quotes
`Hello ${name}`Template literal — embed variables
42Number (integer)
3.14Number (decimal / float)
true / falseBoolean — only two possible values
nullIntentionally empty — set on purpose
undefinedVariable declared but not yet set
[1, 2, 3]Array — ordered list of values
{ name: "Ali", age: 12 }Object — key/value pairs
typeof variableCheck what type a variable is
➕ Operators
+ - * /Math: add, subtract, multiply, divide
%Remainder — e.g. 10 % 3 = 1
**Power — e.g. 2 ** 3 = 8
x++Increment by 1 (x = x + 1)
x--Decrement by 1 (x = x - 1)
===Strictly equal (value AND type)
!==Strictly NOT equal
> < >= <=Greater than, less than, etc.
&&AND — both sides must be true
||OR — at least one side must be true
!NOT — flips true to false, vice versa
x += 5Shorthand: x = x + 5
??Nullish coalescing — use right side if left is null
📝 String Methods
"hello".length5 — number of characters
"hello".toUpperCase()"HELLO"
"HELLO".toLowerCase()"hello"
"hello".includes("ell")true — checks if text is inside
"hello".startsWith("he")true — checks the start
"hello".endsWith("lo")true — checks the end
"hello".slice(1, 3)"el" — extract part of string
"a,b,c".split(",")["a","b","c"] — string to array
" hi ".trim()"hi" — remove extra spaces
"hi".replace("h","b")"bi" — replace text
"hi".repeat(3)"hihihi"
"hello"[0]"h" — access character by index
📋 Array Methods
arr.lengthNumber of items in the array
arr.push(item)Add item to the END
arr.pop()Remove and return last item
arr.unshift(item)Add item to the BEGINNING
arr.shift()Remove and return first item
arr.includes(item)true/false — is item in array?
arr.indexOf(item)Find position (-1 if not found)
arr.join(", ")Convert array to a string
arr.reverse()Reverse the array order
arr.sort()Sort alphabetically
arr.slice(1, 3)Copy part of array (start, end)
arr.splice(1, 1)Remove 1 item at position 1
arr.forEach(item => { })Loop through every item
arr.map(item => item * 2)Create new array with modified values
arr.filter(item => item > 5)Create new array with matching items
arr.find(item => item > 5)Find first matching item
🔢 Math Object
Math.round(4.6)5 — round to nearest integer
Math.floor(4.9)4 — always round DOWN
Math.ceil(4.1)5 — always round UP
Math.random()Random decimal between 0 and 0.999...
Math.floor(Math.random() * 10)Random whole number 0–9
Math.max(1, 5, 3)5 — the biggest number
Math.min(1, 5, 3)1 — the smallest number
Math.abs(-7)7 — absolute value (removes minus)
Math.sqrt(16)4 — square root
Math.PI3.14159... — the value of pi
🤔 Conditionals
if (x > 10) { }Run code if condition is true
else if (x > 5) { }Check next condition
else { }Fallback — runs if nothing matched
x > 5 ? "big" : "small"Ternary — short if/else in one line
switch(color) { case "red": break; }Check multiple possible values
default:The fallback inside a switch
🔄 Loops
for (let i=0; i<5; i++)Classic for loop — run 5 times
while (x < 10) { x++; }Loop while condition is true
for (const item of arr) { }Loop over each item in an array
for (const key in obj) { }Loop over keys of an object
breakExit the loop immediately
continueSkip this iteration, keep looping
⚙️ Functions
function greet(name) { return "Hi " + name; }Named function declaration
const greet = function(name) { }Function expression
const greet = (name) => "Hi " + nameArrow function (shortest form)
const greet = (name) => { return "Hi " + name; }Arrow function with block body
function add(a, b = 0) { }Default parameter value
function sum(...nums) { }Rest parameter — collects extra args
return valueSend a value back to the caller
greet("Ali")Call a function
🗂️ Objects
const student = { name: "Ali", age: 12 }Create an object
student.nameAccess property with dot notation
student["name"]Access property with bracket notation
student.grade = "A"Add a new property
delete student.ageRemove a property
Object.keys(obj)Array of all property names
Object.values(obj)Array of all property values
const { name, age } = studentDestructuring — extract properties
{ ...obj1, ...obj2 }Spread — merge two objects
🌐 DOM — Finding Elements
document.getElementById("id")Find element by its id
document.querySelector(".class")Find first match (CSS selector)
document.querySelectorAll("p")Find ALL matching elements
document.querySelector("input")Find first input on the page
element.parentElementThe element's parent
element.childrenAll direct children
element.nextElementSiblingThe next element
✏️ DOM — Changing Elements
element.innerHTML = "<b>Hi</b>"Set HTML content (can use tags)
element.textContent = "Hello"Set text only (no HTML tags)
element.style.color = "red"Change a CSS style directly
element.style.display = "none"Hide element via JS
element.setAttribute("href", "...")Set any HTML attribute
element.getAttribute("href")Get the value of an attribute
element.classList.add("active")Add a CSS class
element.classList.remove("active")Remove a CSS class
element.classList.toggle("active")Add if missing, remove if present
element.classList.contains("active")true/false — does class exist?
document.createElement("div")Create a new element
parent.appendChild(element)Add element inside parent
element.remove()Delete element from the page
🖱️ Events
el.addEventListener("click", fn)When element is clicked
el.addEventListener("dblclick", fn)When element is double-clicked
el.addEventListener("mouseover", fn)When mouse enters element
el.addEventListener("mouseout", fn)When mouse leaves element
el.addEventListener("keydown", fn)When a key is pressed down
el.addEventListener("keyup", fn)When a key is released
el.addEventListener("change", fn)When input value changes
el.addEventListener("input", fn)Fires on every keystroke
el.addEventListener("submit", fn)When a form is submitted
window.addEventListener("load", fn)When the whole page has loaded
event.preventDefault()Stop the default browser action
event.targetThe element that triggered the event
🛠️ Useful Patterns
console.log("text")Print to the browser console
console.error("oops")Print an error in red
alert("message")Show a popup dialog
confirm("sure?")Show OK/Cancel popup (returns boolean)
prompt("name?")Show input popup (returns string)
setTimeout(fn, 1000)Run function after 1 second
setInterval(fn, 1000)Repeat function every 1 second
clearInterval(id)Stop a setInterval
JSON.stringify(obj)Convert object → JSON string
JSON.parse(str)Convert JSON string → object
localStorage.setItem("k", "v")Save data in the browser
localStorage.getItem("k")Read saved data
localStorage.removeItem("k")Delete saved data
Number("42")Convert string to number
String(42)Convert number to string
Boolean(0)Convert to true/false
Debugging Tip: When your code breaks, always check the browser Console first (press F12 → Console tab). The error message will tell you exactly which line has the problem!
