Syntax, arrays, objects, the DOM and events on one page, with what each line gives back.

Quick rules: use const by default and let when the value must change (never var). Compare with ===, not ==. Put text a user typed on the page with textContent, never innerHTML. React to clicks with addEventListener, not onclick="…" in the HTML.
📦 Variables

A variable is a labelled box that holds a value, so you can use it again by its name. Use const for values that stay the same and let for values that change, like a score. Comments are notes for people: the computer skips them.

const name = "Ali";Cannot be given a new value: use this by default
let score = 0;Can change later: score = 5;
var old = "avoid";Old style from before 2015: do not use it
const MAX_BOOKS = 3;UPPERCASE only for fixed settings known before the program runs
// a noteA comment on one line (the computer skips it)
/* a longer note */A comment over several lines

🧪 Data Types

Every value has a type: text, a number, true or false, a list, or a group of named values. The type decides what you can do: numbers can be added, while text is joined. When you are not sure, ask with typeof.

"Hello" / 'World'String: text inside quotes
`Salaam, ${name}!`Template literal: puts a value inside text
42 / 3.14Number (whole or decimal, same type)
true / falseBoolean: only two values
nullEmpty on purpose
undefinedNo value given yet
[1, 2, 3]Array: an ordered list
{ name: "Ali", age: 12 }Object: named values (key: value)
typeof 42"number": tells you the type
Array.isArray([1, 2])true: the right way to check for an array

➕ Operators

Operators do maths and compare values. A comparison always gives true or false, which is what if and loops use to decide. Compare with ===: it checks both the value and the type.

+ - * /Add, subtract, multiply, divide
10 % 31: the remainder
2 ** 38: power
x++ / x--Add 1 / take away 1
x += 5Short for x = x + 5
=== / !==Equal / not equal (value and type)
> < >= <=Greater, less, or equal
&&AND: both sides must be true
||OR: at least one side true
!NOT: turns true into false and back
name ?? "Guest"Uses "Guest" when name is null or undefined

📝 String Methods

A string is text. String methods are ready-made tools for it: measure it, change capital letters, search inside it or cut a piece out. They never change the original text; they give you a new string.

"hello".length5: number of characters
"hello"[0]"h": first character (counting starts at 0)
"hello".toUpperCase()"HELLO"
"HELLO".toLowerCase()"hello"
"hello".includes("ell")true: is this text inside?
"hello".startsWith("he")true
"hello".endsWith("lo")true
"hello".slice(1, 3)"el": from index 1 up to (not including) 3
"a,b,c".split(",")["a", "b", "c"]: text to array
" hi ".trim()"hi": removes spaces at both ends
"hi hi".replace("hi", "yo")"yo hi": first match only (replaceAll for every one)
"ab".repeat(3)"ababab"

📋 Array Methods

An array is a numbered list, and the numbering starts at 0. These methods add, remove, find and change items. Look for "changes the array": those change your original list, while the others give you a new one.

arr.lengthHow many items
arr[0]The first item
arr.push(item)Adds to the end
arr.pop()Removes and gives back the last item
arr.unshift(item)Adds to the start
arr.shift()Removes and gives back the first item
arr.includes(item)true or false: is it in the list?
arr.indexOf(item)Its position, or -1 if not found
arr.join(", ")Joins the items into one string
arr.slice(1, 3)A copy of items 1 and 2 (the original stays)
arr.splice(1, 1)Removes 1 item at position 1 (changes the array)
arr.reverse()Reverses the order (changes the array)
names.sort()Sorts text A–Z (changes the array)
nums.sort((a, b) => a - b)Sorts numbers small to big; plain [10, 9, 1].sort() gives [1, 10, 9]
arr.forEach(item => { })Runs code for every item
arr.map(n => n * 2)New array with every item changed
arr.filter(n => n > 5)New array with only matching items
arr.find(n => n > 5)The first matching item (or undefined)
arr.reduce((sum, n) => sum + n, 0)Combines all items into one value (here the total)

🔢 Math Object

Math is a toolbox of number functions that is always ready to use. Use it to round numbers, find the biggest or smallest, and pick a fair random number, for example a random quiz question.

Math.round(4.6)5: nearest whole number
Math.floor(4.9)4: always rounds down
Math.ceil(4.1)5: always rounds up
Math.random()A decimal from 0 up to (not including) 1
Math.floor(Math.random() * 10)A whole number from 0 to 9, e.g. to pick a quiz question
Math.max(1, 5, 3) / Math.min(1, 5, 3)5 / 1: biggest and smallest
Math.abs(-7)7: removes the minus
Math.sqrt(16)4: square root
Math.PI3.14159…
(2.567).toFixed(2)"2.57": rounds to 2 decimals (gives a string)

🤔 Conditionals

Conditions let a program decide: if something is true, do this; otherwise, do that. JavaScript checks them from top to bottom and runs only the first block that matches.

if (x > 10) { }Runs the code when the condition is true
else if (x > 5) { }Checks the next condition
else { }Runs when nothing above matched
x > 5 ? "big" : "small"Ternary: a short if/else that gives a value
switch (day) { case "Fri": …; break; }Compares one value with many cases
default:The switch case for "none of these"

🔄 Loops

A loop repeats code so you do not have to copy it. Use for when you know how many times, and while when you repeat until something changes. Always make sure the loop can stop.

for (let i = 0; i < 5; i++) { }Counts 0, 1, 2, 3, 4: runs 5 times
while (x < 10) { x++; }Repeats while the condition is true (change x or it never stops)
for (const item of arr) { }Each item of an array
for (const key in obj) { }Each key (name) of an object
breakLeaves the loop at once
continueSkips to the next round

⚙️ Functions

A function is a named recipe: write the steps once, then use them as often as you like. Values go in through parameters, and return sends the answer back to where the function was called.

function greet(name) { return "Hi " + name; }A function declaration
greet("Ali")Calls it: gives back "Hi Ali"
const greet = function (name) { };A function stored in a variable
const greet = (name) => "Hi " + name;Arrow function: returns the value after =>
const greet = (name) => { return "Hi " + name; };Arrow function with { }: needs return
function add(a, b = 0) { }Default value when b is not given
function sum(...nums) { }Collects any number of values into an array
return value;Sends a value back and ends the function

🗂️ Objects

An object keeps facts that belong together under names, like a library card with a name and a class. Each fact is a property: you read it with a dot, as in student.name.

const student = { name: "Ali", age: 12 };Creates an object
student.name"Ali": dot notation
student["name"]"Ali": bracket notation (key in a string or variable)
student.grade = "A";Adds or changes a property (works on a const object)
delete student.age;Removes a property
Object.keys(student)["name", "grade"]: all the keys
Object.values(student)["Ali", "A"]: all the values
const { name } = student;Destructuring: copies a property into a variable
{ ...obj1, ...obj2 }Spread: a new object with both sets of properties

🌐 DOM: Finding Elements

The DOM is the web page as JavaScript sees it: a tree of elements. Before you can change something on the page, you find it, usually by its id or with a CSS selector.

document.getElementById("total")The element with id="total"
document.querySelector(".card")The first match for a CSS selector
document.querySelectorAll("li")All matches (a list you can loop with forEach)
el.parentElementThe element around it
el.childrenThe elements directly inside it
el.nextElementSiblingThe next element beside it
input.valueThe text typed in an input (always a string)

✏️ DOM: Changing Elements

Once you have found an element, you can change its text, its classes and its attributes, or add new elements. Use textContent for anything a user typed: it is shown as plain text and can never run as code.

el.textContent = "Saved!";Sets the text. Use this for anything a user typed
el.innerHTML = "<b>Hi</b>";Sets HTML tags. Only for your own fixed text: user text here can run harmful code (XSS)
el.style.color = "green";Changes one CSS property
el.classList.add("done")Adds a CSS class (better than many style lines)
el.classList.remove("done")Removes a class
el.classList.toggle("done")Adds it if missing, removes it if there
el.classList.contains("done")true or false
el.hidden = true;Hides the element
el.setAttribute("href", "about.html")Sets an attribute
el.getAttribute("href")Reads an attribute
const li = document.createElement("li");Makes a new element (not on the page yet)
list.appendChild(li)Puts it inside list, at the end
el.remove()Removes it from the page

🖱️ Events

An event is something that happens on the page: a click, a key press, a form being sent. addEventListener tells the browser which function to run when it happens.

btn.addEventListener("click", save)Runs save when clicked (pass the name, no brackets)
"dblclick"Double-click
"mouseenter" / "mouseleave"Mouse moves onto / off the element
"keydown" / "keyup"A key is pressed / let go
"input"The input's value changes (typing, pasting)
"change"The value is finished (leaving the box, picking an option)
form.addEventListener("submit", fn)The form is sent
event.preventDefault()Stops the browser's normal action (e.g. reloading on submit)
event.targetThe element the event happened on
event.keyWhich key was pressed, e.g. "Enter"
<script src="app.js" defer>Runs the script after the page is built

🛠️ Useful Patterns

Small tools you will use in many projects: printing messages to find bugs, asking the user a question, timers, turning text into numbers, saving on this device, and catching errors so the page keeps working.

console.log("text")Prints to the Console (F12)
console.error("oops")Prints an error message in red
alert("Saved")A pop-up message
confirm("Delete?")OK / Cancel: gives true or false
prompt("Your name?")Gives the typed string, or null if Cancel
const id = setTimeout(fn, 1000)Runs fn once after 1 second
clearTimeout(id)Cancels it before it runs
const id = setInterval(fn, 1000)Runs fn every second
clearInterval(id)Stops it
Number("42") / parseInt("42px")42 / 42: text to number
Number.isNaN(Number("abc"))true: the text was not a number
String(42)"42": number to text
Boolean(0)false (0, "", null, undefined and NaN are all false)
JSON.stringify(obj) / JSON.parse(text)Object to JSON text / back to an object
localStorage.setItem("theme", "dark")Saves a string on this device
localStorage.getItem("theme")Reads it back (null if missing)
localStorage.removeItem("theme")Deletes it
try { … } catch (error) { … }Runs code and handles an error instead of crashing
